## 0. Setting, and the exact model of one terminal round at φ = 1 (Task 1)

Fix the data (X, y), so every quantity below is a deterministic function of the data (and of S₀, which is
fixed by the truth; "checkable" means computable from the scores once S₀ is given, as for every T24-type
hypothesis). Fix φ = 1 and write γ := γ₁ = ϖ·BF ∝ π on Ω, and for W ∈ Ω, j ∈ [p]

  o_j(W) = γ(W∪{j}) / (γ(W∪{j}) + γ(W∖{j}))   (with γ(W∪{j}) := 0 if |W∪{j}| > K).

**Labels.** Λ = 𝔊 ∪ 𝔑, 𝔊 = {G₁,…,G_p} (Gibbs), 𝔑 = {U, N₁,…,N_B, I} (uniform swap, B neighbour swaps,
independence), m = |Λ| = p + B + 2, |𝔑| = B + 2. Elementary kernels at φ = 1 (T09(ii), METHODOLOGY §6.5):

- G_j: W ↦ W∪{j} w.p. o_j(W), W∖{j} otherwise.
- U: self-loop if |W| ∈ {0,p}; else j ~ Unif(W), l ~ Unif([p]∖W), W′ = W−j+l accepted w.p. 1 ∧ γ(W′)/γ(W).
- N_i (all B identical): self-loop if W = ∅; j ~ Unif(W); reject if N(j)∖W = ∅; else l ~ Unif(N(j)∖W),
  accept w.p. 1 ∧ [γ(W′)/γ(W)]·|N(j)∖W|/|N(l)∖W′|.
- I: S′ ~ π₀ (exact), accept w.p. 1 ∧ e^{d(S′)−d(W)}.

**Round.** A round from W: draw a uniform permutation σ of Λ, independent of the state and of all other
randomness (§6.5: "drawn independently of the particle's state, afresh for every particle and every round");
put X₀ = W and X_t ~ K_{σ(t)}(X_{t−1}, ·) with fresh randomness (EX-S). Let 𝓕_t be generated by σ and the
randomness of steps 1..t. Two facts used throughout:

- (R1) σ is 𝓕₀-measurable, and P(X_t ∈ · | 𝓕_{t−1}) = K_{σ(t)}(X_{t−1}, ·). (If an implementation draws the
  order incrementally the joint law is the same, so all statements are about this law.)
- (R2) every label is executed exactly once per round; in particular **G_j cannot act twice on coordinate j
  within a round**.

**Scoring (SR and §6.10).** At a G_j step at state W both W∪{j} (if feasible) and W∖{j} are scored; every swap
proposal and every independence proposal is scored, accepted or not; the initial terminal state of a particle
is scored (it is a particle state, cf. T21 PROOF_v3 §(e)). Hence:

- (R3) *every state visited by a particle is scored*; in particular a visit to S₀ scores S₀.
- (R4) a G_j execution at W with W △ S₀ ⊆ {j} scores S₀ whatever its draw.

**Terminal segment.** In the final run the L burn-in and 4 measured rounds are at φ = 1 with no reweighting and
hence no resampling (§6.6 "resampling after every reweighting"; §6.8). Under EX-S with per-particle fresh
randomness:

- (R5) conditional on the data, 𝓒 and the population at the start of the terminal segment, the H = L + 4
  terminal trajectories of distinct particles are independent, each a Markov chain with kernel K₁ per round.

**Near-truth geometry.** For W ⊆ [p]: M(W) = S₀∖W (missing truths), P(W) = W∖S₀ (extras). T24's region is
𝓡_d = {W : |P(W)| ≤ d}. We also use the missing budget e: 𝓡_{d,e} = {W : |M(W)| ≤ e, |P(W)| ≤ d}.

**Families used below** (all data-measurable once S₀ is fixed; all contain S₀):

- Superset family 𝒮_a := {S₀ ∪ P : P ⊆ S₀ᶜ, |P| ≤ a}.
- Start-adapted completion family, for a start x with M(x) ≠ ∅: look-alike set A = A(x) := ⋃_{j∈M(x)} N(j)∖S₀
  (N = the method's own neighbour graph; any other data-measurable A ⊇ ∅ may be used), junk set J = S₀ᶜ∖A,
  junk count c = |x ∩ J|, and
  𝒵(x) := {U ∪ P ∪ Q : x∩S₀ ⊆ U ⊆ S₀, P ⊆ A, Q ⊆ J, |Q| ≤ c};  a(x) := |A| + c.
  States of 𝒵(x) with M = ∅ lie in 𝒮_{a(x)}. Put 𝓕(x) := 𝒵(x) ∪ 𝒮_{a(x)} (and 𝓕(x) := 𝒮_{|P(x)|} if x ⊇ S₀).
  Standing feasibility: s₀ + a(x) ≤ K.

**Progress potential** on 𝓕(x) (Task 1): with a = a(x),

  V(W) = |M(W)| + a  if M(W) ≠ ∅,     V(W) = |P(W)|  if M(W) = ∅.

V(W) = 0 iff W = S₀; V ≤ v(x) := V(x) on the good event below. An elementary transition W → W′ executed from
W ∈ 𝓕(x)∖{S₀} is

- **bad** if W′ ∉ 𝓕(x), or V(W′) > V(W), or W′ ⊉ W ∩ S₀ (some truth present in W is removed — this also
  covers truth-for-truth swaps and independence jumps that keep |M| but change the missing set);
- **progress** if it is not bad and V(W′) < V(W), or if it is a G_j execution with W △ S₀ ⊆ {j} (R4)
  (a scoring evaluation ends the repair, whatever else it does);
- **neutral** otherwise.

Neutral transitions include: look-alike additions/deletions in phase 1 (V ignores extras while M ≠ ∅ — this is
how look-alike additions at incomplete states are "charged to the budget", |A|), junk-for-junk and
extra-for-null swaps, failed deletions. Bad transitions include *internal* V-increases (truth removal by any
label; null addition at a superset), not only exits.

## 1. Three elementary lemmas

**Lemma F (first-failure bound). PROVED.** Let 𝓕 ⊆ Ω and, for each label e, let f_e(W; σ) ∈ [0,1] be the
conditional probability that a step with label e executed at W is a "failure", where the failure rule may
depend on σ only through 𝓕₀-measurable indicators, and suppose a non-failing step from 𝓕 stays in 𝓕. If
X₀ ∈ 𝓕 then
  P(some step of the round fails) ≤ Σ_{e∈Λ} E[ sup_{W∈𝓕} f_e(W; σ) ]  (= Σ_e sup_W f_e(W) if f_e ignores σ).

*Proof.* Let τ be the first failing step. P(τ = t) = E[1{τ > t−1} P(step t fails | 𝓕_{t−1})]; on {τ > t−1},
X_{t−1} ∈ 𝓕, so the conditional probability is ≤ sup_W f_{σ(t)}(W; σ). Summing over t and using that σ is a
bijection (R2): Σ_t sup_W f_{σ(t)}(W;σ) = Σ_e sup_W f_e(W;σ). Take expectations. ∎

**Lemma O (order facts). PROVED.** For a uniform permutation of Λ and disjoint nonempty C, D ⊆ Λ:
(i) P(first label of C∪D lies in C) = |C|/(|C|+|D|); (ii) P(l ≺ e) = ½ for l ≠ e; (iii) for u ∈ [0,1]^Λ and e ∈ Λ,
E[∏_{j ≺ e} u_j] = ∫₀¹ ∏_{j≠e}(1 − t + t u_j) dt.
*Proof.* Realise σ by iid U(0,1) arrival times T_j (ties have probability 0). (i) symmetry; (ii) special case;
(iii) condition on T_e = t: the events {T_j < t} are independent with probability t. ∎

**Lemma C (binomial domination). PROVED.** Let J₁,…,J_H ∈ {0,1} be adapted to 𝓖₀ ⊆ … ⊆ 𝓖_H with
P(J_h = 1 | 𝓖_{h−1}) ≥ c a.s. Then P(Σ_h J_h < k) ≤ g_H(k) := P(Bin(H,c) < k) for every k.
*Proof.* Induction on H; H = 0 trivial. Given 𝓖₁ the shifted sequence satisfies the hypothesis, so
P(Σ_{h≥2} J_h < k − J₁ | 𝓖₁) ≤ g_{H−1}(k − J₁). Since g_{H−1} is nondecreasing in k,
E[g_{H−1}(k − J₁)] ≤ (1−c) g_{H−1}(k) + c g_{H−1}(k−1) = g_H(k). ∎
Also g_H(k) ≤ k(1−c)^{⌊H/k⌋} (split H rounds into k blocks of ⌊H/k⌋; < k successes forces an empty block).

## 2. Lemma P — the per-round progress probability, exact and polynomial (Task 2, Fable's c′)

Fix x and a set Good(x) of outcomes per label (here: progress transitions). For each label e let
s_e(x) = P_x(e's step is Good), b_e(x) = P_x(e's step changes the state and is not Good), q_e = s_e + b_e;
for a G_j with x △ S₀ ⊆ {j} put s_e = 1, b_e = 0 (R4).

**Lemma P. PROVED.** P_x(the first step of the round that changes the state or is Good, is Good)
  = P*(x) := Σ_e s_e(x) ∫₀¹ ∏_{j≠e} (1 − t q_j(x)) dt.
Moreover, for every label g and every D ⊆ Λ∖{g}, with Q_D := Σ_{j∉D∪{g}} q_j(x),
  P*(x) ≥ c_poly(x; g, D) := s_g(x) · [1 − Q_D/(|D|+2)] / (|D|+1).
In particular with D = 𝔑: P*(x) ≥ s_g(x)[1 − Q_𝔊/(B+4)]/(B+3), Q_𝔊 = Σ_{G_j ≠ g} q_{G_j}(x) (Gibbs
leakage at x). With multiple targets C (|C| Good labels, each with s ≥ s_min) the first factor becomes
|C|/(|C|+|D|).

*Proof.* Before the first changing step the state is x, so each executed label acts at x with independent
outcome (R1, fresh randomness). Couple: give each label an independent outcome Y_e ~ K_e(x,·); the round
agrees with "execute Y_e" up to and including the first changing step. The event is ∪_e {Y_e Good,
Y_j null ∀ j ≺ e}; by Lemma O(iii) its probability is Σ_e s_e ∫∏_{j≠e}(1 − t q_j)dt. For the bound keep
only e = g; use ∏_{j∈D}(1−tq_j) ≥ (1−t)^{|D|} and the Weierstrass inequality ∏_{j∉D∪g}(1−tq_j) ≥ 1 − tQ_D;
∫₀¹(1−t)^k dt = 1/(k+1), ∫₀¹ t(1−t)^k dt = 1/((k+1)(k+2)). ∎

Remarks. (a) This is Fable's c′ ~ 1/(B+3), made exact: the factor is the probability that the target precedes
all B+2 non-Gibbs labels, times a leakage correction; no factorial appears. (b) P* is a lower bound for the
probability that the round *contains* a progress step only through its first change; at incomplete states in
correlated designs many labels make neutral changes (look-alike additions) and P* is small (S5: ≈ 0.10–0.14).
The bounds of §4 avoid this by not requiring the progress step to be the first change.

## 3. The undo / EXIT_d question (Task 2) — Proposition U. PROVED (each item is a direct check of §0)

(i) A Gibbs step cannot be undone by Gibbs within the same round (R2). (ii) A non-Gibbs move *can* undo a
just-made correct step: U or N_i can remove a just-added truth (truth-for-null swap), U/N_i can re-introduce a
just-deleted extra (extra-for-extra swap), I can jump anywhere. (iii) Charging: with the potential V of §0,
- truth removal (any label) is a **bad** transition: it is charged to η via sup_W P_W(e removes a truth), a
  quantity of the form Σ_l (1/(k(p−k)))(1 ∧ π(W−i+l)/π(W)) for U, which is super-polynomially small under
  SE + BM-∞ at supersets (§6);
- an extra-for-extra swap is **neutral** (|P| unchanged): it cannot undo V-progress; it can only *hide a slot*
  (replace a not-yet-processed extra by an already-processed null), which costs nothing in η and is charged
  inside the progress constant c₂ through h(l) (§4, Prop. B2) — never by a uniform bound;
- an independence acceptance is bad iff it lands outside 𝓕(x) or raises V; charged to η by
  sup_W Σ_{S′ bad} π₀(S′)(1 ∧ e^{d(S′)−d(W)}) ≤ sup_W min{π₀(Bad), [π₀(W)/π(W)]·π(Bad)}.
So EXIT_d's defect (it bounded only *exits*, while internal non-Gibbs moves changed the prescribed greedy
path) disappears because (1) no greedy path is prescribed, (2) all V-increases, internal or not, are bad, and
(3) V is blind to exactly those internal changes that cannot undo progress.

## 4. Theorem B (restated T24: Gibbs-path repair). Statement and proof.

**Constants** (all exact functions of the scores, π₀, d and N; all sups over finite families). Fix x ∈ Ω∖{S₀}
with s₀ + a(x) ≤ K; a := a(x) (or a := |P(x)| if x ⊇ S₀).

Phase 1 (only if M(x) ≠ ∅), over 𝒵⁺ := {W ∈ 𝒵(x) : M(W) ≠ ∅}:
- ε_add(x) := max_{∅≠M′⊆M(x)} min_{j∈M′} sup_{W′∈𝒵⁺, M(W′)=M′} (1 − o_j(W′))     [uniform addability]
- η₁(x) := Σ_{e∈Λ} sup_{W∈𝒵⁺} P_W(e's step is bad)                              [phase-1 bad rate]

Phase 2, over 𝒮_a° := 𝒮_a∖{S₀}:
- ε_del(a) := sup_{W∈𝒮_a°, l∈P(W)} o_l(W)                                          [uniform deletability]
- h(l) := ½ Σ_{e∈𝔑} sup_{W∈𝒮_a, l∈W} P_W(e's step is neutral and removes l)        [slot hiding]
- H_a := sup_{W∈𝒮_a°} min{ min_{l∈P(W)} h(l), (B+2)/(|P(W)|+B+2) }
- η₂(a) := Σ_{e∈Λ} sup_{W∈𝒮_a°} P_W(e's step is bad)                               [phase-2 bad rate]

Set c₁ := 1 − ε_add(x), c₂ := 1 − ε_del(a) − H_a, c_* := min(c₁, c₂) (c_* := c₂ if x ⊇ S₀),
η := η₁(x) + η₂(a), v := V(x) ≤ |M(x)| + a.

**Theorem B. PROVED (deterministic given the data; EX-A, EX-S, SR).** For a particle at x at the start of H
terminal rounds at φ = 1 with no resampling in between,

  P_x(S₀ not scored within the H rounds) ≤ P(Bin(H, c_*) < v) + H·η ≤ v(1 − c_*)^{⌊H/v⌋} + H·η.

Always c₂ ≥ 1/(B+3) − ε_del(a) (polynomial; Fable's order). If c_* ≤ 0 the bound is trivial.

**Prop. B1 (phase-1 progress). PROVED.** For W ∈ 𝒵⁺: P_W(round has no bad and no progress step) ≤ ε_add(x).
*Proof.* Put M′ = M(W) and pick j ∈ M′ attaining the inner min. On {no bad, no progress} no truth is added or
removed (a removal is bad by definition, an addition is progress), so the missing set equals M′ throughout and every state is in 𝒵⁺ (no bad ⇒ in 𝓕(x); V
unchanged ⇒ still phase 1, and phase-1 states of 𝓕(x) are in 𝒵(x)). At the G_j step (it occurs, R2) the
state W′ ∈ 𝒵⁺ has M(W′) = M′ ∋ j, and adding j would be progress (|M| drops; the result is in 𝒵(x) ∪ 𝒮_a ⊆ 𝓕(x)).
So the event requires the G_j draw to be "remove", conditional probability 1 − o_j(W′) ≤ the sup. ∎
(The cap is respected: |W′∪{j}| ≤ s₀ + a ≤ K.)

**Prop. B2 (phase-2 progress). PROVED.** For W ∈ 𝒮_a°: P_W(no bad and no progress step) ≤ ε_del(a) + H_a.
*Proof.* Two bounds; take the smaller (H_a contains the min). (Slot.) Fix l ∈ P(W). On {no bad, no progress}
|P| is constant and states stay in 𝒮_a°. At the G_l step, if l is present, deletion (prob ≥ 1 − ε_del) would be
progress; so either that draw fails (≤ ε_del) or l was removed earlier. Gibbs steps of other coordinates do
not remove l; a removal by a non-Gibbs label e must be neutral and must precede G_l. By Lemma F applied to
"e precedes G_l and e neutrally removes l" (the indicator {e ≺ G_l} is 𝓕₀-measurable) its probability is
≤ Σ_{e∈𝔑} P(e ≺ G_l) sup_W P_W(e neutrally removes l) = h(l) (Lemma O(ii)). (Order.) Let C = {G_l : l ∈ P(W)},
D = 𝔑. With probability |P(W)|/(|P(W)|+B+2) the first label of C ∪ D is some G_l ∈ C; the steps before it are
Gibbs steps of truths or of nulls ∉ W, which on {no bad} do not change the state (a truth removal or a null
addition is bad); so G_l acts at W ∋ l and deletes with probability ≥ 1 − ε_del. ∎

**Proof of Theorem B.** Let 𝓕 = 𝓕(x). Stop the classification once S₀ is scored. (a) Bad steps: in a round
that starts in 𝓕∖{S₀} with no earlier bad step, Lemma F with failure = bad and family 𝓕∖{S₀} gives
probability ≤ Σ_e sup_{W∈𝓕∖{S₀}} P_W(bad) ≤ η₁ + η₂ = η (sup over a union ≤ sum of sups; at S₀ itself the
particle has already scored). Summing over rounds, P(some bad step before scoring) ≤ Hη. (b) On no bad steps,
every state is in 𝓕 and V is nonincreasing step by step. Let J_h = 1 if round h contains a progress or bad step,
or S₀ is scored by its end, or a bad step/score happened earlier. By Props. B1/B2 (whichever phase the round
starts in), P(J_h = 1 | 𝓖_{h−1}) ≥ c_* where 𝓖_h is the past at the end of round h. (c) On {no bad, S₀ not
scored after H rounds}, V > 0 throughout (V = 0 means S₀ visited, R3), each J_h = 1 is a progress round, and
each progress round lowers V by ≥ 1; hence Σ_h J_h ≤ v − 1. So {not scored} ⊆ {some bad} ∪ {Σ J_h < v}, and
Lemma C finishes. ∎

**Corollary B-unif.** For an eligible set 𝓧 (data-measurable, fixed before selection), with
c_*(𝓧) := inf_{x∈𝓧} c_*(x), η(𝓧) := sup_{x∈𝓧} η(x), v(𝓧) := sup_{x∈𝓧} v(x):
sup_{x∈𝓧} P_x(not scored within H) ≤ P(Bin(H, c_*(𝓧)) < v(𝓧)) + Hη(𝓧). PROVED (immediate).

**Corollary B-M (many particles). PROVED given (R5).** If at the start of the terminal segment the particles
in 𝓧 are at x₁,…,x_N (N = N(𝓧) particles, any selection past), then
P(S₀ not scored during the segment | population) ≤ ∏_{i≤N} min{1, P(Bin(H,c_*(x_i)) < v(x_i)) + Hη(x_i)}
≤ [P(Bin(H, c_*(𝓧)) < v(𝓧)) + Hη(𝓧)]^{N}. In particular a per-particle bound β < 1 bounded away from 1 and
N → ∞ suffice; no H → ∞ and no η → 0 are needed for this route.

**Proposition D (drift form; internal increases need not satisfy Hη → 0). PROVED.** In the setting of
Theorem B split η = η_ex + η_in, where η_ex bounds (Σ over labels of sups) the steps leaving 𝓕(x) and η_in the
remaining bad steps (V-raising or truth-removing inside 𝓕(x)); let v_max := max_{𝓕(x)} V = |M(x)| + a (= a if x ⊇ S₀). For
z > 1 put ρ(z) := z⁻¹ + (1 − z⁻¹)(1 − c_* + η) + exp{(z^{v_max} − 1)η} − 1. Then
  P_x(S₀ not scored within H rounds) ≤ H·η_ex + inf_{z>1} ρ(z)^H z^{v−1}.
*Proof.* Let I_h = 1{round h has a progress step}, N_h = number of bad steps of round h taken from inside
𝓕(x)∖{S₀}. On {no exit, not scored}: V_h ≤ V_{h−1} − I_h + v_max N_h (each increase is ≤ v_max because V ≤ v_max
on 𝓕). For integers, z^{−I+v N} ≤ z^{−I} + (z^{vN} − 1) and z^{−I} = z⁻¹ + (1 − z⁻¹)1{I = 0}. By Props. B1/B2,
P(I_h = 0 | 𝓖_{h−1}) ≤ (1 − c_*) + η. Given σ, step t is bad with conditional probability ≤ π_t :=
sup_W P_W(σ(t) bad), and Σ_t π_t = η (σ is a bijection); the process u^{N_{≤t}}/∏_{s≤t}(1 + (u−1)π_s) is a
supermartingale, so E[u^{N_h} | 𝓖_{h−1}] ≤ ∏_t(1 + (u−1)π_t) ≤ e^{(u−1)η} with u = z^{v_max}. Hence
Y_h := z^{V_h}1{no exit, not scored by round h} satisfies E[Y_h | 𝓖_{h−1}] ≤ ρ(z) Y_{h−1}, so
E Y_H ≤ ρ^H z^{v}; on {no exit, not scored} Y_H ≥ z, so that event has probability ≤ ρ^H z^{v−1}. Exits: ≤ Hη_ex
by Lemma F. ∎
Asymptotically (η → 0, c_* ≥ c > 0) ρ(z) → 1 − c(1 − z⁻¹) < 1, so only Hη_ex → 0 is needed, not Hη_in → 0.
At n = 200 the sup-based constants (c_* ≈ 0.3–0.45, η ≈ 0.4–1) still give ρ > 1; with the *measured*
per-round frequencies (progress ≈ 0.8, bad ≈ 0.1–0.15, `results/compare_cprime.json`) ρ(2) ≈ 0.8 < 1, i.e. the
drift form would certify repair if the sups were replaced by the actual per-round rates (OPEN: a
non-uniform version).

## 5. Proposition A (sweep: whole repair inside one round). PROVED; numerically vacuous at p = 20, n = 200.

For W₀ ∈ 𝒮_a define per label the failures: G_i (i ∈ S₀): i ends absent; G_l (l ∉ S₀): l ends present;
e ∈ 𝔑: accepted move leaving 𝒮_a, or accepted move introducing some l′ with G_{l′} ≺ e. With
ε₂(a) := Σ_{i∈S₀} sup(1−o_i) + Σ_{l∉S₀} sup o_l + Σ_{e∈𝔑}[sup_W P_W(e → 𝒮_aᶜ) + ½ Σ_{l′} sup_W P_W(e introduces l′)]
(sups over 𝒮_a), P_{W₀}(round does not end at S₀) ≤ ε₂(a). *Proof.* Lemma F with the σ-dependent rule; on no
failure every coordinate ends at its S₀-value (each processed once, never re-introduced after processing),
so the end state is S₀, which is scored (R3). ∎ The analogous phase-1 statement (end in 𝒮(A)) has the same
proof. Numerically ε₂(1) ≈ 2.6 at p = 20, n = 200 (extra-for-null swaps are accepted with O(1) probability),
so Prop. A is not the operative mechanism there; Theorem B is.

## 6. Asymptotic status of the premises under G, R, SE, BM-∞ (Task 3). PROOF SKETCH unless marked.

Fixed s₀, fixed budgets a (hence fixed |A|, c), B ≤ 16, regime R1 (p ≤ n^A). Write gains
Δ⁺_j(W) = ‖(P_{W∪j} − P_W)μ‖², Δ⁻_i(W) = ‖(P_W − P_{W∖i})μ‖². Log-odds of a Gibbs flip decompose as
log[prior ratio] + log[BF ratio], prior ratio ∈ [1/(2p), K] , and (standard, cf. T10 Lemma 2 and EXP)
log BF(W∪j)/BF(W) = −½log(n+1) + (δ + σ*Z)²/(2v_W)(1+o_P(1)) + O_P(1) uniformly over |W| ≤ s₀ + a + 1.

| premise | holds w.p. → 1 under G,R,SE,BM-∞? | finite-n expression / reason |

## 7. Counterexamples

**CE1 (H24 uniform exit input is false in correlated designs). COUNTEREXAMPLE (numerical, reproducible) +
PROOF SKETCH (asymptotic).** H24 requires sup_{x∈𝓡_d} P_x(first exit from 𝓡_d in one round) ≤ η_n with
(L+4)η_n → 0. Take Y = (S₀∖{j}) ∪ P with |P| = d, P a set of nulls not correlated with j, and l ∉ Y a null with
|corr(x_j, x_l)| ≥ r₀ > 0 (a group-mate in S3/S4/S6, an AR neighbour in S2). Then Y ∈ 𝓡_d, and adding l is an
exit. Under BM-∞, Δ⁺_l(Y) ≈ r₀²(n−1)θ_j² ≫ log n, so o_l(Y) → 1. With C = {G_l} and D = 𝔑 ∪ {G_j} ∪ {G_q : q ∈ P}
(the labels that could change the state so that adding l is no longer an exit), Lemma O(i) gives probability
1/(B+d+4) that G_l comes first; before it only Gibbs labels of truths in Y (kept, prob → 1 under TS-type
stability at Y) and of other nulls (an addition is itself an exit) act. So the one-round exit probability is
≥ (1 − o(1))/(B+d+4) and (L+4)η_n → ∞ for fixed d. Numbers: `results/counterexample_H24.json`
(script `scripts/counterexample_H24.py`, seeds fixed).

**CE2 (the proposed form (1−c′)^{⌊H/(s₀+d)⌋} is not implied by one-step-per-round progress). COUNTEREXAMPLE.**
The chain on {2,1,0} that moves down by exactly one with probability c′ per round and never up satisfies every
hypothesis of a one-step progress argument with v = 2; at H = 2, P(not at 0) = 1 − c′² > 1 − c′ =
(1−c′)^{⌊2/2⌋}. The correct conclusion is the binomial tail P(Bin(H,c′) < v) ≤ v(1−c′)^{⌊H/v⌋} (Lemma C), i.e.
the brief's form needs the factor v.
