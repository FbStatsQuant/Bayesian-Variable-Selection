# W1-T38E: T38 masked regime, delivery and eligibility of a near-truth model

**Paper role:** Thm 5 (T38), the main theorem. This is the hole both consultants found (`Docs/THEORY_PRIORITIES.md` §3): a guarantee that a near-truth model is **delivered** within an explicit budget. A separate task handles repair (W1-T37R and W1-T24G), so assume a repair route is available as a black box with a named input condition.

## Problem
T38 (`Docs/Theory/PAPER_SELECTION_20261028/new_conjectures/T38_two_regime_HPM_consistency.md`), masked regime (b):
- the start puts mass π₀(𝓡_d) ≥ b_n near the truth (T22(i), with a reference S° ∈ 𝓡_d, S° ≠ S₀ allowed);
- something must then put a *particle at the terminal rounds* (for the Gibbs route) or a *local-search centre* (for the T37 route) inside 𝓡_d.

Preliminary data (p ≫ n, n = 200):
- the median π₀(𝓡₂) is about 0.8, while π₀(S₀) is about 10⁻¹²;
- 541 fits had a local-search centre in 𝓡₂ \ {S₀}.

## Goals, in order
1. **Gibbs/particle delivery.** Prove a lower bound on P(at least one terminal-round particle in 𝓡_d). Candidate ingredients:
   - the T22(i) start mass on 𝓡_d, with Q_f iid start draws (T11(iii)-type);
   - T22(iv), bridge mass never falls below the smaller endpoint mass (apply it to 𝓡_d rather than to S₀; check whether that is valid);
   - T15 occupancy from an evidence lower tail; T13 restricted ESS; T23 basin and recording prefix; T14 first moment.

   Decide which chain gives a clean statement, and state the hypotheses precisely.
2. **Local-search eligibility.** Show the best-scored model before the final search lies in 𝓡_d, that is, F(S°) > sup_{S ∉ 𝓡_d} F(S) w.h.p. (asymptotic, T02/T03-type). Alternatively, analyse the **LS0 tweak** (also run local search from the start mode S̃₀; deterministic, about ℓ·p extra scores) and what it buys.
3. **Compose T38(b).** Write T38(b) as a theorem: delivery (your result) + repair (black-box condition REPAIR(a_n, H) from W1-T24G, or TD′ from W1-T37R) + T21 + T03 ⇒ P(Ŝ = S₀) → 1 − limsup P(U). Include the cost corollary (c), polynomially many score evaluations via T32. Give a full statement with every premise named. Prove the composition; it should be PROVED given the inputs.
4. **Compatibility.** List every statistical premise T38(b) uses and check whether *one design family* can satisfy all of them at once (Astra's rule). In particular, can T27's masking (H2, H3) and T22(i)'s near-truth start mass hold together? Construct such a family, or explain the obstruction.
