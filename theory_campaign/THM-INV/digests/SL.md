## 1. The algorithm (Sec 2.3 remarks + Sec 3.1, l.675-703)

1. Split: randomly partition the P_n predictors into K_n groups s_1..s_{K_n}, each of size <= s (s prespecified; recommended s >= 500; s=1 reduces to SIS-like marginal screening). The split is over predictors (columns), all n observations are kept in every subset. (l.678, l.659-664)
2. Stage 1 (per subset, independent across subsets): on D_n^{s_i} = {y, X_{s_i}} run Bayesian variable selection with prior pi(sigma^2) ~ IG(a0,b0), pi(xi) = lambda_s^|xi| (1-lambda_s)^(|s|-|xi|) I(|xi| <= sbar), beta_xi | xi,sigma^2 ~ N{0, sigma^2 (X_xi' X_xi + tau I)/n} (as printed; likely V_xi^{-1} is intended, cf. Sec 2.1.1 where V_xi^{-1} = X_xi'X_xi/n; "-1" may be lost in extraction). Posterior sampled by SAMC (stochastic approximation Monte Carlo). Selection of predictors = those whose marginal inclusion probability q_j passes an FDR-controlled threshold at level alpha_1 (multiple-testing rule of Liang & Zhang 2008, as in Liang et al 2013), alpha_1 large (10-15%) to avoid losing true predictors. (l.680-694, l.753-756)
3. Iterative step inside stage 1 (Sec 2.3): after selecting from X_s, remove the selected predictors and rerun selection on the remainder X_{s'}, posterior pi(xi | y, X_{s'}); repeat until nothing is selected. In practice the number of iterations is capped at 2 ("we set the iteration number to 2", l.647-648). Justified by Condition 5.
4. Merge: S~ = union_i s~_i, p_n = |S~|.
5. Stage 2: Bayesian variable selection on D_n^{S~} = {y, X_{S~}} with prior pi(xi) = (r_n/p_n)^|xi| (1-r_n/p_n)^(p_n-|xi|) I(|xi| <= rbar_n) (note r_n/p_n, NOT r_n/P_n), same IG and Gaussian priors, FDR level alpha_2 (small, 1%). Alternative output: the MAP model. (l.694-703)
6. Hyperparameters used: r_n = P_n^(1-gamma), gamma = 0.75, lambda_s = |s|^(-gamma), a0=b0=1, tau=0.01. (l.742-745)
7. Parallel: stage 1 over the K_n subsets is "embarrassingly parallel" (no communication). Stage 2 is a single serial run on S~. Sec 7 (l.1594-1602): "the SAM approach never needs to process all the predictors altogether."
8. Target: NOT the full posterior. Final output = marginal inclusion probabilities / MAP model from the posterior restricted to the models contained in S~, with prior r_n/p_n. The paper says explicitly (Sec 7, l.1602-1604): "SAM is not a standard Bayesian approach, as it does not process all data altogether and thus only provides an approximate quantification of uncertainty for each predictor through marginal inclusion probabilities." and "The subset data regression is equivalent to the use of a data-dependent prior, which sets the prior probability to 0 for any models containing predictors that have been screened out in stage 1." The full-data posterior (7) is never computed; only an "Occam's razor approximation" is claimed (verbal).

## 3. Conditions (verbatim / near-verbatim)

- Predictor boundedness (Thm 1): all predictors standardized, |x_i| <= 1.
- Sparsity (3): lim sum_{j=1}^{P_n}|beta*_j| < inf. Sparsity (4): lim sum_j 1{beta*_j != 0} < inf.
- Dimension: P_n >> n^theta for some theta > 0. Prior (6): pi(xi) ∝ lambda_n^|xi| (1-lambda_n)^{P_n-|xi|} I(|xi| <= rbar_n), lambda_n = r_n/P_n, lambda_n -> 0 (multiplicity control; "corresponds to condition (13)").
- (8)-(14): listed in the Theorem 1 row above.
- Condition 1 (l.354-362): "There are some constants M > 0 and delta > 0 such that for any subvector of x, (x_{j1},...,x_{jr})' with 1 <= j1 < ... < jr <= P_n, r <= rbar_n, and |a_i| <= delta for i = 1..r, we have E exp{ (sum_{i=1}^r a_i x_{ji})^2 / r } <= exp(M), where the expectation is taken with respect to the distribution of the random variables x_{ji}." (sub-Gaussian-type tail control.) Satisfied by bounded or Gaussian predictors; fails for heavy-tailed predictors.
- Condition 2 (l.419-424): same index set and |a_i| <= delta, E{ (sum a_i x_{ji})^2 / r } <= M (second moments only). Gives only the in-probability results (16) and the weak form of Thm 3.
- Condition 3 (identifiability, l.468-474): "A predictor x_k is said to be identifiable among all other predictors, if, for any 1 <= j_1,...,j_{rbar_n} <= P_n (j_i != k for all i) and b_i in R, E exp{ -(x_k + sum_{i=1}^{rbar_n} b_i x_{j_i})^2 } <= 1 - delta_n, delta_n >> eps_n^2" (relation inferred; text says "delta_n  2n", glyph lost; consistent with the sufficient condition below). Meaning: no linear combination of rbar_n other predictors mimics x_k. Sufficient conditions given: for mean-0 bounded predictors, x_k identifiable if ch_min{var(x~)} >= rbar_n eps_n^2 (x~ = (x_k, x_{j1},...,x_{j rbar_n})) for every choice; all identifiable if ch_min{var(x)} >= rbar_n eps_n^2. For standard normal predictors, all identifiable if ch_min{var(x)} >= eps_n^2-ish (text l.509-515: "if var(x_k + sum b_i x_{ji}) >= delta_n ... all predictors are identifiable if ch_min{var(x)} >= [delta_n/ eps_n^2-type]"; glyphs garbled).
- Condition 4 (l.578-581): "There is a constant delta > 0 such that for any a = (a_1,...,a_s)' in R^s, with |a_i| <= delta for i=1..s, we have E{(a' x_s)^2} < inf, where x_s denotes a generic observation of the predictors included in X_s." (second moment finite, fixed s.)
- Condition 5 (l.620), verbatim: "**|cov(x_t, y)| > 0 for any true predictor x_t.**" (Note: only strictly positive; no "bounded away from 0", no uniformity in n or P_n, no explicit rate. The extracted "> 0" is the printed symbol.) Role: if x_t in s then cov(x_s, y) != 0, hence by (19) beta_0 != 0 and the iterative rule selects at least something, and continues on the unselected remainder until x_t is picked; "Under assumption 5, this procedure ensures that all true predictors that are contained in X_s will be selected" (l.626-632). Only used to justify the iterative stage-1 procedure; not part of the statement of Cor 2 and not used in any formally stated theorem.
- No exact multicollinearity in x_s (Cor 2): no a != 0 with P(a'x_s = 0) = 1.
- Priors: sigma^2 ~ IG(a0,b0); beta_xi | xi, sigma^2 ~ N(0, sigma^2 V_xi); pi(xi) > 0 for all xi in the subset (Thm 4).
- Choices of V_xi giving B(r_n) <= B r_n^v, Btilde_n <= B n^v: V_xi = cI (both constants); V_xi^{-1} = c E(x_xi'x_xi) (Zellner), B(r_n) <= r_n for standardized x; equicorrelated rho: Btilde_n = 1-rho (as printed); AR/MA designs bounded; ridge V_xi^{-1} = E(x_xi'x_xi) + c_n I, c_n ∝ 1/n.

### Which conditions fail under correlated designs (my assessment, flagged as such)

- Condition 5 is the key fragility. By (19), cov(x_t, y) = sum_j beta*_j cov(x_t, x_j). Masking/cancellation (e.g. two unit-variance true predictors with corr rho and beta*_1 + rho beta*_2 = 0, so cov(x_1,y) = 0 although beta*_1 != 0) gives cov(x_t,y) = 0 exactly, so Condition 5 fails; then beta_0 may be 0 in a subset, nothing is selected, and the iteration stops without t (Cor 2 gives s~ = support of beta_0, which can exclude t). Even near-zero (not exactly zero) cov(x_t, y) with no stated rate makes Condition 5, as an asymptotic condition with growing P_n, not useful: it is a fixed-population statement (">0"), no uniform lower bound. Paper remark (b) concedes "it is rare to have the case that beta_{0,t} is 0 exactly" and truncates iterations to 2, so even the Condition-5 guarantee is not what is implemented.
- Also, a true predictor in a subset can have beta_{0,t} = 0 even when cov(x_t,y) != 0 (partial cancellation by other members of s); the iteration only partly repairs this. If t is NOT in the subset, its signal is carried by proxies in s (beta_0 = Sigma_s^{-1} Sigma_{s,t} beta*_t); stage 1 then keeps correlated stand-ins, and whether t itself is kept depends on the split (random split; no probability statement about co-location of correlated true predictors).
- Condition 3 (identifiability) fails under strong collinearity: it needs ch_min of the covariance of any rbar_n+1 predictors to be >= ~ rbar_n eps_n^2 (or delta_n >> eps_n^2). With P_n >> n, exact or near linear dependence among some rbar_n+1 columns violates it. The paper itself acknowledges (l.455-466) that with multicollinearity "the marginal inclusion probabilities of the spurious predictors are inflated", hence "it is necessary to control the severeness of multicollinearity". Equicorrelated rho in (0,1) is fine (ch_min ~ 1-rho) but the bound on rbar_n eps_n^2 scales with rbar_n.
- Condition 1/2 are tail/moment conditions, not violated by correlation per se.
- Cor 2's "no exact multicollinearity" in x_s is mild (fixed s), but it is fixed-s, n -> inf asymptotics.
- Remark (a) concedes failure of the strategy itself: if most predictors are linearly correlated with X_t, "it is futile to apply this iterative procedure, as all the predictors will be selected."
- Simulations (Ex 1, l.1016-1021): with pairwise correlation 0.9, MAP "almost never catches the true model", but marginal inclusion probabilities of true predictors still trend up in n (no theory there, no splitting in Ex 1).

## 4. Section 6: time complexity (l.1512-1572)

Claims (quoted):
- "Since the SAM approach has an embarrassingly parallel structure, its time complexity can be simply analysed as follows. Suppose that there are enough numbers of processors available in the parallel architecture, and each subset is of about the same size. Let K_n denote the number of subsets, i.e. the number of processors..."
- Per-subset stage 1: "bounded by O(n P_n^2/K_n^2) + {O(sbar_n^3) + O(P_n/K_n)} T" (overhead matrix products X_s'X_s, X_s'y; O(sbar^3) for inverting X_xi'X_xi + V_xi^{-1}; O(P_n/K_n) for the SAMC proposal).
- "If we further let the number of iterations increase with the subset size in a low power, say T = O{(P_n/K_n)^alpha} for some alpha >= 1, then the computational complexity for each subset is O{(P_n/K_n)^{1+alpha}} + O{n (P_n/K_n)^2} by assuming that sbar_n = o{(P_n/K_n)^{1/3}}." "To maintain the same estimation accuracy of marginal inclusion probabilities, alpha should be no less than 1. In this paper, we set alpha = 1."
- Stage 2: "O{(K_n rbar)^{1+alpha}} + O{n (K_n rbar)^2}, where rbar denotes the average number of predictors selected from each subset."
- Optimization: minimize O{(P_n/K_n)^{1+alpha}} + O{(K_n rbar)^{1+alpha}} + O{n(P_n/K_n)^2} + O{n(K_n rbar)^2}: "the time complexity can be minimized at K_n = O(sqrt(P_n)), for any alpha > 0. If K_n = O(sqrt P_n), then the resulting subset size is O(sqrt P_n), and the resulting time complexity of the SAM approach is O(P_n^{(1+alpha)/2}) + O(n P_n), i.e. the SAM approach can work in a linear or low order polynomial time of P_n." (Note: this treats rbar as a constant, and the per-subset costs as the parallel wall-clock time; stage 2 is serial after stage 1.)
- Comparisons: lasso O(n P_n^2) for P_n > n (Meinshausen 2007); parallel lasso (Boyd et al. 2010) with sqrt(P_n) processors lower bounded by O(n P_n^{3/2}); elementwise Gibbs sampler with local shrinkage prior at least O(P_n^4), parallel with sqrt(P_n) processors lower bounded by O(P_n^{7/2}).
- Serial: "even if implementing on a serial computer, the SAM approach can still have a favourable time complexity compared with the direct simulation of the full data posterior (i.e. setting K_n = 1). The time complexity of the SAM approach in a serial implementation is sqrt(P_n) O(P_n^{(1+alpha)/2} + n sqrt(P_n)) if sqrt(P_n) subsets are used, whereas the time complexity of the direct simulation of the full data posterior is O(P_n^{1+alpha}) + O(n P_n^2). The SAM strategy leads to a CPU time saving of order at least O(sqrt(P_n)) in serial implementations!"
- GPU remark: SAM "can benefit from the use of graphics processing units if parallel architectures are not available."
- Empirical (Sec 4.2, l.1318-1322): n=100, P_n=500,000, 1000 subsets of s=500: "the SAM cost for each data set about 16 h in a serial implementation on a single core ... This converts to about half an hour if 100 such cores are run in parallel, after accounting for the CPU times that are spent on each subset and the aggregated subset." In that example stage 1 reduced dimension to 18057.7 predictors (of 500,000; l.~1313), and the final model had 5.3 predictors.
- Observation (mine): the complexity analysis is of cost only; it assumes the number of retained predictors from stage 1 is O(K_n rbar) with rbar = O(1) average per subset, which depends on how many predictors are correlated with the true set (Remark (a)). No statistical-error/accuracy tradeoff in K_n is analysed; the SAMC iteration count T is assumed to scale as (P_n/K_n)^alpha without a mixing proof.

## 5. Uncertainty quantification of the merged posterior (Sec 7, l.1602-1627; quotes)

- "We note that SAM is not a standard Bayesian approach, as it does not process all data altogether and thus only provides an approximate quantification of uncertainty for each predictor through marginal inclusion probabilities."
- "Since the marginal inclusion probability measures the contribution of a predictor given all other predictors in the regression, the marginal inclusion probability of a given predictor in the subset data regression should not be less than that in the full data regression, although the full data regression is never run in the SAM method. This observation is meaningful particularly for the predictors that are screened out in the first stage, for which the marginal inclusion probabilities that are obtained in the subset data regression provide an upper bound for their marginal inclusion probabilities in the full data regression." (Heuristic; no theorem or proof; not generally valid in my view since suppression/masking can raise a predictor's inclusion probability when its partner is added.)
- "Regarding how to interpret the posterior probabilities that are associated with Bayesian model averaging in the subset data regression in comparison with their counterparts in the full data regression, we note that their difference can be interpreted as a difference resulting from their priors on the model space. The subset data regression is equivalent to the use of a data-dependent prior, which sets the prior probability to 0 for any models containing predictors that have been screened out in stage 1. Alternatively, the estimator that is obtained in the subset data regression can be interpreted as an Occam's razor approximation (Madigan and Raftery, 1994) to its counterpart in the full data regression, as the models containing the predictors that are screened out in stage 1 tend to have very low posterior probabilities."
- Coefficient estimation (Sec 4.2, l.~1307-1311): beta estimated "by averaging over the MCMC samples drawn in stage 2, while restricting the coefficients of the predictors that are screened out in stage 1 to 0." No credible intervals, coverage, or calibration results anywhere; no theorem on the stage-2 posterior approximating the full posterior (no total-variation or Hellinger bound between merged and exact posterior). Thresholds q use FDR control on marginal inclusion probabilities (alpha_1 = 0.15, alpha_2 = 0.01), "as in conventional multiple-hypothesis tests" (l.756-758).
- Uncertainty claims in theory are only for the exact posterior (Thms 1-3, contraction in Hellinger distance, marginal inclusion probabilities -> 1 for identifiable true predictors) and for the subset posterior (Thm 4, Cor 2). Sec 3.2 (l.759-762) says that when n is large "the marginal inclusion probability tends to be dichotomized ... the choices of alpha_1 and alpha_2 are not crucial".
