## Deterministic criteria

1. Preprocessing: exact status and precedence for nonfinite/malformed input, n<3, empty predictors, invalid seed, all-constant columns, constant response. Only exactly constant columns drop. Original indices survive dropping and permutation. Standardised means have absolute residual <=1e-13 and squared norms differ from n-1 by <=1e-11 on ordinary canaries. Affine/sign transformations preserve scores to 1e-9 nat and PIPs to 1e-10.
2. Scorer: all feasible scores on small canaries agree with independent 80-digit mpmath calculation to absolute 1e-9 nat (ill-conditioned duplicate cases: 1e-8 nat). Empty score, singleton closed form, normalized capped BB(1,p) prior, BF, full F, and Q lower bound checked separately. No tolerance determines HPM ties. Reject over-cap scoring. Numerical failure must not silently become a -infinity score. Check prescribed Cholesky/rebuild/QR and Q nonnegative recomputation through review and reachable failure fixtures.
3. Enumeration: p<=20 supported, subject to computational resources; enumerate every feasible subset once, include empty. Sum posterior mass within 1e-11 of one; independently computed log Z within 1e-9 nat, PIPs within 1e-10. Verify Z_BF=Z/m(empty). HPM uses exact floating equality, then size, then original-index lexicographic order. Mathematical ties which numerically separate are reported, not coerced. Synthetic equal-F fixtures enforce exact tie behavior.
4. Composite start: deterministic complete-linkage merge ties, oriented dendrogram, top-down cap and whole-cluster next-fit packing match hand fixtures exactly. Convolution vs brute-force normalizer <=1e-10 nat; every feasible pi0 probability <=1e-11 absolute error, total probability <=1e-11 from one. Include nontrivial multiple blocks, binding K, equal correlations, unused next-fit capacity, duplicate/sign-duplicate columns and highly unequal weights. Test categorical boundary conventions and backward/forward draw consumption explicitly.
5. Kernels: for phi=0,0.37,1, each coordinate Gibbs, uniform swap, neighbour swap, independence and whole round has row sums within 1e-12 of one, no entries below -1e-14, invariance residual max(abs(qP-q))<=1e-12. Each elementary kernel and reversal-averaged random-order round has detailed-balance residual <=1e-12. A fixed realized round need not be reversible. Include K=1/cap boundary, empty/full, isolated vertices and unequal neighbour degree. A deliberately missing Hastings correction must fail a canary.
6. Output semantics: exact equality for rule sets/statuses/flags against hand fixtures. HPM accounts for rejected and cached/evicted scores. `pip05` means strictly primary PIP>0.5; no secondary pooling, no truncation at K. `cut_group` uses the uncapped >=threshold graph, not the capped strict-> move graph, and is NA on exact fits. Near ties are inclusive at best-1e-9 and never reorder HPM; truncation has the prescribed full-store predicate. Local certification applies to returned scanned centre. Global certification only exact, with all competitor error heuristics and the required non-validated-bound label.
7. Calibration/resampling/evidence: check cumulative >= versus start >, zero-uniform guard, terminal resampling, incoming-particle evidence increments, exact branch inequality, grid post-snap checks, forced-only pilot snapping, stream IDs and continued diagnostic streams, fresh final streams, four measured rounds, arithmetic evidence/equal-island PIP pooling, and operational resource guards by independent routines and clause review. Deviations fail even if aggregate estimates appear plausible.

## Statistical criteria (fixed in advance)

Primary tests are pooled likelihood-ratio G-tests of independent sampler draws against fully specified exact pi0. Pool cells deterministically using expected probabilities only, ascending expected mass with binary model-code tie order, until each pooled expected count is at least 5; merge a final undersized pool into its predecessor. Never pool on observed counts. Structural-zero observations fail immediately. Fewer than two usable pools is untestable, never a pass. Pearson chi-square is diagnostic only.

Use 100,000 independent draws per fixture, fixed seeds 2026102201, 2026102202, 2026102203, 2026102204, for four families of fixtures: (1) singleton blocks with flat block BF; (2) unequal non-factorizing within-block BF; (3) binding size cap; (4) dominant/rare submodels. Within each fixture pool the full joint model distribution; size/block marginals are diagnostic, not extra primary hypotheses. The four G-test p-values form ONE Holm family, familywise alpha=1e-3. Any Holm rejection fails this battery. Repeat runs cannot erase the first result; altered fixtures/seeds/criteria require a dated amendment and preservation of original evidence. The same harness can accept A draws without changing the family. Reference-sampler validation is a separate labeled family from the A-sampler family.

No G-test is applied to dependent SMC terminal particles as if iid. Tiny-p production exact outputs must pass deterministic criteria. If testing SMC components requires a verification-only adapter, it must not modify production code or expose forbidden production options. Insufficient interfaces are recorded as NOT TESTED, not PASS.
