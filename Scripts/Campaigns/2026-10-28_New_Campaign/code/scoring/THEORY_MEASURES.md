# Theory measures (`R/theory_measures.R`, `R/td_slow.R`, `run_theory_H.R`)

One row per case in `case_theory.csv`. Everything is computed "after the fact": the core's `v3_context`, `v3_setup` are rebuilt from the preprocessed X, y (`v3_preprocess`), so no SMC is re-run and no fit-side code sees truth. The same function (`theory_case_row`) serves p << n (with an exact reference) and p >> n (`run_theory_H.R`, no exact Z: coverage and truth mass are NA).

## pi_0 mass of the truth and of the near-truth regions
Notation as master I.3: blocks C_1..C_J with tables `log r_b(U)` (`U` coded by bits, `v3_tables`), size prior `varpi(k) = w(k)/W_K` (read from the scorer as `log_prior`, which depends on |S| only), `Zbar_0 = sum_S varpi(S) prod_b r_b(S n C_b)`.
- `pi0_S0 = pi_0(S0)` from `v3_start_logmass`; `pi0_S0_tables_diff` = the same quantity recomputed from the table product, minus it (must be 0).
- `R_d = {U u P : U subset S0, P subset S0^c, |P| <= d}`. `pi0_R0`, `pi0_R1`, `pi0_R2` = `pi_0(R_d)` for d = 0, 1, 2 (`log_pi0_*` are the logs). R_0 = all subsets of S0.
- Exact DP (`pi0_dp`): per block, `e_b(j, q) = sum of r_b(U)` over subsets of size j with q null members (q <= d_max); convolution over blocks on the state (total size k <= K, nulls q <= d_max); `pi_0(R_d) = sum_{k, q <= d} varpi(k) A_J(k, q) / Zbar_0`. Validated against brute-force summation of `v3_start_logmass` over R_d (`pi0_Rd_bruteforce`) at p = 8, 10, 20 and 60 (tests).
- **Dropped true variable** (constant or duplicate column removed by `v3_preprocess`): every quantity goes through the preprocessing original-index map. `S0_retained = FALSE`, `n_true_dropped`, `theory_status = truth_dropped`. The full truth is infeasible, so `pi0_S0 = 0` (log -Inf), but R_d contains SUBSETS of S0 and keeps positive mass: `pi0_R0..R2` are evaluated over the feasible retained supports, with the retained truths `S0 n kept` as the true part (`region_basis = retained_truth_subsets`, otherwise `full_truth`). `F_truth`, `miss_class`, `truth_minus_*` and the log truth mass are NA, no error is raised, and TD is undefined (`td_status = undefined_truth_dropped`, no TD columns). Regression test: a constant true column, region mass checked by explicit summation over feasible supports.
- **Availability policy.** Scored-set coverage and the truth trace exist only for a completed fit (same rule in `case_smc_accuracy.csv` and `case_theory.csv`); a failed or partial fit gives NA in both.
- `blocks_match`: the blocks stored in the SMC record equal the recomputed blocks (NA when the record has none); `n_blocks`, `B`, `log_Zbar0`.

## Scored-set coverage and truth tracing
- `scored_coverage = exp(log_mass_scored - log Z_exact)` where `log_mass_scored = log sum_{distinct scored S} exp F(S)` (v2.2 registry, `fit$instrumentation$scored$log_sum_exp_F`); NA if the field or the exact Z is absent.
- `truth_scored`, `truth_first_phase`, `truth_first_mech`, `truth_first_tier/iter/island/stage`: whether the truth model was scored during the fit and where it was first scored, looked up in `fit$instrumentation$scored_set` (p <= 32; key = bitmask over retained positions) after the fit; if a future fit supplies `instrumentation$truth_trace` it is used instead (`truth_trace_source` says which).

## Truth vs HPM
`F_truth = F(S0)`; `F_smc_hpm`; `truth_minus_smc_hpm = F(S0) - F(SMC HPM)`; `truth_minus_exact_hpm`; `log_truth_mass = F(S0) - log Z`. `miss_class`: `hit`, `search_miss` (F(S0) > F(HPM): the search failed to reach a better-scoring truth) or `posterior_miss` (F(S0) <= F(HPM): the posterior itself prefers the HPM).

## T37 truth-dominance audit TD(d, m): literal and `toward` variants
Moves at a centre S are every feasible single add (|S| < K), single remove, and swap (one included out, one excluded in; swaps keep the size, so they are feasible at |S| = K); gain = F(S') - F(S). Centres are S = U u P, U subset S0, P subset (null pool), |P| <= d, |S| <= K. Clauses: **a** = S does not contain S0 (`add_true`), **b** = S strictly contains S0 (`remove_extra`), **c** = S = S0 (`at_S0`).

**Literal variant (T37 wording).** a: margin = gain of the best add of a missing truth minus the best gain among ALL other moves; b: best deletion of an extra (null) variable minus the best gain among all other moves; c: margin = minus the best gain over all moves. A centre violates when margin < m (`_viol`); margin = m is `_tight` (T37(i) needs strict, margin > m).
**Why the literal clause (a) fails generically.** At a centre that misses a truth j and contains a null l, the swap (l out, j in) removes the extra and adds the truth in one step and generally beats "add j". So the literal clause (a) fails at essentially every clause-a centre that contains a null variable, regardless of how strongly the data favour the truth. Example, `p0020_S1_r001` c100 (truth {3, 7, 14, 16}, full pool, m = 0): at d = 1, 240 of the 255 clause-a centres violate (all 240 beaten by the null-out/truth-in swap; the 15 survivors are the centres with P = empty); at d = 2, 2040 of 2055 (again all beaten by that swap); clauses b and c hold; minimum margin -5.5884 (centre {10}: add 14 gains 45.94, swap 10 -> 14 gains 51.53). Checked identically by the C++ `lowp_td`, the R stand-in and (in the tests) an independent mask-based reference.
**`toward` variant.** At S != S0: margin = (best gain among moves that strictly reduce |S delta S0|: add a truth, delete a null, swap null-out/truth-in) minus (best gain among the other moves); at S0 the literal clause c. It is reported alongside, since the literal variant is expected to fail whenever a truth-in swap exists. On the example it holds strictly: no violations at d = 1, 2; minimum margin 3.0716 (d = 1) and 2.6811 (d = 2, over clauses).

**Columns** (`case_theory.csv`), prefix `td{d}_` (full null pool) or `td{d}r_` (restricted pool, opt-in): `restricted`, `engine` (`enum` = `lowp_td`, `R_slow` = stand-in `td_slow`), `complete` (FALSE if `max_scores` stopped it), `scores`; then for variant v in `literal`, `toward`: `td{d}_{v}_{clause}_n` / `_viol` / `_tight` / `_minmargin` (clause = `add_true`, `remove_extra`, `at_S0`), `td{d}_{v}_violations`, `_min_margin`, `_holds_strict` (complete, no violation, no tie); and for the literal variant `td{d}_literal_viol_ab` (violators in clauses a and b) and `td{d}_literal_viol_truthin_swap` (of those, the number whose best competing move is a truth-in swap, i.e. the best non-target move is `swap_null_out_truth_in` and no other target move beats it; the full diagnosis by competing-move type is `r$diagnosis`).
**Settings.** Low p: d = 1, 2, all nulls (`--td-d 1,2`). p >> n (`run_theory_H.R`): **default d = 0 with all nulls only**, because d = 1 costs about 1.4e11 scorer calls per fit at p = 1000. **Opt-in** `--restricted-d1 1` adds d = 1 with the null pool restricted to the union of the core neighbour lists `v3_neighbours(ctx)` of the true variables (columns `td1r_*`, `restricted` = TRUE); `--max-scores` bounds the work (the enumerator refuses with its exact score count; the stand-in stops between centres). d = 0 is never restricted (no nulls in the centres).
Cross-checks (tests): the stand-in, the C++ enumerator and an independent mask-based reference agree on all counts, ties, minimum margins and the truth-in-swap diagnosis, for both variants, at p = 8 and 10 (d = 1, 2), with a restricted pool, and at K < p (n = 10, p = 8, K = 5, d = 2, 3, centres of size K, swaps feasible at |S| = K).
