## 3. Memory formulas (engine at e993ece2 = F2; paths under `Scripts/SMC_BVS/engine_v4/`)

### 3.1 Island (`include/v4/island/memory.h`, `island_memory()` lines 71-107; header text 1-34)
Upper bound; e = 26 + 4k bytes per store entry; k = max(8, q90(π₀ size) + 1, calib `k_store`) (`:13`); c = store cap; T = threads; G = group; kq = min(K, 3k); m_lab = p + B + 2; ntile = ⌈p / tile⌉ (tile 128).
- `inputs` = 8 n p + 16 p + inputs_bytes (setup/calib mapped sections) (`:78`) — **X is 8 n p bytes, in the island process** (n = 200, p = 10⁷ → 16 GB DERIVED).
- `x_tiles` = ntile · tile · n · 8 (label-major second copy of X, tiled) (`:79`) — **another 8 n p** → two copies of X per island.
- `store` = `store_peak_bytes(c, deferred, k)` (`:61-69`): deferred = 2 c e + s e + 64 s + s + 5c + 2·idx with s = max(8192, c/2), idx = 4·pow2(2c + 2). c is 40p + 1 for the top store (merge.h:150; setup tables.cpp:179).
- `leaders` (calibration only) = 2 stores of cap 20 p (`:81`); `worker_bufs` = T · 1.5 · 65,536 · e (×3 with leaders) (`:82`).
- `rb` = 32 p + Hm·p·8 + 16 p (+ 16 p T particle-major) (`:83`); `orders` = G·m_lab·4 + T·m_lab·4 + G(B+2)·8 (`:85`); `rows` = 2 G p 8 (`:86`); `gram_rows` = slots·p·8 (K3) (`:87`); `supports` = 32 G kq² + G kq n 8 + T G kq tile 8 (`:88`); `lm_scratch` (`:91`); `particles` = (2N + G)(4k + 64) + N·4k (`:95`); `calib_snapshot` for calibration islands = (c + leaders) e + idx + N(4k + 64) (`:96-99`); `ckpt` 2 MiB; `headroom` 12% of everything except inputs (`:105`).
- Scales with p: inputs, x_tiles, store (c = 40p + 1), leaders (20p), rb, orders, rows, gram_rows, (idx via c). With G: orders, rows, supports. With N: particles (and calib snapshot). With T: worker_bufs, orders, supports, lm_scratch. **Not with R′.** K enters via kq and the scratch only.
