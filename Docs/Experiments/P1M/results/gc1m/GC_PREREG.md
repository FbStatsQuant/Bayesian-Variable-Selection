| I4 reported only | new final-island stage count T (expected 27), arms (I_max 3 → 0), binaries (`2197fd5b…` → `da0cf85b…`) |
**Why the gate is built this way (disclosed).** (i) The whole-file raw hash embeds the binary block and differs across builds on identical data, so it cannot gate. (ii) The pilot island is a deterministic function of (data, setup, seed) in its **state** (the sampler's configuration and schedule after each stage), but five counters measure the **kernel's execution structure**: with rolling admission (default on in F2) the passes, active columns, pairs scored and supports differ from `2cfaa9e5` by design, and the **cross-build control** T5 (04d8d2b5) vs G-B G1a (F2), same data and seed at 10⁵, gives 160 differences, every one in those five counters, in all 32 active rows, while the state counters are equal in 34 of 34 rows. (iii) Five accounting counters also vary between identical same-build runs (flips ≤ 0.23 % per row, offers ≤ 6.2 %, duplicates ≤ 6.4 %, merges 1–2 events in a few rows). The gated set is the state counters; the gate **as first written** (pairs, supports, passes, act_cols and the raw hash gated) would have FAILED for certain and stopped G-C on a false alarm (Opus G-C check, findings 1–2). **No 1M F2 record exists:** the gate was fixed from the 10⁴ / 10⁵ controls (`tools/identity_controls/`: the G-B AR and ADJ-OPP pairs, the AR N 2,500 twin, the cross-build T5 vs G-B, the 11-17 record against itself, AR vs ADJ-OPP as the negative). **Tested** (`tests/test_gc_identity.py`, **8/8** on real records): PASS for the 11-17 record against itself, the G-B pair, the N 2,500 twin and the cross-build T5 vs G-B; FAIL for different data and for a mutated state counter (M, mean_S), a header mismatch or a missing row; kernel-structure, accounting and timing differences do not fail.
**What the gate establishes and does not:** F2 and `2cfaa9e5` run the same data, setup and pilot-stage trajectory (state) at 1M; the kernel's pass structure differs by design (rolling admission). It does **not** compare the final-island stage (different grids; the 11-17 island files are gone); that equivalence rests on the chain F = T5's island (11-18), F2 = F (VN_ID_1, XB2) and the same-bits statement of CAMPAIGN_PLAN §3. The pair is reported as a grid contrast (§8), descriptive, one seed.

## 6. The conditional 20 seeds (H-34): release and scoring (registered)
**Release trigger (proposed):** HQ releases it once the pilot, W1 and W2 are read back clean (5 fits: AR r01–r04 and ADJ-OPP r01; no stop, C1–C4 pass) and the position check holds (projection ≤ 28,300).
**Design.** 20 independent sampler runs on the rep-1 data: seed 1 = the pilot; seeds 2–20 at the frozen configuration (N 2,500, I_max 0, F2), each running its own setup, calibration and islands; engine seed = data seed + 100 (i − 1). **Completion ≥ 19 of 19 new fits, or each failure listed.**
**Scoring (descriptive; `gc_seeds.py`, registered before release; no threshold except the two stated references):**
1. **Selection identity:** the number of distinct HPM sets over the 20 fits and whether each equals S₀ (`selection.hpm_eq_S0`); the same for the MPM (`selection.mpm`); the count of seeds with HPM = MPM = S₀.
2. **PIP spread across seeds:** for each variable j the sd over the 20 fits of PIP_eq,j (the `fit.bin` `pip_eq` section, read with its section hash verified); reported: max_j, the 99th percentile, and the number of variables above 0.005 (the §0-v2.3 bar, used as a reference), beside the within-fit island spread (`pip.island_spread.max_sd`, M2) and its √16-scaled expectation.
3. **log Ẑ spread:** sd over the 20 seeds of log Ẑ, log Ẑ_occ (M = 1,000) and log Z_T, against the mean within-fit s.e. σ̂ / √16 (the ratio is reported; ≈ 1 if the pooled islands are exchangeable and the estimator is unbiased across runs).
4. **Island agreement:** the 320 island log Ẑ_r values: the between-seed and within-seed variance components (islands nested in seeds); M1–M3, `occ_inhomogeneous`, R_eff / R′ per seed (distribution over the 20); final E1–E3 and sd(log Ẑ_r) > 1 counts.
A seed with a different HPM, a failed fit or a flag is reported, never dropped. **Reading, declared now:** 20 of 20 with HPM = MPM = S₀ and spreads at their within-fit expectations supports "reproducible at 1M on this dataset (same data, 20 independent sampler runs)"; any deviation is stated plainly; no statement beyond one dataset.
