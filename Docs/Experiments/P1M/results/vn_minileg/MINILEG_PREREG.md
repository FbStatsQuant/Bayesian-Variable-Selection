## 3. (a) The N decision rule
### 3.1 The rule, exactly (PREREG of the leg §3.2; nothing new)
Baseline B and arm X are cells of the same I_max. Per (dataset, cell) value of each metric = the mean of the 2 replicates (both delivered and identity-verified). M1 = `fit.meta.occ[M = 1000].sd_log_Z_occ_r`, M2 = `pip.island_spread.max_sd`, M3 = `evidence.sigma_hat` (= sd(log Ẑ_r); the leg's erratum on the σ̂ label), `evidence.sigma_hat_robust` reported beside it. r_X = the geometric mean over the three datasets of value(X)/value(B). c_X = mean billed **islands** core-h of the arm's fits / the baseline's (cost files; calibration excluded; the N-arm calibration is identical by pairing). **ADOPT iff for each of M1, M2, M3: r_X ≤ 1/√c_X and r_X < 1 in every dataset, and the HPM set is the same in every fit of X ∪ B; otherwise KEEP N = 2,500.** An identity failure → INCOMPLETE; a missing metric or cost → NOT_EVALUATED. *Reason (unchanged):* the island-pooled sd falls as 1/√R′, so spending a factor c_X on islands buys 1/√c_X; N = 10⁴ is worth its cost only if it beats that. Equivalently, an ADOPT means that (N = 10⁴, R′/c_X islands) is at least as precise as (N = 2,500, R′) **at equal cost**, so the budget-neutral option S5 of §6 is then available.
**"Wins on accuracy" (HQ H-33) is this ADOPT, in accuracy per core-h; it is not "more accurate at higher cost".** The per-metric ratios are reported whatever the outcome.

### 3.3 Decision and mapping (pre-declared)
- **N*(configuration) = 10⁴ iff that configuration's run returns ADOPT; otherwise (KEEP, INCOMPLETE, NOT_EVALUATED) N* = 2,500.** The two configurations decide independently; there is no AND and no veto: G-B's I_max twin rule (H-30) fixes which configuration runs at 10⁵/1M, and N* is the entry for it. **The frozen configuration governs the plan** (it is the one currently frozen); the I_max-3 result is what is used if the G-B rule reverts 10⁵/1M to I_max 3.
- If the two configurations disagree, the disagreement is **reported as a finding** to HQ (it would say the N effect depends on the grid rule); each still decides its own configuration.
- The verdict (outcome per configuration, ratios, c_X, identity, XB2) goes to HQ; HQ's acceptance fixes N* for the G-B plan (H-33 (3)). Judgement is not substituted for the rule after the data are seen.
### 3.4 Operating characteristics of the rule for an N arm (`vn_budget.py`; 3 datasets × 2 replicates; the three metrics treated as independent, conservative for the joint condition; c_X = 3.85 × lognormal(0, 0.09), so the bar ≈ 0.51)
| true ratio r (all metrics) | 0.35 | 0.40 | 0.45 | **0.50** | 0.55 | 0.60 | ≥ 0.70 |
|---|---|---|---|---|---|---|---|
| P(ADOPT), per-dataset sd(log r) 0.15 | 1.000 | 0.981 | 0.746 | **0.249** | 0.024 | 0.001 | 0 |
| sd 0.10 | 1.000 | 0.999 | 0.883 | **0.317** | 0.020 | 0.000 | 0 |
| sd 0.05 (if pairing shares the grid; measured at the verdict) | 1.000 | 1.000 | 0.976 | **0.455** | 0.023 | 0.000 | 0 |
Reading: the sd of an island-pooled metric falls as 1/√N, i.e. a true ratio of **0.50**, which sits at the bar (0.51): under plain 1/√N scaling the rule ADOPTs in only 25–45 % of repetitions and KEEPs in the rest; it ADOPTs reliably only for a gain beyond 1/√N (r ≲ 0.45). **The expected verdict is KEEP N = 2,500**, and this is by design: N = 10⁴ must beat spending the same core-h on islands. The per-dataset noise figures (0.10–0.15) are the leg's R3 figures for independent seeds; the paired-seed figure 0.05 is an assumption until the verdict. No replicates are added (the rule evaluates exactly 2 per cell; the unspent approved budget is not used to change that).

## 5. (c) The offset N contrast: the ONE pre-declared measurement (no pass/fail)
**Why it is computable now:** the leg's PREREG §4.1 said the N dimension was limited to T's tiers because V could not run N = 10⁴ at F; with F2 the V N contrast exists. It extends, not replaces, PREREG §4.
- **Estimand.** The registered surface δ(N, m, I_max, k) = mean over datasets of [V block-mean log Ẑ − T reference] (T̄ = the mean of the two overlap T seeds), now with the cells (10⁴, 1, 0) and (10⁴, 1, 3), k ∈ {4, 8, 16, 32, 64}; and the paired contrast **Δ_N = δ(10⁴, 1, I) − δ(2,500, 1, I) at k = 64** for I = 0 (frozen) and I = 3: per-dataset difference of the 2-replicate means, mean over the three datasets, 95 % t interval (df 2), every per-dataset value shown. Paired by dataset and, by design, by seed (same grid): the T reference cancels.
- **Tools.** I_max 3: the registered `precision_offset.py` unedited (its contrast `N: (10000,1,3) − (2500,1,3) at k=64`). I_max 0 and any other pair: `vn_offset_contrast.py` reading the registered `offset_per_fit.csv` (**the registered CSV's header lacks the `src` column its rows carry, so columns after `I_max` are shifted by one; the contrast script reads by position; `offset.json` is unaffected**), with the same formulas and t table; its I_max-3 contrast equals the registered one (tested). Command: `python3 -I precision_offset.py --records R/overlap1e4/{W0..W3} R/precision1e4/{A0,P1,P2,P3,P4} R/vn_minileg/{V0,V1,V2} --out vz/offset`, then `python3 -I vn_offset_contrast.py --per-fit vz/offset/offset_per_fit.csv --out vz/contrast`.
- **Headline lines (fixed now; no other result is headlined):** **PN1** Δ_N at k = 64 for the frozen configuration and for I_max 3, each with its interval and the two reference values below; **PN2** the R′ span k = 4 → 64 with the Jensen prediction for the two (10⁴) cells (registered `P2_span` lines, as in the leg); **PN3** the **matched-N** column: δ(10⁴ cells) against the T **tier-0** reference only (T at N = 10⁴, R′ 4: the registered `delta (T tier-0 ref only)` column), where V and T share N.
- **Reference values (printed beside every Δ_N; they are readings, not tests).** **H0:** Δ_N = 0 (V's log Ẑ does not depend on the islands' N). **H-N:** the V − T offset is a finite-N effect ∝ 1/N, i.e. Δ_N = −(1 − 2,500/10⁴) × δ(2,500, 1, I) = +0.75 × |δ(2,500)| for a negative δ (the leg measured −0.0060 / −0.0069 at k = 64, so ≈ +0.0045–0.005). The report states which of the two the interval excludes.
- **How it may be read (declared now).** Interval excludes 0 and contains the H-N value: consistent with a finite-N component of the offset. Interval contains 0 and excludes the H-N value: the offset does not move with N at these settings: it is not a finite-N effect of the islands (noise, or an arm difference that N does not change). Contains both: unresolved. Excludes both: a FINDING of another kind. **No claim "V is biased" is made from Δ_N; no truth for log Z exists.**
- **FINDING rule (as the leg's §3.3):** a Δ_N whose 95 % clustered interval excludes 0 is listed in the verdict and sent to HQ + Theory; it does **not** change the §3 rule's output.
- **Resolution (stated so it is not over-read).** V's log Ẑ at R′ = 64 has sd ≈ 0.0029 per fit at N = 2,500 (≈ 0.0015 at N = 10⁴ if sd ∝ 1/√N); a dataset contrast of 2-replicate means has sd ≈ 0.0023 if the seeds were independent, and a 3-dataset t(2) half-width of ≈ **0.006**; pairing by seed removes the shared grid variability and may halve it (measured at the verdict). The H-N value (+0.0045–0.005) is therefore at the edge of what this measurement can separate from 0.
