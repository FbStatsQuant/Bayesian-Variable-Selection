**Arithmetic proof.** At entry, every lane of `c0..c3` is a zero-extended `uint32_t`, including the lane replaced from `vals`. For unsigned 32-bit `a,b`, `a*b <= (2^32-1)^2 = 2^64-2^33+1 < 2^64`; the full product fits exactly in `uint64_t`. `_mm512_mul_epu32` multiplies the low unsigned dword in each qword lane and returns that full 64-bit product. The high input dword is zero, and both constants M0/M1 are unsigned 32-bit values, so the intrinsic and the old unsigned 64-bit lane multiplication produce exactly the same product, including its upper 32 bits.

After each round, `p & 0xffffffff` is 32-bit; `p >> 32` is 32-bit; XOR with the other 32-bit counter word and the `uint32_t` key remains 32-bit. Key additions wrap in `uint32_t` as before. This proves the lane invariant and equality inductively through all ten rounds and all four output words. The AVX2 and scalar/generic branches retain the old expression unchanged. Equal words imply equal `((c1 << 32) | c0) >> 11`; that integer is at most `2^53-1`, is exactly representable as double, and multiplication by `2^-53` preserves the original uniform bits. No floating-point flags or class-A arithmetic changed.
