# From Theory (2026-11-16): the approximate-Gram condition (AG). Read before writing about it.

**What it is.** (AG) says that the design's sample correlation matrix R̂ = XᵀX/(n−1) is within δ_n of a population matrix
Σ_n in operator norm, with δ_n·√(p log log n) → 0 (`Theory_work/Wave2/W2-FAC-A/STATEMENT.md:90`; W2-UNI STATEMENT §1,
setting (E), :23-24).

**Where it is used.** Only in the **fixed-design branch (E)** of W2-UNI:F-UNI and in the factor route W2-FAC-A:Thm-FAC-L
(registry: the only two rows carrying A:GRAM-OP-BOUND). The random-design branch (R), i.i.d. Gaussian rows, does not use
it. All our studies (2,400-fit, P6, 1M) are random Gaussian designs, so they go through branch (R).

**What it is not.** It is not an explicit constant or a proof artefact. It is a real asymptotic condition, and for random
rows it holds only when p grows much more slowly than n. That is why the internal track C check finds it "outside" on
every design: it was never the route for these designs.

**How to write it.** Present (AG) as the condition of the fixed-design version, with exact Gram (δ_n = 0, p ≤ n − 1) as its
main case. Do not list it among the assumptions our designs must meet, and do not describe it as failing on our designs.
