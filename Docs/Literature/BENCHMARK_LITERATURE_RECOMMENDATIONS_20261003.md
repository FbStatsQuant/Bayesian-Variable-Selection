# Ten variable-selection benchmarks for the local-to-global SMC project

Research date: 3 October 2026. This is a literature-based recommendation, not a new empirical ranking. No simulations or numerical validation were run for this review.

**Recommendation.** Use Lasso, elastic net, adaptive Lasso, SCAD, MCP, adaptive best-subset selection (ABESS), spike-and-slab Lasso, SuSiE, knockoff+, and Gaussian spike-and-slab BVS computed with PARNI. These cover convex regularization, nonconvex regularization, direct subset search, Bayesian optimization, approximate Bayesian inference, frequentist error control, and posterior sampling. The list deliberately combines established methods with newer implementations. PARNI is a specialist exception to the preference for highly cited methods: its relevance to the SMC contribution outweighs its much smaller citation count.

The evidence has three parts: recent papers' actual comparator sets, adoption/citation evidence, and suitability for the project's five designs. This is a targeted literature review, not a systematic census of every variable-selection paper. Papers were sought across broad regression comparisons, subset optimization, Bayesian model-space computation, correlated-variable fine-mapping, and false-discovery control. Abstracts alone were not used to establish comparator lists: methods, simulation sections, tables, and relevant supplements were opened and inspected. A separate [reading ledger](READING_LEDGER.md) identifies the versions and locations read.

**What the project is actually testing.** I read the October 1 methodology, the Experiment 1 design, the Experiment 2 rerun configuration, and its saved recovery table. The current statistical model is Gaussian linear regression with a design-adapted Gaussian slab, an IG(0.01, 0.01) noise prior, and independent Bernoulli(0.2) model indicators. The sampler starts from a product of small-block posteriors and bridges to the specified full posterior. Its composite start changes the computation; it does not change the terminal target. The code currently represents models with integers and is limited to p <= 30.

All five scenarios have n = 100, p = 30, five nonzero coefficients at {2, 3, 8, 14, 19}, effects (1, -1, 0.6, -0.8, 0.5), and noise SD 1. There are 100 datasets per scenario. The first block contains an opposing-sign pair; the remaining active blocks each contain one signal. The statistical correlation blocks and SMC's randomly permuted computational blocks are different objects.

| Scenario | Correlation design | Main selection challenge | Especially informative comparisons |
|---|---|---|---|
| S1 | Independent | Basic sparsity/false-positive tradeoff | Lasso, adaptive Lasso, SCAD, MCP, ABESS, SSL |
| S2 | AR(1), 0.5^distance | Local correlation and weakened marginal signals | Elastic net, adaptive Lasso, SuSiE |
| S3 | Six blocks of five; within-block correlation 0.7 | Distinguishing true variables from correlated proxies | ABESS, SSL, SuSiE; singleton versus group conclusions |
| S4 | Same blocks; within-block correlation 0.85 | Strong proxy competition and opposing-sign cancellation | PARNI versus SMC for computation; SuSiE/ABESS/SSL for selection |
| S5 | Within-block 0.7, between-block 0.3 | Global dependence across blocks | PARNI versus SMC; elastic net, ABESS, SuSiE |

The design document reports that population R-squared decreases from roughly 0.76 to 0.60 across these scenarios. Thus changing correlation also changes effective signal strength. Keep the original scenarios, but do not interpret every performance change as a pure correlation effect. A later equal-SNR sensitivity study would help separate them.

The saved `BVS_recovery.csv` reports exact-posterior median-model exact-support recovery of 88, 79, 72, 29, and 65 out of 100 for S1-S5. The RB-SMC counts are 88, 78, 72, 29, and 65. These are inspected historical outputs, not results recomputed here. They demonstrate why selection quality and posterior approximation need separate assessment: the exact posterior itself can make the wrong support decision under this fixed data-generating truth. Exact enumeration is a reference for this posterior, not an upper bound on every method's support recovery.

**The ten recommended algorithms.** Numbers identify methods; they are not a predicted performance ranking. Settings below are proposed for a future campaign and have not been implemented or tuned on these datasets.

| # | Benchmark and foundational reference | Reason to include it here | Concrete implementation and proposed selection rule |
|---|---|---|---|
| 1 | **Lasso** — [Tibshirani, 1996](https://doi.org/10.1111/j.2517-6161.1996.tb02080.x) | Essential common baseline with overwhelming adoption and repeated use in recent comparisons. Establishes how much the Bayesian procedure improves on inexpensive convex sparsity. | `glmnet`, alpha = 1. Shared 10-fold CV; nonzero coefficients at lambda-min as the conventional arm and lambda-1SE as a prespecified sensitivity. Do not count the two settings as two algorithms. |
| 2 | **Elastic net** — [Zou and Hastie, 2005](https://doi.org/10.1111/j.1467-9868.2005.00503.x) | The natural convex comparator under correlated designs. Its grouping behavior can improve prediction but also retain null proxies. Positive correlation does not imply the opposing-sign pair should receive similar coefficients. | `glmnet`; tune alpha and lambda using fixed common folds. For example, preregister alpha in {0.1, 0.3, 0.5, 0.7, 0.9}; Lasso already covers alpha = 1. Select nonzeros. |
| 3 | **Adaptive Lasso** — [Zou, 2006](https://doi.org/10.1198/016214506000000735) | Very widely cited and explicitly retained by both broad 2025/2026 comparisons. Tests whether variable-specific shrinkage closes the gap without a full Bayesian calculation. | Weighted `glmnet`, with ridge-initialized weights proportional to 1/(abs(beta-initial) + epsilon). Re-estimate the initializer and its tuning inside each training fold; do not let held-out responses determine weights. |
| 4 | **SCAD** — [Fan and Li, 2001](https://doi.org/10.1198/016214501753382273) | Established nonconvex selection method with reduced shrinkage on sufficiently large signals. A serious alternative when ordinary Lasso's coefficient bias harms recovery. | `ncvreg`, SCAD shape 3.7, prespecified lambda path, shared CV. Record convergence and any locally nonconvex region. No unconditional global-optimum or oracle guarantee for finite samples. |
| 5 | **MCP** — [Zhang, 2010](https://doi.org/10.1214/09-AOS729) | Another canonical, repeatedly benchmarked nonconvex method. Its different penalty geometry makes it worth retaining alongside SCAD, especially under strong dependence. | `ncvreg`, MCP shape 3 as a starting convention, shared CV. Preserve convergence diagnostics and the full fitted path. |
| 6 | **ABESS: adaptive best-subset selection by splicing** — [Zhu et al., 2020](https://doi.org/10.1073/pnas.2014241117); [software paper, 2022](https://www.jmlr.org/papers/v23/21-1060.html) | Modern representative of direct L0/subset search. It challenges the need for shrinkage and tests whether considering models jointly helps recover the cancelling pair. | `abess`, Gaussian family, no preliminary screening at p = 30. Search a prespecified size path including 0 through p; choose size by BIC for the support-focused arm and CV for a prediction sensitivity. Never give it k = 5 in the main comparison. Its theory is conditional, not a universal polynomial-time solution to NP-hard subset selection. |
| 7 | **Spike-and-slab Lasso (SSL)** — [Rockova and George, 2018; online 2016](https://doi.org/10.1080/01621459.2016.1260469) | Established bridge between penalized methods and Bayesian sparsity. Particularly useful for asking whether fast Bayesian optimization can match model-space sampling in support recovery. | `SSLASSO`, with the published dynamic posterior exploration strategy and sparse-mode nonzeros. Preregister the spike ladder and convergence/stabilization rule; use a documented sensitivity if it does not stabilize. Standard SSL fits a sparse mode, not the joint model posterior or the SMC evidence. |
| 8 | **SuSiE, using IBSS and refinement** — [Wang et al., 2020](https://doi.org/10.1111/rssb.12388) | Highly adopted modern Bayesian comparator designed to represent ambiguity among correlated variables. Its PIPs and credible sets match the scientific difficulty of S3-S5 particularly well. | Pin a `susieR` release/commit; use ordinary sparse SuSiE with refinement. Start with L = 10, not oracle L = 5, and check sensitivity to a larger bound such as 20. Estimate nuisance variances from training data. Evaluate singleton PIP decisions and credible sets separately. |
| 9 | **Knockoff+ with Lasso importance statistics** — [Barber and Candes, 2015](https://doi.org/10.1214/15-AOS1337); [model-X extension, 2018](https://doi.org/10.1111/rssb.12265) | Widely established external reference for false-discovery control. Its objective is useful beside the project's Bayesian-FDR decisions, even though exact-support recovery is severely constrained in this small problem. | For the present n > 2p Gaussian design, use fixed-X knockoffs and a sufficient, antisymmetric Lasso-path statistic, with offset = 1. Evaluate q = 0.05, 0.10, 0.20 as distinct prespecified levels. Reserve model-X for a separately labeled extension; known generating covariance would be extra information. |
| 10 | **Gaussian spike-and-slab BVS via PARNI** — [Liang, Livingstone and Griffin, 2022](https://doi.org/10.1007/s11222-022-10137-8) | The most directly relevant computational competitor in this shortlist. It can target the same discrete posterior and exposes whether SMC's bridge offers better exploration per unit cost. Its citation/adoption base is much smaller than the other methods'. | Adapt the authors' code to the exact project log-score and model prior; preregister PARNIT-KW as the main variant. Use independent starts and common time/CPU budgets. Apply the same MPM/BFDR decision rules to its PIPs as to SMC. Target adaptation requires validation; the existing code is not assumed to be drop-in compatible. |

**The knockoff limitation is structural.** Standard knockoff+ accepts a positive threshold only if

    (1 + number of W_j <= -t) / max(number of W_j >= t, 1) <= q.

Therefore any nonempty selected set has at least ceiling(1/q) variables. At q = 0.05 it needs at least 20 selections, and at q = 0.10 at least 10. With a true support of size five, exact-support recovery is impossible at either level. At q = 0.20 the five-variable minimum makes exact recovery possible, but there is no promise of useful power. This is an algebraic implication of the published threshold, not an empirical result from these scenarios. Include this benchmark to assess the price and behavior of frequentist error control, and do not advertise its forced disadvantage as evidence of superior SMC support recovery. If a single support-recovery leaderboard is the only goal, move knockoff+ to an error-control supplement and use stability selection in that slot.

The [official knockoff manual](https://cran.r-project.org/web/packages/knockoff/knockoff.pdf), pp. 2-3, also warns that its default cross-validated Lasso statistic does not satisfy the sufficiency requirement for fixed-X knockoffs. A compatible Lasso-path statistic must be selected explicitly. Do not obtain apparent power by silently using offset = 0, since that changes the guarantee. Do not average repeated knockoff statistics without an aggregation method whose error-control result actually applies.

**How to make the eventual comparison interpretable.** Keep two separate questions visible throughout the report.

1. *Does the sampler approximate the stipulated posterior efficiently?* Compare SMC and PARNI under exactly the same likelihood, slab, noise prior, model prior, and intercept convention. Use saved exact enumeration for PIP/evidence references, PIP MAE/RMSE, model-size and joint-inclusion probabilities, posterior mass found, and decision agreement. Repeat computational seeds on fixed datasets. Use wall-clock and total CPU time as well as model-score evaluations; an iteration is not a common unit of work. PARNI does not automatically supply a marginal-likelihood estimator.
2. *Does the full statistical procedure select the true variables well?* Compare all ten procedures with prespecified tuning and decisions. Report exact-support recovery, TP/FP/FN, TPR, empirical FDP/FDR, F1 or Hamming loss, selected size, and independent-test prediction loss. The evidence and PIP-error metrics against this project's posterior are not meaningful for Lasso or for a different-prior Bayesian fit. Approximate PIPs from SuSiE are not estimates of this project's exact PIPs.

For Bayesian singleton decisions, show the MPM threshold and the Bayesian-FDR rule separately. Given decreasing ordered PIPs, the latter selects the largest k whose average (1 - PIP) is <= q. That is a posterior expected-FDP statement under the fitted model. It is not automatically frequentist FDR control for the project's fixed beta across repeated datasets; report the actual mean FDP. The MPM is not a universal exact-support or F1 optimizer under arbitrary correlated designs.

Use the same 500 saved datasets for pairing. Reuse common training folds where the algorithms permit it, preserve fold assignments, and include all tuning in timings. Show lambda-min alongside a sparsity-oriented sensitivity rather than comparing only a dense CV-Lasso output with an especially conservative Bayesian threshold. Do not select a favorable method/threshold separately for each scenario using its true support. Do not force every method to choose five predictors.

The project's no-intercept, uncentered-y convention needs explicit attention. Many packages center y or fit an intercept automatically. Check this before implementing; do not silently recenter the SMC input and then compare against old enumeration. If an implementation cannot support the historical convention, label the difference and prepare a common intercept-handling sensitivity across methods. All supervised preprocessing and adaptive weights must be fitted inside training folds. The `susieR` interface supports an explicit intercept choice; package names alone do not ensure compatible likelihoods.

For correlated designs, report both exact singleton recovery and a separately defined group-localization task. Selecting any member of a true block is not exact recovery of its active member, and finding one member of block 1 is not finding both opposing-sign signals. Do not hand true blocks to only one method unless it is explicitly an oracle analysis. Joint SMC draws can estimate a group's probability of containing a signal; simply summing its marginal PIPs is generally incorrect. BLiP is a promising downstream use of those joint draws, particularly if the scientific conclusion should acknowledge proxy ambiguity.

For a publication about the composite start, retain an ordinary prior-start SMC ablation with the same terminal target, mutation machinery, and budgets. A standard binary-space SMC comparator, such as [Schafer and Chopin (2013)](https://arxiv.org/abs/1101.6037), is also relevant to the computational claim. These are computational controls for the proposed algorithm, not additional entries used to pad the ten-method variable-selection shortlist. Perfect posterior computation cannot compensate for a prior/decision rule that is poorly aligned with exact support recovery.

All future simulations, benchmarks, and computational validation should run on owls, after reading its applicable instructions, with persistent jobs and preserved sources/configuration, seeds, hashes, commands, process/scheduler IDs, environments, timestamps, exit status, logs, raw data/results and validation evidence. No remote job was required for the present document review. Historical Gaussian prior settings and historical runs were preserved.

**Why several plausible methods are outside the main ten.** These are scope decisions, not claims that the omitted methods are inferior.

| Candidate | Reason for reserving it |
|---|---|
| Ordinary spike-and-slab Gibbs / SSVS, MC3, BAS | Valuable established references. For the one main same-posterior sampling slot, a modern informed sampler is a stronger computational challenge. A conventional Gibbs/ADS control can still diagnose where gains arise. |
| Weighted TGS and MAdaSub | Strong candidates for an expanded computation-only study, directly supported by the sampler literature. I would add weighted TGS before adding a second generic penalized variant beyond this list. |
| Horseshoe / regularized horseshoe / Bayesian Lasso | Important shrinkage benchmarks, especially for prediction, but continuous posterior coefficients do not by themselves define a selected support. A thresholding, projection, or decision rule would become an additional methodological choice. The 2026 study's clustering step illustrates this complication. |
| Stability selection / complementary-pairs stability selection | The strongest alternate for the knockoff slot if the initial focus is strictly support recovery. Selection frequencies are not posterior inclusion probabilities, and usual expected-false-selection guarantees are not identical to FDR. |
| L0Learn, COMBSS, mixed-integer best subset | Serious modern subset-search alternatives. ABESS occupies this slot because it is accessible, has a software paper, and appears in an independent recent comparison. At p = 30, exact or certified subset optimization would be a useful optimization reference; distinguish a proven optimum from a time-limited incumbent. |
| FINEMAP, DAP-G, CAVIAR | Clearly established fine-mapping comparators; the original SuSiE and BLiP studies explicitly use them. SuSiE gives this panel a broadly usable representative without making the entire study a fine-mapping software comparison. |
| Nonlocal-prior BVS, e.g. pMOM via mombf | Especially relevant if improving the current prior's selection behavior becomes the objective. It changes the statistical target and should be introduced as a prior comparison rather than a sampler improvement. |
| Group Lasso / sparse group Lasso | The simulated truth is sparse within the correlated blocks, not simply all-in/all-out by group. Supplying the true groups would also be additional information. Include only in a declared group-selection extension. |
| Random forest, Boruta, RFSFS, boosting | More compelling when the target includes nonlinearities or interactions. Their variable-importance/selection definitions add choices in this correctly specified linear experiment. Recent proposed methods such as RFSFS should not displace established controls solely because they win their authors' study. |
| SuSiE-ash/inf, DVS, OLAP | Useful recent directions, but currently either change the scientific setting or have a smaller adoption base. The current truth has no dense effect background; DVS changes the predictor representation; OLAP addresses nonconjugate marginal-likelihood computation that is already analytic here. |

**Practical starting order.** Implement Lasso, elastic net, SCAD, MCP, and ABESS first, because they cover the core classical families with mature software. Then add adaptive Lasso, SSL and SuSiE. Validate PARNI against enumeration before using it for computational claims. Add knockoff+ as the explicitly labeled error-control panel. This is an implementation order, not a recommendation to omit any of the ten.
