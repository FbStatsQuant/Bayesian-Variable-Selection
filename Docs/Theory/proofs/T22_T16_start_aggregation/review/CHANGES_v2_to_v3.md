# Changes from PROOF_v2 to PROOF_v3 (exposition only; no mathematical step changed)

1. The long display in the proof of (i-a) is split over three aligned lines (it overflowed the PDF margin). Same for the display of gamma_1(S) in Lemma 7.
2. Lemma 1: D_S >= 1 is now justified explicitly: D_S = prod_i (1 + (n+1) lambda_i)/(1 + lambda_i) >= 1, with lambda_i >= 0 the eigenvalues of M_S.
3. Notation: c := n+1 renamed varrho; Sylvester's parameter t renamed tau; alpha, beta in Lemma 2 renamed xi, zeta; g(t) renamed g(x) in (i-a).
4. Proof of (iv-a): the case Omega = {S_0} is replaced by the remark that it cannot occur (n >= 3, p >= 1 give K >= 1, so the empty set and {1} lie in Omega); hence R_0, R_1 > 0.
5. Preamble: the convention x^0 := 1 for all x >= 0 is stated globally (covers e^0 and D_b^0 with D_b = 0).
