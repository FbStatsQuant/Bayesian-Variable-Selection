## Statement (as proved)
Source: proofs/T01_T02_contrast_dimension/STATEMENT.md section 3 (T02); theorems/T02_A1_dimension_supersets.md (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- Regime R1 (n -> infinity, s0 fixed, p <= n^A), under G and R.
- (i) For every n and every deterministic integer m, define Theta_{n,m} >= 0 by Pi(|S| > m | y) = 2^-m (2p)^s0 (n+1)^(s0/2) sqrt(n) Theta_{n,m}. Then lim_{L->inf} limsup_n sup_m P0(Theta_{n,m} > L) = 0. Consequently, for deterministic omega_n -> infinity with omega_n = O(log n): Pi(|S| > m_n(omega_n) | y) = O_P(e^-omega_n). No eigenvalue condition beyond lambda_min(R_S0) >= phi0^2 is used; a tight sup_m Theta_{n,m} inside the probability is not claimed.
- (ii) Under SE in addition: Pi({S in Omega : S strictly contains S0} | y) = O_P(r_n), r_n = sqrt(log n / n).
