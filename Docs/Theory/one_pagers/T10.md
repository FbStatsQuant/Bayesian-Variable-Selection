# T10 — Feasible-addition hazards and ordered paths (old label T11)

## Statement (as proved)
Source: proofs/T10_T11_addition_hazard/STATEMENT.md (condensed here from LOCKED_PROOFS.md; theorems/T10_T11_addition_hazard.md) (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- (per LOCKED_PROOFS.md) For every data set, adding one feasible variable (size k < K, j not in S, phi in [0,1]) multiplies the start mass pi0 and the Gibbs-step score by at least the floor r_k = (k+1) / ((2p - k - 1) sqrt(n + 1)): pi0(S + j) >= r_k pi0(S). A round visits an ordered set of a additions with the stated probability. These visit bounds do not give terminal occupancy or a discovery guarantee within the budget.
