## Statement (as conjectured)
Source: PAPER_SELECTION_20261028/new_conjectures/T37_truth_dominance_greedy_repair.md (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- Production local search: scores every feasible flip and swap of the centre, moves to the best strict improvement, at most l moves, then a final certifying scan. Near-truth region R_d = {U cup P : U subset S0, P subset S0^c, |P| <= d}, s0 + d <= K. TD(d, m) (truth dominance with margin m >= 0): for S in R_d not containing S0 some missing true variable has addition gain >= m + the gain of every other feasible move; for S in R_d strictly containing S0 some extra variable has deletion gain >= m + every other move; at S0 every move has gain <= -m.
- (i) Deterministic: under TD(d, 0) with strict inequalities, from any centre S in R_d with l >= |S symmetric-difference S0| the search moves monotonically to S0 in exactly |S symmetric-difference S0| moves, scores S0, reports local_certified there, and never leaves R_d; hence S0 is scored and S-hat = S0 whenever pi(S0) > 1/2 (T21).
- (ii) Finite n, under G: P0(TD(d, m) fails) is at most the sum, over at most 2^s0 C(p,d)(p + s0 p) distinct move comparisons, of P0(a single score difference falls below m); each term is a one- or two-dimensional non-central Gaussian event with non-centrality (n-1) delta^2_{T,l}/sigma*^2 and penalty (1/2) log(n+1) + log[(2p-k-1)/(k+1)].
- (iii) Corollary indexed by n: with s0, d fixed, l_n = ceil(log2(n+p+1)) >= s0 + d eventually, and G, R, SE, BM-infinity, the bound in (ii) -> 0, so TD(d, 0) holds with probability -> 1; clause (i) then replaces GAIN_d, LK_d and EXIT_d.
