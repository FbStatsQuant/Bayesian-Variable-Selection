## Statement (as proved)
Source: proofs/T22_T16_start_aggregation/STATEMENT.md and proofs/T22iii_T16_start_aggregation/STATEMENT.md; theorems/T22_T16_start_aggregation.md (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- PROVED-LOCKED (wave 1, parts (i), (ii), (iv-a), (iv-b) deterministic for every data realisation; (ii) and (iv) assume S0 in Omega, i.e. s0 <= K): with aggregation quantities q_n, e_n for a feasible reference S (size s): (i) if q_n < 1 then pi0(S) >= (1 - q_n)^(s+1) / (1 + e_n)^s and 1 - pi0(S) <= (s+1) q_n/(1 - q_n) + s e_n (also q_n <= u_n). (ii-a) pi0(S0) = pi0(S) [w(s0)/w(s)] prod_b r_b(S0 cap C_b)/r_b(S cap C_b) exactly; (ii-b) if S is contained in S0, pi0(S0)/pi0(S) >= prod_{j=0}^{s0-s-1} r_{s+j}. (iv-a) for 0 <= phi <= 1, 1/q_phi(S0) - 1 <= R0^(1-phi) R1^phi <= max(R0, R1); (iv-b) hence inf_phi q_phi(S0) >= min{pi0(S0), pi(S0)}: the bridge keeps mass on S0 at every temperature. (iv-c) is a conditional probabilistic consequence: if P0(S0 in Omega) -> 1, 1 - pi(S0) -> 0 (T03's conclusion) and 1 - pi0(S0) -> 0 (T22(iii)'s conclusion), then sup_phi [1 - q_phi(S0)] -> 0 in probability.
- PROVED-LOCKED but CONDITIONAL (wave 2, part (iii), folder T22iii_T16_start_aggregation, PROOF_v2): under G, R, within-block SE, VIS, NL_eta, the rate condition NL_avg(kappa) and EXP' (log[r_b(T+l)/r_b(T)] = -(1/2) log(n+1) - nu log(1 - x_{T,l}) + R with max |R| = O_P(1)): q_n <= u_n = O_P(2^B sqrt(log n) n^-kappa), e_n = o_P(n^-m) for every fixed m, and 1 - pi0(S0) = O_P(2^B sqrt(log n) n^-kappa + e_n). A weaker o_P(log n) remainder gives the exponent form.
- CONJECTURED (not proved): (v) block-orthogonal (BO) case: with SE, bounded signal energy and BM-infinity the projection argument supplies VIS; the score conclusion still needs EXP.
