## Statement (as proved)
Source: proofs/T06_T07_identifiability_size_prior/STATEMENT.md section 1 (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- (i) Exact ties. (a) For S, S' in Omega: F_S = F_S' on the contrast sphere iff X_S X_S^T = X_S' X_S'^T (outer products agree); then |S| = |S'| and F(S) = F(S') for every response. (b) If span(X_S) = span(X_S') but the outer products differ, the score functions differ somewhere; such feasible pairs exist at every n >= 4 (p = 4), never when K = 1. (c) Under G, P0-a.s. every exact tie F(S) = F(S') has equal outer products; under G and NIS, P0(there exist S != S' in Omega with F(S) = F(S')) = 0.
- (ii) Fallback without NIS. (a) Deterministic: on {pi(S0) > 1/2}, S0 in Omega and argmax F = {S0}, so S-dagger = S0 for every tie rule. (b) Conditional on H-T03 (T03(i): 1 - pi(S0) = O_P(r_n)): P0(pi(S0) > 1/2) -> 1.
- (iii) Duplicates and weak separation. (a)-(b) Under DUP(a), the transposition tau of i, j preserves size and F; PIP_i = PIP_j and pi(S) < 1/2 for S containing exactly one of i, j. (c) Two-point bound: for any selector delta, max_k P_k(delta != S_k) >= (1/2) sum_k P_k(delta != S_k) >= Phi(-||m1 - m2||/(2 sigma*)); location-invariant selectors: >= Phi(-||mu1 - mu2||/(2 sigma*)). (d) No uniform recovery over classes containing pairs with ||mu1 - mu2||/sigma_n -> 0 (liminf sup error >= 1/2). (e) The near-duplicate report (components of |r_ij| >= 1 - 1e-10) is a warning only: F_{A+i} = F_{A+j} iff |r_ij| = 1, and exact-tie pairs with max |r_ij| <= 1/sqrt(2) exist for every n >= 4 (p = 4).
