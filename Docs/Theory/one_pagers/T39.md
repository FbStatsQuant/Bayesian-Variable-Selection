- With s_n = 1 - (1 - a_n)^h - h eta_n > 0: P(S0 never scored | G_n) <= (1 - b_n s_n)^M <= exp(-M b_n s_n). Each track uses at most 1 + 2mh score evaluations (m = p + B + 2); choosing h = ceil(log 4 / a_n) with h eta_n <= 1/4 and M = ceil(2 b_n^-1 log(1/eps_n)) gives miss probability <= eps_n. With T21: P(no usable output or wrong HPM) <= P(U) + 2 E0[1 - pi(S0)] + delta_n + eps_n. If b_n >= n^-r, a_n >= n^-s, eta_n = o(a_n), expected discovery cost is C_setup + O(p n^(r+s)) score evaluations.
