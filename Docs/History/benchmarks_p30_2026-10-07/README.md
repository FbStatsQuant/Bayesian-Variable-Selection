Six scenarios S1–S6 × 100 datasets, the six benchmark methods of
`Methodology/SMC_Composite_Likelihood_Methodology.tex` (Section "Benchmark methods"). This folder holds the three
methods built by Claude on 2026-10-07 and the exact-reference stage; Lasso, elastic net and SSL were built separately
by another agent in the same shared framework. Decision log with sources: `DECISIONS.md`. Per-method protocol and

## The method contract (shared/run_task.R)

`fit_method(X, y, foldid, seed, control)` → `list(selected, beta, pip, converged, diagnostics, sensitivity, raw)`.
`selected` is the primary support (logical p), `sensitivity` a named list of alternative supports (tuning variants),
`pip` the PIP vector or NULL. The runner records data hashes, source hashes, seeds, runtime, warnings, and writes
`metrics.csv` with one row per rule (primary + sensitivities). Method seeds are `data seed + 1e6 × index`
(PARNI = 6, SuSIE = 7, Exact_best_sub = 8; Exact_best_sub and SuSiE are deterministic, the seed is recorded only).

| method folder   | primary rule                         | sensitivities                                    | cost / dataset (laptop) |
|-----------------|--------------------------------------|--------------------------------------------------|-------------------------|
| Exact_best_sub  | BIC over the exact RSS path, no cap  | EBIC_0.5, EBIC_1                                 | ~7 s                    |
| SuSIE           | IBSS (refine = FALSE), PIP > 0.5     | refine = TRUE support; top predictor of each CS  | ~3 s                    |
| PARNI           | plain PIP > 0.5 of repeat 1          | RB-PIP rule of repeat 1; plain rule of repeats 2–5 | ~140 s (5 repeats)    |

## Run order on NOTS (from `~/projects/BVS/Benchmarks`)

```bash
sbatch slurm/tests.slurm Exact_best_sub SuSIE PARNI                 # test gate -> audit/tests_<job>/gate.json
RUN=runs/smoke_$(date -u +%Y%m%dT%H%M%SZ)
for m in Exact_best_sub SuSIE PARNI; do sbatch --array=1-6 --job-name=smoke_$m slurm/task.slurm $m $RUN smoke; done
sbatch --array=1-6 Exact_reference/exact.slurm smoke                 # exact posterior of replicate 1 of every scenario
Rscript --vanilla shared/aggregate.R $RUN smoke Exact_best_sub SuSIE PARNI
Rscript --vanilla Exact_reference/compare_to_exact.R $RUN            # PIP error and exact-decision agreement
# production (only on the user's go):
bash slurm/submit_campaign.sh runs/production_<date> Exact_best_sub SuSIE PARNI     # 3 x 600-task arrays + aggregation
sbatch --array=1-600%300 Exact_reference/exact.slurm production                     # 600 exact references
Rscript --vanilla Exact_reference/compare_to_exact.R runs/production_<date>
```
