## X1. The noise event 𝓔_t

**Lemma X1.** Let n ≥ 3, p ≥ 2, ‖μ‖² ≤ nM. For every real t with 2 ≤ t ≤ N/64: (i) implies (iv), and
  P(𝓔_tᶜ) ≤ (2 + (2 + e)/(e − 1))e^{−2t} ≤ 4.75e^{−2t} ≤ e^{−t}.
Consequently, for M₀ > 0 and κ₀ ∈ (0, 1), with n₁ := max{3, ⌈e^{2/M₀}⌉, ⌈128^{1/κ₀}⌉}: for every n ≥ n₁ and **every**
t ∈ [M₀ log n, n^{1−κ₀}], P(𝓔_tᶜ) ≤ e^{−t} (one n₁ for the whole range; p ≤ n^A is not used).

*Proof.* (i): by (LM) with D = N and x = 2t, P(‖e‖²/σ*² − N ≥ 2√(2Nt) + 4t) ≤ e^{−2t} and P(N − ‖e‖²/σ*² ≥ 2√(2Nt)) ≤ e^{−2t}.
Failure ≤ 2e^{−2t}.
(ii-a): fix T with |T| = k ≥ 1 and let r := rank X_{c,T} ≤ k. ‖P_Te‖²/σ*² ~ χ²_r (r = 0: P_T = 0 and the display holds). By (LM)
with a_i ≡ 1 on r coordinates, P(χ²_r ≥ r + 2√(rx) + 2x) ≤ e^{−x}, and r + 2√(rx) + 2x ≤ 2r + 3x ≤ 2k + 3x (2√(rx) ≤ r + x). Take
x_k := k log p + k + 2t. Then 2k + 3x_k = 3k log p + 5k + 6t ≤ 3k(log p + 2) + 6t = 3kℓ_p + 6t. There are C(p, k) ≤ p^k sets of size k,
so the failure probability is ≤ Σ_{k=1}^p p^k e^{−k log p − k − 2t} = e^{−2t}Σ_{k≥1}e^{−k} = e^{−2t}/(e − 1). (k = 0: P_∅ = 0.)

C(p − s₀, k) ≤ p^k choices of J. Failure ≤ e^{−2t}/(e − 1).
(iii): fix S with |S| = k ≥ 0; a_S is deterministic and eᵀa_S ~ N(0, σ*²‖a_S‖²) (a_S = 0: trivial). By (G) with
x_k := k log p + k + 2t + log 2, P(|eᵀa_S| ≥ σ*‖a_S‖√(2x_k)) ≤ 2e^{−x_k}, and 2x_k = 2k log p + 2k + 4t + 2 log 2 ≤ 2k(log p + 2) + 6t =

Sum: e^{−2t}[2 + 1/(e−1) + 1/(e−1) + e/(e−1)] = e^{−2t}[2 + (2 + e)/(e − 1)] ≤ 4.75e^{−2t} ≤ e^{−t} since e^t ≥ e² > 4.75.
(iv) from (i): s_y² = ‖μ_c + e‖²/N ≤ 2‖μ‖²/N + 2‖e‖²/N. With ‖μ‖² ≤ nM and N ≥ 2n/3: 2‖μ‖²/N ≤ 3M. By (i) and t/N ≤ 1/64:
