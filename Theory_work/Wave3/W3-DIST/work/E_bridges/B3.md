## Statement

Assume the reader setting (`STATEMENT.md:128-169`) with (A1)–(A5) for the window of M = 1,
  q_n := min{p, ⌈C_q log n⌉},  C_q = 2(s(A + 2) + 4)/log 2,
exactly s ≥ 1 nonzero coordinates of β*, and (A6) (`STATEMENT.md:196-197`):
(a) λ_min(Corr(x_T)) ≥ ψ > 0 for every T with |T| ≤ (2A + 3)s + 2; (b) min_{β*_j≠0}|β*_j|·sd(x_j)/σ* ≥ b_n, b_n²n/log n → ∞.
By `B0.md` work in the unit-noise model (α* = 0, σ* = 1, coefficients β*/σ*; all interface constants in units of σ*²;
we keep the names β*, θ*, μ for the reduced objects). Let 𝒜_n := 𝓔₁ ∩ 𝓔₂(q_n) (`B1.md`, `B2core.md`). Put
  M_E := 2s²b̄², M_C := 2sb̄², B := M_E + M_C, φ₀² := ψ/4, g₀ := c_ψ/8, M_n := b_n²nψ/(8 log n), j₀ := ⌈(2A + 1)s⌉ + 1,
and m♯_n as in `W3-POST/STATEMENT.md:36-37` (computed with p = p_ret and s₀). For n ≥ max(3, 2s), on 𝒜_n:
(i) (TR₀; 2): E_x(a + uᵀx)² ≤ 2·n⁻¹Σ_i(a + uᵀx_i)² for all a ∈ ℝ and all u supported on supp β*.
(ii) p_ret = p ≥ 2, |supp θ*| = s, s ≤ K = min(p, ⌊n/2⌋).
(iii) (E; M_E): ‖μ‖² ≤ nM_E; (C; M_C); (L₀; B): L_{S₀} ≤ B.
(iv) (F_λ; φ₀) of `W3-POST/STATEMENT.md:68-70`: λ_min(X_{S₀∪J}ᵀX_{S₀∪J}/(n − 1)) ≥ φ₀² for every J ⊆ [p]∖S₀ with |J| ≤ j₀;
     and 0 < φ₀ ≤ ½ ≤ 1.
(v) (F_w; g₀) of `W3-POST/STATEMENT.md:71-73`: λ_min(X_{S₀∪J}ᵀX_{S₀∪J}) ≥ g₀ for every J ⊆ [p]∖S₀ with |J| ≤ m♯_n.
(vi) BM-∞ with a common deterministic envelope: θ*²_min nφ₀²/(σ*²log n) ≥ M_n (σ*² = 1 here), and M_n → ∞.
(vii) P(𝒜_nᶜ) ≤ 4p·e^{−c₁n/K⁴} + e^{−c₂n/K⁴} for n ≥ n_B(s, A, K) (`B2.md` (e) with M = 1); hence P(𝒜_n) → 1.
Consequently the hypotheses of W3-POST Theorem 1 item 6 (`W3-POST/STATEMENT.md:95-100`) hold for the unit-noise model
with the (X, θ*)-measurable events 𝒜′_n ⊇ 𝒜_n defined in Step 6 below, common constants (M_E, φ₀, g₀) and the common
envelope M_n; and the four design events of DIST-3 (`STATEMENT.md:95`) contain 𝒜_n with (M, B, C_T) = (M_E, B, 2).

## Proof

**Step 0 (sizes covered by the window).** *Claim:* every T ⊆ [p] with |T| ≤ max{(2A + 3)s + 2, s + m♯_n} has |T| ≤ q_n.
If q_n = p this holds because |T| ≤ p. Otherwise q_n = ⌈C_q log n⌉ and:
(1) (2A + 3)s + 2 ≤ C_q log n for n ≥ 3: C_q log n ≥ C_q log 3 = 2(sA + 2s + 4)(log 3/log 2) ≥ 3.16(sA + 2s + 4) ≥
2sA + 3s + 2 (each coefficient on the left dominates: 3.16 ≥ 2, 6.32 ≥ 3, 12.6 ≥ 2), using log 3/log 2 = 1.5849…;
(2) s + m♯_n ≤ ⌈C_q log n⌉: by the quoted bound with ω = ½log n and s₀ = s ≥ 1, using log C(p, s) ≤ s log p ≤ s log(2p) and
((s + 1)/2)log n + ½log n = ((s + 2)/2)log n ≤ ((s + 2)/2)log(n + 1), we get m♯_n ≤ min{K, s + ⌈(s log(2p) + ((s+2)/2)log(n+1)
+ 3log n)/log 2⌉} = m_n(log n) (`STATEMENT.md:62` with s₀ = s, t = log n; the extra 2 log n ≥ 0 only enlarges). By `B2.md`
(d) with M = 1: m_n(log n) + s ≤ ⌈C_q log n⌉. ∎

**Step 1 ((ii) and (iii)).** On 𝓔₁ (`B1.md` (b)): p_ret = p ≥ 2 (A2), supp θ* = supp β*, so |supp θ*| = s. K = min(p, ⌊n/2⌋)
≥ s because p ≥ s (β* has s nonzero coordinates among p) and ⌊n/2⌋ ≥ s for n ≥ 2s. (iii) is `B1.md` (c) in units
σ*² = 1 with |supp β*| = s. ∎

**Step 2 ((i)).** u supported on supp β* has at most s ≤ (2A + 3)s + 2 nonzero entries, hence (Step 0) at most q_n. Apply
`B2core.md` Corollary B2c on 𝓔₂(q_n) with m = E x, D_σ = diag(sd(x_j)) (sub-Gaussian, so second moments are finite):
E(a + uᵀx)² ≤ 2n⁻¹Σ_i(a + uᵀx_i)². This is (TR₀; 2) (`STATEMENT.md:94`). ∎

**Step 3 ((iv)).** Let T = S₀ ∪ J with J ⊆ [p]∖S₀, |J| ≤ j₀. Then |T| ≤ s + j₀ ≤ s + (2A + 1)s + 2 = (2A + 2)s + 2 ≤
(2A + 3)s + 2 (⌈y⌉ ≤ y + 1), so |T| ≤ q_n by Step 0 and (A6)(a) applies to T. As in `B2.md` (a) (G_T = nΛ_TΣ̂^z_TΛ_T), on
𝓔₁ ∩ 𝓔₂(q_n), for u ∈ ℝ^T and ũ = Λ_Tu:
  uᵀG_Tu ≥ (n/2)ũᵀCorr(x_T)ũ ≥ (n/2)ψ‖ũ‖² ≥ (n/2)ψ(½)‖u‖² = (nψ/4)‖u‖².
So λ_min(G_T/(n − 1)) ≥ nψ/(4(n − 1)) ≥ ψ/4 = φ₀². (T = S₀, J = ∅, is included.) Finally ψ ≤ 1 because λ_min(Corr(x_T))
≤ trace/|T| = 1, so φ₀ = √ψ/2 ∈ (0, ½]. ∎

**Step 4 ((v)).** For J ⊆ [p]∖S₀ with |J| ≤ m♯_n, |S₀ ∪ J| ≤ s + m♯_n ≤ q_n (Step 0), so `B2.md` (a) gives
λ_min(G_{S₀∪J}) ≥ c_ψ/4 ≥ g₀ (for J = ∅ and s ≥ 1 as well). ∎
*Remark.* m♯_n depends on (n, p, s₀) only (`W3-POST/STATEMENT.md:36-37`: "data-free"), so (F_w; g₀) is a statement about
X alone; on 𝒜_n, (p_ret, s₀) = (p, s).

**Step 5 ((vi)).** In the unit-noise model θ*_j = ŝ_jβ*_j/σ* (B0 (f); here β* denotes the original coefficients). On 𝓔₁,
ŝ_j² ≥ Var(x_j)/2, so for j ∈ supp β*, by (A6)(b),
  θ*_j² ≥ Var(x_j)β*_j²/(2σ*²) ≥ b_n²/2,
hence θ*²_min nφ₀²/log n ≥ (b_n²/2)·n·(ψ/4)/log n = b_n²nψ/(8 log n) = M_n, deterministic, and M_n → ∞ because
b_n²n/log n → ∞ and ψ > 0 is fixed. ∎

**Step 6 (item 6's events; DIST-3's design events; (vii)).** *Item 6.* `W3-POST/STATEMENT.md:95-98` asks for
"(X, θ*)-measurable events 𝒜_n with P(𝒜_n) → 1 on which |supp θ*| = s₀ and (E), (F_λ), (F_w) hold with common constants
(M, φ₀, g₀) and (BM) holds with … a common deterministic envelope M_n → ∞", in regime R1 (`:63-64`: s₀ ≥ 1 fixed,
2 ≤ p ≤ n^A, s₀ ≤ K eventually, σ*² > 0 fixed, G) with ε independent of (X, θ*). Define 𝒜′_n as the set of outcomes for
which (p_ret, X, θ*) satisfies: |supp θ*| = s, ‖Xθ*‖² ≤ nM_E, (F_λ; φ₀), (F_w; g₀) (with m♯_n computed from (n, p_ret, s)),
and θ*²_min nφ₀²/log n ≥ M_n. Each condition is a finite collection of inequalities between continuous functions
(norms, smallest eigenvalues of Gram submatrices) of (X, θ*), indexed by the finitely many subsets of [p_ret]; so 𝒜′_n
is (X, θ*)-measurable. By Steps 1–5, 𝒜_n ⊆ 𝒜′_n (μ = Xθ*). R1 holds: s₀ = s ≥ 1 fixed; p ≥ 2 and p ≤ n^A by (A2); s ≤ K for
n ≥ 2s (Step 1); σ*² = 1 (B0); G: ε/σ* ~ N(0, I_n) independent of the design (B0 (e)), and θ* is design-measurable.
*DIST-3.* Its design events 𝒟_n ∩ (E; M) ∩ (L₀; B) ∩ (TR₀; C_T) contain 𝒜_n with (M, B, C_T) = (M_E, B, 2) by (i)–(iii).
*(vii).* `B2.md` (e) with M = 1 (then q_n = min{p, ⌈C_q log n⌉}): for n ≥ n_B(s, A, K), q_n log(ep/q_n) ≤ c₂n/K⁴ and
P(𝒜_nᶜ) ≤ 4pe^{−c₁n/K⁴} + e^{−c₂n/K⁴} ≤ 5n^Ae^{−c₂n/K⁴} → 0 (c₂ ≤ c₁, p ≤ n^A). Hence P(𝒜′_n) ≥ P(𝒜_n) → 1. ∎
