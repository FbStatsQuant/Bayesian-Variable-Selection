# B1 — single-coordinate sub-Gaussianity and (A5) ⇒ 𝒟_n, (E), (C), (L₀)

**Status: DRAFT (by this seat, unchecked).** Stream E, ticket W3-DIST. Target: `STATEMENT.md:346-350` (v1.3.1).
Absolute constant: **c₁ = 1/576**. Numerical sanity checks: `bridges_checks.py`, checks "B1 exponents", "B1 empirical".

## Statement

Let x_1, …, x_n be i.i.d. copies of x ∈ ℝ^p, p ≥ 1, with Var(x_j) ∈ (0, ∞) for every j, and z_j := (x_j − E x_j)/sd(x_j).
Let K > 0 be such that for every j ≤ p and every λ ∈ ℝ
  E exp(λz_j) ≤ exp(K²λ²/2).                                                           (SG₁)
Let ŝ_j² := (n − 1)⁻¹Σ_i(x_{ij} − x̄_j)² and 𝓔₁ := {½ ≤ ŝ_j²/Var(x_j) ≤ 2 for every j ≤ p}.

(a) K ≥ 1, and for n ≥ 3: P(𝓔₁ᶜ) ≤ 4p·exp(−c₁n/K⁴) with c₁ = 1/576.
(b) On 𝓔₁ no column is constant in the sample: p_ret = p, and θ*_j = ŝ_jβ*_j ≠ 0 iff β*_j ≠ 0, so S₀ = supp β* and
    s₀ = |supp β*|. If p ≥ 2, 𝓔₁ ⊆ 𝒟_n.
(c) Suppose in addition |supp β*| ≤ s and |β*_j|·sd(x_j) ≤ b̄σ* for every j (reader (A5)). On 𝓔₁:
    ‖μ‖² ≤ 2s²b̄²σ*²(n − 1) ≤ n·(2s²b̄²)σ*²,   ‖θ*‖² ≤ 2sb̄²σ*² ≤ n·(2sb̄²)σ*²,
    i.e. (E; M_E) and (C; M_C) in units of σ*² with M_E := 2s²b̄², M_C := 2sb̄²; and
    L_{S₀} ≤ (‖μ‖² + ‖θ*‖²)/n ≤ (M_E + M_C)σ*², i.e. (L₀; M_E + M_C) in units of σ*².
(Here μ = CX^rβ*, θ* = D_xβ* with D_x = diag(ŝ_j), X = CX^rD_x⁻¹, as in `STATEMENT.md:32-33`; L_S as in `API_CARDS.md:14`.)

Remark (DIST-2 needs less). If (SG₁) is assumed only for j ∈ J₀ := supp β* ∪ {j₁, j₂} with j₁ ≠ j₂ outside supp β* (or
any two indices when |supp β*| ≤ 1), the same proof gives, with probability ≥ 1 − 4|J₀|e^{−c₁n/K⁴}, the event
𝓔₁(J₀) := {½ ≤ ŝ_j²/Var(x_j) ≤ 2, j ∈ J₀}, on which p_ret ≥ 2, S₀ = supp β*, and (c) holds (its proof uses only j ∈ supp β*).

## Proof

**Lemma B1.0 (scalar sub-Gaussian facts).** Let Y be real with E exp(λY) ≤ exp(κ²λ²/2) for all λ ∈ ℝ (κ > 0). Then
(i) P(|Y| > t) ≤ 2exp(−t²/(2κ²)) for t ≥ 0; (ii) E Y^{2k} ≤ 2·k!·(2κ²)^k for every integer k ≥ 1; (iii) E Y² ≤ κ².
*Proof.* (i) Markov: P(Y > t) ≤ e^{−λt}E e^{λY} ≤ exp(−λt + κ²λ²/2) for λ > 0; λ = t/κ² gives exp(−t²/(2κ²)). The same
for −Y (its mgf bound is the same, replace λ by −λ). Add. (ii) By Tonelli and (i),
  E Y^{2k} = ∫₀^∞ 2k t^{2k−1} P(|Y| > t) dt ≤ 4k ∫₀^∞ t^{2k−1} e^{−t²/(2κ²)} dt = 4k · ½(2κ²)^k Γ(k) = 2·k!·(2κ²)^k,
using ∫₀^∞ t^{2k−1}e^{−t²/c}dt = c^kΓ(k)/2 (substitute u = t²/c). (iii) cosh u ≥ 1 + u²/2 for all real u, so
1 + λ²EY²/2 ≤ E cosh(λY) = ½(E e^{λY} + E e^{−λY}) ≤ e^{κ²λ²/2}; hence EY² ≤ 2(e^{κ²λ²/2} − 1)/λ² for every λ ≠ 0, and
letting λ → 0 gives EY² ≤ κ². ∎

**Lemma B1.1 (mgf of Z² − 1).** Let Z be real with EZ² = 1 and E exp(λZ) ≤ exp(K²λ²/2) for all λ. Then K ≥ 1 and
  E exp(λ(Z² − 1)) ≤ exp(16λ²K⁴) for 0 ≤ λ ≤ 1/(4K²),   E exp(−μ(Z² − 1)) ≤ exp(8μ²K⁴) for every μ ≥ 0.
*Proof.* K ≥ 1 by Lemma B1.0(iii): 1 = EZ² ≤ K². Upper side: by monotone convergence (all terms ≥ 0),
E e^{λZ²} = Σ_{k≥0} λ^k EZ^{2k}/k! = 1 + λ + Σ_{k≥2} λ^k EZ^{2k}/k!. By B1.0(ii), EZ^{2k}/k! ≤ 2(2K²)^k, so for
2λK² ≤ ½:  Σ_{k≥2} λ^kEZ^{2k}/k! ≤ 2Σ_{k≥2}(2λK²)^k = 2(2λK²)²/(1 − 2λK²) ≤ 4(2λK²)² = 16λ²K⁴. Hence
E e^{λZ²} ≤ 1 + λ + 16λ²K⁴ ≤ e^{λ + 16λ²K⁴} (1 + u ≤ e^u). Multiply by e^{−λ}. Lower side: e^{−u} ≤ 1 − u + u²/2 for u ≥ 0
(the difference has non-negative second derivative 1 − e^{−u} ≥ 0 and vanishes with its first derivative at 0), so
E e^{−μZ²} ≤ 1 − μ + μ²EZ⁴/2 ≤ 1 − μ + 8μ²K⁴ (EZ⁴ ≤ 2·2!·(2K²)² = 16K⁴ by B1.0(ii)) ≤ e^{−μ + 8μ²K⁴}. Multiply by e^{μ}. ∎

**Proof of (a).** K ≥ 1 by Lemma B1.1 applied to Z = z_1 (Var(z_1) = E z_1² = 1). Fix j and write Z_i := z_{ij}
(i.i.d., distributed as z_j), W := n⁻¹Σ_iZ_i², Z̄ := n⁻¹Σ_iZ_i. Since x_{ij} − x̄_j = sd(x_j)(Z_i − Z̄),
  ŝ_j²/Var(x_j) = (n − 1)⁻¹Σ_i(Z_i − Z̄)² = (n − 1)⁻¹ n (W − Z̄²).                           (B1.1)
*Three tail bounds.* (1) For μ := 1/(64K⁴) (Chernoff with the lower mgf bound, δ = ¼):
  P(W ≤ ¾) = P(Σ_i(1 − Z_i²) ≥ n/4) ≤ e^{−μn/4}(E e^{μ(1 − Z²)})^n ≤ exp(−μn/4 + 8nμ²K⁴) = exp(−n/(512K⁴)),
  since −μ/4 + 8μ²K⁴ = −1/(256K⁴) + 1/(512K⁴) = −1/(512K⁴).
(2) For λ := 1/(96K⁴) (≤ 1/(4K²) because K ≥ 1), δ = ⅓:
  P(W ≥ 4/3) = P(Σ_i(Z_i² − 1) ≥ n/3) ≤ e^{−λn/3}(E e^{λ(Z² − 1)})^n ≤ exp(−λn/3 + 16nλ²K⁴) = exp(−n/(576K⁴)),
  since −λ/3 + 16λ²K⁴ = −1/(288K⁴) + 16/(9216K⁴) = −1/(288K⁴) + 1/(576K⁴) = −1/(576K⁴).
(3) E e^{λZ̄} = Π_iE e^{(λ/n)Z_i} ≤ exp(K²λ²/(2n)), so by Lemma B1.0(i) with κ² = K²/n:
  P(|Z̄| ≥ ½) ≤ 2exp(−n/(8K²)) ≤ 2exp(−n/(8K⁴))  (K ≥ 1).
*On the complement of the three events* (W > ¾, W < 4/3, |Z̄| < ½), by (B1.1):
  lower: n(W − Z̄²) ≥ n(¾ − ¼) = n/2 ≥ (n − 1)/2, so ŝ_j²/Var(x_j) ≥ ½;
  upper: n(W − Z̄²) ≤ nW ≤ 4n/3 ≤ 2(n − 1) (the last step is 4n ≤ 6n − 6, i.e. n ≥ 3), so ŝ_j²/Var(x_j) ≤ 2.
So P(½ ≤ ŝ_j²/Var(x_j) ≤ 2 fails) ≤ e^{−n/(512K⁴)} + e^{−n/(576K⁴)} + 2e^{−n/(8K⁴)} ≤ 4e^{−n/(576K⁴)}, because each of the
three exponents is ≥ n/(576K⁴). A union bound over j ≤ p gives (a) with c₁ = 1/576. ∎(a)

**Proof of (b).** On 𝓔₁, ŝ_j² ≥ Var(x_j)/2 > 0 for all j, so no column is constant in the sample and the code retains all
of them (`STATEMENT.md:23-25`): p_ret = p. θ*_j = ŝ_jβ*_j with ŝ_j > 0, so supp θ* = supp β*. 𝒟_n = {p_ret ≥ 2}
(`STATEMENT.md:26`). ∎(b)

**Proof of (c).** μ = CX^rβ* = Σ_{j∈supp β*} β*_j Cx^r_j, with ‖Cx^r_j‖² = Σ_i(x_{ij} − x̄_j)² = (n − 1)ŝ_j². By the
triangle inequality, on 𝓔₁ (ŝ_j ≤ √2 sd(x_j)) and with (A5),
  ‖μ‖ ≤ Σ_{j∈supp β*} |β*_j| ŝ_j √(n − 1) ≤ √2 √(n − 1) Σ_{j∈supp β*} |β*_j| sd(x_j) ≤ √2 √(n − 1) · s b̄σ*,
so ‖μ‖² ≤ 2s²b̄²σ*²(n − 1) ≤ n·2s²b̄²σ*². Next ‖θ*‖² = Σ_{j∈supp β*} ŝ_j²β*_j² ≤ 2Σ_{j∈supp β*}(sd(x_j)β*_j)² ≤ 2sb̄²σ*²
≤ n·2sb̄²σ*² (n ≥ 1). For L_{S₀}: by the variational formula of `API_CARDS.md:10-11` applied with y_c replaced by μ_c
(the formula is an identity for every vector; derivation below), L_S = min_φ{‖μ_c − X_{c,S}φ‖² + φᵀ(G_S + I)φ/n}. Take S = S₀
and φ = θ*_{S₀}: μ = Xθ* = X_{S₀}θ*_{S₀}, so μ_c = Uᵀμ = X_{c,S₀}θ*_{S₀} and the first term is 0; the second is
(θ*ᵀG_{S₀}θ* + ‖θ*‖²)/n = (‖X_{S₀}θ*‖² + ‖θ*‖²)/n = (‖μ‖² + ‖θ*‖²)/n. Hence L_{S₀} ≤ (‖μ‖² + ‖θ*‖²)/n ≤ (2s²b̄² + 2sb̄²/n)σ*²
≤ (M_E + M_C)σ*².
*Derivation of the variational formula.* For a ∈ ℝ^N, X := X_{c,S}, G = XᵀX = G_S (U is an isometry on 1^⊥ ∋ columns of
X_S, so X_{c,S}ᵀX_{c,S} = X_SᵀUUᵀX_S = X_SᵀX_S), the function φ ↦ ‖a − Xφ‖² + φᵀ(G + I)φ/n is strictly convex with gradient
−2Xᵀa + 2Gφ + 2(G + I)φ/n = −2Xᵀa + 2H_Sφ/n, H_S = (n + 1)G + I; its minimiser is φ̂ = nH_S⁻¹Xᵀa and the minimum is
aᵀa − 2aᵀXφ̂ + φ̂ᵀ(G + (G + I)/n)φ̂ = aᵀa − 2aᵀXφ̂ + φ̂ᵀH_Sφ̂/n = aᵀa − aᵀXφ̂ = aᵀ(I − nXH_S⁻¹Xᵀ)a = aᵀ(I − M_S)a. ∎(c)

**Proof of the Remark.** (a)'s per-coordinate bound is used only for j ∈ J₀; (b): the j ∈ J₀ are retained, |J₀| ≥ 2;
S₀ = supp β* because supp β* ⊆ J₀ is retained (a dropped column outside J₀ carries β*_j = 0); (c) uses only j ∈ supp β*. ∎
