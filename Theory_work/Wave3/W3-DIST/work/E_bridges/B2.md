## Statement

be an integer, and assume (SG_q) of `B2core.md` (reader (A3) with window q) and
  (A4_q)  λ_min(Corr(x_T)) ≥ c_ψ/n for every T ⊆ [p] with 1 ≤ |T| ≤ q.
Let 𝓔₁ be the event of `B1.md` and 𝓔₂(q) that of `B2core.md`. X = CX^rD_x⁻¹ (standardised columns, ‖x_j‖² = n − 1),

(c) For S₀ = supp θ* (s₀ = |S₀|) and every integer m ≥ 0 with min{m + s₀, p} ≤ q, (ND; c_D, m) of `STATEMENT.md:54-55`

(e) (Probability.) If q_n log(ep/q_n) ≤ c₂n/K⁴ then P((𝓔₁ ∩ 𝓔₂(q_n))ᶜ) ≤ 4p·e^{−c₁n/K⁴} + e^{−c₂n/K⁴} (n ≥ 3). If p ≤ n^A and

## Proof

**(a).** Write x_{ij} = E x_j + sd(x_j)z_{ij}. Then Cx^r_j = sd(x_j)Cz_{·j} and x_j = Cx^r_j/ŝ_j = (sd(x_j)/ŝ_j)Cz_{·j}. For
T ⊆ [p] let Z_T ∈ ℝ^{n×|T|} have entries z_{ij}, j ∈ T, and Λ_T := diag(sd(x_j)/ŝ_j : j ∈ T). Then X_T = CZ_TΛ_T and, as
CᵀC = C,
  G_T = Λ_TZ_TᵀCZ_TΛ_T = n·Λ_TΣ̂^z_TΛ_T,   Σ̂^z_T = n⁻¹Σ_i(z_{i,T} − z̄_T)(z_{i,T} − z̄_T)ᵀ.
For u ∈ ℝ^T put ũ := Λ_Tu (same support, padded by zeros to ℝ^p it has |T| ≤ q nonzero entries). On 𝓔₂(q)
(`B2core.md`, "in particular") and by (A4_q), Corr(x_T) = Corr(z_T) = Γ_T:
  uᵀG_Tu = n·ũᵀΣ̂^z_Tũ ≥ (n/2)ũᵀΓ_Tũ ≥ (n/2)(c_ψ/n)‖ũ‖² = (c_ψ/2)Σ_{j∈T}(sd(x_j)²/ŝ_j²)u_j² ≥ (c_ψ/4)‖u‖²,
the last step by ŝ_j² ≤ 2Var(x_j) on 𝓔₁. Hence λ_min(G_T) ≥ c_ψ/4 ≥ c_ψ/8 = g₀. ∎(a)

**(b).** *Spectral form of D.* For |T| = k ≥ 1 let λ_1 ≥ … ≥ λ_k ≥ 0 be the eigenvalues of G_T and G_T = QΛQᵀ (Q orthogonal).
Then H_T = Q((n + 1)Λ + I)Qᵀ and G_T + I = Q(Λ + I)Qᵀ, so
  D_T = Π_{l=1}^k φ(λ_l),   φ(λ) := ((n + 1)λ + 1)/(λ + 1).
φ is increasing on [0, ∞) (φ′(λ) = n/(λ + 1)² > 0), φ(0) = 1. For T = ∅ the empty product is 1 = D_∅.
*One column.* Let S ⊆ [p], |S| = k ≥ 0, j ∉ S, S′ := S ∪ {j}. Reorder coordinates so that j is last; this is a
permutation similarity and changes neither spectra nor determinants. G_S is the leading k × k principal submatrix of G_{S′}.
Let μ_1 ≥ … ≥ μ_{k+1} be the eigenvalues of G_{S′} and λ_1 ≥ … ≥ λ_k those of G_S. *Interlacing (the half used):*
μ_l ≥ λ_l for l ≤ k. Proof (Courant–Fischer): μ_l = max_{dim V = l} min_{v∈V, ‖v‖=1} vᵀG_{S′}v; restricting to subspaces
V = V′ × {0}, V′ ⊆ ℝ^k, for which vᵀG_{S′}v = v′ᵀG_Sv′, gives μ_l ≥ max_{dim V′=l} min_{v′∈V′, ‖v′‖=1} v′ᵀG_Sv′ = λ_l. Hence,
since φ is increasing and positive,
  D_{S′}/D_S = φ(μ_{k+1})·Π_{l=1}^k φ(μ_l)/φ(λ_l) ≥ φ(μ_{k+1}) = φ(λ_min(G_{S′})).                      (B2.1)
(For k = 0 the product is empty and (B2.1) is an equality.)
*Iteration.* Let S, J be disjoint with |S ∪ J| ≤ q, J = {j_1, …, j_r}, r ≥ 1, S_l := S ∪ {j_1, …, j_l}. Each S_l (l ≥ 1) has
1 ≤ |S_l| ≤ q, so λ_min(G_{S_l}) ≥ g₀ by (a), and by (B2.1) and monotonicity of φ,
  D_{S_l}/D_{S_{l−1}} ≥ φ(g₀) = ((n + 1)g₀ + 1)/(g₀ + 1) ≥ (n + 1)g₀/(1 + g₀) = c_D(n + 1).
Multiplying over l = 1, …, r: D_{S∪J}/D_S ≥ [c_D(n + 1)]^r. ∎(b)

**(c).** (ND; c_D, m) asks, for every 1 ≤ j ≤ min(m, p − s₀),
C(p − s₀, j)⁻¹Σ_{J⊆[p]∖S₀, |J|=j}(D_{S₀}/D_{S₀∪J})^{1/2} ≤ [c_D(n + 1)]^{−j/2}. For such j, |S₀ ∪ J| = s₀ + j ≤
min{s₀ + m, p} ≤ q, so by (b) every summand is ≤ [c_D(n + 1)]^{−j/2}, and so is their average. If m ≤ q − s₀ then
min{m + s₀, p} ≤ m + s₀ ≤ q. ∎(c)

**(d).** m_n(t) ≤ s₀ + ⌈N(t)/log 2⌉ ≤ s₀ + 1 + N(t)/log 2 with N(t) := s₀log(2p) + ((s₀ + 2)/2)log(n + 1) + 3t (the min
with K only lowers m_n). With s₀ ≤ s, p ≤ n^A (so log(2p) ≤ log 2 + A log n), log(n + 1) ≤ 2log n (n + 1 ≤ n² for n ≥ 2) and
t = M log n:
  N(M log n) ≤ s log 2 + (sA + s + 2 + 3M) log n,
  m_n(M log n) + s ≤ 2s + 1 + s + (sA + s + 2 + 3M) log n/log 2 = 3s + 1 + (sA + s + 2 + 3M) log n/log 2.
It suffices that the right side is ≤ C_qM log n = 2(sA + 2s + 4)M log n/log 2, i.e. (multiply by log 2)
  (3s + 1) log 2 ≤ [2(sA + 2s + 4)M − (sA + s + 2 + 3M)] log n = [(2sA + 4s + 5)M − (sA + s + 2)] log n.
Since M ≥ 1 and 2sA + 4s + 5 > 0, the bracket is ≥ (2sA + 4s + 5) − (sA + s + 2) = sA + 3s + 3 ≥ 3s + 3, and log n ≥ log 2,
so the right side is ≥ (3s + 3) log 2 ≥ (3s + 1) log 2. Hence m_n(M log n) + s ≤ C_qM log n ≤ ⌈C_qM log n⌉.
*Consequences.* m_n is non-decreasing in t (N(t) is increasing, ⌈·⌉ and min{K, ·} are monotone), so for t ≤ M log n:
m_n(t) + s₀ ≤ m_n(M log n) + s ≤ ⌈C_qM log n⌉, and min{m_n(t) + s₀, p} ≤ min{⌈C_qM log n⌉, p} = q_n. On 𝓔₁, p_ret = p and
s₀ = |supp β*| ≤ s (`B1.md` (b)), so m_n (defined with p = p_ret and s₀) is the function bounded above, and (c) with
q = q_n gives (ND; c_D, m_n(t)). (Grid check of the inequality: 156 240 cases, `bridges_checks_out.txt`.) ∎(d)

**(e).** q′ = min(q_n, p) = q_n. The bound is `B1.md` (a) plus `B2core.md` (hypothesis (SG_{q_n}) is (A3) with window
q_n). For the second sentence: q_n ≤ ⌈C_qM log n⌉ ≤ C_qM log n + 1 ≤ C_q√n + 1 (M log n ≤ √n), and log(ep/q_n) ≤
1 + log p ≤ 1 + A log n (q_n ≥ 1); so q_n log(ep/q_n) ≤ (C_q√n + 1)(1 + A log n) ≤ c₂n/K⁴ for n ≥ n_B. ∎(e)

## Remarks
1. (A4_q) is needed on sets of size up to q_n = O(M log n), because (ND) is needed on |J| ≤ m_n(t) and t is of order
   M log n; this is why the reader's window depends on M (`ROUTES.md:104-105`).
2. The multiplicative form of `B2core.md` is what allows the floor c_ψ/n in (A4): an additive (Weyl-type) transfer would
   need the population floor to dominate the sampling error of order √(q log p/n) (compare W3-POST Corollary 1R,
   `W3-POST/STATEMENT.md:106-109`, which needs ψ_n√n/(log n)^{3/2} → ∞).
3. (b) holds for every anchor S, not only S₀; (c) is the averaged form actually consumed by (1.1).
