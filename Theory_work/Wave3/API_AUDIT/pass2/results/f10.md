2. **Measurability of g** (L3_freezing.md:28-33). Φ is jointly measurable on E × Υ with the dummy record off A_s (B-d, L1_bridge.md:119-125). 3. **Uniform bound** (L3_freezing.md:34-36). On A₀ the grid has Δ_t > 0 and Σ_t Δ_t = φ_T − φ₀ = 1. Under EX-A and START, (B-a) gives Ẑ = Z₀ ∏_t (1/N)Σ_i e^{Δ_t d(S_i)}. Each factor is an average of numbers in [e^{Δ_t min d}, e^{Δ_t max d}], so Ẑ ≤ Z₀ e^{max_Ω d}. Here d and Z₀ = m(∅)Z̄₀ are data-only quantities (STATEMENT §0; Ω finite, m > 0, so d is finite). Hence |g| ≤ B_h Z₀ e^{max_Ω d} uniformly in (c,u). The arithmetic is correct, and the bound holds for every u, not just a.s. OK.

4. **Hypotheses of the freezing lemma** (L3_freezing.md:37). It needs g bounded and product-measurable (items 2–3) and 𝓒 independent of U_r. Independence holds because 𝓒 is a function of fixed data and streams 0–9 (CAL) and stream 9 + r is independent of those (SI). No independence between islands is used. U_r has the same iid U[0,1) law as U under H-U, so ḡ(c) = E[g(c,U)], which is ψ_q(c) on A₀ and 0 off A₀ and so matches the statement. OK.
