**Lemma CR (lines 12–30) — no problem found.**
- **Reduction and representation (17–21).** Affine invariance justifies means 0 and variances 1. With v = ru + sw and Cv = rCu + sCw, one gets ⟨Cu,Cv⟩/N = rα + sγ = e₁ᵀMx, ‖Cu‖²/N = e₁ᵀMe₁ and ‖Cv‖²/N = xᵀMx, so the displayed formula for r̂ is correct.
- **Deterministic bound on E_η (22–25).** ‖Δ‖_op ≤ ‖Δ‖_F ≤ 2η is correct, so |e₁ᵀΔx| ≤ 2η and both quadratic forms lie in [1−2η, 1+2η]; d is their geometric mean and lies in the same interval. The decomposition r̂ − r = (e₁ᵀMx − r)/d + r(1/d − 1) is exact. With |1/d − 1| ≤ 2η/(1−2η) and |r| ≤ 1 the total is 4η/(1−2η) ≤ 8η for η ≤ ¼.
- **χ² tails (26–27).** Nα and Nβ are χ²_N with N = n−1 ≥ 2. Upper tail with x = Nη²/16: 2√(Nx) + 2x = Nη/2 + Nη²/8 ≤ Nη. Lower tail with x = Nη²/4: 2√(Nx) = Nη. Both applications of [LM] are within its hypotheses.
- **Cross term (28).** Given u, ⟨Cu,w⟩ ~ N(0, Nα). On {α ≤ 2} the Gaussian tail gives 2exp(−N²η²/(2Nα)) ≤ 2e^{−Nη²/4}.
- **Event bookkeeping (29).** The event {α > 1+η} is already counted among the χ² terms, so P(E_ηᶜ) ≤ 2e^{−Nη²/16} + 2e^{−Nη²/4} + 2e^{−Nη²/4} ≤ 6e^{−Nη²/16}.
- **Constant (29–30).** η = δ/8 ≤ ¼ exactly when δ ≤ 2, and Nη²/16 = Nδ²/1024. Since |r̂ − r| ≤ δ on E_η, {|r̂ − r| > δ} ⊆ E_ηᶜ.
