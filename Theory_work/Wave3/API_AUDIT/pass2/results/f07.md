**What I checked in the corollary's own proof (`lemmas/E_corollary.md:14-21`)**

- **Pointwise bound (`:14-15`).** For S ∈ Ω, both h(S; c) and h(S₀; c) lie in [0,1], so |h(S; c) − h(S₀; c)| ≤ 1{S ≠ S₀}. This also holds when S₀ ∉ Ω, since h is assumed defined on Ω ∪ {S₀}.
- **Averaging (`:15-16`).** The triangle inequality over the 4N_e endpoints gives |H_r(h) − h(S₀; 𝓒)| ≤ H_r(1{S ≠ S₀}) for every realisation. The endpoints lie in Ω, so each term is covered.
- **Conditional expectation (`:17-19`).**
  - Multiplying by 1_{E₀}W_r ≥ 0 preserves the inequality.
  - Both sides are bounded on E₀, because W_r ≤ Z₀e^{max d}/Z by the Lemma F bound and |H_r − h(S₀)| ≤ 1.
  - They vanish off E₀, so monotonicity of E[· | 𝓒] applies in the localised form.
  - Only measurability of h(·; 𝓒) is needed here; N1 is not applied to h itself.
- **Equality (`:19-21`).** h₀ = 1{S ≠ S₀} is deterministic (S₀ and the data are fixed), has values in [0,1], and does not depend on any final stream. It is therefore admissible for N1 with B_h = 1.
  - If S₀ ∈ Ω, π(h₀) = 1 − π(S₀) = δ₁.
  - If S₀ ∉ Ω, h₀ ≡ 1 on Ω and π(h₀) = 1 = δ₁ under the convention π(S₀) := 0.
- **Final step and tightness.** δ₁ ≥ 0 gives δ₁ ≤ 2δ₁. For h = h₀, h₀(S₀) = 0 and H_r(h₀) ≥ 0, so the first inequality is an equality.
