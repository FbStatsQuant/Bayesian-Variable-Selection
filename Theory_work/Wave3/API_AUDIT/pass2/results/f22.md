- **Well-definedness (:7-13).** `mb[b][j]` for j ≤ t_b = min(|C_b|, K) only reads `logr` entries with |U| ≤ K, which are finite by (H1), and `arg[b][j]` is non-empty because size-j codes exist for j ≤ |C_b|. `M[b][0] = 0` for all b by induction (only j = 0 is admissible), so `logprior[0] + M[J][0]` is finite. Hence the maximum over k is finite, k̂ exists and `M[J][k̂]` is finite. Each finite `M[b][r]` is a maximum of finitely many doubles, so it is attained exactly by some admissible j, which is a tight edge with finite `M[b−1][r−j]`. Descending ends at b = 0 with a finite `M[0][r_0]`, which forces r_0 = 0. So E ≠ ∅ and step (2) is correct.
- **Size of E (:20).** Σ j_b = r_J − r_0 = k̂. Correct.
- **Step (1) (:43-47).**
  - (⇐) Constraints on S restrict blockwise because the blocks partition the index set; `reach[0][0]` is true and induction along the tight path gives `reach[J][k̂]`. Correct.
  - (⇒) Unrolling `reach[J][k̂]` gives tight edges with `allowed_{b−1}(j)`, and the chain must end at `reach[0][0]`, so r_0 = 0 and the path is tight in the sense of :16. The witnesses c_b ∈ `arg[b][j_b]` assemble to S ∈ E with IN ⊆ S and S ∩ OUT = ∅. Correct, and the block indexing b−1 versus b is consistent throughout.
- **Step (3) (:50-53).** Inv(0) is trivial.
  - If i ∈ S_E, then S_E itself witnesses feasibility: IN ∪ {i} ⊆ S_E and OUT = {0..i−1} ∖ S_E.
  - If i ∉ S_E and some S ∈ E is consistent with (IN ∪ {i}, OUT), then S ∩ {0..i−1} = IN = S_E ∩ {0..i−1} because IN ∪ OUT = {0..i−1}. So min(S Δ S_E) = i ∈ S. Both sets have size k̂, so L1(iii) applies within its hypothesis and gives S lex-smaller than S_E, a contradiction.
  - Inv(p) gives IN = S_E. Correct.
- **Arithmetic.** The argument uses only the computed doubles and exact `==` comparisons. No exactness or monotonicity of floating-point addition is needed, so it holds verbatim in binary64, and also under exact arithmetic. ±0 is harmless because `==` treats them as equal on both sides.

The first sentence of the claim (TDP-E returns lex_min E in binary64) is proved.
