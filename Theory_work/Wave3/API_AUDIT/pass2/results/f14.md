The range j ∈ {0,…,min(t_{b−1},k)} is exact, because k ≤ K gives min(t_{b−1},k) = min(|C_{b−1}|,k). "Max of a sum = sum of maxima" is applied to a product set; when Ch_{b−1}(k−j) = ∅ the term is −∞, which the stated convention handles, and μ_{b−1}(j) is always real (C(|C_{b−1}|, j) ≥ 1).

  - The strict update `v > M[b][k]` computes the running maximum (exact under (H2)).

- **Use of L2.** I re-read L2's proof (L2_block_maxima.md:27-41), since L3 depends on `mb` = μ and the vector lengths. Its induction over the code list is correct under (H1)/(H2), and the entries it reads are exactly those (H1) defines (|U| ≤ t_b).
