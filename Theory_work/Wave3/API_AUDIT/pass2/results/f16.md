## W1-N3:Cex-N3-Dm — deviation family D_m

**What I checked.**

- **D_m is a valid instance** (L6:10–14).
  - K = m+2 ≤ p = 2m+4; blocks are increasing lists that partition {0,…,2m+3}; |C_b| ≤ 4.
  - Tables are defined exactly on |U| ≤ min(|C_b|, K). K ≥ 2 so the pair entries of the inner blocks exist; for m ∈ {0,1} the size > K entries of C_m are unspecified and never read.
  - The codes are right: {a,d} = 2⁰ + 2³ = 9 and {b,c} = 2¹ + 2² = 6.
- **Maximisers** (L6:29–33). Each inner term is ≤ 1 with equality iff a singleton; the last term is ≤ 5 with equality iff {a,d} or {b,c}. All maximisers have size m+2 = K, so they lie in Ω_K. Hence 𝒜 = 𝒜*, k* = m+2 and N = 2^{m+1} > cap for every cap ≤ 2^m.
- **Independent recomputation of the DP.** For the m pair-blocks, M[m][k] = k for k ≤ m and M[m][m+q] = m − 11q. With `mb[m]` = (0, −3, 5, −3, −3), only j = 2 attains M[m+1][m+2] = m+5 (the alternatives are m−22, m−14, m−4, m−5). `arg[m][2]` = (6, 9) ascending. This confirms the argument through the code path, not only through κ.
- **S\*** (L6:34–36). Via L1(iii): the minimum of XΔY is 2i ∈ X at the first differing pair, or a ∈ X when only the last block differs. So S* = E_m ∪ {2m, 2m+3}.
- **DFS prefix** (L6:37–41).
  - C_m is last in block order, so it is the first coordinate pair of κ and the first level of `rec`.
  - The 2^m code-6 sets precede all code-9 sets, so for cap ≤ 2^m every processed set contains b and differs from S*.
  - The DFS-first set has every inner code 1, i.e. it is E_m ∪ {b,c}. That set is also the lex-min of the whole code-6 family, so it is the lex-min of any processed prefix: `res.S` = E_m ∪ {2m+1, 2m+2}.
- **Special cases.** m = 0 gives p = 4, K = 2, one block, cap = 1, `res.S` = {1,2}, S* = {0,3}. m = 20 gives 2²⁰ = 1,048,576 ≥ 10⁶, p = 44, K = 22, sets {0,…,38,41,42} versus {0,…,38,40,43}.
- **Consistency check.** For cap = 2^m + 1 the prefix contains the first code-9 set, which is S*, so the code returns S*. The claim's restriction to cap ≤ 2^m is therefore the right one.

**Findings.** No GAP or ERROR.
