## W3-RM:B1 — Lemma B1 (`lemmas/L1_fixed.md:17-25`)

**Checked:** each of the four implications, as a pure restriction of quantifiers for an arbitrary partition with |C_b| ≤ 16.

- **(FL-16) ⇒ (G3a).** A nonempty T ⊆ C_b has 1 ≤ |T| ≤ 16, so the floor applies with the same φ₀.
- **(V) ⇒ (V_b).** U ⊆ C_{b(j)} ∖ {j} gives U ⊆ [p] ∖ {j} and |U| ≤ 15. (V) places no restriction on truths inside U, so the case where U contains other truths is covered. The direction u_{U,j} is well defined by (FL-16) on U ∪ {j}, which has at most 16 elements.
- **(L-gain^σ) ⇒ (L_b^σ) and (L-gain) ⇒ (L_b).** The block-relative U has U ⊆ [p] ∖ {l}, |U| ≤ 15 and l ∉ Q. The extra requirement U ⊇ S₀ ∩ C_{b(l)} only shrinks the quantifier range. The right-hand sides (ησ² log n, resp. ητ²_U log n) are the same function of U in both forms, so η and Q carry over.

No findings. The implications are deterministic and hold for every partition.

- **Floor.** For 1 ≤ |T| ≤ 16, the partition {T} ∪ singletons is admissible, so (G3a) gives the floor on T.

## W3-RM:B2 — Lemma B2 (`lemmas/L1_fixed.md:45-62`)

**Checked:** the proof is a delta to GROW L3, taken as proved for |Q| ≤ C_Q log n. The source file is not in the packet, so I could not confirm the line citations or the sentence "nothing else depends on |Q|" against it. I instead rebuilt each step where |Q| can enter from the description here and in `L1b_rss.md` and verified the arithmetic.

- **Counting (item 1).** k̃ ≤ |Q| + 16s₀ + 16·#{good blocks with N_b ≠ ∅} holds for any |Q|: at most |Q| elements in Q, at most s₀ bad blocks of size ≤ 16, the rest in good blocks outside Q.
- **Ladder (item 2).** With m_i = 2^{i+1}k₀ and m_i < k̃ ≤ 2m_i, more than m_i/32 blocks exceed the threshold at min(2m_i, K). Markov gives a per-rung bound of order (p/m_i)^{ε/(1+ε)} · n^{−(1−(1+1/ε)η)/(2(1+ε))} up to n^{o(1)}. The only k₀-dependence is m_i^{−ε/(1+ε)} ≤ 1. There are O(log n) rungs because K ≤ n/2. The sum vanishes when Aε + (1+1/ε)η/2 < ½, which is solvable exactly when η < η_A. The block event family has at most 2^{16}p members regardless of Q.
- **Feasibility (item 3).** If Q = [p], then |Q| ≤ K forces K = p; either k̃ = p (so S̃ = [p] ⊇ S₀) or k̃ < K. If Q ≠ [p], then k̃ ≤ 2k₀ = 2|Q| + 32s₀ ≤ K − 1 by (L-feas). The text's "otherwise" lumps the sub-case Q = [p], k̃ < K under the bound k̃ ≤ 2k₀ < K "by the second alternative"; feasibility there is immediate from k̃ < K. This is a wording slip only.
- **Junk exclusion (item 4).** The margin is log(p/k̃) + ½ log(n+1) − ½(√(η log n) + z_n)² − 2κ_E with z_n² = 2 log p + o(log n), giving [½ − η/2 − √(2Aη)] log n − log k̃ − o(log n). The bracket is positive iff √η < √(2A+1) − √(2A), i.e. η < η_A. log k̃ ≤ log(2|Q| + 32s₀) = o(log n) suffices; O(log log n) is not needed.
- **Truth inclusion.** This uses only (V_b), the block family and the feasibility from item 3; it does not depend on |Q|.
- **Degenerate case.** If Q = [p], the hypothesis log|Q| = o(log n) forces p = n^{o(1)}; the ladder and junk steps are then vacuous, which is consistent.

No GAP or ERROR.

## W3-RM:B3 — Lemma B3 (`lemmas/L1_fixed.md:70-88`)

**Checked:**

- **Coverage of TL(𝓛).** Neighbours A of T ∈ 𝓛 with S₀ ⊄ A are exactly T ∖ {i} and (T ∖ {i}) ∪ {l} with i ∈ S₀, l ∉ T. Both are treated.
- **Family size.** |𝔉| ≤ 1 + 2^{|Q∖S₀|}(1 + p + s₀ + s₀p) is the correct count of the four member types. Every nonempty member lies in some Q ∪ {l}, so (FL-Q) and interlacing give the floor φ₀².
- **Display (1.1).** log|𝔉| ≤ q log 2 + A log n + log(2(1+s₀)) + O(1) and |𝒱𝒱| ≤ |𝔉|² + |𝔉| ≤ 2|𝔉|². Hence t_n + h_n² ≤ C₁(A, s₀)(q + log n).
- **L0′ hypotheses.** Member sizes ≤ q + 1 and log|𝔉| = O((log n)^κ) fit envelope exponent κ + 1. Q is deterministic, the design is fixed, and ‖μ‖² ≤ Mn is assumed.
- **Signal term.** A ⊇ S₀ ∖ {i} gives r_A = θ*_i(I − P_A)x_i. Here l ≠ i (since l ∉ T ∋ i), so A ∪ {i} = T or T ∪ {l}, both ⊆ Q ∪ {l}. The Schur complement gives Λ_A ≥ (n−1)φ₀²θ*²_min = L′_n. Λ_T = 0.
- **RSS difference.** RSS_A − RSS_T = Λ_A + 2r_Aᵀε + ‖P_Tε‖² − ‖P_Aε‖² ≥ Λ_A − 2σh_n√Λ_A − σ²t_n. AM–GM (2σh_n√Λ ≤ Λ/2 + 2σ²h_n²) gives the second form. The condition Λ_A ≥ 4σ²(2h_n² + t_n) is exactly what yields ≥ Λ_A/4.
- **Scale.** (BM-Q) with (1.1) gives L′_n/(σ²(t_n + h_n²)) → ∞, uniformly over A because Λ_A ≥ L′_n.
- **Final comparison.** The prior ratio is ≤ log(2p) ≤ A log n + log 2 and the dimension term is ½ log(n+1); both are zero for swaps. The likelihood term is ν log(RSS_A/RSS_T) ≥ ν(RSS_A − RSS_T)/RSS_A ≥ (n/2)(Λ_A/4)/(C_R n) = Λ_A/(8C_R), using RSS_A ≤ C_R n from the energy bound. So F(A) − F(T) ≤ (A+1) log n + 1 + 2κ_E − L′_n/(8C_R) < 0 once L′_n/log n → ∞, which (BM-Q) implies.

No findings.
