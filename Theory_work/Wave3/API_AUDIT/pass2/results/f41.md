1. **Coverage of S′ by (F_λ)** (E_visibility.md:76). For S ∈ 𝔉 (S ∈ Ω, S₀ ⊄ S, |S∖S₀| ≤ j₀), S′ = S ∪ S₀ = S₀ ∪ (S∖S₀) with |S′∖S₀| ≤ j₀. The step needs (F_λ) to give λ_min(X_{S′}ᵀX_{S′}/(n−1)) ≥ φ₀² on every such S₀ ∪ J, |J| ≤ j₀.
   - This matches how the ticket uses (F_λ) elsewhere: (C10) is applied to exactly the underfits with |J′| ≤ j₀ (A_occam.md:77-83), and STATEMENT.md:137 calls it "the bounded-size normalised floor on S₀ ∪ J".

   - The case S = ∅ (S′ = S₀) is covered by the S₀ part of the floor.

2. **Application of [P3] `lem:signal`** (E_visibility.md:76-77). The inequality used is Δ_S ≥ λ_min(G_{S′})‖θ*_{S₀∖S}‖². Its hypotheses hold here:

3. **Constant bookkeeping** (E_visibility.md:77). S₀∖S ≠ ∅, so ‖θ*_{S₀∖S}‖² ≥ θ²_min. With BM(c) read as θ²_min ≥ cσ*² log n/(nφ₀²), we get Nφ₀²θ²_min ≥ (N/n)cσ*² log n = (1 − 1/n)cσ*² log n.
