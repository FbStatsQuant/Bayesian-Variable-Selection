**(i) Path in 2^𝒱, strict monotonicity, τ(C) ≤ 2^{v̄} − 1 (L4_search.md:30-34).**
- The centre C ⊆ 𝒱 is feasible because |C| ≤ |𝒱| ≤ K.
- For a state S^t ⊆ 𝒱 with S^t ≠ S₀, L3.4 says every maximiser of F over the feasible neighbours lies in 𝒱 and strictly exceeds F(S^t). The tie rule picks among exact maximisers, so the next centre is in 𝒱 with strictly larger F, whatever the tie rule (Remark 3 is correct).
- The step "S^{t+1} exists" needs at least one feasible neighbour. This holds: a nonempty S always has a feasible deletion, and S = ∅ ≠ S₀ has a feasible addition once K ≥ 1, which is true under D0 for n ≥ 2. The proof leaves this implicit; it is not a defect.
- Strict increase makes the states pairwise distinct. They lie in 2^𝒱, which has at most 2^{|𝒱|} ≤ 2^{v̄} elements. The path cannot stop at a state other than S₀, so it reaches S₀, and the τ + 1 distinct states S⁰, …, S^τ give τ ≤ 2^{v̄} − 1. The count is right.
- The lemma does not state S₀ ⊆ 𝒱, but this is harmless: when neighbour sets are nonempty, the assumed L3.4 conclusion forces the strictly increasing finite path to terminate at S₀, so S₀ ⊆ 𝒱 follows.

**(ii) The path stops at S₀ (L4_search.md:35).** This is immediate from the second half of L3.4 (no feasible neighbour with F ≥ F(S₀)) and the strict-improvement move rule.

**(iii) Capped search (L4_search.md:36-41).** I checked the scan and move indexing against "at most ℓ moves, then one further scan; stop earlier at the first scan with no strict improvement".
- Scans occur at S⁰, …, S^{min(ℓ, τ)}. An early stop can only happen at S₀, by (i).
- For τ ≥ 1, S₀ = S^τ is the scan-maximiser at S^{τ−1}, so it is a scanned and therefore scored neighbour. That scan is executed exactly when τ − 1 ≤ ℓ: inside the loop if τ − 1 < ℓ, as the one further scan if τ − 1 = ℓ. The edge case ℓ = 0, τ = 1 is consistent.
- For τ = 0, S₀ = C is the centre, whose score is needed for the comparison (and is emitted for LS0).
- If ℓ ≥ τ, the τ-th move is permitted, the centre becomes S₀, and one more scan is always executed (in-loop if τ < ℓ, the final scan if τ = ℓ). By (ii) it finds no strict improvement, so the endpoint is certified and `local_limit` is not set.
- The parenthetical about the public `local_certified` flag is a scope disclaimer and asserts nothing that needs proof.

The side hypothesis |𝒱| ≤ min(v̄, K) is used only for feasibility of centres and for the 2^{v̄} count, and both uses are correct.
