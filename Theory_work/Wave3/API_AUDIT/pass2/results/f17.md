## W1-N3:L7 — tie-aware DP (TDP) returns S*, with the stated cost

**What I checked**

1. **Well-definedness of the constrained tables** (L7_tie_aware_dp.md:8-12). For |S| = k ≤ K every block part has |S_b| ≤ min(|C_b|, k) ≤ t_b, so only ρ-entries defined in STATEMENT.md:56-58 are read. The range j ≤ min(t_{b−1}, k) in the recurrence matches this.

2. **Constrained DP claim** (L7:24-29), Φ(IN,OUT;k) = max over 𝒮(IN,OUT;k) of f, with −∞ if empty.
   - The constraints IN ⊆ S and S ∩ OUT = ∅ are per element and the blocks partition {0,…,p−1}. So 𝒮(IN,OUT;k) is the set of tuples (S_b) drawn from the restricted per-block families with Σ|S_b| = k.
   - Splitting off the last block gives the same disjoint-union bijection as in L3, now with restricted families, and the max of a sum of independently chosen terms is the sum of the maxima.
   - The one difference from L3 is that μ_b^{IN,OUT}(j) can itself be −∞ (in L3 every μ_b(j) is real). The conventions real + (−∞) = −∞ and (−∞) + (−∞) = −∞ handle this, so "applies verbatim" is slightly loose wording but the argument is correct.
   - With IN = OUT = ∅ this reduces to L3/L4, so V* = max over Ω_K of f and k* is the smallest maximising size, matching STATEMENT.md:81.

3. **Invariant** (L7:31-40). Inv(i): IN ∪ OUT = {0,…,i−1} and IN = S* ∩ {0,…,i−1}.
   - Inv(0) is trivial.
   - Φ(IN∪{i}, OUT; k*) ≤ V* always, since it is a max of f over a subset of Ω_K, or −∞.
   - Case i ∈ S*: S* lies in 𝒮(IN∪{i}, OUT; k*) because |S*| = k*, IN ∪ {i} ⊆ S*, and S* ∩ OUT = ∅ by Inv(i). So Φ ≥ f(S*) = V*, hence Φ = V*, and i joins IN.
   - Case i ∉ S*: suppose S ∈ 𝒮(IN∪{i}, OUT; k*) has f(S) = V*. Then S ∈ 𝒜*. Since S ⊇ IN and S misses OUT = {0,…,i−1} \ IN, S ∩ {0,…,i−1} = IN = S* ∩ {0,…,i−1}. Also i ∈ S \ S*, so S ≠ S* and min(S Δ S*) = i ∈ S. L1(iii) applies (distinct sets of equal size k*) and gives lex_less(S, S*), contradicting minimality of S*. So Φ < V* and i joins OUT.
   - Inv(p) gives IN = S*.
   - I re-derived L1(iii) (L1_reduction.md:41-49) and it is correct; its hypotheses (distinct, equal size) hold where it is used.

4. **Boundary cases.**
   - K = 0: k* = 0, every Φ({i}, ∅; 0) = −∞ ≠ V*, so the output is ∅ = S*.
   - K < |C_b|: handled by t_b.
   - Block order unrelated to index order: the greedy loop runs over indices i, not blocks, and the constrained DP does not depend on block order. No issue.

5. **Cost** (L7:42-45).
   - Evaluations: one in step 1 (it gives Φ(∅,∅;k) for all k) plus one per i in step 2, so p+1.
   - Per evaluation, block pass: one pass over the 2^{|C_b|} codes with O(1) mask tests yields all μ_b^{IN,OUT}(j). Building the per-block IN/OUT masks costs O(p) ≤ Σ_b 2^{|C_b|}.
   - Per evaluation, convolution: Σ_b Σ_{k≤K} (min(t_b,k)+1) ≤ J(K+1)².
   - Total: (p+1)·O(Σ_b 2^{|C_b|} + J(K+1)²) = O(p·Σ_b(2^{|C_b|} + (K+1)²)), using p ≥ 1.
   - "Never enumerates 𝒜*": the algorithm only compares DP values and builds one set.
