## W2-LOC2:Lemma-BC (L6_poly.md:78-84, proof 86-109)

I checked the whole proof and found no problem.

- **Cofactor expansion (L6_poly.md:88-93).** (B⁻¹)_ij is the cofactor with row j and column i deleted, divided by det B. Each monomial is a bijection σ from rows ≠ j to columns ≠ i. In the graph r → σ(r), vertex j has no outgoing edge and i has no incoming edge. The walk from i cannot revisit a vertex, since that vertex would have two predecessors (or be i, which has none), so it ends at j with length h ∈ [1, m−1]. Correct.
- **Longest edge (L6_poly.md:93-95).** Some path edge has d ≥ d(i,j)/h. Since 1 + d/h ≥ (1+d)/h, that factor is at most K0·h^α·(1+d(i,j))^(−α) ≤ K0·(m−1)^α·(1+d(i,j))^(−α). The other m−2 factors are each ≤ K0, using K0 = max(1, K_dec) so that diagonal entries (= 1) are covered. Correct.
- **Constant in (P1) (L6_poly.md:96-99).** There are (m−1)! monomials and det B ≥ c^m (all eigenvalues ≥ c). (P1) follows as displayed, with a constant depending only on (m, α, c, K_dec).
- **Passage to conditional covariance (L6_poly.md:101-105).** For B = Σ_{U∪{j,k}}, Cov((W_j,W_k) | W_U) = (H)⁻¹ with H the {j,k} principal block of B⁻¹. H has spectrum in [1/C, 1/c], so det H ≥ C⁻² and |S_jk| = |H_jk|/det H ≤ C²|H_jk|. Here m = |U| + 2 ≤ M + 2, so K_M is the maximum of finitely many constants and is uniform in p, positions, indices and U. Correct.
- **Spectral part for arbitrary U (L6_poly.md:106-109).** Cov(W_V | W_U) is the inverse of the V-block of (Σ_{U∪V})⁻¹, whose spectrum lies in [1/C, 1/c]. So the conditional covariance has spectrum in [c, C]. The conditional variance is ≥ c and ≤ the marginal variance 1. Correct, and independent of the decay assumption.

The argument is valid for any α > 0, so the premise α > 17/2 is more than enough.

## W2-LOC2:Lemma-IR (L6_poly.md:118-129, proof 131-167)

I checked the whole proof and found no problem.

- **Truncation (L6_poly.md:131-138).** Sites are distinct integers on a line, so at most two indices sit at each positive distance. Schur's test gives ‖A − A_B‖ ≤ 2K_dec·Σ_{d>B}(1+d)^(−α) ≤ H1·B^(1−α). A has floor c (principal submatrix of Σ), A_B is symmetric, so λ_min(A_B) ≥ c/2 for B ≥ B0. Correct.
- **Conjugation (L6_poly.md:138-152).** The entries of E are (A_B)_ik·(e^{t(d(i,j)−d(k,j))} − 1), with |d(i,j) − d(k,j)| ≤ d(i,k) ≤ B. Using e^x − 1 ≤ x·e^x and td ≤ k, row and column sums are at most 2K_dec·t·e^k·Σ d(1+d)^(−α). The series is finite exactly because α > 2. Since t = k/B ≤ k, one small k works for all B ≥ 1. Then ‖(A_B + E)⁻¹‖ ≤ 1/(c/2 − c/4) = 4/c, and because d(j,j) = 0 the (i,j) entry gives |(A_B⁻¹)_ij| ≤ (4/c)·e^(−k·d(i,j)/B). Correct.
- **Resolvent and choice of B (L6_poly.md:154-160).** ‖A⁻¹ − A_B⁻¹‖ ≤ (1/c)(2/c)·H1·B^(1−α). With B = ⌊d/(M1·log(2+d))⌋ and k·M1 > α, the exponential term is ≤ (4/c)(2+d)^(−α) ≤ const·f(d). For large d, B is at least half its unrounded value, so B^(1−α) ≤ const·d^(1−α)·[log(2+d)]^(α−1) ≤ const·f(d). The threshold "d large" (B ≥ max(B0, 1)) depends only on the constants. For smaller d, including the diagonal, f(d) is bounded below by a positive constant and |(A⁻¹)_ij| ≤ 1/c, so these are absorbed into H. H depends only on (c, K_dec, α), hence is uniform in the subset and n. (P2) holds.
- **(P3) (L6_poly.md:162-167).** β_T(l)_v = −(B⁻¹)_vl/(B⁻¹)_ll with (B⁻¹)_ll = 1/Var(W_l | W_T) ≥ 1, so |β_T(l)_v| ≤ H·f(d(l,v)). With at most two sites per distance and d ≥ 1, ‖β‖₁ ≤ 2H·Σ_{d≥1} f(d), finite because the exponent 1 − α < −1 beats the logarithmic factor. The tail F(r) = 2H·Σ_{d>r} f(d) → 0 uniformly in (T, l, n). Correct.

The stated hypothesis α > 2 is exactly what the proof uses (twice: the E row-sum series and the summability of f).
