## C-PACK:I1-UM-FP (Lemma UM-FP, I1_e4_replacement.md:109-115, objects 91-107)

**Checked.** Part (a) against N3(e), the inequality chain in (b), the fold bound, and the crude bounds on η and ε.

- (a) N3(e) gives ĝ(`res.S`) = `res.lg0` = max_{Ω_K} ĝ under (H1), (H2-FP), (H3), (H4), which are the lemma's hypotheses. With `res.S` ∈ Ω_K and a unique ĝ-maximiser, `res.S` = R.
- (b) The chain ĝ(R) ≥ f*(R) − η − ε ≥ f*(S) + Δ − η − ε > f*(S) + η + ε ≥ ĝ(S) is valid for every S ≠ R in Ω_K. It uses only |f̂ − f*| ≤ η and |ĝ − f̂| ≤ ε uniformly on Ω_K. The K = 0 case (Δ = +∞, ε = 0) is consistent.
- Fold bound: there are m + 1 summands, the first addition 0 + ρ̂_{b₁} is exact, and m rounded additions remain. Each satisfies fl(a+b) = (a+b)(1+δ) with |δ| ≤ u under round-to-nearest without overflow, and is exact when the result is subnormal. This gives γ_m Σ|x_i| with mu < 1 assumed; m = 0 is exact. The index is right (γ_m, not γ_{m+1}).
- ε ≤ γ_K(Λ̂ + K T̂) holds because m(S) ≤ |S| ≤ K and γ is increasing.
- The margin paragraph (125-130) is correct: Δ ≥ log((1−t)/t), and log(1/a_n) − Δ is bounded above in probability. The numeric example at K = 100 (about 1.1·10⁻⁹) is correct.

**Finding (MINOR), I1_e4_replacement.md:96-98.** The bound η ≤ η_λ + Kη_ρ, with U = ∅ excluded from η_ρ, silently assumes that blocks not met by S contribute nothing to f̂ − f*. That needs ρ*_b(∅) = 0 (true in the method, since r_b(∅) = 1) and f̂ defined as the sum over met blocks only (or ρ̂_b(∅) stored as exact 0). The lemma itself uses η as defined, so (a) and (b) are unaffected.

## C-PACK:I1-PXNrepair (§1.1, I1_e4_replacement.md:61-69)

**Checked.** The counterexample, the replacement bound, and the two closing claims at lines 68-69.

- Counterexample: p = 2, K = 1, λ = (−10, 0), unit singleton tables give f(∅) = −10 and f({0}) = f({1}) = 1. So N = 2 > cap = 1, and N3(d) returns the DFS-first element, which depends on block order. Each singleton has mass e/(2e + e⁻¹⁰) < ½. This is consistent with N3(b) and N3(d).
- Replacement bound: on 𝒜_n the unordered partitions coincide and f is a sum over blocks, so π₀ = π̃₀ as exact-arithmetic functions. On 𝒜_n ∩ {π̃₀(S°) > ½}, S° lies in Ω_K (positive mass) and is the unique maximiser, so Lemma UM gives C₀ = S°. The union bound P(C₀ ≠ S°) ≤ P(𝒜_nᶜ) + P(π̃₀(S°) ≤ ½) follows, with H1/H4 assumed to hold surely (inherited through e4′) and the hypothetical-object convention on the exact branch.
- With Theorem R and P3′ taken as stated, this gives P(C₀ = S°) → 1.

**Finding (MINOR), I1_e4_replacement.md:69.** The sentence "every later step of PXN uses the centre only through C₀ = S° on 𝒯_n ⊆ {S̃₀ = S°}" is asserted, not shown. For the coded centre the inclusion needs 𝒯_n ⊆ 𝒜_n ∩ {π̃₀(S°) > ½}, or the weaker P(𝒯_n ∩ {C₀ ≠ S°}) → 0. PXN's definition of 𝒯_n is not in the material. If 𝒯_n was defined through the group-version centre equalling S°, the repair is to intersect it with 𝒜_n ∩ {π̃₀(S°) > ½}, at o(1) cost by the displayed bound. The bound itself is unaffected.
