**(iii) (L1:41-49).**
- t = min(X Δ Y) exists because X ≠ Y. The elements below t are common to both sets, giving a shared prefix of length r.
- If t ∈ X, then |Y| = |X| ≥ r+1. Y has exactly r elements below t, so its (r+1)-th element y exists, is not below t, and is not t (t ∉ Y); hence y > t. The (r+1)-th element of sorted X is t. The first difference is at position r+1 with t < y, so lex_less(X, Y) holds, and the proper-prefix rule never applies because the lengths are equal.
- If t ∈ Y, the symmetric argument gives lex_less(Y, X), and asymmetry gives ¬lex_less(X, Y). Both directions of the equivalence are therefore covered.
- The strict-total-order claim follows from the standard fact for fixed-length sequences. OK.
