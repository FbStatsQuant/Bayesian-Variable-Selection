## W3-RM:NA-F (Lemma NA-F, `lemmas/L2_NAF.md:21-53`)

**What I checked.** Every step of the proof, the constants, and whether the externally consumed results (GROW L2.2 score reduction, LOC2 L0′ score conversion) are invoked inside their stated hypotheses.

- **Step 0 (L2_NAF.md:25-27).** For (T, l) ∈ 𝔓, T ∪ {l} ⊆ Q ∪ {l}, so (FL-Q) and interlacing give full column rank and (I − P_T)x_l ≠ 0. Hence u_{T,l} and Z_{T,l} are defined, and u_{T,l} ∈ span X_{Q∪{l}}. Correct.
- **Step 1 (L2_NAF.md:29-32).** Both u_{T,l} and v lie in V_l, so w = u_{T,l} − v ∈ V_l and wᵀε = wᵀΠ_lε. With ‖w‖ ≤ ρ_n this gives (2.1). Correct.
- **Step 2, event E₁ (L2_NAF.md:34-36).** 𝒰_n is deterministic and consists of unit vectors, so each vᵀε/σ is N(0,1). With a_n² = 2 log(2|𝒰_n|) + 2 log log n, the union bound gives |𝒰_n|·2·exp(−a_n²/2) = 1/log n exactly. Correct.
- **Step 2, event E₂ (L2_NAF.md:37-40).** There are at most p − q + 1 ≤ p distinct projectors, since q ≥ 1. Each has rank d_l ≤ q + 1. Laurent–Massart is quoted correctly, and d + 2√(dx) + 2x ≤ 2d + 3x follows from AM–GM. So P(χ²_{d_l} ≥ G_n) ≤ e^{−x} and the union gives p·e^{−x} = 1/log n. Correct.
- **Step 3 (L2_NAF.md:42-49).** On E₁ ∩ E₂, Z² ≤ (a_n + ρ_n√G_n)². The bounds used are:
  - a_n² ≤ 2 log p + 2h log n + 2 log 2 + 2 log log n;
  - G_n ≤ C₂(A)(q + log n), using p ≤ n^A;
  - ρ_n²G_n = o(log n) by the rate hypothesis, and the cross term is 2√(O(log n)·o(log n)) = o(log n).
  
  For the threshold, q + 1 ≤ 2(log n)^κ gives c_n ≥ 2 log p + log n − 2κ log log n − O(1). The margin is (1 − 2h) log n − o(log n) > 0 for n ≥ n₀, with n₀ common to all pairs because the bound is deterministic on E₁ ∩ E₂. So P(max_𝔓 Z² ≤ c_n) ≥ 1 − 2/log n. Correct.
- **Step 4 (L2_NAF.md:51-53).** The consumed results are applied within their hypotheses: (F0) supplies q ≤ (log n)^κ, |Q| ≤ K and ‖μ‖² ≤ Mn, and (FL-Q) supplies the Gram floor on the lattice family. Since T ⊇ S₀, μ ∈ span X_T, so δ_{T,l} = 0 and the RSS drop is exactly σ²Z²_{T,l}, which is the form the score reduction needs. The c_n here is the same expression as in GROW L2.2 (as quoted in Lemma B4). Taking the external conversion as stated, P(NA(𝓛)) → 1 follows.
- **Empty case 𝔓 = ∅.** Handled explicitly at L2_NAF.md:17-19.

**Findings.** None. No use of independence between approximants or projections is hidden anywhere; the membership requirement v ∈ span X_{Q∪{l}} is stated in the hypothesis and is exactly what Step 1 uses.

## W3-RM:N-loc (Lemma N-loc ⇒ (N-D)(i), `lemmas/L2_NAF.md:60-73`)

**What I checked.** The geometric inequality, the cardinality count, membership in span X_{Q∪{l}}, determinism, and that the rate and h carry over unchanged.

- **Orthogonal decomposition (L2_NAF.md:68-70).** With N = T ∩ N_l ⊆ T, P_T − P_N is the orthogonal projector onto span X_T ⊖ span X_N. So b ∈ span X_T, a ⊥ b, and (I − P_N)x_l = a + b with ‖a + b‖ ≥ ‖a‖ > 0, where a ≠ 0 comes from (FL-Q). Correct.
- **Distance bound (L2_NAF.md:71-72).** ⟨a, a + b⟩ = ‖a‖² and ‖a + b‖ = ‖a‖√(1 + t²), so ‖u_{T,l} − u_{N,l}‖² = 2(1 − (1 + t²)^{−1/2}). The inequality (1 + t²)^{−1/2} ≥ 1 − t²/2 holds by convexity of (1+s)^{−1/2} (tangent line at s = 0), giving ≤ t² ≤ ρ_n². Correct.
- **Membership.** u_{N,l} ∈ span X_{N∪{l}} ⊆ span X_{Q∪{l}} because N ⊆ Q. Correct.
- **Cardinality (L2_NAF.md:72-73).** u_{N,l} is determined by (l, N) with N ⊆ N_l, so |𝒰_n| ≤ p·2^{ν_n} and log|𝒰_n| ≤ log p + ν_n log 2 ≤ log p + h log n. Correct.
- **Determinism and rate.** N_l is deterministic and X is fixed, so 𝒰_n is deterministic. The condition ρ_n²(q + log n)/log n → 0 is assumed with the same ρ_n. The empty case is covered at L2_NAF.md:65-66.

**Findings.** None. The parenthetical "i.e. limsup ν_n/log n < 1/(2 log 2)" is equivalent to the displayed condition only eventually, which is harmless in an asymptotic statement.
