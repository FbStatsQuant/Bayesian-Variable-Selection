## W2-APP:VN (Lemma VN, L5_VN.md:23-26; proof :37-56)

**Checked.**
- **Regularity (:37-45).** The sets {l} ∪ U ∪ S₀ have size ≤ 16 + s₀, so (F16) supplies the population floors Var(W_l | W_U) ≥ c and λ_min(Σ_UU) ≥ c; Var(Y° | W_U) ≥ σ². The sample response is Σ_k(θ*_k/t_k)CW_k + Cε with t_k = 1 + O(ħ_n), so the bounded-dimension perturbation gives |ρ̂_{U,l} − Corr(W_l, Y° | W_U)| ≤ Cħ_n uniformly over all l and U. That uniformity is why no union over maximisers or over data-dependent partitions is needed.
- **Signal bound (:43).** h_{U,l} ≥ n(√κ_n − Cħ_n)² ≥ nκ_n/2 needs Cħ_n ≤ (1 − 2^{−1/2})√κ_n, which holds eventually because nκ_n/log n → ∞.
- **Block-table increment (:46-49).** RSS_{U∪l}/RSS_U = 1 − ρ̂² is exact; −log(1 − x) ≥ x applies since ρ̂² < 1 a.s.; the two remainders cost ≥ −2κ_E on the L0 event for subsets of size ≤ 16 (U ∪ {l} ⊆ C_b). L0.2(c) is taken as stated.
- **Prior ratio (:52).** With w(k) = [2C(2p−1,k)]⁻¹, w(k+1)/w(k) = (k+1)/(2p−1−k) ≥ 1/(2p−1), so the term is ≥ −log(2p).
- **Contradiction (:53-54).** The increment is ≥ −log(2p) − ½log(n+1) − 2κ_E + nκ_n/4 > 0 eventually, using log p ≤ A log n. U = S̃ ∩ C_b has |U| ≤ 15, U ∩ S₀ = ∅, l ∉ U, so VNF applies; k < K gives S̃ ∪ {l} ∈ Ω.
- **Count (:55-56).** At most s₀ blocks meet S₀, each contributing ≤ 15 non-truth indices; and |S̃| = K gives |S̃ ∖ S₀| ≥ K − s₀. Both branches yield min(K − s₀, |𝒩_n| − 15s₀).

**Findings.** None. One unverifiable detail: "ν ≥ n/2" (:49) depends on the definition of ν in GROW L0, which is not in the material. If ν were (n−1)/2 the bound loses at most ½, which does not affect the conclusion.

## W2-APP:Ex-STAR ((V1), L5_VN.md:64-72)

**Checked.**
- **Spectrum.** The star adjacency matrix has eigenvalues ±√m_n and 0, so Σ has spectrum {1 ± r_n√m_n, 1} = {½, 1, 3/2}; the diagonal is 1. (F16) holds with c = ½ and LSF holds with φ² = ψ_n = ½.
- **VNF.** For a leaf l and U ⊆ [p] ∖ {1, l}, Σ_{lU} = 0. Hence Cov(W_l, W₁ | W_U) = r_n, Var(W_l | W_U) = 1, and Var(Y° | W_U) = θ²Var(W₁ | W_U) + σ² ∈ [θ²/2 + σ², θ² + σ²]. So Corr² ≥ θ²/(4m_n(θ² + σ²)) = κ_n, and since the true value is of the same order, "VNF iff m_n = o(n/log n)" is correct.
- **Start-mode bound.** With m_n = ⌊n^{1/3}⌋, nκ_n/log n ≍ n^{2/3}/log n → ∞. Since p ≥ m_n + 1, K − 1 ≥ m_n − 15 for large n, so Lemma VN gives ≥ m_n − 15 ≫ log n nulls in every maximiser. Both parts of the corollary apply.
- **PTV.** |θ|·Var(W₁ | W_U) ≥ |θ|/2 for U ∌ 1. Correct.
- **Non-membership count.** K/r_n = 2K√m_n, and at most two indices sit at each distance, so at most 2a⁻¹log(2K√m_n) < m_n leaves can satisfy the Σ-decay bound. Correct for (LOC-Σ).

**Findings.**
- **MINOR — L5_VN.md:70-71.** "STAR ∉ LOC for any fixed (K, a)" is argued only for the (LOC-Σ) alternative. The class LOC (L2_CT.md:36-39) also admits (LOC-Θ), decay of Σ⁻¹, and that case is not addressed here (L4_families.md:95-96 does address it for the Toeplitz row). The repair is one line, either way:
  - by Lemma CD(c), (LOC-Θ) with (K, a) implies (LOC-Σ) with constants (2C, t*(1/C, K, a)), C = 3/2, and the same count applies; or
  - directly: with A the star adjacency, A³ = m_nA, so Σ⁻¹ = I − (4r_n/3)A + (4r_n²/3)A². Then |Θ_{1l}| = 2/(3√m_n), which forces d(1, l) ≤ a⁻¹log(3K√m_n/2), again O(log m_n) < m_n positions.

  The statement is true. The counterexample itself (bounded spectrum, VN-obstructed routes) does not depend on this sentence.
