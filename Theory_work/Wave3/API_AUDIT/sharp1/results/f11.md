## W2-FAC-PK:Thm-NEG (STATEMENT.md:63-68)

### (a) Hypotheses

**(PK) liminf p/K > 16/15 (STATEMENT.md:51) — stronger than the proof needs.**
- It is used at one step only, L1(d) (L1_start.md:65-67). The contradiction there is K ≥ 15|𝔅| ≥ 15(p − 16(J₀ + s₀))/16, which needs only p > (16/15)K + 16(J₀ + s₀), an additive constant rather than a multiplicative margin.
- The other uses of (PK) are harmless: (N1) needs p → ∞, and (N2) needs |𝔅| ≥ n/33, which follows from p > K (L2_neg.md:19-21).
- A pigeonhole step relaxes it further.
  - L1(c) uses only concavity and (PB), not 16/15 (L1_start.md:61-64). So if any regular block is fully kept, all regular blocks keep at least 15.
  - The number of fully kept regular blocks is then at most K − 15|𝔅| ≤ K − 15p/16 + 15(J₀ + s₀).
  - Every regular block that is not fully kept excludes its minimum, by L1(b).
  - So |O* ∖ C₀| ≥ N_n − (K − 15p/16) − C, and the induction in L2.3 (L2_neg.md:54-56) runs with this count in place of N_n.
  - Since N_n ≥ 2n^β w.p. → 1, the condition p ≥ (16/15)(K − n^β) + 16(J₀ + s₀) suffices for the same conclusion.
- The constant 16/15 is an artefact of block size 16, not a threshold of the phenomenon. The file concedes the remaining range as open (F2, REPORT.md:87).
- Some lower condition on p − K is presumably necessary. For p ≤ K the companion ticket is cited as proving the opposite (L3_static.md:129-130). For p − K = O(1) only O(1) nulls are excluded, so polynomially many swaps look implausible. The true threshold is unknown; p − K ≳ n^{1/2+ε} is my guess, via the cross-block exchange of F2.

**(PB) all but J₀ blocks of size exactly 16 (STATEMENT.md:52-54) — partly improvable.**
- It is used only in L1(c),(d).
- Fixed J₀ is not needed: any J_n with |𝔅| ≥ cn and the additive slack above works.
- g_n(u) is the same function for every truth-free block whatever its size (L1_start.md:30-31). So the balancing argument (c) extends to unequal block sizes whenever the receiving block is not full.
- (PB) is assumed, not proved, for the coded partition (L1_start.md:73-79). Turning that sketch into a lemma would remove a hypothesis from the claim as it applies to the actual method.

**θ̄ ≠ 0 — necessary for the mechanism.**
- Saturation rests on c(U, l) = (1 − ρ)ρθ̄/(1 + (u − 1)ρ) > 0 (L1_start.md:50-53).
- At θ̄ = 0 the nulls carry no order-n signal and nothing forces |S̃₀| = K.
- I have no proved counterexample showing LS0 succeeds at θ̄ = 0.

**Fixed ϑ, s₀, ρ, σ² — stronger than needed, low priority.**
- L2.2(ii) (L2_neg.md:34-40) needs only that the truth-in swap gain beats Δ_K ≈ ½ log n. That is roughly |ϑ|_min ≥ C√(log n/n) with C large.
- Saturation needs only that the (n/2)c₂ gain beats 3 log n.
- For a counterexample class, fixed signals are not a real defect.
