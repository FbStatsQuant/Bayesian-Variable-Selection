## C-GROW:Thm-GROW (STATEMENT.md:114-117)

The theorem is correct as taken, but several hypotheses are stronger than the ticket's own proofs use, and clause (b) and the mode of convergence can be strengthened with small edits. The larger restrictions (|Q| = O(log n), whole-lattice NA, fixed s₀, polynomial p) look improvable only with new work.

### (a) Hypotheses

**Stronger than the proof needs — easy to weaken**

1. **Clause (b), production cap (STATEMENT.md:116-117; L4_assembly.md:31).** (G4-χ) enters (b) only through the count |S̃₀∖S₀| ≤ |𝒫_n| < ℓ_n. L1.2(ii) needs only ℓ ≥ |C∖S₀| − 1 (L1_descent.md:47).
   - So (b) holds under either (G4) alternative whenever |𝒫_n| ≤ ℓ_n + 1 = ⌈log₂(n+p+1)⌉ + 1 eventually.
   - This raises the range from (1 − δ₀) ln n to about 1.44·max(1, log p/log n)·ln n.
   - It newly covers (G4-dir) designs. For the AR(1) instance, |𝒫⁰_n| ≤ 2s₀d_n (L5_instances.md:14), so the production cap suffices when s₀·log 2 < a·log(1/|ρ|) with p ≥ n^a (taking a = 1 if p is smaller). Example: s₀ = 1, |ρ| < ½.
   - It does not cover study S2 (s₀ = 14, ρ = 0.5) unless p is a very high power of n, so MR1 remains needed there.

2. **MR1 (STATEMENT.md:76-78).** The proof uses only cap ≥ |S̃₀∖S₀| − 1 (L4_assembly.md:27-28).
   - On the sandwich event |S̃₀∖S₀| ≤ |𝒫_n| ≤ C_Q log n, so any deterministic cap ℓ_n·ω_n with ω_n → ∞ (e.g. ℓ_n²) gives the same theorem with no data-dependent cap.
   - The cap is necessary in order: on the theorem's events exactly |S̃₀∖S₀| − 1 moves are needed (METHOD_REQUIREMENTS.md:21-24). Only the additive slack ℓ_n + |S₀| + 1 is unused.
   - MR1 remains the better engineering choice for the S5 frontier, where |S̃₀| appears to grow polynomially.

3. **TV with M_n → ∞ (STATEMENT.md:93).** The only use is L3_sandwich.md:82-84, which needs ½M_n log n − σ²z_n² > 2C_R(log 2p + ½ log(n+1) + 2κ_E).
   - A fixed constant suffices: M > 4(A+1)σ² + 2C_R(2A+1).
   - This puts TV on the standard "C·σ² log p" detection scale used by Yang–Wainwright–Jordan, Narisetty–He and Castillo–Schmidt-Hieber–van der Vaart.

4. **BM-∞ (STATEMENT.md:87-88).** Inside this ticket it is used only for TL (L2_NA_TL.md:29-34).
   - There a finite constant suffices: θ*²_min·nφ₀² ≥ C·σ² log n with C explicit from 8C_R(A+1), h_n², t_n.
   - Whether the external T03♯ needs the divergent form cannot be judged from these files.
   - If it does not, the theorem holds at the standard beta-min level. If it does, BM-∞ is binding only through E[1 − π(S₀)] → 0.

5. **(G4-χ) charges all of 𝒫_n (STATEMENT.md:96; L2_NA_TL.md:54-65).** The Cauchy–Schwarz step needs only the span of {u_{T,l} : T ∈ 𝓛} for each l.
   - Suppose that for each l there is Q(l) ⊆ Q with (I − P_T)x_l = (I − P_{T∩Q(l)})x_l for all T ∈ 𝓛, and the Q(l) take n^{o(1)} distinct values. An example is exact orthogonality between groups.
   - Then the same proof gives NA under max_l |Q(l)∖S₀| ≤ (1 − δ₀) log n, with |𝒫_n| itself up to C_Q log n. The union over the distinct χ² variables costs only O(√(log n·log log n)).
   - This interpolates between (G4-χ) (one Q(l) = Q) and (G4-dir) (rank 0, many directions).
   - The ticket concedes "Neither is necessary" (L2_NA_TL.md:71-73).

6. **Exponent A in η_A (STATEMENT.md:94).** L3 uses A only via log p ≤ A log n (L3_sandwich.md:54-57, 90-93).
   - η_A can be replaced by the threshold at a := limsup log p/log n, which is larger when p ≪ n^A.
   - The restriction A ≥ 1 is not used in L0–L3.

**Stronger than the mechanism needs — hard to weaken**

7. **Whole-lattice NA and |Q| ≤ C_Q log n (STATEMENT.md:89, 96-98).**
   - The descent needs NA only on [S₀, S̃₀] (L1_descent.md:27-33). REPORT.md:91-92 says so itself.
   - The ticket's numerics show NA(𝓛) failing in 10/20 S5 runs while LS0 still reaches S₀ (STATEMENT.md:155-156). So (G4) is not necessary for the conclusion.
   - The log n scale is, however, natural for whole-lattice NA without correlation structure. With the shipped prior the per-variable penalty is fixed at ½ log n + log p, and 2^{|𝒫|} directions in a |𝒫|-dimensional noise subspace can pick up noise of order |𝒫|. I cannot show that the constant 1 is tight.
   - |Q| = O(log n) is forced by the union bound over 2^{|𝒫|} lattice sets (L2_NA_TL.md:15; L0_toolkit.md:23-25). The sandwich itself needs only log|Q| = o(log n) (L3_sandwich.md:91-93).

8. **Fixed s₀ (STATEMENT.md:59).**
   - L0–L3 use s₀ only through S₀ ⊆ Q and constants (k₀ = |Q| + 16s₀, |𝔉| ≤ 5s₀n^D). They would go through for s₀ = O(log n).
   - The binding use is the external T03♯ (j₀, m♯_n).
   - Yang–Wainwright–Jordan, Castillo–Schmidt-Hieber–van der Vaart and Narisetty–He all allow growing s₀.

9. **TV for every U ⊆ C_b∖{j}.** This excludes masked truths. It is needed for S₀ ⊆ S̃, and hence for the delete-only path, but not obviously for the conclusion, since swaps could recover a masked truth.

10. **(G3a) on every block (STATEMENT.md:92).** This excludes near-duplicate null pairs anywhere in the design, although complete linkage puts such pairs in the same block. It is used for the L0 remainder on 𝔉_blk (L3_sandwich.md:17-19). It can probably be confined to blocks meeting Q with a modified expansion, but I am unsure.

**Necessary or sharp for the step where it is used**

11. **NEG threshold η_A (STATEMENT.md:94).** It is sharp for the sandwich step when p = n^A.
    - A far null with δ² = ησ² log n enters a block table when (δ + σZ)² ≳ σ²(log n + 2 log p).
    - Over about n^A weakly dependent nulls, max|Z| ≈ √(2A log n).
    - So some null outside Q enters once √η > √(2A+1) − √(2A).
    - This shows sharpness for the step S̃ ⊆ Q, not necessity for the theorem.

12. **Gram floor (G2) on S₀ ∪ {l}.** Some floor is necessary: an exact copy of a truth makes TL fail by a tie and S₀ unidentifiable. The floor on all of Q ∪ {l} with fixed φ₀ is a proof convenience.

### (b) Conclusion

- **Mode and rate.** Only "→ 0" is stated. The proof's failure probabilities are 1/log n by choice of log log n slacks (L2_NA_TL.md:60-62, 67; L3_sandwich.md:20-21).
  - Replacing each log log n by ε log n keeps every inequality, because the δ₀ slack in (G4-χ), log N_n = o(log n), and the strict η < η_A all leave room.
  - With the ladder bound n^{−ξ/(1+ε₂)} (L3_sandwich.md:70) and P(𝒟₂ᶜ) ≤ C_F n^{−2}, this gives D_n = O(n^{−c}), provided the 𝒟₁, 𝒟₃ events of GEN-L1 (not in the files) are polynomial.
  - The rate for P(𝒪 ∩ {Ŝ⁺ ≠ S₀}) then depends on an expectation form of T03♯, which states only O_P(√(log n/n)). I cannot judge that from the files.
  - For comparison, Yang–Wainwright–Jordan give polynomial-in-p probability bounds.

- **Scaling range.**
  - p ≤ n^A against log p = o(n) in Narisetty–He and Yang–Wainwright–Jordan. NA itself does not use the polynomial bound, because the BB prior's log p term tracks 2 log p. The binding uses are the ladder (L3_sandwich.md:70), η_A → 0 as A → ∞, and T03♯.
  - Relevance set O(log n) against overfitted models up to about n/log p in the Yang–Wainwright–Jordan canonical-path analysis and Zhou–Yang–Chang–Liang. Those results use tunable prior penalties and cover MCMC mixing, not this deterministic start-mode descent. I am fairly, not fully, confident of their exact conditions.

- **Move count.** Exactly |S̃₀∖S₀| moves is sharp on the events.

### (c) Cheapest route to a stronger version

**Easy (about a page of edits, no new ideas):**
- Restate (b) as: under (G1)–(G4) with |𝒫_n| ≤ ℓ_n + 1 the production cap suffices (edit L4_assembly.md:31).
- Replace M_n → ∞ by M ≥ M₀(A, σ², M) in (G3b).
- State the cap premise as "any cap ≥ |S̃₀∖S₀| − 1 with probability → 1".
- Add the local-rank variant of (G4).
- Use ε log n slacks to state D_n = O(n^{−c}).
- Replace A in η_A by limsup log p/log n.

**Hard:**
- Path-restricted NA, or a "no spurious local maximum among supersets of S₀" argument, to pass |Q| ≫ log n. This is the S5 frontier (REPORT.md:86-90).
- Growing s₀ and a finite-constant beta-min. Both need T03♯ re-examined.
- Super-polynomial p.
