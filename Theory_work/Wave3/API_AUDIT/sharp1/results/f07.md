## W2-APP:Thm-LOC — Theorem LOC (`lemmas/L3_LOC.md:34-38`; premises `:19-23`, `:25-28`, `:30-32`)

**Summary.** The design class (bounded spectrum, exponential locality along a line) and the O(log n) relevance set are sharp for this proof route. The signal side is not: fixed θ_lo and fixed a₀ are stronger than the proof uses, and the upper spectral bound C is redundant under (LOC-Σ). I could not check the upstream GROW statements, which are not in the bundle, so the signal-side relaxation is argued from how this file uses them.

### (a) Hypotheses

1. **Fixed signal floor θ_lo and fixed PTV constant a₀ (`L3_LOC.md:19-20`, `:28`) — stronger than the proof needs.** The signal enters at three places, and each needs only a diverging envelope:
   - TV step (`L3_LOC.md:63-66`): gives δ²_{U,j} ≥ N a₀²/4 and M_n := N a₀²/(4 log n). The perturbation error is O(ħ_n) = O(√(log n/n)), so n·a₀,n²/log n → ∞ should suffice, provided GROW's (G3b) needs only M_n → ∞.
   - TL step (`L3_LOC.md:158-160`): the consumed Lemma L2.1 has n₀ depending only on "the BM-∞ envelope", i.e. θ_lo²nφ₀²/(σ² log n) → ∞ (`L1_POST.md:30`).
   - Posterior input: POST(b) already allows varying θ*_j (`L1_POST.md:33`).
   
   NA (`L3_LOC.md:99`) uses neither PTV nor the signal, and d_n (`:30`) uses only θ_hi. So the theorem should hold for θ_lo,n → 0 and a₀,n → 0 with n·min(θ_lo,n², a₀,n²)/log n → ∞, and with bounded rather than fixed coefficients. `L3_LOC.md:200` lists only the constant-level regime as not claimed.

2. **Upper spectral bound C (`L3_LOC.md:26`; `L2_CT.md:36-39`) — redundant under (LOC-Σ).** With unit diagonal and at most two indices per distance, the Schur test gives λ_max(Σ) ≤ 1 + 2K/(e^a − 1). C is used only through CD(a) with α = 1/C (`L2_CT.md:43`, `:57`; confirmed at `L3_LOC.md:183-184`). Under (LOC-Θ) the same test bounds λ_max(Θ) by max_jΘ_jj + 2K/(e^a − 1), so the floor c could be replaced by a floor on Var(W_j | W_{−j}). I could not show C is redundant under (LOC-Θ).

3. **Global floor λ_min(Σ_n) ≥ c — effectively needed by the route.** It is used in CT (`L2_CT.md:52-57`). The proof conditions only on sets of size O(log n) (`L3_LOC.md:77-83`, `:86-90`, `:123-130`), which suggests a sparse floor might do. But under (LOC-Σ) a fixed floor on windows of length L_n → ∞ already implies the global floor up to O(1/L_n²), by a standard localisation argument, so nothing is gained. Some floor on bounded sets containing S₀ is necessary for any method (a null with correlation 1 − n⁻² to a truth; cf. `L1_POST.md:78-82`). A floor far from S₀ is not shown necessary.

4. **Exponential decay with fixed rate, one-dimensional ordering, fixed s₀ — sharp for this route.**
   - The route needs |Q| = O(log n) (`L3_LOC.md:30-32`) so that the families of size p·2^{|Q|} are polynomial (`:71-72`, `:104-105`).
   - Slower decay breaks this: polynomial decay gives d_n ≍ n^{1/(2β)}; stretched-exponential decay gives |Q| ≍ (log n)^{1/γ}.
   - d ≥ 2 and growing s₀ break it the same way (`:154-156`; |Q| ≤ s₀(2d_n + 1)).
   - The sandwich conclusion itself cannot hold with an O(log n) set once visible nulls outnumber log n (Lemma VN, `L5_VN.md:28-34`).
   - The order log n is right: under AR(1) with contiguous blocks, each block within distance ≈ log n/(2t) of a truth contributes a visible null.
   - None of this is shown necessary for the final conclusion Ŝ⁺ = S₀.

5. **PTV over |U| ≤ 15.** The U = ∅ case is necessary for "S₀ ⊆ S̃ for every partition" (the cancellation example at `L4_families.md:49-51`). The bound 15 is the block cap minus one; for a partition with blocks ≤ B, PTV(|U| ≤ B − 1) suffices. This is a trivial parametrisation.

6. **Gaussian rows and p ≤ n^A.** Gaussianity is used essentially: exact independence of regression residuals (`L3_LOC.md:107-108`), χ² laws, and the spherical argument (`:90-91`). This is unlike POST, where it enters only through the entrywise event (`L1_POST.md:83-84`). The bound p ≤ n^A is project-wide and built into T03♯ and j₀.

### (b) Conclusion

- **Posterior rate O_P(√(log n/n)) (`L3_LOC.md:38`).** By my own heuristic (not verified), this is the true order for this prior when log p ≍ log n. One-extra-variable models carry mass ≈ p⁻¹n^{−1/2}Σ_l e^{Z_l²/2} ≍ √(log p/n). So the sharp form is √(log p/n), and the stated rate is loose only for sub-polynomial p. A faster rate would need a different prior (the Johnson–Rossell non-local-prior point), not a better proof.

- **Reported model: P(𝒪 ∩ {Ŝ⁺ ≠ S₀}) → 0 with no rate.** The proof contains a rate. The 1/log n in (E1) (`L3_LOC.md:119`) is an artefact of taking only 2 log log n of slack when the threshold has ≈ log n to spare (`:146-148`). The sandwich count is already Ck·n^{−1/2} (`:91`). A bound of n^{−1/2}·polylog looks extractable. It cannot be much better: a single null beats the threshold with probability ≈ n^{−1/2}/√(log n), so almost-sure convergence by summability is not available.

- **Scaling against the literature.**
  - Beta-min: the theorem has fixed signals. The known optimal level is |θ_j| ≳ σ√(log p/n) (Wainwright's information-theoretic bound; matched up to constants by Castillo–Schmidt-Hieber–van der Vaart and by Yang–Wainwright–Jordan, to my recollection).
  - Sparsity: s₀ is fixed here; those works and Narisetty–He allow it to grow.
  - Dimension: p ≤ n^A here; Narisetty–He allow log p = o(n).
  - Yang–Wainwright–Jordan give a computational guarantee with no locality assumption but under a sparse-projection condition on a fixed design. I am not confident of its exact form, and I am not sure of the "Zhou–Yang–Chang–Liang" reference.
  - None of these covers this method's reported model, so the comparison is about regime only.

- **No delivery claim (P(𝒪) → 1) and dependence on named premises (`L3_LOC.md:22-23`).** This is a scope limit, not something the proof can sharpen.

### (c) Cheapest route to a stronger version

1. **Easy.** Restate with θ_lo,n and a₀,n such that n·min(θ_lo,n², a₀,n²)/log n → ∞. This needs a re-read of GROW (G3b), L1.1 and L2.1 to confirm they need only M_n → ∞ and the BM-∞ envelope, plus a change of "fixed coefficients" to "bounded" at `L3_LOC.md:64-65`.
2. **Trivial.** Drop C from (LOC-Σ), with C := 1 + 2K/(e^a − 1), and state PTV for |U| ≤ B − 1.
3. **Easy to moderate.** Carry the rate: take slack x_n ≍ log n in (E1) and collect the n^{−2}, e^{−cn} and n^{−1/2} terms, giving D_n = O(n^{−1/2}·polylog); and state the posterior rate as √(log p/n) if T03♯ supports it.
4. **Hard.**
   - Constant-level beta-min C√(log p/n).
   - Growing s₀, which needs a lattice that factorises over separated truths in place of 2^{|Q|}.
   - d ≥ 2. The window comparison in L3.6 appears to survive with a larger window (Step 2 still gives log N = log p + o(log n), `L3_LOC.md:154-155`). The obstacle is the L0 events and the 2^{|Q|} union over a lattice of size (log n)^d.
   - Polynomial decay, which needs a route not based on an O(log n) sandwich.
   - Non-Gaussian rows.
