## Claim W2-FAC-A:Prop-F-FAC — Proposition F-FAC (delivery), `lemmas/L7_delivery.md:22-24`, premises `:7-20`

The claim has two parts. P(no output) = 0 is inherited from Proposition F and cannot be strengthened. The statistical part, P(Ŝ⁺ = S₀) → 1, rests only on the event 𝒦_n ("LS0 scores S₀ within the cap") plus the posterior input (L7:39-49). My assessment concerns that part.

### (a) Hypotheses

**(TV) / (TV-pop) / (GC-CS) look unnecessary for this claim — the main finding.**
- They enter only through the sandwich (L2_sandwich.md:39-43), which Step 3 uses to place the start mode in 𝓛 (L7:40).
- Delivery needs only that LS0 scores S₀, not that the start mode contains S₀.
- A short argument from ingredients already in the ticket appears to replace the sandwich (my sketch, not checked line by line):
  1. *A missing truth can always be added with gain of order n.* Take any T ⊆ [p] with M := S₀ ∖ T ≠ ∅. Under (AG) the Gram floor λ_min(R̂) ≥ 3ψ₀/4 holds on all subsets (L4_assembly.md:42), so ‖(I − P_T)μ‖² ≥ (n−1)φ²‖θ*_M‖². Expanding ‖(I − P_T)μ‖² = Σ_{i∈M} θ*_i‖(I − P_T)x_i‖·u_{T,i}ᵀμ gives max_{i∈M}|u_{T,i}ᵀμ| ≥ √(n−1)·φ²·θ*_min.
  2. *Noise and score control are already uniform.* Corollary U bounds |Z_{T,l}| = O(√log n) for every T ⊆ [p], not only lattice sets (L1_uniform_add.md:149-154). (E1), (E2) hold for every A ⊆ [p] (L3_NA_TL.md:11-24), and s_Y is bounded on E_Y (L3:26-28). With K = p eventually the addition is feasible, so the best move from any T ⊉ S₀ raises F by at least c·n, for fixed nonzero θ*.
  3. *Only O(1) such moves can occur.* On E_Y the total range of F over subsets of [p] is O(n) + O(p log n) = O(n), because RSS_[p] ≥ c·n and p log n = o(n) under (P). So the greedy path has a bounded number m₁ of moves outside 𝓛.
  4. *Then the existing descent takes over.* Under TL(𝓛) (L3:62-77) the path cannot leave 𝓛 once inside. From the entry point C′ ∈ 𝓛, C-GROW L1.2 (L4:13-16) reaches S₀ in |C′ ∖ S₀| ≤ |S̃₀| + m₁ deletions. The total is at most |S̃₀| + 2m₁ ≤ ℓ_n + |S̃₀| eventually, since ℓ_n → ∞.
- If this holds, P(𝒦_nᶜ) ≤ P(NA(𝓛)ᶜ) + P(TL(𝓛)ᶜ) + o(1) with no visibility condition. That would cover the a = 1/2 study configurations that are currently excluded (REPORT.md:13-15, open item at :115-116; L5_random_instances.md:155-159).
- It would also make the "exact start-mode maximiser" premise irrelevant to the statistical step, since any emitted centre works. L7:51-52 already notes only "some maximiser" is used.
- The sketch uses fixed nonzero θ*; under bare BM-∞ with θ*_min → 0 the move count in step 3 needs more care.

**(P): limsup log p/log n < 1/6 (STATEMENT.md:92-93).**
- This is necessary for the proof's route, not shown necessary for the claim. Proposition SHARP (L6_sharp.md:12-13, 49-52) kills NA(𝓛) above 1/6 but says explicitly it is not a method inconsistency.
- The ticket's own numerics show LS0 reaching S₀ in 718/720 runs with log p/log n up to 0.75 (REPORT.md:100-101).
- For general κ̄ > 1 the exponent 1/(2κ̄(κ̄+2)) is a worst-case class constant. It is attainable only when many coordinates carry the minimal loading, so an instance-dependent constant would be larger for heterogeneous loadings. This is minor, since every headline instance has κ = 1.

**(AG): δ_n√(p log log n) → 0 (STATEMENT.md:90-91).**
- This is slightly stronger than used. L3.1 needs only ε_n = o(√log n) (L3:45-46, 53), and U(d) needs δ_n ≤ ψ₀/4. So δ_n√(p log log n) = o(√log n) suffices.
- The gain is small and vacuous for iid rows under (P), where the Frobenius bound δ_n = pδ′_n (L5:34-35) already works.
- If the exponent were ever lifted, this perturbation step would bind at p ≈ n^{1/3}. The factor eigenvalue of order p fluctuates by about p/√n, so the operator-norm coupling cannot go further.

**Other hypotheses.**
- *Gaussian noise.* The exact split (1.1) and the sharp constant 2 log p need it. A sub-Gaussian version would probably lose the constant and hence the exponent. I am unsure whether a sharp version exists.
- *One global factor, fixed s₀.* Both are genuine limits of the present argument (L8_frontier.md:73-76). Growing s₀ depends on the external T03♯.
- *BM-∞.* It is rate-optimal up to the diverging factor, compared with the usual β_min² ≳ log p/n.
- *CAL.* Not assuming it is already a strength.

### (b) Conclusion

**Scaling range.** p < n^{1/6} is far below what is known statistically for Bayesian selection consistency: Narisetty–He allow log p = o(n), and Castillo–Schmidt-Hieber–van der Vaart work under compatibility conditions. Yang–Wainwright–Jordan's rapid-mixing result for a different sampler also allows p ≫ n. I do not claim their sparse-projection condition or size cap transfers to this prior (BB(1,p) charges only about 2 log p per variable) or to this start (the mode tends to [p]). I am not confident enough about the Zhou et al. result to cite it. The posterior input T03♯ is not the bottleneck here; the search analysis is.

**Rate.** The 1/log n failure bound (L1:96; L3:80) is an artefact of the log log n allowances. Because (P) is strict there is ε·log n of slack (L3:48-54), so replacing 2 log log n by 2c log n for small c would give P(NA(𝓛)ᶜ ∪ TL(𝓛)ᶜ) ≤ n^{−c}. The overall rate is still limited by the external inputs (the [GEN-L1] events and E[1 − π(S₀)]), so this is a minor point.

**Boundary.** Nothing is claimed at equality 1/6. That is a second-order matter and I see no cheap gain.

### (c) Cheapest routes to a stronger version

1. **Easy: drop (TV), (TV-pop) and (GC-CS) from Proposition F-FAC**, and likewise from D_n → 0 in (L4)/(L5) via [OP]. Add a short "underfitted phase" lemma as in (a). It needs no new probabilistic estimate, about a page, and the main care is the cap bookkeeping.
2. **Easy, cosmetic:** relax (AG) to o(√log n) and state a polynomial rate for the NA/TL part.
3. **Hard: go beyond 1/6.** Delivery needs only that S₀ is scored within the cap, not NA(𝓛). A natural split is:
   - (i) TL(𝓛) plus "every T ∈ 𝓛 ∖ {S₀} has a strictly improving neighbour". The TL proof (L3:62-77) does not appear to use the 1/6 exponent. The second property looks plausible for exact-Gram CS from the one-dimensional move identities (L8:21-26), because the kept null nearest the centre c_T seems always cheap to delete. I have not proved this.
   - (ii) A bound of about ℓ_n/2 on the number of non-deletion moves. This is exactly the one-sided late stage that L8:59-65 leaves open, and it needs new work.
   
   A variant with a larger LS0 cap would need only (i), but that is a method change and would require re-doing the resource allocation.

**Overall.** The exponent is sharp for the route and improvable only with hard new work. The visibility/genericity hypothesis appears removable with a modest argument, which fixes the verdict.
