### (a) Hypotheses

**1. LSF(ii) rate `ψ_n√n/(log n)^{3/2} → ∞` (`L1_POST.md:24-25`) is much stronger than needed.**
- It is used only in step (3), `L1_POST.md:49-54`, through the additive bound ‖R̂_S − Σ_S‖₂ ≤ |S|·max-entry ≤ C″(log n)^{3/2}/√n, which then has to be o(ψ_n).
- For Gaussian rows a multiplicative bound is available. For fixed S, (CW_S)ᵀ(CW_S) = Σ_S^{1/2}·Wishart_{|S|}(n−1, I)·Σ_S^{1/2}.
- Davidson–Szarek gives λ_min(Wishart) ≥ (√(n−1) − √|S| − t)² with probability ≥ 1 − e^{−t²/2}. A union over the at most exp(O(log² n)) sets of size ≤ k̄_n with t = C log n is harmless.
- Hence, uniformly over those sets, λ_min(X_SᵀX_S) ≥ (n−1)(1 − o(1))·λ_min(Σ_S); the sample-sd rescaling costs a factor 1 + O(√(log n/n)) on the entrywise event.
- So SE_w(m♯_n; 1) holds with probability → 1 as soon as **liminf nψ_n > 1**. This gains a factor of about √n(log n)^{3/2}.
- This threshold is sharp for conclusion (a). If a witness set (anchored, see item 2) has nλ_min(Σ_{S_n}) → 0, then with v its bottom eigenvector ‖CW_{S_n}v‖² ~ ψ_nχ²_{n−1}, so λ_min(X_SᵀX_S) → 0 in probability and SE_w(·; g₀) fails for every fixed g₀.
- It also removes the mismatch with part (c), `L1_POST.md:34-35`, where the exact-Gram case already needs only ψ_n ≥ 1/(n−1).
- Whether SE_w with an absolute floor is needed for posterior consistency itself is a question about T03♯, which I cannot judge from the files. If the score depends on X_S only through its column span, the floor would be a proof artefact.

**2. LSF(i) and (ii) quantify over all S of the given size; only anchored sets are used.**
- The proof uses only sets S₀ ∪ J (`L1_POST.md:41-42`, `:51-54`). Remark 2 (`:78-82`) already concedes this and gives an example separating the two conditions.
- The anchored version (λ_min(Σ_{S₀∪J}) ≥ φ² for |J| ≤ j₀; ≥ ψ_n for the anchored sets up to size k̄_n) suffices with no change to the proof.
- By Remark 2, the anchored fixed floor is necessary for conclusion (a). Publishing the stronger all-sets form is avoidable.
- A fixed φ is probably not necessary for posterior consistency. The BM envelope θ_lo²nφ₀²/(σ² log n) at `:30` suggests a trade-off allowing φ_n → 0, but that needs a T03♯ with vanishing φ₀ — hard, and I am unsure.

**3. Fixed θ_lo (`L1_POST.md:11`).**
- Step (4), `:55-57`, uses θ_lo only through the envelope θ_lo²nφ₀²/(σ² log n) → ∞.
- A deterministic sequence θ_lo,n with nθ²_lo,n/log n → ∞ gives the same common envelope, and the diagonal argument (`:58-66`) is unchanged.

### (b) Conclusion

**Rate √(log n/n): sharp in order when log p ≍ log n.**
- This is my own derivation, not in the ticket. It uses the score increment and prior ratio displayed at `L5_VN.md:46-52`, and assumes the model-level score has the same form as the block-table one.
- From those lines, π(S₀∪{l})/π(S₀) ≥ [(s₀+1)/(2p)]·(n+1)^{-1/2}·e^{h_l/2 − 2κ_E}.
- Summing over the p − s₀ nulls gives 1 − π(S₀) ≥ c·n^{-1/2}·π(S₀) always, so nothing faster than n^{-1/2} is possible for this prior.
- Since e^{χ²₁/2} has tail index 1, p⁻¹Σ_l e^{h_l/2} ≍ √(log p) when the h_l are approximately independent. That step is heuristic.
- So 1 − π(S₀) ≍_P √(log p/n), which is √(log n/n) at p = n^A.
- For fixed or sub-polynomial p the stated rate is loose by √(log n/max(1, log p)). A √(max(1, log p)/n) statement would need T03♯ restated in log p; that is a minor gain.
- The rate is set by the prior (size penalty about 2^{-k}, n^{-1/2} per added variable). As I recall, Yang–Wainwright–Jordan obtain 1 − π(S₀) ≲ p^{-1} under a p^{-κ} size penalty, but that is a different method and not an improvement available to this one.
- I recall no explicit rates from Narisetty–He or Castillo et al. to compare with.

**Mode and uniformity.**
- The proof (`:58-66`) actually delivers a supremum over designs in 𝒜_n. The probability bound for 𝒢_n depends only on A and the constants.
- So the O_P statement is uniform over all (Σ_n, S₀ positions, θ* in the box) satisfying LSF with the given constants. The lemma states it for one sequence only. This strengthening is free.
- P(𝒜_n) → 1 can be stated with a polynomial rate n^{-c}, by taking C_A large.
- An in-expectation rate E[1 − π(S₀)] = O(√(log n/n)) is plausible, but it needs T03♯ in that form. I cannot tell from the files.

### (c) Cheapest route to a stronger version

All four steps are edits to steps (3)–(5); they look like a day of work plus a re-check, and need no new input from T03♯ except confirming the reading of BM-∞.
1. Restate LSF on anchored sets S₀ ∪ J.
2. Replace the Weyl/max-entry bound for the logarithmic sizes by the Wishart multiplicative bound, with hypothesis liminf nψ_n > 1. Define 𝒜_n as the entrywise event intersected with the X-measurable event {λ_min(X_SᵀX_S) ≥ 1 for all anchored |S| ≤ k̄_n}.
3. Allow θ_lo,n with nθ²_lo,n/log n → ∞.
4. State the conclusion uniformly over the class.

Add a remark that the rate is of exact order for p = n^A. Growing s₀, log p = o(n) and vanishing φ are hard and sit outside this ticket.
