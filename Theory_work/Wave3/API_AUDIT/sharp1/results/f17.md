## W3-POST:Prop-LB — Proposition LB (deterministic lower bound δ ≥ 1/(1+√(n+1)))

Statement at `lemmas/LB_rate_lower_bound.md:9-17`; proof at `:19-32`; used as Theorem 1 item 7 (`STATEMENT.md:101-104`) and sharpness record item 4 (`ASSUMPTION_MAP.md:123-130`).

**(a) Hypotheses**

- **Domain 1 ≤ s₀, s₀+1 ≤ K is necessary in kind.** The proof needs one feasible one-variable extension (`LB:20`). The ticket's own p = s₀ = 2 example (δ ≈ 6.5·10⁻¹⁰, `STATEMENT`-level report at `REPORT.md:73-74`) shows failure without it. For the other excluded case, s₀ = K < p (cap binding), I expect failure as well, since swaps and deletions can be made exponentially small by a strong signal; the ticket has not tested this.
- **Redundant hypotheses (cosmetic).** s₀+1 ≤ K = min(p, ⌊n/2⌋) already forces s₀ < p, p ≥ 2 and n ≥ 4. So "n ≥ 3", "p ≥ 2" and "s₀ < p" at `LB:10-11` add nothing; the domain is just 1 ≤ s₀ ≤ K−1.
- **s₀ ≥ 1 is needed only for the constant.** It is used once, in the monotonicity step `LB:30-31`. At s₀ = 0 the same three steps give prior ratio 1/(2p−1) and multiplicity p, so (p−s₀)·r = p/((2p−1)√(n+1)) > 1/(2√(n+1)). Hence δ ≥ 1/(1+2√(n+1)) for the null model whenever K ≥ 1. The n^{−1/2} floor therefore holds on the whole range 0 ≤ s₀ ≤ K−1.
- **No noise, design or signal condition is used** (`LB:35-36`), and S₀ need not be the true support. Nothing to weaken there. The proposition is really the statement max_{|S|<K} π(S) ≤ √(n+1)/(1+√(n+1)).

**(b) Conclusion**

As a worst-case bound over all (X, y, p) it is essentially tight, but the proof discards three things, the last of which matters for the sharpness claim it supports.

1. **n+1 can be n (cosmetic).** In `LB:25-27`, write a = uᵀ(I−P_H)u and b = uᵀ(I−P_A)u, with 0 ≤ a ≤ b ≤ ‖x_j‖² = n−1. Then D_S/D_{S₀} = (1+(n+1)a)/(1+b) ≤ (n+1) − n/(1+b) ≤ n, with equality when x_j ⟂ X_{S₀}. So δ ≥ 1/(1+√n). This exactly explains the reported minimum ratios: 1.00005 at n = 10⁴ equals √(1+1/n) (`LB:6`), and 1.013 (`STATEMENT.md:103-104`) is √(1+1/n) at n ≈ 38. The deterministic infimum is therefore attained in the limit at p = s₀+1.

2. **The multiplicity factor is thrown away (`LB:30-31`).** The proof actually gives δ/(1−δ) ≥ c(p,s₀)/√n with c(p,s₀) = (p−s₀)(s₀+1)/(2p−1−s₀). The proposition keeps only its minimum 1, taken at p = s₀+1.
   - In the project's regime p → ∞, c → (s₀+1)/2, and c ≥ (s₀+1)/3 as soon as p ≥ 2s₀.
   - This yields a sparsity obstruction the ticket does not record: π(S₀) ≤ [1 + (s₀+1)/(3√n)]⁻¹ for every design and signal. So π(S₀) → 1 is impossible for the coded prior unless s₀ = o(√n), and the rate r_n is impossible unless s₀ = O(√log n).
   - That bears directly on `REPORT.md:190` (item 8, "growing s₀ = o(log n/log log n)"): rate r_n cannot survive there once s₀ ≫ √log n. The achievable target is of order s₀·√(log p/n).
   - Free corollaries of the same lines: every null PIP_j ≥ π(S₀)(s₀+1)/((2p−1−s₀)√n), and π(S ⊋ S₀) ≥ π(S₀)·c(p,s₀)/√n. The latter is a lower-bound companion to Theorem 1 item 5(a).
   - Adding |J| ≥ 2 supersets by the same argument is second order for fixed s₀.

3. **The √log n gap to Theorem 1 (`LB:16-17`, `LB:39-40`, `ASSUMPTION_MAP.md:126-129`) looks closable in probability, on the lower-bound side.** Step (iii) at `LB:28` replaces the fit factor by 1. Under G that factor is ≥ exp(ν(Q_{S₀}−Q_S)/(2b₀+Q_{S₀})) ≈ exp(χ²_j/2).
   - My own computation (heuristic, unchecked): W = e^{χ²₁/2} has tail P(W>w) ~ 1/(w√(π log w)) and truncated mean E[W; W ≤ p] = 2√(log p/π). The maximum of p copies is of smaller order than p times this, so a weak law gives p⁻¹ΣW_j ≈ 2√(log p/π).
   - The expected result is δ ≥ (1−o_P(1))·(s₀+1)·√(log p/(πn)) for incoherent designs with p → ∞. At p = n^A this matches Theorem 1's upper rate, so the upper bound is the sharp one there and LB is loose by √log p.
   - At fixed p it is the other way round: LB is tight (E0, `LB:37-38`) and the upper bound is loose. The two-sided truth appears to be δ ≍_P √((1 ∨ log p)/n).

4. **Literature.** The n^{−1/2} floor is a property of the coded prior, not of the problem. BB(1,p) gives total one-up prior odds ≈ (s₀+1)/2, and g = n gives an Occam factor n^{−1/2}.
   - Yang–Wainwright–Jordan obtain 1 − π(γ*) = O(p⁻¹) with a p^{−κ|γ|} prior.
   - In Castillo–Schmidt-Hieber–van der Vaart (2015), as I recall it, the dimension-prior condition requires a decay p^{−A₄} with A₄ > 0, satisfied by Beta(1, p^u) only for u > 1. The coded u = 1 would then sit on the boundary. I have not re-read this.
   - Narisetty–He state no rate, as far as I recall.
   - So no improvement of the n^{−1/2} order is available without changing the target; only the constant and the log factor are.

**(c) Cheapest routes**

- **Trivial (a few lines each):**
  - State δ/(1−δ) ≥ c(p,s₀)/√n with c kept.
  - Allow s₀ = 0 with constant 1/2.
  - Replace n+1 by n.
  - Record the corollaries s₀ = o(√n) and the null-PIP floor.
- **Modest (about a page): orthogonal designs, p = n^a, a ≤ 1.** Here G = (n−1)I satisfies (E), (F_λ), (F_w) with φ₀ = 1.
  - Keep the fit factor via (1−x)^{−ν} ≥ e^{νx}.
  - The x_jᵀε are independent Gaussians.
  - Truncate at χ²_j ≤ 2 log p. The per-term variance is ≤ p/√(π log p), so Chebyshev gives the weak law.
  - The studentisation error is χ²·O_P(n^{−1/2}) = o_P(1) on the truncation range.
  - This already proves that √(log n/n) is attained on a design sequence inside Theorem 1's hypotheses, which closes sharpness item 4 for a ≤ 1.
- **Moderate (p ≫ n).** Same truncated second-moment argument, under a coherence condition: max partial correlation among nulls given S₀ is o(1/log p). Gaussian rows with p = n^A satisfy it. On the truncation box the bivariate density ratio is 1+o(1), so the covariances are o(mean²). This needs care with the ridge and IG factors but no new idea.

The stated bound is correct and worst-case tight. A strictly more informative version (p- and s₀-dependent constant, s₀ = 0 included) is immediate, and the √log p version is a concrete short argument.
