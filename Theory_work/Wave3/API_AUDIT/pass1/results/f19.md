The proposed Gram (n−1)[(1−ρ)I + ρ11'] has eigenvalue (n−1)(1−ρ) with multiplicity p−1 (on the complement of 1_p) and (n−1)(1+(p−1)ρ) with multiplicity one (on 1_p). - **Sufficiency (L0_rank.md:9).** An n×p matrix Q with orthonormal columns in 1-perp exists exactly when p ≤ dim(1-perp) = n−1. Σ is symmetric positive definite, so a symmetric positive definite square root R exists.
  - With X = sqrt(n−1)·Q·R: 1'X = sqrt(n−1)(1'Q)R = 0, and X'X = (n−1)·R·Q'Q·R = (n−1)R² = (n−1)Σ. Correct.
  - diag(Σ) = 1, so each column has squared norm n−1. With centering this gives sample variance 1, so columns are nonconstant and standardization returns X. This is consistent with hypothesis G in STATEMENT.md:7-9.
