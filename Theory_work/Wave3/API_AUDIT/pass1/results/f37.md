**Tools (L2:3-9).**
- (T1) is the standard two-sided Gaussian tail bound.
- (T2) is Laurent–Massart Lemma 1 as stated. The side remark d + 2√(dx) + 2x ≤ (√d + √(2x))² holds because the right side is d + 2√(2dx) + 2x.
- (T3) holds: 0 ⪯ A ⪯ I and A = ΠAΠ give A ⪯ Π. εᵀΠε/σ² ~ χ²_{rank A}, and χ²_r is stochastically dominated by χ²_m for r ≤ m.

**Deterministic witness (L2:11-13).** OK. γ(·|S) depends on (X, θ*) only, the smallest-index tie-break is deterministic, and σ_S does not depend on t, so the same t maximises γ/σ_S².

**E1 (L2:15-20).** OK.
- x_tᵀR_S Cε = (C R_S x_t)ᵀε = (R_S x_t)ᵀε, since R_S x_t is centred.
- The variance is σ² x_tᵀR_S² x_t ≤ σ² x_tᵀR_S x_t ≤ σ² a(t|S).
- (T1) with threshold σ r_n a^{1/2} gives failure ≤ 2exp(−r_n²/2) = 2exp(−log(2N_q) − x) = e^{-x}/N_q.
- There are at most N_q = Σ_{k≤q} C(p,k) sets, and one Gaussian variable per set because t(S) is not random. The union bound gives e^{-x}.

**E4 (L2:22-26).** OK.

- The one-sided tail gives exp(−r_n²/2) = e^{-x}/(2N_q) per set, so the union is e^{-x}/2 ≤ e^{-x}.
- When m_S = 0 the variable is the constant 0.

**E2⁺ (L2:28-37).** OK.
- (n−1)τ̂² = ‖μ‖² + 2μᵀε + ‖Cε‖² uses Cμ = μ.
- ‖Cε‖²/σ² ~ χ²_{n−1}, and σ²(n−1)(1 + 2a_x + 2a_x²) = σ²(n−1 + 2√((n−1)x) + 2x), which matches (T2). With the one-sided Gaussian bound for μᵀε the failure is ≤ 2e^{-x}.
- On the event, using 2σ‖μ‖ ≤ √(n−1)τ_n² (AM–GM) and σ² ≤ τ_n², dividing by n−1 gives τ̂² ≤ τ_n²(1 + (2+√2)a + 2a²).
- This is ≤ τ_n²(1 + 4a + 4a²) = τ_n²(1 + 2a)², so τ̂ ≤ τ̄_n(x).

**E2⁻ (L2:30, 38-39).** OK.
- The lower χ² tail of (T2) matches σ²(n−1)(1 − 2a_x) = σ²(n−1 − 2√((n−1)x)).

- Hence τ̂² ≥ τ_n²(1 − (2+√2)a) ≥ τ_n²(1 − 4a).

**E3a (L2:43-49).** OK.
