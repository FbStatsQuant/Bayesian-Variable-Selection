## C-DLV:L2-S2 — Lemma S.2 (numerical failures C1–C5), L2_degenerate.md:20-35

**What I checked.** Positive definiteness, the Cholesky pivot claim, the lower bound on Q, the `q_nonneg` identity, the threshold remark, finiteness of log m, and the size invariant k ≤ K including B ≤ K.

- **Positive definiteness (L2:22-23).** G_S = X_SᵀX_S ⪰ 0 gives H = (n+1)G_S + I ⪰ I and A = G_S + I ⪰ I. This holds even when X_S is rank-deficient, so no full-rank hypothesis is hidden. OK.
- **Pivots (L2:23-25).** For a positive definite matrix in exact arithmetic, d_j = det_j/det_{j−1} > 0 and is finite. The test `!(d > 0) || !isfinite(d)` therefore never fires. OK.
- **Bound on Q (L2:27-29).** With z = X_Sᵀy, zᵀH⁻¹z = yᵀX_S H⁻¹X_Sᵀy. The eigenvalues of X_S H⁻¹X_Sᵀ are s²/((n+1)s² + 1) ≤ 1/(n+1), or 0. Hence n zᵀH⁻¹z ≤ (n/(n+1)) yᵀy and Q ≥ yᵀy/(n+1). After standardisation yᵀy = n − 1 > 0; this is available because a constant y exits earlier (A5), so the scorer is only reached with nonconstant y. OK.
- **Threshold remark (L2:29).** Q < 10⁻⁸ yᵀy together with Q ≥ yᵀy/(n+1) forces n + 1 > 10⁸. OK.
- **`q_nonneg` identity (L2:29-31).** I recomputed it:
  - ‖y − X_Sβ‖² + (‖X_Sβ‖² + ‖β‖²)/n = yᵀy − 2βᵀz + βᵀ[(1 + 1/n)G_S + I/n]β = yᵀy − 2βᵀz + n⁻¹βᵀHβ.
  - With β = nH⁻¹z this equals yᵀy − 2n zᵀH⁻¹z + n zᵀH⁻¹z = Q.
  - So the fallback does not change the value. OK.
- **Finiteness (L2:31-32).** The log-determinants of positive definite matrices are finite and 2b₀ + Q > 0, so log m(S) is finite and route 1 returns true. This uses b₀ ≥ 0 (prior hyperparameter), which is implicit. The k = 0 case is direct. OK.
- **k > K invariant (L2:32-34).** B = min(⌊√n⌋, ⌊√p⌋, 16) ≤ K = min(p, ⌊n/2⌋) holds: ⌊√p⌋ ≤ p for p ≥ 1, and ⌊√n⌋ ≤ ⌊n/2⌋ for n ≥ 2 (n = 3 gives 1 ≤ 1). Table models are subsets of a block and so have size ≤ B ≤ K.
  - Note, not a finding: the parenthetical caller list omits the exact-branch timing scores. These are covered by L1_resources.md:65-67 (size min(k_t, K_t) ≤ K_t on the timing context), and the positive-definiteness and Q argument applies to any column subset.
