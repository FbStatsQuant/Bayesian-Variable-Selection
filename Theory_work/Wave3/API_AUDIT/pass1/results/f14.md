- **TV.** The population bound is |θ_j|Var(W_j|W_U) − Σ|θ_k|r^{|j−k|} ≥ a₀ by P3, P4 and (6.0). The Schur-complement perturbation is O(ħ_n) in bounded dimension, and the residual norm² is ≤ N, so δ² ≥ N a₀²/4. This holds for every |U| ≤ 15, hence for any X-measurable blocks.
