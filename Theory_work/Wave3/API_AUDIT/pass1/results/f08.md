- With lo = u, hi = b and 60 halvings in exact arithmetic (EX-A), every lo and hi is of the form u + mδ with δ = (b − u)2⁻⁶⁰, and at the end hi − lo = δ.

## C-DLV:L5-5.1 — Lemma 5.1 (two-model closed form)

**Checked:** the algebra and the three bounds, for a > 0 and c ≥ 1.

- With σ(x) = a/(1+a), σ(x+s) = ac/(1+ac), σ(x+2s) = ac²/(1+ac²), Lemma 3.1 gives ρ⁽²⁾ = (1+ac)²/((1+a)(1+ac²)).
- (1+ac)² − (1+a)(1+ac²) = 2ac − a − ac² = −a(c−1)², so the stated closed form holds.
- (i) a/((1+a)(1+ac²)) has its maximum at a = 1/c with value 1/(1+c)², and (c−1)²/(c+1)² = tanh²(s/2) for c = eˢ. Correct.
- (ii) a(c−1)² ≤ ac² ≤ 1 + ac² gives 1 − ρ⁽²⁾ ≤ 1/(1+a). Correct.
- (iii) (c−1)² ≤ c² and 1 + a ≥ 1 give 1 − ρ⁽²⁾ ≤ ac²/(1+ac²). Correct.

## C-DLV:L5-5.2 — Lemma 5.2 (insertions, ε-remainder on [0, 2])

**Checked:** the perturbation identity, the three sufficient conditions, the per-step increment, the phase counts with their ceilings, the terminal-trial bookkeeping, and the constants.

- **Perturbation.** q_t(M₂) = (1 − r_t)·q⁽²⁾_t(M₂) is exact, so ρ = ρ⁽²⁾·(1−r_u)(1−r_{2v−u})/(1−r_v)². For 0 ≤ u ≤ v ≤ 1 all three points lie in [0, 2], giving (1−ε)²ρ⁽²⁾ ≤ ρ ≤ ρ⁽²⁾/(1−ε)². Both implications at L5_insertions.md:39-40 follow. θ < 0.94 holds at ε = 0.02 (θ = 0.9371).
- **Conditions (A), (B), (C).** Each is the correct inversion of Lemma 5.1 (ii), (i), (iii) respectively.
- **Increment.** A failing w = u + h (with w ≤ b ≤ 1) negates all three, so x < λ_θ, hD > s_θ and x + 2hD > −λ_θ. With v − u ≥ h/2 from Lemma 5.0 this gives x′ − x > max{s_θ/2, (−λ_θ − x)/4}. An appended bisection point is never snapped (L5_insertions.md:7-9: a snap would put v at 1 ≥ b, where ρ(u,1) ≤ ρ(u,b) < 0.90), so v = v_raw.
- **Phase 1 count.** For m appended trials starting in Phase 1, 2s_θ < y_m < (3/4)^{m−1}y₀, so m − 1 < log_{4/3}(y₀/(2s_θ)) and m ≤ ⌈·⌉. Steps in between only decrease y because D > 0 and u increases.
- **Phase 2 count.** m starting coordinates in a half-open interval of width 2λ_θ + 2s_θ, with gaps > s_θ/2, give m ≤ ⌈(2λ_θ + 2s_θ)/(s_θ/2)⌉.
- **Phase 3.** x ≥ λ_θ gives ρ⁽²⁾ ≥ θ for every v, so ρ(u,b) ≥ 0.90 and the trial is not bisection-limited.
- **Terminal trial.** At most one trial is unappended (`non_progress`, or a failed post-snap validation), and the additive 1 covers it. A trial that appends and then trips `too_many_intervals` did have a passing mid, so it is correctly counted among the appended ones.
- **Constants at ε = 0.01.** θ/(1−θ) = 0.9/0.0801 = 11.23596, so λ_θ = 2.41912. √(1−θ) = 0.285878, so s_θ = ln(1.800643) = 0.588143. 4(λ_θ/s_θ + 1) = 20.4526, ceiling 21, hence N̄_b = 22 + the Phase 1 term. All match.

## C-DLV:L5-5.2p — Lemma 5.2′ (remainder controlled on [0, 1+η])

## C-DLV:Cor-5.3 — Corollary 5.3

**Checked:** parts (a), (b), (c), the summary sentence, and the negative remark about N̄_b versus N̄_b′.

- **(a)** By L3 Lemma 3.4(b), #intervals = N_p′ + N_b^app. Each non-bisection step appends a distinct target or the final snapped 1, so N_p′ ≤ k. N_b^app ≤ N_b^try ≤ N̄ under whichever of Lemma 5.2 or 5.2′ applies. So k + N̄ ≤ T_e rules out `too_many_intervals`.
- **(b)** The smallest mid m = u + (b−u)2⁻⁶⁰ has 2m − u = u + 2⁻⁵⁹(b−u) ≤ b ≤ 1, so u, m, 2m − u lie in [0, 1] and the remainder bound holds under either hypothesis. (m − u)D ≤ s_θ gives ρ⁽²⁾ ≥ θ by (B), hence ρ(u,m) ≥ 0.90. By L3 Lemma 3.4(c), `non_progress` is equivalent to ρ(u,m) < 0.90, so it cannot occur. D ≤ s_θ2⁶⁰ suffices uniformly because b − u ≤ 1.
- **(c)** I reconstructed the example. Take the pure two-model family (ε = 0) with a = e^{x₀} = 1, targets {0, 1}, and D = log 2/(1 − 2⁻⁴²).
  - At v* = 1 − 2⁻⁴², c = 2 and 1 − ρ⁽²⁾ = 1/(2·5) = 0.1 exactly, so v* is the exact passing boundary.
  - 1 − ρ⁽²⁾ is strictly increasing in c, so ρ(0,1) < 0.90 and the first trial is bisection-limited.
  - v* is a multiple of 2⁻⁶⁰, so bisection returns lo = v*. Since 2⁻⁴² ≈ 2.3·10⁻¹³ < 10⁻¹², lo is in the snap band, is snapped to 1, and validation fails.
  - So (γ) occurs under the hypothesis with modest D, as claimed.
- **Summary sentence** (L5_insertions.md:90-91). It follows from (a)–(c) and the list of failure reasons in L3 Lemma 3.4(c).
