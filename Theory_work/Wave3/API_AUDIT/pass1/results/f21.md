## W2-FAC-S5:L1.L1.4 — exact score increments

**Checked.**
- **Schur increment.** With H_T = aΣ̃_TT, quad_T − quad_R = (z_j − β̃ᵀz_R)²/(aṽ_j).
- **Gains.** ψ_R = ψ_T + n·t̃_j²/a gives both G_del and G_add, the latter with base ψ_T. The swap split is a telescoping identity.
- **Size term.** (aλ+1)/(a′λ+1) = (n+1)(1 − n/((n+1)(a′λ+1))). With x ≤ 1/((n−1)d+1) ≤ 1/3 and log(1−x) ≥ −2x, each f(λ_i) lies in [log(n+1) − 2/((n−1)d), log(n+1)]. Summing k terms for T and k−1 for T∖j gives (L1.4.1).
- **Leakage.**
  - σ_j = a⁻¹β̃ᵀϑ^R uses S₀ ⊆ R (so Σ̃_RR⁻¹Σ̃_{RS₀} selects columns) and j ∉ S₀ (so Σ̃_{jS₀} = Σ_{jS₀}); both are assumed.
  - ‖β̃‖ ≤ √k/d; β̃ − β = −a⁻¹Σ̃_RR⁻¹Σ_RR⁻¹Σ_Rj; |ρ̃_j − r_j| ≤ kG^obs/(ad²); |ṽ_j − v_j| ≤ 1/a + k/(ad²); ṽ_j ≥ v_j ≥ d.
  - The exact ε_j formula follows by dividing through. The three terms are bounded by O(k|τ|/n²), O(kG^obs/n²) and O(√k/n^{3/2}), with the constant depending on d, ‖ϑ‖, σ only.
- **Multiplier.**
  - n·t̃²/(aψ_T) = M_T(τ+ε)²/ν holds identically.
  - I re-derived the consumed FACB L1.5(b) bound directly: n·H_T⁻¹ ⪯ G_T⁻¹ gives Q_T ≥ RSS_T/s² for every T, and zᵀG⁻¹(G+I)((n+1)G+I)⁻¹z ≤ ((n−1)/(n+1))(1 + 1/λ_min(G_T)) ≤ 1 + 1/((n−1)d) gives the upper bound. Its hypotheses hold here: λ_min(G_T) ≥ (n−1)d by L1.2(a), and μ ∈ span X_T for T ⊇ S₀, which gives RSS_T = ‖e‖² − σ²Φ(T).
  - On E2, s²ψ_T/σ² ∈ [n−1−p−2n^{2/3}, n−1+n^{2/3}+O(1)], so |η_T| ≤ (n^{α−1} + 2n^{−1/3})(1+o(1)) + O(1/n), within 8n^{−min(1−α,1/3)} for large n, uniformly over T ⊇ S₀.
- **Elementary bounds.** log(1+y) ≥ y − y²/2, and −log(1−y) ≤ y + y² for y ≤ 1/2. The G_del lower bound follows. The G_add upper bound holds with factor 1 + x/ν, so the stated 1 + 2x/ν is a valid weaker bound under x ≤ ν/2.
