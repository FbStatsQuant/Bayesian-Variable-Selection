## C-DLV:L1-R — Lemma R (L1_resources.md:70-98, with R.0–R.4)

**What I checked.** I recomputed every count and every big-O collapse from the R.0 budgets. The code-reading facts (loop caps, per-item costs at the cited path:line) cannot be verified from the material and were taken as inputs; only the arithmetic built on them was checked.

- **R.0 inequalities.** L ≤ ℓ+4, H₀ ≤ N₀, K ≤ n/2, J·2^B ≤ 2¹⁶p and (K+1)² ≤ n² (n ≥ 3) all hold.
- **Pilot cap.** L3 Lemma 3.3 gives k ≤ T_e: every non-final increment is ≥ 1/T_e, so (k−1)/T_e < 1.
- **Score count Σ̄ (lines 49-52).**
  - Islands per tier are 1+4ℓ at N ≤ 4H₀, each with T+L+4 ≤ T̄+ℓ+8 rounds and 2m requests per particle-round.
  - Local searches are (ℓ+1) per tier and 3 in the final run, each ≤ (ℓ+1)(p+p²/4)+1.
  - The scan bound p + k*(p−k*) ≤ p + p²/4 is correct, since k(p−k) is increasing for k ≤ p/2.
  - Hence Σ̄ = O((n+p)·p·ℓ·T₀) = O((n+p)p log³(n+p)), using N₀ = O(n+p) for n ≥ 3 and T₀ = O(ℓ²).
- **Per-request cost.** κ ≤ C_s(n³+1) and ω ≤ C_o′p(n+2) hold; K log(Kp) ≤ 2Kp.
- **W̄ collapse (lines 73-76), term by term.**
  - (N̄²W + N̄H₀)(T̄+ℓ+8)(R′+8ℓ+8) = O((n+p)²p log³).
  - (ℓ+1)T̄²(40p+2) = O(p log⁵(n+p)), which is dominated by (n+p)p·n³·log³.
  - p²(2¹⁶+n²) ≤ C(p³ + p²n²). The TDP term matches consumed W1-N3:L7, with Σ_b ≤ J(2^B+(K+1)²) and J ≤ p.
  - U₂₀₀ = O(n m_t² + n³ + pn) = O(n³ + np²), since m_t ≤ max(64, n/2).
  - The remaining terms are lower order.
- **M̄ collapse (lines 78-81).** Each term is O((n+p)²); the largest are N̄(W+K), 500p(W+K)R′, (n+K)K·w and n·max(64,k_t)+m_t².
- **Monotonicity in p** for the p → p_raw substitution (R.4) holds for K, B, ℓ, N₀, T₀ and m_t.
- **Hypotheses of consumed results.** W1-PXN (K) is consistent with the LS0 count; L7 supplies only the operation bound, and the storage bound is the stated premise TDP-IMPL.

**Findings.**

1. **MINOR** — L1_resources.md:53 vs :73. The exact-branch count E+200 is stated separately, but W̄ contains only Σ̄·(n³+p(n+2)) and U₂₀₀. The enumeration cost E·(κ+ω) is therefore covered only through the unstated inequality E ≤ 9N₀p ≤ Σ̄. That inequality is true (Σ̄ ≥ R′N̄·T̄·2m ≫ 9N₀p), so the bound stands.

2. **MINOR** — L1_resources.md:78, :87-88, :107-108 vs STATEMENT.md:36-37. With w concurrent workers running islands, each worker holds a population and its resampled copy. M̄ carries N̄(W+K) once and multiplies only the scorer workspace by w, although CONFIG says the memory envelope is multiplied by w. Since w and R′ are fixed, enlarging C_M by max(w, R′) repairs it, and O((n+p)²+Cert_M) is unaffected. The constants are then not "absolute" as line 70 says; they depend on w and k.

3. **MINOR** — L1_resources.md:90-91. The local-search archive count (2(ℓ+1)+3)(ℓ+1)K is not ≤ K(ℓ+3)² for large ℓ (ratio → 2). It is absorbed by C_M.

No false inequality or missing case was found; the stated asymptotic forms follow from the listed counts.

## C-DLV:Cor-R — Corollary R (L1_resources.md:129-143, with R.5)

**What I checked.**

- **B1/B3.** P_e = O((n+p)²): 29·2^{⌈log₂(1000p)⌉} ≤ 58000p, 2000pK ≤ 1000pn, and the population term is O((n+p)²). mem_n ≥ P₀, P₁ holds by declaration.
- **B2.** E ≤ (5H₀+4N₀)p ≤ 9N₀p and MACH on the timed loop give P_t ≤ 9N₀p(τU₂₀₀+τ₀)/200 = P̄_t. This is O(N₀p(n³+pn+n m_t²)) = O((n+p)p(n³+pn)), inside the time_n shape.
- **E1–E5.** Elapsed time and the just-completed operation are each ≤ τW̄+τ₀, so their sum is ≤ 2(τW̄+τ₀) ≤ time_n; the factor 2 is present in line 130.
- **X1/X5.** Peak bytes ≤ βM̄+β₀ ≤ mem_n, plus MACH's allocation-success clause.
- **Final shapes.** mem_n and time_n absorb β₀ and τ₀, since (n+p)² ≥ 16.

**Findings.**

1. **MINOR** — L1_resources.md:132-133. The exact-branch bytes are not ≤ P₀ "term by term". When k* = K, 8(40p+1)k* = 320pK + 8K exceeds the matching part (80p+1)·4K = 320pK + 4K, and 32p has no partner. The aggregate inequality does hold: the difference is ≥ 2560p − 4k* > 0 from the 64-byte parts, and 32p ≤ 16⌈p/B⌉2^B. B2-bytes is therefore still excluded.

2. **MINOR** — L1_resources.md:127, :135-136 vs STATEMENT.md:28. MACH is written as one inequality for wall time. The corollary applies it to sub-segments: the timed loop alone, and elapsed time at a checkpoint. This needs the segment-wise reading of MACH, which is the natural one, but it should be stated. Under a whole-run-only reading, P̄_t would need W̄ in place of U₂₀₀, which is still polynomial.

3. **MINOR** — inherited from L1-R finding 2. If the population term needs the factor w, mem_n ≥ βM̄+β₀ must use the enlarged constant. The displayed sufficient allocation C[(n+p)²+Cert_M] is unchanged.

No step fails; under MACH, CONFIG, TDP-IMPL, EX-A and IDEAL-W the listed resource paths are excluded for every realisation.
