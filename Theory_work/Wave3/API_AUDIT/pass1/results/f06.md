## C-DLV:L3-3.1 — Lemma 3.1 (exact identity)

Checked: F(t) = ℓ_M(t) − log q_t(M) follows from the definition q_t(M) = e^{ℓ_M(t) − F(t)}. Since ℓ_M is affine, its symmetric second difference at (u, v, 2v−u) is zero. Hence Δ(u,v) = −log q_u(M) + 2 log q_v(M) − log q_{2v−u}(M), and ρ = e^{−Δ} gives the identity for all real u, v and every M ∈ V. This needs only that V is finite and nonempty with finite A and d, which the Setting provides. Consequences (i) (q_v(M) ≤ 1) and (ii) (√0.9·√0.9 = 0.9) are correct.

## C-DLV:L3-3.2 — Lemma 3.2 (convexity facts)

Checked:
- F is a log-sum-exp of affine functions, so it is C^∞ with F′ = E_{q_t}d and F″ = Var_{q_t}(d) ≥ 0.
- I re-derived the Peano representation from the two Taylor remainders at v ± h. It gives F(v−h) − 2F(v) + F(v+h) = ∫(h − |t−v|)F″(t)dt, and the kernel integrates to h². So 0 ≤ Δ ≤ (v−u)²·sup_{[u,2v−u]}Var.
- Monotonicity: ∂_vΔ = 2[F′(2v−u) − F′(v)] ≥ 0 for v ≥ u, since F′ is non-decreasing and 2v−u ≥ v. So ρ(u,·) is non-increasing on [u, ∞).

## C-DLV:Cor-3.2p — Corollary 3.2′ (dominance intervals)

Checked: q_t(M) = 1/(1 + Σ_{S≠M} e^{ℓ_S(t) − ℓ_M(t)}), so q_t(M) ≥ c ⟺ Σ ≤ 1/c − 1. The sum is a finite sum of exponentials of affine functions of t, hence convex (identically 0 if V = {M}), and a sublevel set of a convex function on ℝ is an interval. The restriction c ∈ (½, 1) is not needed, but the statement is correct as written.

## C-DLV:L3-3.4 — Lemma 3.4 (what the construction does)

Checked:
- **(a)/(b)** Because b is the smallest target > u and an unsnapped appended v satisfies u < v ≤ b, the target is never skipped. A bisection value lo ∈ (u, b) is never a pilot temperature, so each interval is counted exactly once as either a "pilot/snapped-1" step or an appended bisection step. Pilot temperatures are hit at most once because u is strictly increasing, so N_p′ ≤ k. A bisection value snapped to 1 has ρ(u,1) ≤ ρ(u,b) < 0.90 by Lemma 3.2 and b ≤ 1, so it fails validation and is not appended. Hence #intervals = N_p′ + N_b^app.
- **(c) `no_target_above_u`** cannot occur: the target list ends exactly at 1 (Lemma 3.3) and u < 1 inside the loop.
- **(c) `validation_failed`** on an unsnapped point cannot occur: under EX-A the validation re-evaluates the same ρ(u,v) that already passed. For a snapped point it fails iff ρ(u,1) < 0.90.
- **(c) `non_progress`**: if no mid passes, the tested mids are u + (b−u)2^{−j} for j = 1..60, so the last is u + (b−u)2⁻⁶⁰ and it fails. If some mid passes, it is u + jδ with j ≥ 1 and δ = (b−u)2⁻⁶⁰, so by monotonicity u + δ passes. If the trial is not bisection-limited, ρ(u,b) ≥ 0.90 and monotonicity again gives ρ(u, u+δ) ≥ 0.90. So the equivalence holds in all cases, and the second progress check cannot fire since lo > u.
- **(c) `too_many_intervals`** iff the count exceeds T_e, checked after appending; this is consistent with L1 R.1's "≤ T_e + 1 appended points".

The exhaustiveness of the five exit sites is a code-reading input (INVENTORY D1a, v3_calib.h:76/86/90/92/94) and is consistent with the lemma.

## C-DLV:L3-3.5a — Proposition 3.5(a)
