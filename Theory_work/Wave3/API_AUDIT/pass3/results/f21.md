**Finding 1 — GAP — L1_bcs_structure.md:101–105 (L1.6).**

The chain "R_loc + š_maxΔ_triv = R_loc(1 + š_max√d_max) + o(R_loc) = 2R_loc(1+o(1))" and the conclusion "R_n = R′_n = 2R_loc(1+o(1)) = O(√log p)" use a growth condition on p that is not stated.

- Δ_triv contains the additive term √a·L_n = √a·log log n, because E^loc_n only imposes |η| ≤ L_n.
- R_loc = √(2 log(2^q p) + 2L_n).
- So š_max√a·L_n = o(R_loc) needs (log log n)² = o(log p), and R_loc = O(√log p) needs log log n = O(log p).
- The setting is G, (BCS), (P) only; (P) is p ≤ ⌊n/2⌋, and the STATEMENT claims uniformity over every such sequence.

Counterexample: take p fixed (say two groups of 5) or p_n = ⌈log n⌉. On E^loc_n, η may equal L_n. With T = ∅, Z_l(∅) = g_l = √aη + √bζ_G + √cξ_l can be about √a·log log n. That exceeds 2R_loc(1+o(1)) ≈ 2√(2 log log n) and is not O(√log p).

The Remark's "Z² ≤ 8 log p(1+o(1))" has the same dependence.

Repair: state R_n = R′_n := 2R_loc + š_max√a·L_n = O(√(log p) + log log n) = O(√log n). L0.6 only needs R_n = o(√n), so (TR) and (TR′) survive. Alternatively add the hypothesis (log log n)² = o(log p). Tightening the event to |η| ≤ √(2L_n) removes the L_n term but still gives only O(√(log p + log log n)).

**Finding 2 — GAP — L1_bcs_structure.md:109–110 (L1.7), via L0_general_tools.md:25–30 (L0.2).**

The conclusion "and then M_T ≤ ½(1 + 2/log n) (L0.2)" does not follow on the events actually defined.

- L0.2 derives it from RSS_A = ‖e‖² − σ²Φ(A) with Φ(A) ≤ n/log n. That needs a lower bound ‖e‖²/σ² ≥ n − o(n/log n).
- E⁰_n contains only the upper bound ‖e‖²/σ² ≤ n − 1 + n^{2/3} and the lower bound r ≥ (n−1−p)(1−n^{−1/3}).
- With p ≈ n/2, E⁰_n therefore permits ‖e‖² ≈ σ²n/2, where M_T ≈ 1. The implication "on E⁰_n, Φ(T) ≤ n/log n ⇒ M_T ≤ ½(1+2/log n)" is false as a statement on that event.
- L1.7 also omits L0.2's hypotheses: T ⊇ S₀ (otherwise RSS_T ≠ ‖e‖² − σ²Φ(T)) and the event E⁰_n. It names only the max|g_j| event "added to E^loc_n".

Repair: add {‖e‖²/σ² ≥ n − 1 − n^{2/3}} to E⁰_n (probability → 1 by Laurent–Massart). State L1.7 for T ⊇ S₀ on E⁰_n ∩ E^loc_n. Then RSS_T ≥ σ²(n − 1 − n^{2/3} − n/log n) and M_T ≤ ½(1 + 2/log n) for n ≥ n₀.
