- **Stays in 𝒯.** The chosen move has positive gain and all truth-out moves are negative by L3(a). Correct.
- **(i) Endpoint.** Finite Ω and strictly increasing F give termination at a set with no improving neighbour. L3(c),(d),(e) exclude everything but S₀; sets of size < K without S₀ are never visited. No move count is used here, so there is no circularity with the budgets.
