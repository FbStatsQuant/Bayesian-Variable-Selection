## W2-FAC-A:Lemma-CS-1D (L8_frontier.md:6-13; proof 15-17)

**What I checked.** The score form is cited from FINAL s1, which is not in the ticket. I used the form the ticket itself relies on: F(S) = log w(|S|) − ½[log det H_S − log det(G_S + I)] − ν log(0.02 + Q_S) + const, with H_S = (n+1)G_S + I and Q_S = yᵀy − n zᵀH_S⁻¹z (L3_NA_TL.md:16-24, 39; L7_delivery.md:32). Against that form:

- **Matrices.** G_T = (n−1)[(1−a)I_k + a11ᵀ] for every T of size k, so H_T = AI + B11ᵀ and G_T + I = A′I + B′11ᵀ with the stated A, B, A′, B′. Correct.
- **Determinant and inverse.** det(αI + β11ᵀ) = α^{k−1}(α + kβ) and (αI + β11ᵀ)⁻¹ = α⁻¹(I − β(α + kβ)⁻¹11ᵀ) are correct. Hence −½[log det H_T − log det(G_T + I)] = D_k as displayed; the formula at k = 0 gives 0, consistent with D_0 := 0.
- **Quadratic form.** z_TᵀH_T⁻¹z_T = A⁻¹(P_T − B(A + kB)⁻¹L_T²) and B/(A + kB) = 1/(k + A/B) = 1/N_k, so it equals A⁻¹Φ(T). With yᵀy = n − 1, Q_T = (n−1) − (n/A)Φ(T). Correct.
- **Edge cases.** k = 0 gives Φ(∅) = 0 with N_0 = A/B > 0. The log argument is positive because Q_S ≥ yᵀy/(n+1) > 0.

I also verified the three move identities at L8_frontier.md:21-24 by expansion with L = Nc. They lie outside the registered span but are used by Lemma GAP. Deletion gives (N/(N−1))v², addition gives (N/(N+1))u², swap gives u² − v² − (u−v)²/N. All three are correct, as is "F increasing in Φ at fixed size".

**Findings.** None. The lemma is an exact algebraic identity and the proof is complete given the score form.

## W2-FAC-A:Lemma-GAP (L8_frontier.md:32-37; proof 38-42)

**What I checked.**

- **Centre update.** c_{T∖e} = (Nc − z_e)/(N−1) = c + (c − z_e)/(N−1). Correct.
- **N − 1 > 1.** Before deleting a null, k ≥ s₀ + 1 ≥ 2 and A/B > (1−a)/a > 0, so N − 1 ≥ 1 + A/B > 1. Correct.
- **Induction step.** By (ii) at step t−1, c_T lies in [ℓ, r], the kept nulls adjacent to D. The closest kept null is therefore ℓ or r, so D ∪ {e} is contiguous. Take z_e ≥ c, so e = r. Minimality gives c − ℓ′ ≥ z_e − c, hence c′ = c − (z_e − c)/(N−1) ≥ ℓ′. Also c′ ≤ c ≤ z_e ≤ next kept null above. So (ii) holds for T∖e. The other side is symmetric.
- **Truths.** Truths in the current set enter only through c_T and N; the argument never uses that they are absent. The hypothesis that the deleted element is a null and closest among all current elements is enough.
- **Sanity check.** I ran one small numerical instance by hand (one truth, three nulls, A/B = 1); it satisfied the invariant at each step.

**Findings.**

1. **MINOR — L8_frontier.md:38-39 (base case t = 1).** The sentence shows that the kept nulls on either side of z_{e₁} are at least as far from c_{[p]} as z_{e₁}. That places the pre-deletion centre c_{[p]} in the interval, whereas (ii) at t = 1 concerns the post-deletion centre c_{T₁}. The missing line is the step computation applied to T = [p]: no kept null lies strictly between c and z_{e₁}, so ℓ′ ≤ c, and then c′ ≥ ℓ′ exactly as in the step. The claim is unaffected.

2. **MINOR — L8_frontier.md:39-42 (step).** Two small points, neither affecting the claim:
   - Adjacency of e to D_{t−1} is used for "D ∪ {e} is still contiguous" but never stated. It follows from the induction hypothesis (ii) as shown above.
   - The conclusion "strictly between" fails in the degenerate case z_e = c, where c′ = c may equal an endpoint. The statement only claims the closed interval, so this is harmless. Ties among null z-values are likewise ignored (a null event; the order can be chosen consistently).
