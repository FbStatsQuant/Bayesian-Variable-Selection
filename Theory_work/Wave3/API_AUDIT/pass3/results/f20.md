**Finding 1 — GAP — L0_general_tools.md:25–30 (used again at 126–129)**

The claim "on E⁰_n, if Φ(A) ≤ n/log n then M_A ≤ ½(1 + 2/log n)" does not follow from E⁰_n as defined.

- The justification is RSS_A = ‖e‖² − σ²Φ(A), which needs a lower bound ‖e‖²/σ² ≥ n − O(n^{2/3}).
- E⁰_n contains only the upper bound on ‖e‖² and the lower bound on r. The only lower bound available is ‖e‖² ≥ σ²r ≈ σ²(n − 1 − p), which is about σ²n/2 when p = n/2.
- Counterexample: sample points with ‖e‖²/σ² = 0.6n and r ≈ n/2 lie in E⁰_n; there M_A ≈ 0.83 even when Φ(A) = 0.
- Consequence: the L0.7 bound Θ⁺_k ≥ (1 − o(1))[log n + 2 log(·)] − O(1), which is the factor-2 gain over the general ½ log n threshold, is unproved on the stated event.
- Repair: add {‖e‖²/σ² ≥ n − 1 − n^{2/3}} to E⁰_n. It has probability → 1 by the same Laurent–Massart bound, and then n/(2(n − 1 − n^{2/3} − n/log n)) ≤ ½(1 + 2/log n) for large n.
- Side remark (MINOR): the same addition is needed for s² ≥ σ²/2 at line 27 if s₀ = 0 and p = n/2. That lower bound is not used in L0.

**Finding 2 — GAP — L0_general_tools.md:95–101 (statement) vs 111–114 (proof)**

L0.6(b) uses a hypothesis that is not in its statement.

- The statement assumes only (EG), (θ) and (TR), where (TR) concerns truth residuals.
- The proof of (b) needs Z²(l; T) ≤ R′_n² = O(log p) for the null l, called (TR′), which is introduced mid-proof with "provided". (TR′) does not follow from (TR) or from E⁰_n.
- Counterexample to (b) as stated: take Σ = I (so c_min = 1, an (EG) design), p = n/2, and a truth j with ϑ_j² < 0.4σ².
  - Here Z²(l; T) = g_l², and (I − P_A)x_j ⊥ x_l, so (TR) does not constrain g_l.
  - Sample points with g_l² = 0.4n lie in E⁰_n ∩ (TR), since E⁰_n only forces ‖P_X e‖²/σ² ≲ p + o(n).
  - There RSS_A − RSS_T ≈ (ϑ_j² − 0.4σ²)(n − 1) < 0, so the truth-out swap has gain of order +n.
- Repair: add (TR′) to the hypotheses of L0.6(b), for every T ⊇ S₀ and null l ∉ T that occur. L1.6 supplies it for (BCS) on E^{loc}_n ∩ E⁰_n, so the BCS use is unaffected.

**Finding 3 — MINOR — L0_general_tools.md:45–49 and 53–55**

The "Schur-complement formula" is false as an exact identity, but the stated bound on δ survives.

- H_{T∖j} = (n² − 1)Σ + I, so det H_T/det H_{T∖j} = (n² − 1)v^{(λ₁)} + 1 with the ridge-regularised v^{(λ)} := Σ_jj − Σ_{jR}(Σ_RR + λI)⁻¹Σ_{Rj}, λ₁ = 1/(n² − 1), R = T∖j.
- Likewise det(G_T + I)/det(G_{T∖j} + I) = (n − 1)v^{(λ₂)} + 1 with λ₂ = 1/(n − 1).
- The two v's differ from each other, and from the conditional variance v_j, by O(1/n). That is the same order as δ itself, so the derivation as written does not prove the bound. (L1.2, lines 35–36, already notes that the method uses c₁ ≠ c₂.)
- Repair: v^{(λ)} + λ = 1/[(Σ_TT + λI)⁻¹]_jj. Hence the ratio equals [(Σ_TT + λ₂I)⁻¹]_jj / [(Σ_TT + λ₁I)⁻¹]_jj, which lies in [(c_min + λ₁)/(c_min + λ₂), 1] ⊆ [1 − 1/((n − 1)c_min), 1].
- This gives |δ| ≤ 1/((n − 1)c_min) per Schur step, and ≤ 2/((n − 1)c_min) for the swap, exactly as stated.
