## W2-FAC-XA:L8-T — Theorem T (truth deletion / truth-out swap ≤ −cn)

**Verdict: OK.** I re-derived every step of §1 and §2 and found no problem.

**Section 1, bounds (1)–(2) (L8_truth_start.md:48-68).**
- (1): H_A=(n+1)(G_A+hI), so each eigenvalue t of G_A contributes log(n+1)+log[(t+h)/(t+1)]. The second term equals −log(1+(1−h)/(t+h)), which lies in [−1/t, 0], and t ≥ (n−1)g. This gives (1).
- (2): nH_A^{-1}=(1−h)(G_A+hI)^{-1} is correct, so ω_A = z'{G^{-1}−(G+hI)^{-1}+h(G+hI)^{-1}}z. Both bracketed pieces are PSD. Eigenwise, h/(t(t+h)) + h/(t+h) ≤ h[1+1/((n−1)g)]/t, and z'G^{-1}z = ‖P_A y‖² ≤ n−1. So 0 ≤ ω_A ≤ 2 for large n.

**Event (4) (lines 84-104).**
- R ≥ gI forces rank p, and centred columns give PC=P, so Z/σ² ~ χ²_p and ‖(C−P)e‖²/σ² ~ χ²_{n−1−p}. These laws do not depend on X.
- The Markov and Chebyshev bounds depend only on (n,p), so the event is uniform over designs.
- Upper bound: ‖Xθ‖ ≤ B√(n−1) and ‖e‖² ≤ 2σ²n give s² ≤ (B+σ√(2n/(n−1)))² ≤ S².
- Lower bound: s² ≥ ‖(C−P)e‖²/(n−1) ≥ σ²/2.

**Identity (5) and bound (6) (lines 106-123).**
- A ⊇ S0∖{i} gives v=θ_i(I−P_A)x_i. The global floor gives ‖x_i−X_A a‖² ≥ (n−1)g(1+‖a‖²) ≥ (n−1)g; this is valid for |A| up to p−1, and for the swap case since l≠i.
- (I−P_A)Y = v+(I−P_A)e and v ∈ range(I−P_A) give s²RSS_A = ‖v‖²+2v'e+e'(I−P_A)e. Subtracting s²RSS_T = e'(I−P_T)e gives (5) exactly.
- v ∈ span X gives |v'e| ≤ ‖v‖√Z. e'(P_T−P_A)e ≥ −Z also covers the swap case, where P_T−P_A is indefinite.
- With Z=o(n) and s² ≤ S², (6) follows with d=b²g/(4S²). The bound involves only Z, so it holds simultaneously over all T, i, l with no union over models.

**Score comparison (lines 125-134).**

- All of these are o(n) against ν·log(1+d/3) ≥ (n/2)log(1+d/3), so c=¼log(1+d/3) works.
