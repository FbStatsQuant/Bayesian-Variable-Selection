No defect found. I re-derived each step of the proof at `L2_neg.md:32-48` against the L0 closed forms and the events E^S_n, E^N_n, 𝒟_n.

**(i) Deletion bound.**

- With K = ⌊n/2⌋ and p ≤ n − 1 ≤ 2K + 1, (2p − K)/K ≤ 3 + 2/K, so the log term is ≤ log 3 + 2/(3K) ≤ log 3 + 1/K.
- ½log(n + 1) ≤ ½log n + 1/(2n) and |δ_{n,K}| ≤ 3/((n − 1)(1 − ρ)) together fit in the stated 4/((n − 1)(1 − ρ)).

**(ii) Missing truth gives an order-n swap.**

**(iii) Low excluded null gives a swap beating every deletion.**
- |x_T| ≤ (0.81(2K + 1) + C_ρ(L_n + 1))/K ≤ 2. I checked the ϱ formula of L0.4 by direct algebra: the order-n terms κ_cκ and λ₁θ̄ cancel, leaving |ϱ| ≤ C(|η| + 1).
