**L1a (`L1_geometry.md:11-33`)**

- **Centering reduction.** Rotating the rows so the constant vector is the first direction gives dS as the Gram of d = n−1 independent N(0,Σ) rows, for any common row mean. Correct.
- **Second moments.** Var(x_i x_j) = Σ_ii Σ_jj + Σ_ij² = 1 + Σ_ij², so E(S_ij − Σ_ij)² = (1+Σ_ij²)/d and E(S_ii − 1)² = 2/d. Hence E‖S−Σ‖_F² ≤ 2p²/d. Correct.
- **Event B.** Chebyshev gives P(|S_ii − 1| > 1/2) ≤ (2/d)/(1/4) = 8/d, and the union bound gives 8p/d. Correct.
- **Entrywise bound on B.** R_ij − Σ_ij = (S_ij − Σ_ij)/√(S_ii S_jj) + Σ_ij(1/√(S_ii S_jj) − 1). On [1/2,3/2]² the first factor is at most 2, and each partial derivative of (uv)^{-1/2} is at most ½·2^{3/2}·2^{1/2} = 2. The domain is convex, so the Lipschitz constant 2 claimed at line 29 holds.
- **Constant 80.** With a = |S_ij − Σ_ij|, b = |S_ii − 1|, c = |S_jj − 1|: (2a + 2(b+c))² ≤ 8a² + 16(b² + c²), whose expectation is at most 16/d + 64/d = 80/d. Diagonal entries of R − Σ vanish, so the count p(p−1) is right.
- **Tail bounds.** P(‖R−Σ‖_F > Mp/√d) ≤ 8p/d + 80/M² follows by splitting on B and applying Markov. Since e ≤ c⁻¹‖R−Σ‖ ≤ c⁻¹‖R−Σ‖_F, taking M = c√d/(4p) gives P(e > 1/4) ≤ 1280p²/(c²d) + 8p/d. Correct.

**L1b (`L1_geometry.md:35-54`)**
