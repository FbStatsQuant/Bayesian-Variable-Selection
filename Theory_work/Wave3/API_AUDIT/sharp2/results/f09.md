## W3-START2:OVL (Proposition OVL⁺, `STATEMENT.md:181-189`)

**(a) Hypotheses.**

- **Visibility and (AL) are stronger than the proof needs.** The proof uses them only to get π₀(𝓛(Q)) ≥ ½ with probability → 1 (`lemmas/P2_OVL.md:45-47`). The rest is the deterministic identity P2.1(a) and the product bound P2.1(b) on 𝓔^blk ∩ 𝓨 (`P2_OVL.md:17`, `:48-57`). So the proof actually gives, under (E), (GF-16) and the gain bound alone, π₀(S₀) ≥ π₀(𝓛(Q))·n^{−E_n−ε} with probability → 1.
  - OVL⁺ is the corollary of this with (T1⁺)(a).
  - The same factorised form combines with (T3⁺)(b) to give a Gaussian-row OVL, which is not stated.
  - It also covers lattice mass that is only n^{−o(1)}, or bounded below in probability, when ϱ_n(Q; h) does not tend to 0.
  - Some visibility is still necessary for the unfactorised conclusion: (N3) at `STATEMENT.md:167-168` gives polynomial collapse of π₀(S₀) below the threshold 1 + 2A̲.
- **The gain bound is asked for more sets than are used.** The statement asks "every U ⊆ [p]∖{l}, |U| ≤ 15" (`STATEMENT.md:184`). The proof uses only T with U*_b ⊆ T ⊆ C_b∖{l} (`P2_OVL.md:50-52`). A block-relative premise suffices, since the partition is deterministic in Setting F. The partition-free form is the supremum over partitions, so it is right only as a partition-free corollary.
- **Fixed q̄ is not needed.** It enters at three places: P(𝓨ᶜ) ≤ q̄·2¹⁶/log n (`P2_OVL.md:43`), the slack ε/(3q̄) per column (`:49`), and the factor (1 + s₀ + q̄)^{q̄} (`:54`). The per-column slack is exp(O(√(log n·log log n))). So q̄ = o(√(log n / log log n)) goes through unchanged in structure.
- **Fixed ā** is used only for x → 0 in (TK-a) (`P2_OVL.md:52`); ā = o(n/log n) would do there. This is cosmetic, because E_n then grows.

**(b) Conclusion.**

- **The exponent E_n is sharp for one column.** The per-column exponent [(a − 1)/2 − log p/log n]₊ matches the upper bound of (N2⁺)/(C2)(i), which gives π₀(S₀) ≤ n^{−κ′} for κ′ < (c − 1)/2 − Ā (`STATEMENT.md:158-159`). For several leaking columns in different blocks the sum is also attained, because γ₀ factorises over blocks.
- **E_n is loose for mutually redundant columns in one block.** The chain bound (CH) (`P2_OVL.md:24-25`) charges each column its worst-case m_l. Two correlated nulls that each explain the same residual are charged twice, while the true cost is closer to the maximum. A path-dependent exponent, the largest sum of chain gains over N ⊆ Q∖S₀, would be tighter. It is harder to state partition-free.
- **The n^{−ε} slack is improvable.** There are at most q̄·2¹⁶ Gaussian variables. A fixed cut-off H, the same device as LEAK-0 Step 1 (`lemmas/P1_LEADING.md:45-49`), in place of 2 log log n gives, for every ε, π₀(S₀) ≥ n^{−E_n}·exp(−C_ε√log n) with probability ≥ 1 − ε. Accordingly, the P-OVL criterion "limsup(E_n − max(1, log p/log n)) < 0" (`STATEMENT.md:187`) relaxes to E_n ≤ max(1, log p/log n) − M_n/√log n with M_n → ∞.
- **Literature.** I know of no direct comparator: this is the mass of a blockwise start distribution, not a posterior. The threshold a = 1 + 2 log p/log n is the method's own BIC-plus-(1/p)-prior threshold.

**(c) Cheapest route.** Restate as "π₀(S₀) ≥ π₀(𝓛(Q))·n^{−E_n}·e^{−M_n√log n} with probability → 1 under (E), (GF-16) and the block-relative gain bound, q̄ slowly growing". Then list the corollaries for (V-c), (V-m) and Gaussian rows. This is a rewrite of `P2_OVL.md:41-58` with one changed event; it looks easy. The path-dependent exponent is harder and optional.

## W3-START2:NEC (Proposition NEC, `STATEMENT.md:154-173`)

**(a) Hypotheses.**

- **(N1)** is sharp: it rests on the deterministic floor o₀ ≥ ½(n + 1)^{−1/2} (`REPORT.md:89`). The n^{−1/2} rate is intrinsic to local-prior Bayes factors for a superfluous variable (the Johnson–Rossell observation), so it is not a proof artefact.
- **(N2⁺), the count 17 − s₀.** The ticket leaves this open (`REPORT.md:109-110`). I believe it is necessary for a statement over all partitions with blocks ≤ 16.
  - Take Example P3.3 (`lemmas/P3_NEC.md:44-64`) with p = 16, s₀ truths and 16 − s₀ leaking nulls, and the single-block partition.
  - Every null is exceptional, so δ_{S₀,l} = 0 (`P1_LEADING.md:34`) and T₁ = O_P(n^{−1/2}) by LEAK-0 Step 3.
  - The truths have gains of order n, and the block-relative 𝔏^b is the quantity that controls U (`P1_LEADING.md:95-102`). So π₀(S₀) → 1 while 16 − s₀ nulls satisfy the premise.
  - This needs the base block-relative interface, which I cannot see in full. If it holds, open item O1 closes negatively for the abstract partition class at almost no cost. For the coded partition the answer depends on the code.
- **(N2⁺), designated nulls only.** The premise uses a fixed number r(s₀) of leakers, so the threshold c > 1 + 2Ā is the single-leaker threshold. For p ≫ n this demands a very strong leaker. The proof ingredients give more.
  - Use o₀ ≥ T₁ (`REPORT.md:89`) and T₁ = [(s₀ + 1)/(2p − 1 − s₀)]·Σ_{l∉S₀}ρ_l (`P1_LEADING.md:43`).
  - Suppose N_n nulls satisfy the premise. At most 16 − s₀ share the block of S₀ (`P1_LEADING.md:30-32`), so m := N_n − max(0, 16 − s₀) are proper.
  - By Markov on the count (no independence needed), at least half of them have |Z_l| ≤ M with probability ≥ 1 − 4e^{−M²/2}.
  - The lower step bound from the proof of (C2)(i) then gives o₀ ≳ (m/p)·n^{(c−1)/2}·e^{−M√(c log n)}.
  - So collapse holds for c > 1 + 2(Ā − ν) when N_n ≥ n^ν. This contains (N2⁺) as m = 1.
  - It is the natural converse of the averaged functional 𝔏^♯ in (T1⁺)(b), which the current NEC does not provide.
- **(N2⁺), "every proper V".** The proof uses only V = U*_{b(l_n)} for one witness (`P3_NEC.md:32-34`). Partition-free, the quantifier over V is essentially forced. No gain here.
- **(N3).** The threshold 1 + 2A̲ against (V-c)'s 1 + 2A is tight when log p/log n converges. It corresponds to a β-min of order σ²(log n + 2 log p)/n, the same √(log p/n) scale as in Castillo–Schmidt-Hieber–van der Vaart and Yang–Wainwright–Jordan. The extra log n is the method's BIC-type penalty, not slack in the proof.

**(b) Conclusion.**

- The exponent κ′ < (c − 1 − 2Ā)/2 matches OVL⁺'s lower bound n^{−E_n−ε}, so it is sharp up to n^{o(1)}.
- Two cosmetic sharpenings are available. Use the actual log p/log n instead of the limsup Ā (and liminf A̲ in (N3)). Replace "every κ′ <" by the explicit bound π₀(S₀) ≤ (p/m)·n^{−(c−1)/2}·e^{M_n√log n}.

**(c) Cheapest route.** Add the many-leaker clause (N2⁺⁺) by the T₁ lower bound above, about one page, reusing (C2)(i)'s step bound on 𝓔^blk. Add the single-block counterexample to settle the count. Both look easy, subject to the unseen base lines BASE `lemmas/L7_NEC.md:14-26`.

## W3-START2:START-R (Theorem START-R(b), `STATEMENT.md:134-145`; (L-R⁺) at `:63-73`)

**(a) Hypotheses.**

- **|Q| ≤ K only.** Nothing is left to weaken.
- **|H_l| ≤ (log n)^{κ_Q}.** The report labels this NECESSARY-FOR-ROUTE (`REPORT.md:96`). That is true only for the polylogarithmic C_L = 0 clause.
  - For the main display, N_ref enters through E Ψ_n ≤ N_ref·Φ_n and P(Eᶜ) ≤ (4 + 3N_ref)n^{−2} (`lemmas/P4_BR.md:27-30`, `:40-42`).
  - The target exp(C_B√log n) already has subpolynomial room.
  - So |H_l| ≤ exp(κ√log n) should give the same display with C_R increased by about 15κ.
  - Caveat: I cannot see BASE L9.5, so this assumes N_ref enters nowhere else.
  - Polynomial-size H_l (for example polynomially decaying correlations) is not reachable this way. It would need to replace the "max ≤ sum over reference sets" step, which is hard.
- **(L-loc-R), r_n·(n log n)^{1/4} → 0.** The (log n)^{1/4} factor looks needed only for the C_L = 0 clause. For the main display r_n = O(n^{−1/4}) plausibly suffices, since (L-gain-R) already admits O(1) shifts of δ. I am unsure without L9.4.
- **(L-gain-R) at level C_L·n^{−1/2}.** This is exactly the level giving δ = O(1). Any null with larger population partial covariance must be put in Q. A graded version with covariance ≤ √(a·log n/n) and rate n^{−(1−a′)/2}, the Gaussian-row analogue of F2⁺'s η′, is absent. It looks moderate, not trivial.
- **Gaussian rows, fixed s₀, p ≤ n^A.** These are inherited. Narisetty–He and Castillo–Schmidt-Hieber–van der Vaart handle growing sparsity and log p = o(n) for full posteriors, so the scope here is narrower. Since the bound is n^{−1/2}·exp(C√log p), an extension to log p = o(log² n) is conceivable. It would touch every base lemma, so it is hard.

**(b) Conclusion.**

- **Exponent ½** is sharp by (T0).
- **The factor exp(C_R√log n).** The ticket does not claim sharpness (`STATEMENT.md:201`). I believe the form is unavoidable when C_L > 0.
  - Suppose a positive fraction of nulls have a population shift d at the allowed level.
  - Then p⁻¹Σ_l exp((d + G_l)²/2) is an index-1 heavy-tailed sum, of order e^{d√(2 log p)} up to polylogarithmic factors.
  - The floor o₀ ≥ T₁ turns this into a lower bound. This is a heuristic, not checked line by line.
- **The constant C_R = 2d̄√(2A + 1)/a̲ + 2** is crude. The only loss in n versus p is z̄_n² ≤ (2A + 1)·log n (`P4_BR.md:33`). Stating the factor as exp(C·√(log(p·log n))) is free and matters for small p.
- **The factor (|Q| + 1) and the limit |Q| ≲ n^{1/2}.** These are worst-case sharp. If the lattice mass sits at T = Q, which is possible because blockwise leakage is on U*_b ⊊ S₀, each outside null has prior odds of about (|Q| + 1)/p. Replacing |Q| + 1 by the π₀-average of |T| + 1 would be stronger, but it needs a reworked AGG. That is hard.
- **C_L = 0 clause.** The exponent 15κ_Q + ½ comes from the sum over N_ref. It is probably loose when the reference statistics are correlated, but I cannot quantify it.
- **Mode of convergence.** The failure probability is O(1/log n) (`P4_BR.md:67`). Polynomial failure probability is not available at this rate, because exp(Z²/2) has no mean.

**(c) Cheapest route.** Three modest changes, subject to the L9.5 caveat:

1. Restate (L-R⁺) with |H_l| ≤ exp(κ_H√log n) for the main display, keeping polylogarithmic size only for the C_L = 0 clause.
2. Write the factor in log p.
3. Add a T₁-based lower-bound remark showing that e^{c√log p} cannot be removed when C_L > 0.

The graded (L-gain-R) and polynomial H_l need new work.
