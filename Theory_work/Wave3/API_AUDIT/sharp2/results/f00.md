# Sharpness audit — W3-MISR (MIS(i), MIS(i′), MIS(ii), Cor-G(a))

All order-of-magnitude computations below are my own heuristics in the unit-noise model (orthogonal or well-conditioned null columns); none is in the ticket and none is checked. Citations of the literature are from memory; where I am unsure I say so.

Two computations are used repeatedly:

- **(H1) Null Bayes factor.** For a null column j, ℓ(S₀∪{j})/ℓ(S₀) ≈ [(s+1)/(2p)]·n^{−1/2}·Y_j with Y_j = exp(χ²₁/2), so P(Y > y) ≈ 1/(y√(π log y)) (tail index 1). Then E min(1, n^{−1/2}Y) = √(2 log n/(πn))·(1+o(1)), and (1/p)Σ_{j≤p} Y_j ≈ 2√(log p/π) in probability.
- **(H2) Effective variance.** Because b₀ is fixed on the standardised scale (b = b₀s_y², BRIEF.md:16) and the slab is N(0, nσ²(G_S+I)⁻¹), the score behaves as if the noise variance were v_eff ≈ v + (1+2b₀)‖μ‖²/(nN).

## W3-MISR:MIS(i) (STATEMENT.md:110-123)

**(a) Hypotheses**

- **Fixed s, p ≤ n^A (STATEMENT.md:46).** This is the main gap to the literature and the files say so (ASSUMPTION_MAP.md:48-50).
  - Castillo–Schmidt-Hieber–van der Vaart and Yang–Wainwright–Jordan work with growing s and log p = o(n) (for YWJ roughly s ≲ n/log p).
  - By (H1) the natural extension is E δ ≍ s·√(log(p∨n)/n), which needs s = o(√(n/log n)).
  - That restriction would be intrinsic to this prior: w(k+1)/w(k) ≈ k/(2p) sits at the boundary exponent 1, and the only extra Occam factor is n^{−1/2}.
  - p ≤ n^A enters through j₀ and m♯_n (STATEMENT.md:34).
- **(E^σ; M), ‖μ‖² ≤ nMv with M fixed (STATEMENT.md:47).** Stronger than needed, by roughly a factor n.
  - The files show failure only at energy/(nv) ≍ n² (N5) and report no failure at energy/(nv) ≍ n (N5 control θ₁ = √n; N4 with b = 1) or in N4 with b = 2 (ASSUMPTION_MAP.md:17, REPORT.md:61-62).
  - (H2) explains all of these. In N5, v_eff ≈ 1.02n, so the θ₂ margin of 200 log n fails relative to v_eff. In the √n control, v_eff ≈ 2. In N4 with b = 2 the tail of the null factor is damped, exp(χ²v/(2v_eff)), which matches the observed δ/r_n ≈ 0.47.
  - So N5 looks like a margin failure relative to v_eff, exactly as N2 was re-read as a margin failure relative to v (ASSUMPTION_MAP.md:20).
  - Conjecture: (E^σ) can be dropped if the margin is stated relative to v_eff; equivalently, M_n = o(n/log n) leaves the statement unchanged and M_n = O(n) changes only constants.
  - The visible M-dependence already allows growth: (8+24M)/(n−1) and ρ_n = 8(M+1)/(Nφ₀²) (M_misr.md:61, 65). The unknown is how κ²/c_den depends on M.
- **(ID^{M,σ}; c), c > c₁ ≈ 161–259 (STATEMENT.md:53-54, 110).** The relative form is right (N2). The constant is far from sharp.
  - In the orthogonal case, consistency needs c > 2A+1, and the r_n rate needs about c > (1+√(2A+1))² ≈ 7.5 at A = 1.
  - N1 already works with constant 16 (REPORT.md:58).
  - The Bayesian literature (YWJ, Narisetty–He) also has unspecified large constants, so this is not a gap relative to them, only relative to the truth.
- **GR^c (STATEMENT.md:36-37).**
  - Scalar covariance is genuinely needed for a mean-only target when p ≫ n. With within-design heteroscedasticity, the null statistic is ρ_jZ² with ρ_j = Σ_i x_ij²v_i/(N v̄). If ρ > 1 the superset mass is ≍ n^{A(ρ−1)−1/2}, so the rate is lost, and consistency itself fails once A(ρ−1) > ½. This is consistent with N3(ii) (ASSUMPTION_MAP.md:15).
  - What is plausibly needed is only sup_j|ρ_j − 1| = o(1/log n).
  - Gaussianity is plausibly replaceable by iid errors with enough moments plus delocalised columns, since moderate deviations cover the range √(2A log n). This is hard and upstream.
- **(OS; C_OS).** The rate r_n is built into the hypothesis (STATEMENT.md:49, 62). The proof actually gives an oracle bound (see (c)1), so C_OS·r_n need not be assumed.
- **(F₀).** Used only for a coefficient bound (ASSUMPTION_MAP.md:18). A decaying φ₀ looks possible; inherited.

**(b) Conclusion**

- **Main rate E δ ≤ C r_n: sharp in order, and the file under-records this.**
  - ASSUMPTION_MAP.md:27 lists only the lower bound (1+√(n+1))⁻¹, leaving a √log n gap.
  - By (H1), E δ ≳ √(log n/n) whenever a fixed fraction of the candidates are null: δ ≥ ΣR_j/(1+ΣR_j) deterministically, and E Σ_j R_j·1{R_j ≤ 1/p} ≍ r_n uses only the marginal law of each R_j (R_j := ℓ(S₀∪{j})/ℓ(S₀) for null j).
  - The n^{−1/2} factor is intrinsic to local slabs at unit-information scale (Johnson–Rossell's point about local priors). The p^{−c}-type rates of YWJ come from g ≍ p^{2α} and κ-penalties, not from a better proof.
- **Item 2 (STATEMENT.md:120): loose by a log factor.** By (H1), P(HPM ≠ S₀) ≍ p·P(χ²₁ > log n + 2 log(2p/(s+1))) ≍ (n log n)^{−1/2}, against the stated 2C√(log n/n). The loss is Markov's inequality applied to a heavy-tailed δ (M_misr.md:40-43).
- **No separation of false positives and false negatives.** The superset mass is ≍ r_n, but the underfit mass under c > c₁ is polynomially small (see MIS(i′)(b)). A two-rate statement would be stronger.
- **Mode of convergence.** Uniform, non-asymptotic expectation with constants free of v. I see nothing to gain here; an almost-sure statement is not meaningful for arrays.

**(c) Cheapest routes**

1. **Oracle form (modest).** State E δ ≤ C₀n^{−1/2} + 2𝒪_n^{>0} + 2^{s+1}(2p)^s(n+1)^{s/2}𝒪_n^{>j₀} + 5/n, read off M_misr.md:66-67, 83, 105, 125. This removes C_OS from the class, but by (H1) it gains real adaptivity only in degenerate cases such as p = s.
2. **Matching lower bound E δ ≥ c·r_n (modest).** This closes the √log gap in the sharpness record.
3. **M = M_n (bookkeeping).** Needs the M-dependence of κ²/c_den upstream.
4. **HPM/MPM at (n log n)^{−1/2}.** Needs a union bound over models and a bound on T₀ better than the n^{−1/2} of Lemma C2 (M_misr.md:61). With the present T₀ bound one reaches only O(n^{−1/2}). Upstream work.
5. **Sharp c, the v_eff form, growing s, log p = o(n).** New upstream work; hard.

## W3-MISR:MIS(i′) (STATEMENT.md:127-140)

**(a) Hypotheses**

- **Clause (a)** is already trimmed to the first (OS) inequality (STATEMENT.md:62, 129-130); the files record its unweighted part as necessary (ASSUMPTION_MAP.md:19).
- **(E^σ; M) in clause (a)** is the place where it is cheapest to relax. For supersets the ridge gain is at most ρ_n = 8(M+1)/(Nφ₀²) (M_misr.md:65), which stays bounded for M_n = O(n). The binding term is (8+24M)/(n−1) in T₀ (M_misr.md:61, 83), which allows M_n ≲ √(n log n), modulo κ²/c_den.
- **Clauses (b)–(d)** inherit c > c₁ (artefact, as above).
- **Clause (c)**: the factor c″ ≥ c·n/(n−1) is harmless. The threshold constant is the artefact c₁ (≥ 161); my orthogonal-case heuristic is about 2A+1 for inclusion and about (1+√(2A+1))² for the r_n rate. I cannot compare with the constant in Song–Liang's Corollary 2 from memory.

**(b) Conclusion**

- **Clause (a): rate sharp** by the (H1) lower bound, which is exactly a bound on superset mass. For comparison, Castillo–Schmidt-Hieber–van der Vaart's no-superset theorem needs a prior exponent strictly above 1, as I recall (unsure of the exact condition). Here exponent 1 plus the n^{−1/2} slab factor gives r_n, which is the right order for this prior.
- **Clause (b): not sharp, by a wide margin.**
  - In the orthogonal case E π(S ∌ j) ≈ P(Z < −√c′ + √((2A+1) log n)), with c′ log n = Nθ_j²/v, which is ≈ n^{−(√c−√(2A+1))²/2}. With c > 161 and A = 1 that is about n^{−60}.
  - The stated r_n comes from three proof terms, none intrinsic to missing a strong coordinate: Ẽ T₀ ≲ n^{−1/2}; the second (OS) inequality normalised at C_OS·r_n; and the bad-event probability 5/n (M_misr.md:101-105).
  - So "1 − PIP_j for strong j" converges polynomially fast, and the statement hides the asymmetry with false positives.
- **Clause (d):** the rate is sharp because Ω∖𝒩_n contains the supersets. The size clause E π(|S| ≥ s+j₀) ≤ C′r_n is very likely loose, since mass on j₀ extra variables is roughly r_n^{j₀}, but the looseness is again the T₀ term.

**(c) Routes**

- **Easy part.** Print the explicit bound of M_misr.md:105 instead of C′r_n. Under the (F_w) bridge the >j₀ tail sum should be far below r_n, giving E π(S ∌ j) ≤ E T₀ + O(1/n) = O(n^{−1/2}). That is only a √log gain.
- **Real gain.** O(n^{−κ(c)}), or at least O(1/n), needs a T₀ bound restricted to models missing j and tighter good events. That means re-doing Lemma C2 and (G3′) upstream. Moderate to hard.

## W3-MISR:MIS(ii) (STATEMENT.md:144-160)

**(a) Hypotheses**

- **(GR^c | 𝓕_n) is stronger than the proof needs.** The stability and (PR) extension is declared only for §2–§3 (STATEMENT.md:116-117), yet δ_n is a function of the direction T(y^r) alone (R_reduction.md:76-81).
  - It suffices that the regular conditional law of T(y^r) given 𝓕_n equals Law(T_G(κ_n)).
  - More generally, E[δ_n | 𝓕_n] ≤ C r_n + d_TV(Law(T(y^r) | 𝓕_n), Law(T_G(κ_n))) a.s.
  - The freezing step at M_misr.md:143-145 goes through with a kernel in place of the independent W_n.
- **Unharvested corollary from "any 𝓕_n" (M_misr.md:166-169).** Take noise √v·R·W with a random common scale R that is independent of W (jointly spherical errors, e.g. multivariate-t with a common mixing variable). Put R in 𝓕_n and use κ_n = (X, β, R²v). Part (c) then gives O_P(r_n) whenever R is tight and the margin is of BM-∞ type. This is a non-Gaussian error law covered at no cost; it is not iid heavy tails.
- **Necessity.** Independence of W_n from 𝓕_n is equivalent to "conditionally N(0, I)", so within the Gaussian form nothing is lost. The class hypotheses are as in MIS(i).
- **Slices (b):** finite s̄ only; growing s is inherited and hard.

**(b) Conclusion**

- E[δ_n | 𝓕_n] ≤ C r_n and E δ_n ≤ C r_n + P(𝒜_nᶜ) are sharp in order, as in MIS(i).
- **Part (c), δ_n = O_P(r_n):** sharp for p = n^a, but not for bounded or sub-polynomial p. By (H1) the in-probability order is √((1+log p)/n); the √log n in expectation at fixed p is purely a tail effect. The scope 2 ≤ p ≤ n^A includes fixed p, and every boundary experiment in the ticket uses p = 8 (ASSUMPTION_MAP.md:7-9).
- The HPM/MPM probabilities inherit the log-factor looseness of MIS(i) item 2.

**(c) Routes**

- **Conditional (PR) with the conditional TV term, and the scale-mixture corollary:** a few lines each from R′(c) and M.3. Easy.
- **O_P(√((1+log p)/n)):** needs 𝒢^sup truncated at level log p + M instead of log n, and an (OS) variant. Upstream, moderate.

## W3-MISR:Cor-G(a) (STATEMENT.md:164-170)

**(a) Hypotheses**

- **Joint Gaussianity of the candidate rows is not used.** The proof (G_corollaries.md:28-31) needs only that ξ := X_𝓜β_𝓜 − a1 − X_𝒞γ is N_n(0, τ²I) and independent of X_𝒞.
  - The candidate design may therefore have any law: non-Gaussian, dependent rows, heavy tails.
  - Only the scalar omitted index x_𝓜ᵀβ_𝓜 needs a linear, homoscedastic, Gaussian conditional law given x_𝒞.
- **Σ_𝒞𝒞 ≻ 0 is not needed.** Any solution γ of Σ_𝒞𝒞γ = Σ_𝒞𝓜β_𝓜 works, and Σ_jj > 0 gives non-constant columns. Non-unique β is already allowed (STATEMENT.md:41-42).
- **What is necessary for exact GR^c.**
  - ε and ξ are independent, so by Cramér's theorem ξ + ε is Gaussian only if both are. Gaussianity of ε and of the omitted index is therefore necessary.
  - Conditional homoscedasticity is necessary. Elliptical non-Gaussian iid rows fail, because the conditional variance depends on x_𝒞; this is the N3(ii) situation.
  - A row covariance Ω for the omitted part would need Ω ∝ I on contrasts.
- **Beyond exact GR^c.** Under (PR), or with a common mixing scale placed in 𝓕_n (see MIS(ii)), matrix-variate-t rows are also covered.

**(b) Conclusion**

An exact identity with deterministic (β^𝒞, σ²+τ²) and arbitrary n-dependence. Nothing to improve; the removal of "τ² fixed" is complete.

**(c) Route**

Restate (a) as: "X_𝒞 arbitrary with non-constant columns a.s.; given X_𝒞, X_𝓜β_𝓜 ~ N(a1 + X_𝒞γ, τ²I); ε Gaussian and independent." The proof is the last three lines of G.1 unchanged. Gaussian rows then become one instance, and Cramér's theorem gives a partial converse. This matters for the p ≫ n message, since candidates are rarely Gaussian. It is trivial to do.
