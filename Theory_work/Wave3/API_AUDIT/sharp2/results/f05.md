## W3-START:F3 — Corollary F3 (bounded gains), `STATEMENT.md:276-277`; proof `lemmas/L6_COROLLARIES.md:62-71`

**(a) Hypotheses.**
- **The growth premise on |Q| is stronger than the proof uses.** "(|Q|+1)n^{−1/2}e^{C₁√log n} → 0 for every fixed C₁" is invoked once, at C₁ = C₃+1, to get ϱ_n(Q) ≤ c_{0,n} (`L6_COROLLARIES.md:67-68`). It can be dropped altogether. If (|Q|+1)n^{−1/2}e^{C₂√log n} ≥ 1 the conclusion is trivial. Otherwise ϱ_n(Q) ≤ e^{−(C₂−C₃)√log n} ≤ c_{0,n} eventually, and L6.0′ applies at that n because it is an inequality at fixed n (`L6_COROLLARIES.md:19-25`).
- **"δ² ≤ C₀τ²_U with C₀ fixed" is one point of a continuum.** The same (J2) step (`L6_COROLLARIES.md:65`) with δ² ≤ G_nτ²_U gives 𝔏_n(Q) ≤ √(2/π)z̄_n·exp(G_n/2 + √G_n·z̄_n). F1 (G_n = η log n) and F3 (G_n = C₀) are two readings of one bound, and every intermediate G_n = o(log n) is covered for free.
- **Energy and Gram-floor constants (likely, not fully traced).** M and g_* enter only through e^{2κ_E} in c_L (`L2_TK.md:60`, `L3_LEAK.md:71`). Since F3 already tolerates e^{O(√log n)}, ‖μ‖² ≤ Mn·√log n or g_* ≳ 1/√log n should go through; the thresholds n₃, n₄ would need re-tracking.
- The bound over every 15-set U (rather than block-relative sets) is the price of partition-freeness, not slack.

**(b) Conclusion.**
- **The form n^{−1/2}e^{C√log n} is necessary over the F3 class.** This is my own sketch, not in the ticket. Take one truth x₁ = e₁ with (n−1)θ₁² = cσ² log n, c > 1+2A, and all nulls x_l = ρe₁ + √(1−ρ²)e_l with ρ² = C₀/(c log n), p ≤ n−1.
  - (E), (GF-16), (V-c) hold, and every null gain is ≤ (1+o(1))C₀σ².
  - τ_∅ ≈ σ, and the Z_{∅,l} are nearly independent.
  - By (T0)/(AGG-b) and the (f1) lower bound, o₀ ≥ T₁ ≳ n^{−1/2}p^{−1}Σ_l exp((√C₀+Z_l)²/2) ≥ n^{−1/2}exp((1−o(1))√(2C₀ log p)) with probability → 1.
  - So the factor is not a (J2) artefact when τ_U ≈ σ.
- **The constant is loose.** C₂ = √(C₀(2A+1)) + 2 (`L6_COROLLARIES.md:70`) against the lower-bound constant √(2A̲C₀). The +1 inside the root comes from z̄_n² ≤ (2A+1) log n, and the +2 from absorbing polylog factors. Any C₂ > √(2ĀC₀) is provable by the same lines.
- **In the strong-signal regime the factor is spurious.** If Δ_U ≥ Δ_lo > 0 whenever δ_{U,l} ≠ 0 and δ² ≤ C₀Δ_U, then (J1) (`STATEMENT.md:108`) gives J = O(1) with no truncation, and the rate is (|Q|+1)√(log n/n). F3 does not separate the two regimes; min{(J1), (J2)} would.
- No comparable result exists in Johnson–Rossell, Narisetty–He, Castillo–Schmidt-Hieber–van der Vaart or Yang–Wainwright–Jordan: they treat the posterior, not a block-product start.

**(c) Cheapest route.** Restate F3 as: "δ² ≤ G_nτ²_U for all l ∉ Q, |U| ≤ 15 ⇒ w.p. → 1, 1−π₀(𝓛(Q)) ≤ (|Q|+1)n^{−1/2}exp(G_n/2 + (1+ε)√(2G_n log p)) + n^{−κ}", with no growth premise on |Q|. Add the lower-bound example above as a remark. This is an edit of L6.1 and L6.3 only.

## W3-START:F4 — Corollary F4 (isolated leaking columns), `STATEMENT.md:278-287`; proof `lemmas/L3_LEAK.md:95-109`, `L6_COROLLARIES.md:73-79`

**(a) Hypotheses.**
- **"|I_n| ≤ ī fixed" is far stronger than needed.** With the stated level √(4 log log n), the budget term is 2¹⁶|I_n|(log n)^{−2} (`L3_LEAK.md:100`), so |I_n| = o((log n)²) already works verbatim.
- **Polynomially many leaking columns are reachable.** Take h_l² := 2 log|I_n| + 4 log log n (capped at z_n²). The budget from I_n is 2¹⁶(log n)^{−2} → 0. With |I_n| = n^ι, (J2) gives a charge n^{ι + c/2 + √(2cι) − 1/2 − A + o(1)}, which tends to 0 iff **√c + √(2ι) < √(1+2A)**.
  - At ι = 0 this is F4's c < 1+2A.
  - At ι = A it is exactly F1's η_A = (√(2A+1) − √(2A))² (`STATEMENT.md:125`).
  - So F1 and F4 are the endpoints of one corollary that the level-vector machinery already supports. The stated remark (`STATEMENT.md:284-287`) treats them as unrelated thresholds.
- **A̲ versus Ā.** The proof uses p only through n^{c/2}/(p√n) (`L3_LEAK.md:104-105`). Stating the condition pointwise, c ≤ 1 + 2 log p/log n − ε, removes the gap between F4 (A̲) and the failure side (C2)(i) (Ā) when log p/log n does not converge.
- A single c for all of I_n is cosmetic; column-specific c_l follow term by term.

**(b) Conclusion.**
- **The threshold 1+2A is sharp** when log p/log n → A, by (C2)(i) (`STATEMENT.md:223-224`). The match is on the actual partition and at U = U*_b only; F4 requires the bound at every 15-set.
- **The extended threshold √c + √(2ι) < √(1+2A) is plausibly sharp too.** With n^ι near-independent leaking columns and τ ≈ σ, max_l(δ+σZ_l)²/τ² ≈ (√c+√(2ι))² log n, and one competitor S₀ ∪ {l*} beats the prior price. I have not written this out; it needs weak dependence of the Z_l.
- **The leak term n^{−(1+2A̲−c)/2+o(1)}** has the right exponent: the single-null Bayes factor is n^{(c−1)/2}e^{O_P(√log n)}/(2p). The o(1) is e^{O(√(log n·log log n))} from the level choice. Any h_l → ∞ gives e^{h_l√(c log n)}, matching the true e^{O_P(√log n)} fluctuation.

**(c) Cheapest route.** Replace L3.5 by the three-line computation above with h_l² = 2 log|I_n| + 4 log log n and state the condition with log p/log n. No new probabilistic input is needed. The matching failure statement for ι > 0 is a separate, moderate task (a maximum over near-independent witnesses in (C2)(i)).

## W3-START:NEC — Proposition NEC (N1)–(N4), `STATEMENT.md:316-331`; proof `lemmas/L7_NEC.md`

**(a) Hypotheses.**
- **(N1)** is deterministic and needs nothing (`L1_AGG_FLOOR.md:126-137`).
- **(N2)/(N3) use (E) and (GF-16) only at the witness sets.** They enter through 𝓔^blk and 2κ_E at U and U ∪ {l} (`L7_NEC.md:21-25, 36-43`).
  - For (N3) a floor on subsets of S₀ suffices (U*_{b(j)} ⊆ S₀).
  - For (N2) a floor on V ∪ {l}, V ⊆ S₀, suffices; the determinant direction is free by `L1_AGG_FLOOR.md:121-125`.
  - Because both proofs absorb o(log n), κ_E = o(log n) is enough: (1+1/g_*)(1+M) = o(log n) instead of fixed constants.
- **Gaussian noise is not needed for the limits.** Each proof uses one linear form and 𝒟₁–𝒟₃ at two sets (`L7_NEC.md:46`). Noise with ‖Cε‖² = (n−1)σ²(1+o_P(1/log n)) and O_P(1) projections suffices, for example iid with a finite fourth moment. A negative result under weaker noise is the stronger statement.
- **"c fixed" can drift.** Expanding (δ+σZ)² ≥ δ² − 2|δ|σ|Z| instead of the ε₁-split (`L7_NEC.md:22`) gives π₀(S₀) → 0 as soon as (c_n − 1 − 2 log(2p)/log n)·√log n → ∞. The transition window has width 1/√log n in c. The pointwise form also removes the Ā/A̲ mismatch between (N2) and (N3).

**(b) Conclusion.**
- **(N1)** The exponent ½ is sharp and attained (F2).
  - It is the usual local-prior rate: a unit-information prior pays n^{−1/2} per spurious coordinate. Johnson–Rossell's non-local priors exist to beat exactly this, so it is method-intrinsic.
  - The constant ½ is weaker than the proved f_n(s₀) → (s₀+1)/2.
  - The matching √(log p/n) lower bound when τ = σ is disclaimed (`STATEMENT.md:380`). For orthogonal designs with s₀ = 0 I believe T₁ ≈ ½n^{−1/2}·√(2/π)·√(2 log p), matching 𝔏⁰_n in the constant, but this needs a triangular-array law for tail-index-1 sums. That part is HARD for general designs.
- **(N2)** is vacuous for s₀ ≤ 15 (`STATEMENT.md:320-324`), yet a non-vacuous partition-free version is one pigeonhole step away.
  - A block holding all of S₀ has at most 16 − s₀ nulls.
  - Suppose 17 − s₀ distinct nulls each satisfy δ²_{V,l} ≥ cτ²_V log n for every **proper** V ⊊ S₀ with |V| ≤ 15.
  - Then one of them has U*_{b(l)} ⊊ S₀. The partition is deterministic in Setting F, so the witness is too, and (C2)(i) applies: π₀(S₀) ≤ n^{−κ′}.
  - This is the exact converse of the "+15√(2/π)z_n/p" term in 𝔏⁰_n (`STATEMENT.md:113-116`).
- **(N3)** The constant 1+2A is sharp for this method.
  - The visibility level σ²(log n + 2 log p) exceeds the 2σ² log p-type beta-min of exact-recovery theory by the log n dimension penalty. That belongs to the prior, not the proof.
  - Castillo–Schmidt-Hieber–van der Vaart, Narisetty–He and Yang–Wainwright–Jordan state beta-min only up to unspecified constants, so a sharp constant with a matching failure result is not behind the literature.
  - The premise "for every V ⊆ S₀∖{j}" cannot be cut to V = S₀∖{j} partition-free: a truth can proxy for others given a smaller V.
- **Exponent in (N2)/(N3).** The n^{−κ′} bound is right to n^{o(1)}; with |Z| = O_P(1) the slack is e^{O_P(√log n)}.

**(c) Cheapest route.** Add (N2′) by pigeonhole (two lines after `L7_NEC.md:57`). Restate (C2), (N2), (N3) with c_n and log(2p)/log n. Note that only witness-set floors are used. The non-Gaussian extension is a short remark. The √(log p/n) floor is new work.

## W3-START:TRANSFER — Theorem START-R(a), `STATEMENT.md:290-305`; proof `lemmas/L8_TRANSFER.md`

**(a) Hypotheses.**
- **Deterministic envelopes ϱ̄_n, b̄_n, r̄_n are not needed.** Proposition L5.2 bounds P_x(1−π₀ > C·ϱ_n(Q(x); h(x)) + n^{−κ}) with the design's own ϱ_n (`L8_TRANSFER.md:47-49`). Integrating over {ϱ_n ≤ c₀, b_n ≤ η} gives 1−π₀(𝓛(Q)) = O_P(ϱ_n(Q; h)) + o_P(n^{−κ}) with the random rate, under only ϱ_n → 0 and b_n(h) → 0 in probability. This is strictly stronger. It also makes the separate ε-argument for the C_L = 0 clause (`L9_BR.md:168-173`) unnecessary.
- **"|S₀| = s₀ fixed on 𝒳_n"** can be |S₀(X^r)| ≤ s̄: the constants of L5.2 are explicit in s₀ (`L5_ASM_STARTF.md:41-42`); take the maximum over s₀ ≤ s̄.
- **"σ² fixed"** can plausibly be a design-measurable σ²(X^r) in a compact subinterval of (0, ∞), since κ_E and the thresholds depend continuously on σ². This is relevant to (T6), but the uniformity in σ² has not been checked.
- **Response-selected S₀, Q, h are excluded** (`L8_TRANSFER.md:68-69`). The Markov step delivers only ε-level probabilities, so no union bound over a selected family is available without exponential control of U_Q. That is HARD and not natural for this target.
- Independence of ε and X^r is already not assumed; nothing to gain there.

**(b) Conclusion.**
- No rate is lost against (T1); the transfer is as sharp as (T1)(d).
- The proof gives a conditional (given-design) bound, P(· | X^r) ≤ ε + b_n(h) on 𝒳_n. Only the weaker joint-law statement is stated.

**(c) Cheapest route.** Restate L8.2 with the event {ϱ_n(Q; h) ≤ c₀, b_n(h) ≤ η} in place of deterministic envelopes, with s₀ ≤ s̄, and record the conditional form. This is about ten lines and has no new estimate.
