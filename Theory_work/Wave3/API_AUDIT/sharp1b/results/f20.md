## W3-SAMP:D — Theorem D (draw discovery), `STATEMENT.md:97-105`

**(a) Hypotheses**

- **KERNEL.** Only the control-flow clause of W1-N1 Lemma B (B-b) is used (`D_theorem.md:13-15`); invariance plays no role. The statement already says so (`STATEMENT.md:97-98`). Nothing to gain.
- **IND-T (D-ii).** It only changes the exponent from D_r to 4D_r. Since Q_D → ∞ iff 4Q_D → ∞, it has no asymptotic content. Correctly "optional".
- **P-MAP is stated globally** (`STATEMENT.md:78`, `:102-104`), but the inclusion at `D_theorem.md:48` is {completed} ∩ {Ŝ ≠ S₀} ⊆ {S† ≠ S₀} ∪ (𝒜 ∩ {S₀ ∉ 𝓜_r}) with {completed} ⊆ 𝒜. The first event can therefore be intersected with 𝒜, so P(𝒜 ∩ {S† ≠ S₀}) → 0 suffices. `C_theorem.md:74-75` already uses the localised form P(𝒜 ∩ {δ ≥ ½}). This is a one-line weakening, and it matters because P(𝒜) → 1 is never assumed.
- **P-MAP itself is essentially necessary** for "Ŝ = S₀": Ŝ is the maximum of 𝓜 ⊆ Ω, so if S† ≠ S₀ then Ŝ = S₀ only when S† was missed.
- **P-OVL is necessary and sufficient for the draw mechanism** (equality in D-i), up to the corner π₀(S₀) → 1, where the exact condition is −D_r·log(1 − π₀(S₀)) → ∞. It is not necessary for the method. The ticket's own record shows this: with no draw hitting S₀, S₀ was still a particle endpoint in 13773/15015 and 30559/31505 islands (`ASSUMPTION_MAP.md:18`).

**(b) Conclusion**

- The production condition max(n,p)·log₂(n+1)·π₀(S₀) → ∞ (`STATEMENT.md:104-105`) allows start mass as small as roughly 1/(max(n,p)·log n). That is a wide range.
- It is still an importance-sampling cost: about 1/π₀(S₀) independent draws. Yang–Wainwright–Jordan (2016) show that add/delete/swap Metropolis–Hastings reaches the truth in polynomially many steps from any start, with no start-mass condition. As I recall the order is p·n·s₀²·log p, under their β-min, restricted-size and prior conditions. Zhou, Yang, Vats, Roberts and Rosenthal (2022) remove the p-dependence with informed proposals.
- I am not sure which paper "Zhou–Yang–Chang–Liang" refers to, so I do not rely on it.
- The coded round runs p Gibbs steps plus swaps per particle, so its budget is of the same order as those mixing bounds. A discovery theorem through the local moves with no overlap condition is therefore plausible, but it needs landscape and mixing input that this ticket excludes (`STATEMENT.md:183`).

**(c) Routes**

Cheap, marginal:
1. Localise P-MAP to 𝒜, as above.
2. Set version, same proof. For any data-measurable G ⊆ Ω, P(no draw in G | 𝓒) = (1 − π₀(G))^{D_r}. Hence P(completed ∩ {F(Ŝ) < min_G F}) ≤ E[1_𝒜(1 − π₀(G))^{D_r}]. With G = {S†} this is exact-mode recovery with no statistical premise. With G a high-posterior set it gives an approximate-mode guarantee when the posterior does not concentrate.
3. Record that the HPM clauses of TR-d and C-v are corollaries of D-iv. P-OVL∞ implies π₀(S₀)·L → ∞ (`TR_theorem.md:65`), which implies P-OVL. P-START implies P-OVL trivially.

Substantive, needs work:
4. A neighbour-scoring bound, deferred at `ASSUMPTION_MAP.md:36` and `REPORT.md:174`. Every Gibbs-j step evaluates Y ⊕ j with emit = true (`CC_code_check.md:48-52`), so S₀ ∈ 𝓜 whenever some particle sits at S₀ ⊕ j when its G_j step fires. I could not find a two-line bound: resampling can kill initial draws, and the within-round state before G_j is not controlled.
5. If the final local search (`CC_code_check.md:55-57`) is an iterated ascent — not visible in the ticket — then under a unimodality premise of the Yang–Wainwright–Jordan type, Ŝ = S† on completed runs with no overlap condition at all. This needs a code check plus an imported landscape premise.

The core equality is sharp. The method-level strengthening is real but not cheap.
