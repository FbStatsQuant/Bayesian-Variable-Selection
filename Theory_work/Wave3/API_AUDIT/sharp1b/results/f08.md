## W2-FAC-A:Thm-FAC-L

**Summary.** Several hypotheses are stronger than the written proof uses and can be relaxed with small edits. The headline restriction (log p/log n < 1/6, one factor, p = o(n)) is tight for the full-lattice route but not for the conclusion; lifting it needs new work.

### (a) Hypotheses

1. **(AG) is stronger than the proof needs** (STATEMENT.md:90-91). The coupling error L_ψδ_n√(5(p+1) log log n) enters only through ε_n = o(√log n) (L3_NA_TL.md:45-46, 53) and Z̄_n = O(√log n) (L3_NA_TL.md:70). L2 and (H0) use only δ_n ≤ ψ₀/4 (L2_sandwich.md:9-10). So "δ_n ≤ ψ₀/4 eventually and δ_n√(p log log n) = o(√log n)" suffices, a √log n gain. For bounded p this reduces to the eigenvalue floor alone.

2. **(TV) with M_n → ∞ is stronger than needed** (STATEMENT.md:94-95). L2_sandwich.md:39-42 only needs ½M log n/(2C_R) to beat log(2p) + ½log(n+1) + 2κ_E + σ²z_n²/(2C_R). A fixed constant M ≥ M₀(M_energy, σ², A) suffices.

3. **One-step visibility for every U is not needed for the sandwich.** The contradiction at L2_sandwich.md:29-43 works with any block-internal superset: for each (j, U) it is enough that some V ∋ j, V ⊆ C_b∖U has ‖(P_{U∪V} − P_U)μ‖² ≥ M|V| log n.
   - The noise costs at most |V|σ²z_n² on the same event 𝓩, and the prior costs at most |V| log(2p).
   - This assumes the [GEN-L1] nested-set bound covers general nested pairs in the block family; I cannot see that file.
   - For compound symmetry it largely closes the a = 1/2 gap (L5_random_instances.md:155-159, REPORT.md:115-116). If the (GC-CS) expression vanishes at (j, U), then Θ − Θ_U ≠ 0, so it is nonzero at (j, U ∪ {l}) for any null l in the block. Only blocks with no spare null stay excluded.
   - A truth masked in a singleton block really does break Sand_n, so some visibility is necessary for this route. It is not necessary for the conclusion (GEN treats masked truths).

4. **(L5) "iid Gaussian rows" is used only for entrywise correlation concentration** (L5_random_instances.md:31-35) and a.s. nonconstant columns (L7_delivery.md:27-28). Since g | X ~ N(0, R̂) needs only Gaussian noise (L1_uniform_add.md:19), any design law with P(‖R̂ − Σ_n‖_op ≤ δ_n) → 1, a.s. nonconstant columns and (TV-pop) works, e.g. sub-Gaussian rows.

5. **Fixed γ̄ is not needed.** γ̄ enters through log(p2^γ̄), √γ̄ and log(eγ̄) (L1_uniform_add.md:98-108), and the proof needs ε_n = o(√log n). So γ̄_n = o(log n) is admissible for the lattice part with ψ₀, κ̄ fixed. The method's 16-block cap and Lemma P5 are separate.

6. **"Every λ_l ≠ 0" with κ defined through a global minimum** (STATEMENT.md:63-69) is pessimistic.
   - c_min is used only for s_T ≥ c_min·h_T (L1_uniform_add.md:90-91), so one weakly loaded variable inflates κ and collapses α₀.
   - Variables with zero loading can be admitted by counting only groups with λ_{T_g} ≠ 0. The size-dependent gain is then lost, giving exponent 1/(2(1+κ̄)²), which is 1/8 at κ̄ = 1. This matches the remark at STATEMENT.md:76.
   - Some bound on loading heterogeneity is necessary for the full-lattice route. Many small nonzero loadings make sup_T of the factor term grow (my heuristic: h variables with loadings ~h^{-1/2} give a term ~√h).

7. **(P) is necessary for NA(𝓛) at κ̄ = 1** (L6_sharp.md:12, 44-47) **but not shown necessary for the conclusion.** D_n → 0 needs only that LS0 from S̃₀ scores S₀ (L4_assembly.md:29-32). For κ̄ > 1 no matching lower bound is given; I expect α₀(κ̄) is attained by two-level loadings (heuristic).

8. **BM-∞, fixed s₀, Gaussian noise.**
   - TL needs only θ*²_min·n ≥ C log n (L3_NA_TL.md:71-76); the diverging factor comes from T03♯, which I cannot inspect. Order log p/n is the known necessary level for support recovery (Wainwright 2009).
   - Fixed s₀ is not used in L2/L3 beyond the energy bound. Whether T03♯ allows growing s₀ is unclear to me.
   - Gaussianity gives the exact constants behind 1/6. Removing it is not cheap.

### (b) Conclusion

- **Scaling range is the main weakness.** The theorem covers p < n^{1/6} (hence p = o(n), K = p), one factor. Posterior selection consistency is known for p ≫ n (Narisetty–He with log p = o(n); Castillo–Schmidt-Hieber–van der Vaart), and Yang–Wainwright–Jordan prove rapid mixing for p ≫ n. Those results restrict model size and tune the prior penalty, so they do not transfer to a dense start S̃₀ → [p] under the fixed BB(1,p)/g = n calibration.
- **The numerics point beyond 1/6.** D3 has 720/720 pure-deletion paths up to log p/log n = 0.75 (REPORT.md:100-101).
- **The boundary can be made second-order.** With ε_n ≍ (log p)^{1/4} + (log log n)^{1/2} (L1_uniform_add.md:105-108), the proof gives the sufficient condition log n − 6 log p ≥ C[(log p)^{3/4} + √(log p·log log n) + 1] at κ̄ = 1, in place of a strict limsup.
- **Rates are available but unstated.** The lattice events fail with probability O(1/log n) (L3_NA_TL.md:80; L2_sandwich.md:24). Replacing the log log n slack by η log n, which the strict gap in (P) allows, gives n^{-η} for NA/TL. The overall rate is limited by [GEN-L1] and T03♯ (external).
- **The (L1) envelope is sharp to leading order** in both regimes: 2√(2 log p) at small |T| (L6_sharp.md:30) and √(2 log(p/|T|)) for the top-k average.

### (c) Cheapest routes

- **Easy (edits to L1 Corollary U, L2, L3, L5):** items 1–5 above, the 1/8 extension in item 6, the second-order boundary and the explicit rate. None changes the mechanism.
- **Hard, the real gain:** the path route (L8_frontier.md:46-65).
  - By Lemma GAP the visited sets are complements of contiguous runs, at most p² sets. Swap domination adds one arbitrary deletion, so NA is needed on about p³ sets rather than 2^p.
  - The open step is the one-sided late stage, which is exactly the SHARP witness geometry.
  - The (AG) coupling for iid rows would then cap near p ≪ n^{1/3} (L5_random_instances.md:34-35) and would need replacing.
- **Hard:** p > K and k ≥ 2 (L8_frontier.md:68-76). For k ≥ 2 with generic loadings I expect the full-lattice route to fail outright (heuristic), so the path route would be required.
