## W3-SAMP:D — Theorem D (draw discovery), `STATEMENT.md:97-105`

**Summary.** The draw-count identity D-i is exact and cannot be improved for the draw mechanism. The theorem as a statement about the reported HPM is improvable in three modest ways (truth-free target, exact overlap condition, a set-valued version) and one hard way (crediting the local moves and local search).

### (a) Hypotheses

- **H-U, START, SI: needed.** They are used at `D_theorem.md:12-20` (strong Markov, Ψ(V) ~ π₀) and `:25-29` (freezing, 𝓒 ⊥ U_r). Dropping any one loses the equality in D-i. If only the inequality were wanted, START could be weakened to "each draw hits S₀ with conditional probability ≥ a", but that is not worth stating.
- **IND-T (D-ii only): necessary for the exponent 4D_r.** If the four streams are identical copies, each is still marginally iid uniform, so H-U holds; the islands then coincide and the miss probability is exactly (1−π₀(S₀))^{D_r}. Asymptotically it is immaterial, since Q_D → ∞ iff 4Q_D → ∞. D-iv correctly does not use it.
- **KERNEL: stronger than used.** Only the control-flow clause of W1-N1 Lemma B (B-b) enters, at `D_theorem.md:13-15` (τ_k is a stopping time). π-invariance plays no role in D. The statement already says this (`STATEMENT.md:97-98`), so this is cosmetic: list the clause, not KERNEL.
- **P-MAP: the right premise for the target S₀, but not needed for the mechanism.**
  - It is strictly weaker than P-CONC (`ASSUMPTION_MAP.md:17`): it needs only max_S π(S)/π(S₀) < 1, not Σ_{S≠S₀} π(S)/π(S₀) → 0.
  - It is near-necessary for S₀: on {completed}, Ŝ = S₀ with S† ≠ S₀ can only happen if the run never scores S†.
  - However, the deterministic step at `D_theorem.md:40-42` uses only "S† ∈ 𝓜 ⇒ Ŝ = S†". S₀ enters solely through the event {S† = S₀}. So the truth premise can be removed altogether by targeting S† (see (c)-1).
- **P-OVL (`STATEMENT.md:82-83`): not the exact condition, even for the draw mechanism.**
  - The proof relaxes (1−a)^D ≤ e^{−aD} at `D_theorem.md:56`.
  - The exact condition for the draw term E[1_𝒜(1−π₀(S₀))^{D_r}] → 0 is Q* := D_r·|log(1−π₀(S₀))| → ∞ in probability (∞ off 𝒜).
  - Since |log(1−a)| ≥ a, P-OVL implies this. The two differ only when π₀(S₀) → 1 with D_r bounded. Example: the component setting N_e = 1, T = 1, L = 0 has D_r = 6, so Q_D ≤ 6 and P-OVL fails, yet the miss probability is δ₀⁶ → 0.
  - In production D_r ≥ max(2500, n, p)(L+6) → ∞ and the two conditions coincide, so the production corollary gains nothing. The gain is confined to the "any frozen parameters" scope (`STATEMENT.md:43-46`).
  - With Q*, D-iv would also subsume the HPM clause of C-v (`C_theorem.md:64` is the same mechanism using only the N_e initial draws).
- **P-OVL is only sufficient for the method.** The ticket records this itself (`ASSUMPTION_MAP.md:18`, `D_theorem.md:62-64`). Among islands where no draw hit S₀, S₀ was still a terminal particle endpoint in 13773/15015 and 30559/31505. On those finite targets the bound overstates the miss probability by roughly 12× and 32×.

### (b) Conclusion

- **D-i equality: SHARP.** For independent draws from π₀ with budget D, (1−π₀(S₀))^D cannot be beaten.
- **Production scaling: order-sharp given the proof's inputs.**
  - The condition is π₀(S₀) ≫ 1/(max(n,p)·log n).
  - The corollary uses T ≥ 1 (`D_theorem.md:53-54`). CC6 gives only an upper bound on T (`CC_code_check.md:94-100`), so a factor of T cannot be gained deterministically.
  - The conditional form with the realised D_r = N_e(T+L+5) is already in D-iii.
- **What the condition means in practice.** For p = n^A, the block start must already place mass ≳ n^{−max(1,A)} on S₀. A structure-free start has π₀(S₀) ≈ p^{−s₀} and fails for s₀ ≥ 2. So D is really a theorem about the quality of the start, not about the sampler.
- **Comparison with the literature.**
  - Yang–Wainwright–Jordan (2016) show the add/delete/swap Metropolis chain mixes in time polynomial in (n, p, s₀) from an arbitrary start. Their conditions are a beta-min of order √(log p / n), restricted-eigenvalue-type design conditions and a model-size cap. No start-overlap condition is needed there.
  - D gives the method's Gibbs flips, swaps, final local search and LS0 zero credit ("only enlarge 𝓜", `D_theorem.md:62-63`). In the YWJ regime, P-OVL is therefore plausibly unnecessary for the method.
  - I am not confident this transfers directly. The budget here is T+L+4 sweeps, and Ω allows sizes up to ⌊n/2⌋, well beyond a YWJ-type size cap.
  - Johnson–Rossell, Narisetty–He and Castillo–Schmidt-Hieber–van der Vaart bear on P-MAP/P-CONC, not on D's computational content. I see nothing in them that changes D.
- **Relation to Theorem TR's HPM clause.** P-OVL∞ with P-CONC forces π₀(S₀)·L → ∞ (`TR_theorem.md:65`), hence D_rπ₀(S₀) → ∞. So D-iv already implies the HPM clause of TR-d. D is the stronger HPM result in the package, which makes its sharpness matter more.
- **Mode of convergence: adequate.** D-iii is an explicit finite-sample bound, and rates follow directly (for example Q_D ≥ c·log n gives n^{−c}). Nothing to gain.

### (c) Cheapest routes to a stronger version

1. **Truth-free HPM exactness (easy).**
   - State: P(completed ∩ {Ŝ ≠ S†}) ≤ E[1_𝒜(1−π₀(S†))^{D_r}], with exponent 4D_r under IND-T.
   - Proof: S† is σ(data)-measurable and the data are fixed at the conditional level (`STATEMENT.md:29-30`). So the argument at `D_theorem.md:6-29` applies verbatim with S† in place of S₀, and the deterministic step at `:40-42` needs only S† ∈ 𝓜.
   - Current D-iii follows, slightly sharpened: P(completed ∩ {Ŝ ≠ S₀}) ≤ P(S† ≠ S₀) + E[1_𝒜·1{S† = S₀}·(1−π₀(S₀))^{D_r}].
   - Gain: a purely computational statement ("reported HPM = exact posterior mode") valid below the beta-min level, for any sparsity and any design. It cleanly separates the statistical term from the algorithmic one. Effort: a few lines.
2. **Exact overlap condition (easy).** Replace Q_D by Q* = D_r·|log(1−π₀(S₀))| in P-OVL and D-iv, and delete the relaxation at `D_theorem.md:56`. This is necessary and sufficient for the draw term. Effort: one line.
3. **Set version of D-i (easy).** For any σ(data, 𝓒)-measurable G ⊆ Ω, P(no draw in G | 𝓒) = (1−π₀(G))^{D_r}. The freezing step at `D_theorem.md:25-29` is unchanged. Alone it changes nothing; it is the hook for route 4.
4. **Method-level discovery (hard).** Credit the Gibbs/swap neighbour scoring and the final local search/LS0, which starts from the running best (`CC_code_check.md:50-57`). This is BT1 §3.2, deferred at `ASSUMPTION_MAP.md:36` and `REPORT.md:174`.
   - Obstacles: rejected draws never become particle states; initial draws can be removed by resampling before any Gibbs step; and a basin or unimodality condition over all of Ω (sizes up to n/2) is needed for the local-search route.
   - This needs new work and primitive design conditions. The numerics above suggest it would be a large gain.
   - A possible deterministic side case: if the block tables offered to the ledger (`CC_code_check.md:55`) enumerate every U ⊆ C_b with |U| ≤ K, then S₀ ⊆ C_b for some b gives S₀ ∈ 𝓜 with no overlap condition. I cannot verify the table contents from the ticket files.

Routes 1 and 2 are strict strengthenings at negligible cost, so the claim is not sharp as stated, even though its core identity is.
