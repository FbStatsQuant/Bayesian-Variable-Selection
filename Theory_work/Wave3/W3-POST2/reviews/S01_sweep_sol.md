1. **[MAJOR] Bounded reference cost is incorrectly presented as necessary.** `ASSUMPTION_MAP.md:18,55`. Claim B proves a sufficient condition and a particular upper bound whose displayed constant grows with B; it proves no necessity. The necessity assertion is false for tightness of the stated normalisation: fix p=2, T=∅ and a standardised column x₁, and take μ=x₁, so B_T=‖μ‖²=n−1→∞ and the energy bound holds. For all sufficiently large n, K=2, and for each integer m<K the positive R_m^∅ belongs to a fixed finite collection depending only on p. Thus Θ″_{n,m}≤1/(R_m^∅√n)=O(n⁻¹/²) deterministically, uniformly in m (m≥K gives zero). Bounded cost is not necessary even in this elementary example. **Fix:** replace both “needed” assertions by “sufficient for the uniform bound obtained by this proof”; describe exp(O_P(B_n)) as an upper payment, not a necessary payment. The necessity claim as a whole is unsound; the sufficient theorem B survives.

2. **[MAJOR] The numerical Occam sums implement the wrong weights on precisely the rank-deficient cases being used to support the relaxation.** `numerics/post2_checks.py:100–105`; compare `STATEMENT.md:30` and `lemmas/A_occam.md:9`. The code uses 1 for d=0 and (2eC_A j log n/d)^(d/2) otherwise. The theorem uses 2^(j/2)(eC_A j log n/max(d,1))^(d/2). The implemented sum undercounts each rank-deficient term by 2^((j−d)/2). Independent check `reviews/S01_scratch/check.py` gives factors √2 for (j,d)=(1,0),(2,1), and 2 for (3,1). Consequently the singular-design Ow and amplified Owj0 output is not the specified interface, including the “79→15” figures used in the assumption map. **Fix:** implement the specified weight for every d, reproduce the affected output, and update all numerical summaries. This does not refute the analytic moment bound, which uses the correct weight.

3. **[MINOR] The numerical implementation of OS also has the wrong general summation domain.** `numerics/post2_checks.py:85–105`. It sums only models in Ω and never computes m♯_n; the theorem requires unions through j≤min(m♯_n,p−s₀), including unions outside Ω. Current experiments have fixed p=10<n/2, so m♯_n=K=p eventually (and at the listed sizes the cutoff is capped); this masks the defect rather than fixing it. **Fix:** compute m♯_n from R_m and evaluate determinant/rank quantities for every required comparison union separately from the posterior's feasible models. Keep O⁰ capped as currently implemented.

4. **[MINOR] N1's reported ID margin is a minimum over a strict subcollection, hence only an upper bound on the required margin.** `numerics/post2_checks.py:164–168`; `ASSUMPTION_MAP.md:25–26`; `lemmas/E_visibility.md:75–79`. For s₀=2,A=1, the package defines j₀=7. N1 restricts to at most two extra variables and total size at most three. The actual ID minimum includes underfits with up to seven extras and models of total size eight. A restricted minimum cannot certify ID, and the table's positive margins do not verify the theorem's hypothesis. **Fix:** enumerate all S∈Ω with S₀⊄S and |S∖S₀|≤j₀; report both Δ_S and, for the adopted theorem, L_S. Alternatively relabel the existing quantity explicitly as a restricted diagnostic and remove “ID holds” conclusions based on it.

5. **[MINOR] N4 does not actually instantiate (ID;c) as labelled.** `ASSUMPTION_MAP.md:28`; `numerics/post2_checks.py:190–200`. Standardisation gives Δ_∅=(n−1)θ²=c(1−1/n)log n, strictly below c log n. Moreover the ID condition is a minimum over all bounded-excess underfits, not just ∅; adding null predictors can reduce Δ further. Thus the assertion “(ID;c)” and equality “Δ_∅=c log n” are false at the specified n. **Fix:** call c the coefficient-scale parameter, report the actual full ID/ID^M minimum, and use a separate achieved margin constant. Scaling θ² by 1/(n−1) fixes the empty-model equality but still does not fix the missing minimisation.

6. **[MINOR] The theorem's weighted sum is not simply the necessary sum restricted to a smaller j range.** `STATEMENT.md:59–61`; `lemmas/A_occam.md:96–97`. O⁰ stops at K−s₀, whereas O^{>0} stops at min(m♯_n,p−s₀). The latter can exceed K−s₀, so OS also includes comparison unions outside Ω that have no counterpart in the deterministic necessity bound. The text mentions these unions elsewhere, but its explanation of the gap omits this additional enlargement and calls it a restriction. **Fix:** compare on j≤min(K−s₀,m♯_n), then separately identify (i) weights, (ii) omitted feasible large supersets, (iii) added infeasible comparison unions, and (iv) the amplified tail condition.

7. **[MINOR] Exact span membership alone does not imply a bounded determinant ratio or the claimed fixed-p obstruction by A2.** `lemmas/A_occam.md:98–99`. The sentence “one null column x_k∈col X_{S₀} gives ... D_{S₀∪{k}}/D_{S₀}=O(1)” needs a bounded representation norm (or F₀ and standardisation); neither follows from span membership in the general design-free A2 discussion. Counterexample: s₀=2, both true columns have norm √N and correlation 1−n⁻², and x₃=(x₁−x₂)/√(2n⁻²). Then x₃ is standardised and exactly in their span, but its addition has determinant ratio asymptotic to n/2. Independent calculation in `S01_scratch/check.py`: 50.4976,200.4994,800.4998 for n=100,400,1600. The particular N1 construction has a bounded representation and is fine. **Fix:** explicitly restrict the remark to that construction, or assume a uniformly bounded minimal-norm representation and invoke the preceding Schur bound.

8. **[MINOR] Finite posterior expectations and an upper bound on Hellinger loss do not establish the stated sharpness/attainment.** `ASSUMPTION_MAP.md:31,54`; `lemmas/D_hellinger.md:89–92`. N7 computes posterior expectations, over four n values, and an upper bound on h̄², not h̄² itself. A flat expectation/log n does not prove a lower bound in posterior probability; a flat upper bound on Hellinger loss does not prove a matching lower bound on Hellinger loss. D4 acknowledges elsewhere that unbounded-loss expectations are not the theorem's conclusion. **Fix:** label N7 “consistent with the rates” and reserve “attained” for a proved lower bound. An analytic weak-signal example with π(∅)→1 and ‖μ‖²≍log n would establish the mean-loss obstruction; proving Hellinger sharpness additionally needs a lower-distance calculation. The oracle conditional χ² spread can justify D(a)'s scale, but is distinct from the reported numerical Hellinger-bound experiment.

9. **[MINOR] The assumption map restores an unproved universal margin-necessity claim that the proof remarks correctly withdrew.** `ASSUMPTION_MAP.md:28`, “order needed” and “improvable (≈40×)”; compare `lemmas/E_visibility.md:75`. Four finite-n medians at fixed p do not prove that log n is a necessary universal margin order, nor that c₁ can universally be reduced to 4. Those experiments do not even evaluate the full margin (finding 5). Failure of ID by itself does not imply failure of selection. **Fix:** say “smaller constants work in these experiments; no converse/universal improved constant proved.” Keep the explicitly recorded R03b proposals separate from adopted results.

10. **[MINOR] The lower-bound domain disappears in the standalone sharpness record.** `ASSUMPTION_MAP.md:53`. The assertion Eδ_n≥(1+√(n+1))⁻¹ omits s₀<p and s₀+1≤K. R1 permits p=s₀, where no strict superset exists and this lower bound can fail (the cited LB file explicitly records its domain counterexample). Claim C's statement and C's proof remarks correctly retain the qualifications. **Fix:** repeat the domain in the map; make the “sharp up to √log n” comparison conditional on it.

11. **[MINOR] The effective-rank remark does not specify the n-dependent scale that controls determinant cost.** `lemmas/B_tail_approx.md:57–58`. “Small eigenvalues” need not be inexpensive: λ_n=n⁻¹/²→0 gives f(λ_n)=((n+1)λ_n+1)/(λ_n+1)≍√n, so √D still pays n^(1/4) for this eigenvalue. A fixed positive eigenvalue, however small numerically, pays order √n. Only λ=0 contributes exactly 1; λ=O(1/n) contributes O(1). **Fix:** give these thresholds and express the gain through the exact product, rather than saying the reference pays only for its large eigenvalues.

12. **[MINOR] “The posterior lives on” the weak-signal cutoff needs a diverging slack.** `lemmas/B_tail_approx.md:54–55`. The preceding bound gives O_P(e^(−ω_n)) at m≈(½log n+ω_n)/log2. Vanishing mass outside the cutoff follows when ω_n→∞, not for an unspecified deterministic ω_n (Claim B earlier allows arbitrary deterministic sequences). **Fix:** explicitly require ω_n→∞ for this concentration interpretation, and use an integer ceiling/cap when stating the cutoff.

13. **[MINOR] The boundary-violation record does not cover every new assumption as required by the sharpness gate.** `ASSUMPTION_MAP.md:12–18,20–31`. There is no experiment outside F₀, no growing/unbounded reference-cost boundary test, and no non-Gaussian boundary test; N6 also keeps μ in col X despite the new arbitrary-mean use. Thus the gate's “just outside each assumption” exercise is incomplete; the necessity wording for reference cost is especially unsupported. **Fix:** supply small explicit boundary tests, or record each missing test and why it is not undertaken. For G′, separate Gaussianity (a proof technique) from the arbitrary-mean extension; test a mean with a component orthogonal to col X. Do not use the existing table as evidence that all new assumptions were tested.

14. **[MINOR] The archived A2 output cannot substantiate “slack≥0 in every case.”** `ASSUMPTION_MAP.md:24`; `numerics/post2_checks.py:133,143,171–172`; `numerics/post2_checks_out.txt:3–7`. The table reports median slack; neither an assertion nor the minimum over seeds is stored. A negative outlier can be hidden by a positive median. My independent eight-case check found minimum slack 0.48379, consistent with A2, but does not certify the original entire run. **Fix:** print the minimum slack and a violation count (with a numerical tolerance) over all cases. Keep medians for trend summaries.

15. **[MINOR] The assumption map misidentifies where Gaussianity enters Claim B.** `ASSUMPTION_MAP.md:17`. It says Gaussianity is used in [P1] lem:num/den. The numerator identity is a density-normalisation/Tonelli identity for any positive truth density f₀, as `lemmas/B_tail_approx.md:20` itself correctly notes. Gaussianity supplies the explicit f₀ exponent, χ² fluctuation and Gaussian residual cross-term calculations in the denominator, and the sample-scale event probability. **Fix:** correct the “enters” column and avoid presenting lem:num as a Gaussian-only ingredient.

16. **[NIT] Fixed p does not mean that R1's A tends to zero.** `ASSUMPTION_MAP.md:6`. A is a fixed upper-envelope exponent, constrained to A≥1 here; log p/log n→0 is a different quantity. The numerical implementation itself correctly takes A=max(1,log p/log n), giving A=1 for these runs. **Fix:** say “fixed p, so log p/log n→0; these experiments do not probe polynomially growing p.”

17. **[NIT] The documented numerical command advertises a nonexistent experiment.** `numerics/post2_checks.py:9,283–286`. Passing the advertised `A2` argument raises KeyError because no A2 function exists. A2 diagnostics currently run as part of N1/N2/basic. **Fix:** remove A2 from the command example or add an actual A2 entry point.
