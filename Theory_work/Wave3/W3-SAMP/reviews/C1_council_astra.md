## Issues

1. **NON-BLOCKING — numerical “LT-b” labels use a stronger bound than the displayed theorem.** `numerics/run_checks_v4.py:36`, `numerics/README.md:16`, `lemmas/LT_theorem.md:105`. The script uses λ₀/ε, whereas STATEMENT.md:125 displays 19o₁/ε. The reported 18 non-vacuous cells comprise eight LT-a cells, three LT-b′ cells, and seven cells for the sharper λ₀ version of LT-b. The literal displayed LT-b bound is vacuous in these seven cells: even in the more concentrated target, 19o₁/0.2 is approximately 0.982 before adding the positive δ/(εη) and lower-tail terms. **Fix:** label those seven cells “LT-b with exact λ₀,” and state the sharper inequality explicitly before its 19o₁ relaxation, or report both right sides as run_checks.py already does. This does not undermine the theorem: LT's proof already establishes the sharper bound, so passing that check also supports its relaxation.

2. **NON-BLOCKING — inconsistent partial-sum indexing in the occupation proof.** `lemmas/C_theorem.md:26-27`. The definition V_{t−1} = Σ_{v<t}x_v implies V_t = Σ_{v≤t}x_v. With τ = min{t : V_t > u}, the correct crossing statement is Y ≥ V_τ > u, as intended; however line 26 first defines V_{t−1} and then uses V_t without explicitly extending the definition or declaring the empty-sum endpoint. **Fix:** define V_{−1} = 0 and V_t = Σ_{v=0}^t x_v for t = 0,…,T before defining Y and τ. This makes the t = 0 case and crossing argument unambiguous. The bound itself is correct.
