Numbered issues (paths below are relative to Theory_work/Wave3/W3-SAMP):

1. **MEDIUM — P-OVL∞ is localized incorrectly and its advertised production equivalence is false as written.** `STATEMENT.md:75`, `STATEMENT.md:157`, `lemmas/TR_theorem.md:18-21`.

   The expression `1_A L/M -> infinity in probability` is zero on A-complement. For any fixed positive c, its probability of being at most c is at least P(A-complement), so the assumption forces P(A) -> 1. In contrast, `M = o_P(log n) on A` only requires small localized M/log n and imposes no such success probability. For example, at the level of these probability conditions, if P(A)=1/2, M=1, and L grows like log n, the latter holds and the former fails. This conflicts with the scope at STATEMENT:35 and :163. The analogous P-OVL definition already specifies an infinity extension off A; P-OVL∞ does not.

   **Fix:** define P-OVL∞ as `P(A intersect {L/M <= c}) -> 0` for every finite c>0, or define Q=L/M on A and Q=infinity off A and require Q -> infinity. Use this same convention in the TR statement and proof. Then `1_A exp(-L/M) -> 0` follows directly, the proof is unchanged, and the production equivalence with localized `M/log n -> 0` becomes correct. Do not fix this by adding a calibration-success theorem or premise; that would unnecessarily change the intended scope.

2. **LOW — the label “a property of (pi, pi_0) only” overstates the general overlap premise.** `STATEMENT.md:75`, `STATEMENT.md:158`, `lemmas/TR_theorem.md:60`.

   M is a property of the two distributions. The asymptotic condition L/M -> infinity also depends on the executed burn-in budget L, which the component theorem permits to vary with the frozen calibration record. Holding both distributions fixed and changing L can change whether the condition holds. It is independent of the final particle realization, but that is a different assertion from dependence on the distributions alone. In the production corollary L is prescribed, and the reduction to a distributional overlap rate is appropriate.

   **Fix:** call the general premise “a global-overlap condition relative to the executed terminal budget, involving no final-particle statistic.” Reserve the distribution-only rate description for the production corollary with its specified L. Keep the existing warning that the method does not compute or certify M.

3. **LOW — the vanishing-threshold MPM proof uses the wrong strictness at exactly one half.** `lemmas/LT_theorem.md:77-79`.

   LT-b′ bounds `P(E_r > u)`, while an MPM error can occur when the pooled error equals 1/2: a true coordinate with reported PIP exactly 1/2 is excluded. Therefore the parenthetical “MPM (u = 1/2)” does not by itself justify the implication. The earlier LT-d proof explicitly handles this tie correctly, and the asymptotic conclusion remains valid.

   **Fix:** use any fixed u<1/2, for example 1/4, in the convergence bound and then use `{MPM wrong} subset {pooled error >= 1/2} subset {pooled error > 1/4}`. Alternatively state and prove the non-strict tail version of LT-b′. No new hypothesis is needed.
