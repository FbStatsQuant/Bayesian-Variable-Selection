1. **Substantive gap: L7.1 does not yet prove its extras bound (L7_counterexample.md:51-65).** The empty-block addition argument proves that every block in B is occupied when |S̃₀|<K. The last sentence, “Elements of S̃₀ in blocks of B are proxies or nulls, not in S₀,” is false as a description of these blocks: a block without x₀ can contain a further truth x′_j together with proxies. Occupancy could therefore be supplied solely by truths. No partition argument excluding this possibility is given; the preceding hypothesis checks explicitly accommodate these mixed blocks. Merely subtracting s₀−1 truth-containing blocks would lose the margin used in L7.3. This is a proof gap, not a counterexample to the proposition. The following direct replacement repairs the stated bound without changing d_n or imposing a partition assumption.

   **Concrete replacement for the |S̃₀|<K case:** suppose some b∈B has (S̃₀∩C_b)\S₀=∅, and put U=S̃₀∩C_b⊆S₀\{0}. Pick a proxy k∈C_b. Compare S̃₀ with S̃₀∪{k}; the gain is

   log[w(q+1)/w(q)] + log[r_b(U∪{k})/r_b(U)].

   Apply L1 to the deterministic family

   F_n={A, A∪{k}: A⊆S₀\{0}, k a proxy}.

   This contains ∅, has J=s₀ fixed, cardinality at most 2^(s₀−1)(d_n+1)≤C_F n, and normalized Gram floor 1: the further truths are orthonormal and orthogonal to each proxy. Specify the auxiliary residual family {r_A:A∈F_n}, which also has polynomial size, for L1's events. For every such U,k, (I−P_U)x_k=x_k, so the contrast numerator is the same (δ_k+Z_k)² used in the current proof, while its denominator is RSS_U≤||Y||²≤C_R n. Consequently the identical uniform lower bound holds:

   log[r_b(U∪{k})/r_b(U)] ≥ −(1/2)log(n+1) + θ²(n−1)a²/(4C_R d_n) − 2κ_E.

   The prior contributes at least −log(2p), so the gain is strictly positive for all these U,k simultaneously for large n on an event of probability tending to one. This contradicts maximality. Thus every b∈B contains at least one selected extra, which proves |S̃₀\S₀|≥|B|≥ceil(d_n/B)−1. The |S̃₀|=K case at lines 56-57 is already correct, since K−s₀≫d_n. This replacement closes the substantive gap; until it or an equivalent argument is incorporated, the v2 extras bound and its use in C6/L7.3 are not established by the written proof.
