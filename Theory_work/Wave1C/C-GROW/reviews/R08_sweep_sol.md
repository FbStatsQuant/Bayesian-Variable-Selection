1. **Minor — wrong unconditional covariance in the written S5 certificate.** `GROW/lemmas/L5_instances.md:104–105` states
   `Cov(x_j, μ) = 0.7θ_j + 0.3Σ_{k≠j}θ_k`.
   The truth has variance one, so the correct expression is
   `θ_j + 0.3Σ_{k≠j}θ_k = 0.7θ_j + 0.3Σ_kθ_k`.
   These are different numbers: for truth 26 at c = 1, the printed formula gives −0.1, whereas the correct covariance is −0.4. Consequently, the displayed reduction as written does not produce the subsequent 4/25 certificate. The numerical script uses the correct expression (`f2_exact_tau0.py:21`), and its rational minima reproduce the reported output; this is a repairable formula error, not a refutation of TV. **Fix:** replace the first covariance expression with either correct form, preserving the correct own-group and paired-group expressions that follow.

2. **Minor — the public random-design clause should state its noise model explicitly and distinguish Y from standardized y.** `GROW/STATEMENT.md:124–129` switches from fixed-design G to a joint random-design law, but does not explicitly say that ε is independent of the raw design and has law `N(0, σ²I)`. Retain independent method randomness under the named implementation premises. This aligns the public clause with L6 rather than changing L6's proof.
