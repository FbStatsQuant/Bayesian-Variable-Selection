Helper: test sub-agent for C-GROW. All files in `Theory_work/Wave1C/C-GROW/numerics/`, names starting with `f`/`F` (d*/D* belong to the other helper;
`F2_exact_tau0.txt` is **not** mine). Python 3.13 (numpy 2.3.0, scipy 1.15.3), `bvs_core.py` imported unchanged. No git command was run.
Every number below is read from `F1_summary.md`, `F1X_summary.md`, `F2_summary.md`, `F3_summary.md`, `F_aggregates.txt`, `F_pathinspect.md`
(each generated from `f*_results.pkl` / `F*_raw.csv` by `f_report.py`, `f3_report.py`, `f_aggregate.py`, `f_path_inspect.py`). Observations only, not proofs.

## Findings that matter

1. **NA (no addable variable over the lattice) is violated at every tested n when P is the d_n-set, in the SoP-formula sizes |P| = 80–312.** F1: NA fails (max add gain ≥ 0) in 60/60 runs at n = 200, 49/60 at n = 800, 35/60 at n = 3200 (144/180 total; ρ = −0.5: 47/60, 0.5: 40/60, 0.8: 57/60); largest gain +12.1 nats (n = 200), +6.9 (800), +7.9 (3200). F2 (P = all 96 nulls): 18/20, 16/20, 10/20 at n = 800, 3200, 12800 (largest +6.1, +2.3, +3.2). The fraction falls with n, the size of the worst violation does not. Worst pairs were re-evaluated with `bvs_core.Problem.F`: agreement to 4e-11. The worst pairs sit at near-full T (|T∖S0| = 51–287 nulls) and add a null (a null of P in 16/18 F1 rows; in 2 rows the worst l is outside Q).
2. **The Gaussian threshold c*_n is exceeded by the tested Z²:** max Z²_{T,l} > c*_n(|T|) for some tested (T,l) in 55/60, 44/60, 34/60 runs at n = 200/800/3200 (F1; max Z² per row 11.6–24.6, max excess Z²−c* up to 13.9). The maximum is over 5·10⁵–3·10⁶ (T,l) pairs per run, while c*_n(k) at k ≈ 80–98 is only about 6–8 (see the Z² columns in F1_summary.md).
3. **In the (G4-χ) regime NA holds from n = 800 on:** F1X (extra; p = 100, P = the ⌊0.9 log n⌋ nulls nearest a truth, all 2^|P| lattice sets, 20 seeds, ρ = 0.5, 0.8): NA violated 0/40 at n = 800 and 0/40 at n = 3200 (max gain −0.07 resp. −0.87), but 4/40 at n = 200 (max +1.45, |P| = 4).
4. **TL holds with large margin on every tested T** (all runs, F1/F1X/F2): largest swap/deletion difference F(A)−F(T) is −8.6 / −6.4 (F1, n = 200), −16.8 / −18.0 (F2, n = 800), and −283 / −279 at n = 3200 (F1). No truth was removed on any of the 360 uncapped LS paths (F1 180, F1X 120, F2 60).
5. **Consequence for C1 ("exactly |C∖S0| deletions"):** F1: 176/180 paths are pure deletions of start extras ending at S0; 3 runs (all n = 200) end *certified at S0 + one null* (an improving add exists at S0 or after the deletions: gain 0.65, 2.36 nats; F(S0) < F(final) by 0.43–2.36), 1 run has a null↔null swap. F2: 47/60 pure; **11/60 paths contain 1–2 null↔null swaps** (first-move swap gain 6.4–8.2 > best deletion gain 5.9–6.5; moves = |extras| + 1 or + 2; 10 of them end at S0, one at S0 + a null), 1 run (S0 ⊄ S~0) uses a null→truth swap (gain 69.2), and 2/60 (both n = 800) end at S0 + a null (one of them after pure deletions). F1X: 118/120 pure, 2 end at S0 + a null (n = 200). So the path is not "one deletion per move" in S5 at n ≥ 800, although it stays in L; uncapped final = S0 in 120/120 F1 runs at n ≥ 800 and in 40/40 F2 runs at n ≥ 3200.
6. **Sandwich holds with P = d_n-set:** F1 S0 ⊆ S~0 ⊆ Q and S~0∖S0 ⊆ P in 180/180 runs; |S~0∖S0| = 0–3 (n = 200), 0–6 (800), 1–9 (3200); ρ = 0.8 has 1–9, ρ = ±0.5 has 0–2. Not an artefact of tiny P: with the tiny F1X P the extras are outside P in all runs at n ≥ 800 (P was an arbitrary nearest-nulls choice, not the minimal P ⊇ extras). F2: S0 ⊆ S~0 in 59/60 runs; the single miss: c = 0.5, n = 800, noise seed 0 (truth 26 missing from S~0, start = (2,47,53,70,75,82,93); first move swap 70→26 gains 69.2 nats). |S~0∖S0| in S5: 1–8 (n = 800), 15–20 (3200), 24–42 (12800) (c = 0.5: 24–32, c = 1: 40–42 at n = 12800), ≫ log n = 9.5.
7. **Population margins (exact, coded partition) are not binding:** TV = min δ²/log n ≥ 8.2 (ρ = 0.8, n = 200) … 237.8 (ρ = ±0.5, n = 3200) in F1; F2: 4.78 (c = 0.5, n = 800), 15.85, 54.13 (n = 12800), c = 1: 19.12, 63.42, 216.5; F3: 39.96. η = 0.05–0.087 (η_A twice that). NEG margin ≤ 4.1e-5 wherever defined (F1; l ∉ Q exists in 12/18 rows; F3: 1.3e-5) ≪ η. In F1X, where P is tiny, NEG = 13.5–517 ≫ η (every Q is too small for the block structure).
8. **Caps (F2):** production ℓ_n scores S0 in 20/20 at n = 800 but **0/20 at n = 3200 and 0/20 at n = 12800** (`local_limit` 20/20 both); ℓ_n + |S~0| scores S0 and ends certified at S0 in 20/20 at both n (no local_limit); at n = 800 both caps give final = S0 in 18/20 (the 2 misses are the S0+null / swap runs above). F1: both caps score S0 in 180/180; final = S0 in 177/180 (the same 3 runs as in 5.), local_limit never (ℓ_n = 9–12, ℓ_n + |S~0| = 13–25).
9. **F3 (p = 399, n = 400, ρ = 0.5, 20 seeds):** |S~0| = 4 in 20/20 seeds, S~0 = S0 (no nulls at all). Not falsified, but nulls are negligible there. For comparison (F1), at p = 100 and n = 800, 3200 the start mode contains 2 nulls (ρ = ±0.5; 1 at p = 400, n = 3200; 0 at p = 400, n = 800), at index distance 1–2 from a truth for ρ = ±0.5 (F1_raw.csv `extras_dist`); for ρ = 0.8 the extras lie at distance 1–10.
10. **Caveats:** NA/TL were tested on a *finite family* (all of L if |P| ≤ 12; else all |T∖S0| ≤ 2, all |Q∖T| ≤ 2 — sampled to ≤ 4000 and ≤ 4000 (≤ 1000 if |Q| > 120) sets — plus 300 random subsets of P), so the maxima are lower bounds on the sup; the path states are not necessarily in the family.

## 1. Conventions and deviations (state of the specification as implemented)

* Library `f_common.py` (imports `bvs_core.py`): row = (design, θ, S0, P, n, seeds). Exact Gram X = `exact_gram_design(Σ, n, default_rng(xseed))`, one fixed X per row (xseed = 1000 + 7n + p + int(100(ρ+1)); S5: 555 + n + 5 as in `study_common.build_xy`); `X'X = (n−1)Σ` checked (max abs error ≤ 1.6e-11 over all rows, column means ≤ 2.6e-14; column "gram err" in the summaries).
  Noise ε_s = N(0,I_n), `default_rng((100000 + n)·1000 + s)` for AR(1) (S5: `9000 s + 31 n + 7·5 + 5`, same as the study); y = `standardize_y(Xθ + ε)` (σ = 1); Z_{T,l} uses the raw ε.
* AR(1) truths: indices ⌊p/8 + k p/4⌋, k = 0..3: p = 100: 12, 37, 62, 87; p = 199: 24, 74, 124, 174; p = 400: 50, 150, 250, 350 (p = 399: 49, 149, 249, 349); θ = (1.4, −1.0, 1.8, −1.2).
  d_n = ⌈ log(16 s0² max|θ|² n (1+ρ²)/(1−ρ²)/(η log n)) / (2 log(1/|ρ|)) ⌉ with A = log p/log n, η = ½(√(2A+1) − √(2A))² (the task's η; η_A = 2η is also printed). d_n and |P| are in the first two columns of `F1_summary.md` (ρ = ±0.5: d_n = 10, 10, 11, 11, 12, 12 and |P| = 80, 80, 88, 88, 96, 96 for (n, p) = (200,100), (200,199), (800,100), (800,400), (3200,100), (3200,400); ρ = 0.8: d_n = 34–39, |P| = 96, 195, 96, 288, 96, 312). For ρ = 0.8, |P| is 96 at p = 100 (all nulls) and 195 at (200,199).
* Lattice family: see caveat 10. The family is drawn once per row (shared by the 10 seeds). Models with |T| > K = min(p, ⌊n/2⌋) are infeasible and skipped: this only matters for row (ρ = 0.8, p = 199, n = 200) with |Q| = 199 > K = 100 (G1 violated there); that row's lattice task was re-run after adding the skip (old pickle: `f1_results_v1_before_Kfix.pkl`; with the skip: 4144 sets tested, 1156 skipped; NA max-gain per seed unchanged, 11.05 … 4.21, TL diffs −8.6 / −6.4).
* Incremental formulas for F(T∪{l}) − F(T) for all l and all seeds (Schur complements, `Adder.adds`): checked directly against `bvs_core.Problem.F` for the worst NA pair and worst TL swap of every run (max abs diff 4e-11) and at spot checks (≤ 2e-11).
  TL: A ∈ {T − i, T − i + l : i ∈ S0, l ∉ T, l ≠ i}; reported separately as swap and deletion maxima.
* Production runs use `bc.start_mode` on `bc.partition(X)` (B = min(⌊√n⌋, ⌊√p⌋, 16), K = min(p, ⌊n/2⌋)), `bc.local_search` with ℓ = 10⁴ (uncapped), ℓ_n = ⌈log₂(n+p+1)⌉ and ℓ_n + |S~0|. "S0 scored" = S0 in the scored set of that LS.
* Population checks (`pop_margins`): `bc.Pop.from_design`, Λ tables over all 2^|C_b| subsets of each block (≤ 2^16: no capping was needed); TV over blocks containing truths with all U ⊆ C∖{j}; NEG over l ∉ Q with S0∩C_b ⊆ U ⊆ C_b∖{l}; both on the coded partition of the exact-Gram X (seed-free).
* F2: Σ from `study_common.scenario_sigma(5, 100)` (S0 = indices 2, 26, 53, 75; θ = c(1.4, −1.0, 1.8, −1.2)), P = all 96 nulls, Q = [p]; K = min(100, n/2) = 100.
* F1X is an extra beyond the specification (|P| = ⌊0.9 log n⌋ = 4, 6, 7 at n = 200, 800, 3200; P = nulls sorted by (distance to nearest truth, index), first m). 20 seeds.
