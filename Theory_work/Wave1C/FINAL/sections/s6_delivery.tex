\section{Delivery}\label{sec:delivery}

All results of §\ref{sec:hpm} are joint with output: they leave $\PP(U_n)$ free. C-DLV asked whether $\PP(U_n)\to0$ for v3.1 + LS0 under a declared polynomial resource allocation. \textbf{For the shipped calibration this target remains open}; what is proved is an exact reduction to one calibration event, and — with a total tier-1 calibration fallback — $\PP(\text{no output})=0$ (Proposition~\ref{prop:F}, extended to the GROW class by Proposition~\ref{prop:FG}). The fallback is implemented on the C-ENG branch \texttt{w1c/ls0-merge} (default on, switch \texttt{v3.grid\_fallback}; not merged to main), and none of the 2,400 study fits had status \texttt{schedule\_limit} (§\ref{sec:impl}).

\textbf{Setting.} Method $\mathfrak M$ = v3.1 + LS0 as specified, \textbf{with LS0 move cap $\ell_n$} (C-DLV's CONFIG; for the C-GROW cap $a_n$ see Proposition~\ref{prop:F} and §\ref{sec:cap}), $R'=4k$ declared ($k$ fixed); premises EX-A (also as a unit-cost model for exact reals, including exp and log), EX-S, SR, OP-LS0 (cap $\ell_n$), e4, GUARD-W, IDEAL-W, MACH, CONFIG, TDP-IMPL; valid declared seed; \textbf{CAL is not assumed}. Classes: LH (exact Gram), LH-iid, the W1-GEN class; fixed $s_0$, $p\le n^A$. $\mathcal U_n$ = no output; $\mathcal{SL}_n$ = status \texttt{schedule\_limit} \srcq{W1C/C-DLV/STATEMENT.md:10-46}{IDEAL-W}; \srcq{W1C/C-DLV/lemmas/L4_delivery.md:6-9}{OP-LS0 (cap ℓ_n = ℓ)}.

\textbf{Allocation.} In Theorem~\ref{thm:D} and Corollary~\ref{cor:Dprime} the declared allocation satisfies C-DLV Corollary R: $\mathrm{mem}_n\ge\max\{\beta\bar{M}(n,p_{\rm raw})+\beta_0,P_0,P_1\}$ and $\mathrm{time}_n\ge\max\{2[\tau\bar{W}(n,p_{\rm raw})+\tau_0],\bar{P}_t\}$, with \texttt{allocation\$mem\_gb} $\ge\mathrm{mem}_n/2^{30}$ and \texttt{allocation\$hours} $\ge\mathrm{time}_n/3600$; here $\bar W,\bar M$ are Lemma R's work and memory envelopes, $P_0,P_1,\bar P_t$ its preflight bounds, $\tau,\tau_0,\beta,\beta_0$ MACH's constants \srcq{W1C/C-DLV/lemmas/L1_resources.md:129-143}{Corollary R}. These statements use LS0 cap $\ell_n$; for the GROW cap use A1's amended envelopes as specified in Proposition~\ref{prop:F}. (A merely ``valid'' allocation does not suffice: a tiny memory budget stops the fit at preflight with \texttt{resource\_limit}.)

\subsection{The exact reduction}
\begin{theorem}[D; C-DLV]\label{thm:D}
Under the setting and allocation above, for every $n\ge3$: (i) $\mathcal U_n\subseteq\mathcal{SL}_n\cup\mathcal N_n$ with $\PP(\mathcal N_n)=0$, and $\mathcal{SL}_n\subseteq\mathcal U_n$; (ii) $\mathcal{SL}_n=\{$calibration escalates to tier 1, and some tier-1 grid construction fails$\}$; (iii) a construction fails iff ($\alpha$) its interval count exceeds the tier cap $T_e$ (pilot stages plus appended bisection points), or ($\beta$) \texttt{non\_progress} (requires a $d$-range on the candidate set above $2\sqrt{c_0}\,2^{60}\approx7.5\cdot10^{17}$, $c_0=\log(10/9)$), or ($\gamma$) failed validation at a point snapped to 1. Hence $\PP(\mathcal U_n)\to0\iff\PP(\mathcal{SL}_n)\to0$.
\end{theorem}
Supporting results: \textbf{(P1)} inventory of every exit of \texttt{v3\_fit} without estimates (\st{AUDITED} by code reading); \textbf{(P2) Lemma R}: operations, words, preflight bytes and preflight seconds are bounded by explicit polynomials in $(n,p_{\rm raw})$ for every valid input, seed and uniform realisation, so under MACH and the allocation above no resource path fires; \textbf{(P3) Lemma S}: on the classes the input/degenerate statuses have probability 0 and under EX-A no scorer call fails; \textbf{(P5)} grid lemmas (exact identity $\rho_V(u,v)=q_u(M)q_{2v-u}(M)/q_v(M)^2$; pilot schedules have $\le T_e$ strictly increasing stages ending at 1; dominance or two-model sufficient conditions) \srcq{W1C/C-DLV/STATEMENT.md:52-67}{(P2) Lemma R}.

\textbf{(O) The open event, exact form.} $\PP(\mathcal{SL}_n)\to0$ on the classes, i.e.\ $\PP(E_n\cap F^1_n)\to0$, $E_n$ = some tier-0 trigger fires, $F^1_n$ = some tier-1 construction fails through ($\alpha$)--($\gamma$). Sufficient routes: (O-a) $\PP(E_n)\to0$; (O-b) control of ($\alpha$)--($\gamma$) for the realised tier-1 candidate sets and pilot schedule jointly with the trigger. The pilot stage count is the CJ06 / Conjecture~P question; neither a pilot bound alone nor endpoint posterior concentration suffices. No design sequence is known to satisfy the (P5) sufficient conditions; in all 134 production fits run by C-DLV no tier-0 trigger fired, so tier~1 was never reached \srcq{W1C/C-DLV/STATEMENT.md:68-84}{Open obstruction}.

CAL is not used; the LH exact-Gram instance carries the input status \st{SAME-FAMILY-ONLY}.
\end{corollary}

\subsection{Proposition F: the total tier-1 fallback}
C-DLV found (as a finding on a shipped component, not made by the ticket) that \texttt{schedule\_limit} is the only no-output path not excluded by the declared allocation and the idealisation premises, and that freezing a valid fallback grid removes it \srcq{W1C/C-DLV/lemmas/L4_delivery.md:79-93}{Proposition F}. The HQ red-team audit A1 found \st{HOLDS-WITH-AMENDMENTS} and no fatal finding; its one MAJOR finding is that the combination with C-GROW's LS0 cap needs amended resource envelopes and allocation (the old time shape is not justified after the change: at $p\propto n$ the old core term is of order $n^5\log^3n$, while the sufficient extra LS0 term is of order $n^6$) \srcq{W1C/HQ_AUDIT/A1_propF_redteam.md:7-19}{MAJOR}. The statement below is A1's ``Exact corrected statement'' \srcq{W1C/HQ_AUDIT/A1_propF_redteam.md:60-75}{Exact corrected statement}.

\begin{proposition}[F: total tier-1 fallback, with the C-GROW cap; C-DLV + A1]\label{prop:F}
Consider the specified v3.1 method with deterministic LS0 from the exact e4 start mode, complete scans, emitted centre and scored-set HPM retention. Let $\ell_n=\lceil\log_2(n+p+1)\rceil$, $K=\min(p,\lfloor n/2\rfloor)$, and set LS0's move cap to $a_n=\ell_n+|\tilde{S}_0|$; all other local-search caps remain $\ell_n$. Keep fixed declared $R'=4k$, fixed worker count, and the other CONFIG restrictions of C-DLV. Assume EX-A with its unit-cost interpretation, IDEAL-W, EX-S, SR, e4, GUARD-W, TDP-IMPL and MACH as stated in C-DLV, and OP-LS0 with the cap replaced by $a_n$, with valid declared seed/allocation and model G on the stated classes.

\emph{Fallback.} At the first failed tier-1 grid construction, terminate that tier and select its last successful construction if one exists, otherwise its completed pilot schedule. Preserve the tier-1 budgets and inherited scored state, freeze the selected complete grid through the normal frozen-record construction before final randomness, and continue with the prescribed final run and LS0. Retain the failure/fallback metadata; make no further calibration attempts and do not promote a partial failed grid to a fallback. Leave other branches unchanged.

\emph{Allocation.} With $q(p)=p+p^2/4$, $W_G:=\bar{W}+C\,K\,q(p)\,[n^3+p(n+2)]$ and $M_G:=\bar{M}+C\,K(K+1)$ ($\bar{W},\bar{M}$ the work and memory envelopes of C-DLV Lemma R, $C$ a large enough implementation-dependent constant, raw dimension in the envelopes), choose
\[
\mathrm{mem}_n\ge\max\{\beta M_G(n,p_{\rm raw})+\beta_0,P_0,P_1\},\quad \mathrm{time}_n\ge\max\{2[\tau W_G(n,p_{\rm raw})+\tau_0],\bar{P}_t\},
\]
\texttt{allocation\$mem\_gb} $\ge\mathrm{mem}_n/2^{30}$, \texttt{allocation\$hours} $\ge\mathrm{time}_n/3600$, where $P_0,P_1,\bar{P}_t$ are Corollary R's preflight bounds and certificate budgets remain included.

Then for every admissible $n\ge3$, $\PP(\text{no output})=0$. On LH exact Gram, LH-iid and the W1-GEN class, under the respective statistical hypotheses and inherited dependency qualifications used in Corollary~\ref{cor:Dprime}, $\PP(\Shat=S_0)\to1$ under the original unconditioned data law. CAL, restricted-ESS success, and any bound on the probability of triggering the fallback are unnecessary. With the original LS0 cap $a_n=\ell_n$, the original Lemma R envelopes suffice.
\end{proposition}

\subsection{Extension to the GROW class (A2, checked by A3)}
\begin{proposition}[F on the GROW class; A2 with A3's amendments]\label{prop:FG}
Under exactly the method, fallback, premises and allocation of Proposition~\ref{prop:F} (cap $a_n=\ell_n+|\tilde S_0|$, i.e.\ MR1 (C-GROW)), add to its classes: (i) fixed designs under GROW's G, (H0), (G1)--(G4), including exact-Gram AR(1) under all the hypotheses of (C5)(a); (ii) iid-row AR(1) under all the hypotheses of (C5)(c), including independent Gaussian noise and the separation condition (the iid instance uses its joint-law event theorem, not fixed-design NEG or (G4-dir)) \srcq{W1C/HQ_AUDIT/A2_propF_GROW.md:25}{Add to Proposition F's classes}. CAL, candidate restricted-ESS success and a bound on the fallback probability are unnecessary.
\end{proposition}

\begin{remark}[what Propositions F and F-GROW do and do not say]
(1) The fallback changes the calibration law only on the event where the shipped code returns no estimates; final-run validity holds conditionally on any frozen grid (calibration contract). The fallback grid keeps the contract's $T_e$ cap but need not have the candidate grid's restricted-ESS property. (2) Implementation precision (A1): the shipped code sets \texttt{out\$grid=NULL} on \emph{any} grid failure, so changing only the status line would fail validation; the patch must carry a complete grid through the tier return and the normal freeze, and must not use a failed construction's partial prefix \srcq{W1C/HQ_AUDIT/A1_propF_redteam.md:43}{out\$grid=NULL}. (3) It is a theorem about an abstract unit-cost, unbounded-word machine with MACH's allocation-success and environment clauses; it is \emph{not} a reliability statement about the shipped binary or the default 8~GiB / 24~h allocation. The exclusion of every other no-output path is relative to the P1 exit inventory and Lemma S.3, both \st{AUDITED (code reading)} on the serial shipped call graph; the LS0, worker and fallback paths are covered by premises, not by that audit \srcq{W1C/HQ_AUDIT/A1_propF_redteam.md:33}{LS0, workers, merge, certificates, return allocation}. (4) The classes are LH, LH-iid, the GEN class (Proposition~\ref{prop:F}) and the GROW class including iid AR(1) (Proposition~\ref{prop:FG}); not the C-MIS candidate-rerun setting, random-row S5 or factor designs with growing $p$. (5) Implementation: C-ENG implements exactly this fallback (last successful tier-1 construction, else the completed tier-1 pilot; frozen through the ordinary \texttt{v3\_frozen}; flag \texttt{grid\_fallback} only when it fires), reviewed APPROVE, on the unmerged branch \srcq{BR/Theory_work/Wave1C/C-ENG/REPORT.md:54}{last successful tier-1 construction}; the branch's preflight formula does not include the MR1 (C-GROW) LS0 term, so the amended allocation must be declared by the user \srcq{BR/Theory_work/Wave1C/C-ENG/REPORT.md:62-64}{Not counted}. The writer has not audited the branch code against the proposition beyond the C-ENG report and the LS0 lines cited in §\ref{sec:cap}.
\end{remark}
