\textbf{What this is.} The single starting point for the SMC-BVS theory loop: the method as specified and implemented (\S\ref{sec:method}), every empirical result (\S\ref{sec:empirics}), the approved paper-1 theorem targets with exact statements and per-clause status (\S\ref{sec:theory}), the work done and the routes that failed (\S\ref{sec:history}), and what is open (\S\ref{sec:open}). It consolidates the archive of the theory campaign thread ``New BVS Headquarters'' (2026-11-02 to 04), abbreviated \texttt{NBH/} = \path{Theory_work/Old_Projects/New_BVS_Headquarters/}, and the repository results. All citations refer to repo commit \texttt{\sourcecommit}.

\textbf{Where things stand (one paragraph each).}
\begin{itemize}
\item \textbf{Goal.} Objectives in order: (1) accuracy in recovering the true posterior, (2) parallel scalability over particles and islands (not over variables), (3) BVS selection accuracy; target venue Biometrika with Lean certificates for key results (\S\ref{sec:problem}). Thesis: ``In split-and-merge, correlation breaks correctness. In local-to-global SMC, correlation costs only sequential depth and particles, never correctness'' \pos{1044}.
\item \textbf{Method.} SMC-BVS v3.1 = the v3 study method unchanged as a statistical method (g-prior with $g=n$, BB$(1,p)$ size prior, cap $K=\min(p,\lfloor n/2\rfloor)$, correlation-clustered exact block start $\pi_0$, tempering bridge, islands, unbiased $\hat Z$, HPM = best model ever scored) plus a parallel island layer, optional stacking, LS0, the $\hat Z$-weighted PIP, a general-$h$ accumulator, a certificate card and NA outputs \src{NBH/START_HERE.md:16-25}. Not every v3.1 component is in the frozen production code; see the divergence boxes in \S\ref{sec:method}.
\item \textbf{Empirics.} At $n=200$: low $p\in\{20,30\}$ (exact posterior by enumeration) and high $p\in\{500,1000\}$ (2,400 fits; 1,829 exact recoveries, 565 posterior misses, 0 search misses, 6 stopped runs) \src{NBH/START_HERE.md:54}, \src{Docs/HQ/STATUS.md:23-66}. Read \S\ref{sec:empirics} for what ``0 search misses'' does and does not identify.
\item \textbf{Theory.} The paper-1 list (main cards M1--M8 = \rid{TH01}--\rid{TH08}; supplement cards \rid{TH09}--\rid{TH20}) is \approvedFB{} as the current targets. Approval does \emph{not} change proof status: most clauses are candidate proofs (``PROVED (candidate)'', ``PROVED (by this seat, unchecked)'', ``PROOF SKETCH''), checked per clause by the same model family (SF), a different family (XF) or Lean; nothing is adopted as final \src{NBH/START_HERE.md:42-45}; the approval is recorded in \path{sources/approval_2026-11-07.md}. Lean: the library has 101 declarations with 0 \texttt{sorry} \src{NBH/branch_snapshots/L-LEAN/STATUS.md:3}, formalising abstract finite cores (T21 inequality, T07, T11(iii), Theorem A; T12 core only partially, with \texttt{hstep} an explicit hypothesis); \textbf{no main card is Lean-certified as a whole} \src{NBH/03_results_and_conclusions.md:22}. External human review of the proofs has not happened; all checks are AI-based (two model families plus Lean for finite cores) \src{NBH/03_results_and_conclusions.md:340}.
\item \textbf{Main open edges.} p $\gg$ n versions (candidate repair API-PXNGAP, not cross-checked); N1 for general $h$ (binding proposal §13.1); §5.3 constants only useful for $\varepsilon\lesssim n^{-1/2}/p$; the Song--Liang separation is not proved (numerical only); asymptotic onsets near $n\approx2\cdot10^6$ versus the study's $n=200$ \src{NBH/START_HERE.md:46-51}; the sampler-level results about the true model are stated only on explicit design families (M1(i) on families with $\mathrm{osc}\,d\le D_*=O_P(1)$, under the T03♯ hypotheses and stacking $R'_n$, exhibited on W; M4(f) and M5(b1-LH) on LH, as joint statements with the output event, with no delivery claim; LH-iid only in an unreviewed candidate), and the exact-posterior result T03♯ needs fixed-design hypotheses; none covers the study's own generator (\S\ref{sec:theory}, \S\ref{sec:open}).
\end{itemize}

\textbf{Rules for agents of the loop.}
\begin{enumerate}[label=R\arabic*.]
\item Never upgrade a status. Copy status words verbatim; a result becomes stronger only through a recorded proof plus the check level the acceptance criteria demand (\S\ref{sec:open}).
\item Every claim you add cites a source (\verb|\src{path:line}| or \verb|\pos{N}|) or a new file you created; new mathematics goes in a new file with its own proof and status (``PROVED (candidate)'' until checked).
\item Respect Felipe's ground rules GR1--GR8 (\S\ref{sec:problem:rules}); losing a binding goal (§5.3 weight stability, §13.1 general-$h$ accuracy) without an approved replacement is escalated to Felipe, never silently dropped.
\item Before attacking a problem, read its history (\S\ref{sec:history}, the ``do not retry'' table) and its obligations (\S\ref{sec:oblig}); many natural routes are already refuted.
\item Keep the regime of every result explicit: any $X$ / fixed design under T03$\sharp$ hypotheses / LH / W / LH-iid / study design; asymptotic vs finite-$n$; ``jointly with output''.
\end{enumerate}
