\subsection{Infrastructure rules for the new loop}\label{sec:open:infra}

\begin{enumerate}[leftmargin=1.5em]

\item \textbf{64K output-token failure rule.} ``tell agents to write long proofs in several files/commits, never one giant response''.
\item \textbf{Thread launches} must use a branch that exists where the thread starts.
\item \textbf{Briefs.} ``N/3''-type headlines may overclaim; wait-for-run agents exit early; stale branch heads can mislead reviews.
\item \textbf{Authority.} HQ has full authority for method and theorem decisions \pos{1061} but never adopts or locks results; the burden of proof is on any method change (``investment rule''); Felipe's preference ``use CW instead of CP''.
