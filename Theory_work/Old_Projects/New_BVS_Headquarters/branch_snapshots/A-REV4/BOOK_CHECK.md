## Other precise qualifications/errors

**GAP B3 — fix the probability convention for evidence expectations.** Section 0.1 places random data in the probability space, whereas section 1(e2) and REPORT Proposition 2(e) pull `Z` out of an unconditional expectation: `E[1_O Zhat] <= Z P(A)`. This is a fixed-data formula only. With joint data/algorithm probability the correct formula is `E[1_O Zhat] <= E[1_A Z(data)]`; alternatively condition every term on data. A deterministic exact evidence taking values 1 and 2 on two equally likely data outcomes with `A=O=whole space` has left side 3/2, so it cannot be bounded pointwise by the random right side `Z(data)` on the outcome with Z=1. Markov event bounds survive joint integration because they compare to each data set's own Z. State the fixed-data convention for all Proposition 2 expectations, then use a separate joint convention in the HPM/statistical statements.

**GAP B4 — exact-branch extension.** PROOF section 1 is explicitly on the SMC branch, but its final Remark 3 says (a)-(e) hold trivially on the exact branch. There is no successful SMC calibration event A there. Either set `A=whole space` by an explicit branchwise convention, or state the exact-branch consequence separately (`Zhat=Z` on available exact outputs). In particular the unchanged `Z P(A)` expectation formula is not meaningful with an undefined A, and is false if absence of successful SMC calibration is interpreted as `A=false`.

**ERROR B5 — wrong HPM does not logically imply posterior miss.** REPORT Proposition 1's data paragraph says “Every completed wrong HPM is a posterior miss (F(S0) <= F(HPM)).” PROOF section 3 similarly begins its study corollary “A completed fit is a posterior miss.” A finite scored set omitting S0 can return a lower-scoring wrong HPM although S0 is the unique global maximum; e.g. scores `F(S0)=1`, `F(S1)=0` with scored set `{S1}`. The correct logical claim is that a *strict same-size posterior miss, once established by audit scores*, certifies the size-prior ceiling. If zero search misses is an inspected empirical fact for the particular completed campaign fits, label the statement as that empirical observation and cite its audit source. It is not a consequence of completion or of T07. The sharp size-prior construction itself and its strict same-size certificate are sound.
