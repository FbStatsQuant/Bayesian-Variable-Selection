## Strategy in play

Reduce to the Gaussian sequence model: u_j/sigma_star^2 = (sqrt(lambda) + zeta_j)^2 on S0, zeta_j^2 off S0, zeta_j iid N(0,1), independent of the residual chi^2_{n-p}.
Known variance: the posterior score is additive over coordinates: score(S) = log w(|S|) - (|S|/2) log D + (h/2 sigma^2) sum_{j in S} u_j.
- Necessary: HPM = S0 implies h u_j/sigma^2 > tau_{s0} for all j in S0, where tau_k = log D + 2 log((2p-k)/k) is the penalty of the k-th inclusion; and h u_j/sigma^2 < tau_{s0+1} for all j off S0.
- Sufficient: (A) h u_j/sigma^2 > tau_1 = log D + 2 log(2p-1) for all j in S0 and (B) no superset S0 U T beats S0 (Chernoff + prior-ratio sum, as in T7's size-by-size count). Decomposition score(S0)-score(S) = [S0 vs S0 U T] + [S0 U T vs (S0\J) U T] >= [S0 vs S0 U T] + [S0 vs S0\J].
- Result: P0(HPM=S0) sandwiched between psi(lambda, tau_{s0}/h)^{s0} (times a superset factor) and psi(lambda, tau_1/h)^{s0}(1 - E_n), psi(lambda,t) = Phi(sqrt(lambda)-sqrt(t)) + Phi(-sqrt(lambda)-sqrt(t)). Trichotomy: sqrt(lambda_n) - sqrt(tau_n) -> +inf / -inf / c gives P -> 1 / 0 / Phi(c)^{s0}, tau_n = log D + 2 log((2p-s0)/s0) = log n + 2 log(2p/s0) + o(1).
Minimax: Bayes rule under a uniform prior over supports with known positive amplitude is the top-s0 selector; its error is a lower bound for every selector; threshold 2 log(p-s0) with the same window shape. Gap of centres = log n + 2 log 2 - 2 log s0 + o(1) (heuristic confirmed for s0 = 1, corrected by -2 log s0 in general).
Integrated variance: deletion tests use nu log(1 + h U_J/A), A = 2 b0 + Q_{S0} = 2 b0 + sigma^2 chi^2_{n-s0} + (1-h) U_{S0}; superset part cited from proofs/T7_T8 (Prop 4.2 + Lemma 3.1, hypotheses met with phi_0 = 1, A = 1, bounded signal). Same trichotomy under s0 beta_n^2 <= M.
