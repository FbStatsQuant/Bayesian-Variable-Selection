# Addendum (writing review, 2026-10-15): T9a(iii) for every cap $k_{\max}\ge s_0$

Source: Astra team, reviewer A2 finding 4, verified by the Astra lead (`writing/astra/LEAD_REPORT.md`, D18). This addendum adds to §9 and leaves the rest of PROOF.md unchanged.

**Claim.** Under the hypotheses of §9 with the cap condition $k_{\max}\ge\min\{p,m_n+s_0\}$ replaced by $k_{\max}\ge s_0$, the conclusion still holds:
$$\Pi_{k_{\max}}(|S|>d\mid y)\to0,\qquad d=s_0+\lceil s_0(2A+1)\rceil .$$

**Proof.**
1. Let $\Pi_\infty$ be the posterior under the uncapped prior ($k_{\max}=p$). This case satisfies the §9 cap condition, so §9 gives $\Pi_\infty(|S|>d\mid y)\to0$.
2. The capped prior is the uncapped prior restricted to $\{|S|\le c\}$ and renormalised, where $c=k_{\max}$. The likelihood does not depend on the cap. Hence $\Pi_c(\cdot\mid y)=\Pi_\infty(\cdot\mid y,\ |S|\le c)$.
3. Write $F(r)=\Pi_\infty(|S|\le r\mid y)$.
   - If $c\le d$, then $\Pi_c(|S|>d\mid y)=0$.
   - If $c>d$, then $\Pi_c(|S|>d\mid y)=\{F(c)-F(d)\}/F(c)\le1-F(d)=\Pi_\infty(|S|>d\mid y)$, because $F(c)F(d)\le F(d)$.
4. Steps 1 and 3 give the claim. $s_0\le c$ ensures $S_0$ is in the support, which the master Theorem 5 (§4) needs. $\square$
