## Statement (as conjectured)
Source: theorems/T05_A4_orthogonal_threshold.md (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- Under G, R, ORTH (G = (n-1) I_p, p <= n-1; fixed 1 <= s0 < p; equal magnitudes b_n on S0; b_n^2/sigma*^2 bounded), no beta-min. Let lambda_n = (n-1) b_n^2 / sigma*^2 and tau_n = log n + 2 log((2 p_n - s0)/s0).
- (i) exact identities: D_S = n^|S|; Q_S = y'y - n^-1 sum_{j in S} z_j^2; exact addition log-odds log[(k+1)/(2p-k-1)] - (1/2) log n + nu log[(0.02+Q_S)/(0.02+Q_S - z_j^2/n)].
- (ii) threshold: if sqrt(lambda_n) - sqrt(tau_n) -> c in [-inf, inf], then P0(S-dagger = S0) -> Phi(c)^s0.
- (iii) gap: if p_n - s0 -> infinity, signal sequences with sqrt(lambda_n) - sqrt(2 log(p_n - s0)) -> infinity and sqrt(tau_n) - sqrt(lambda_n) -> infinity are recovered by the known-size known-noise selector with probability -> 1 while the v3 global HPM fails with probability -> 1; such sequences exist since tau_n - 2 log(p_n - s0) = log n + 2 log(2/s0) + o(1). No minimax theorem is adopted.
