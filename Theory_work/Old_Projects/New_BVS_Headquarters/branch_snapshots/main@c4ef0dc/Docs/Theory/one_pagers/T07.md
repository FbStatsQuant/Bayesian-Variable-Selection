# T07 — Size-only ranking ceiling and Bayes decisions (old label A6 = T5-C)
Status: PROVED-LOCKED (all parts, wave 3); not adopted (adoption is Felipe's decision)  | Rank: core (proposition) | Paper role: JRSS-B Prop 1 (HPM is the Bayes rule for exact recovery; a size-only prior cannot fix a same-size swap); Biometrika: remark

## Statement (as proved)
Source: proofs/T06_T07_identifiability_size_prior/STATEMENT.md section 2 (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- (i) Ceiling: for every response and every positive size-only prior w~, {S-dagger_w~ = S0} is contained in {S*_{s0} = S0}, where S*_k is the least element of argmax over |S| = k of m(S). So on a within-size ranking error no positive size-only prior yields S0.
- (ii) Bayes decisions: (a) 0-1 loss on supports: posterior risk 1 - pi(a); the minimisers are exactly argmax F, and S-dagger is one. (b) Hamming loss: MPM = {j : PIP_j > 1/2} minimises the risk over all subsets (unique iff no PIP_j = 1/2). (c) Capped: the top-l PIPs inside {PIP_j > 1/2}, l = min(K, N+), minimise Hamming risk over Omega.
- (iii) Target vs reported: (a) S-hat = S-dagger iff S-dagger is in the scored set; S-hat minimises posterior 0-1 loss iff the scored set meets argmax F. (b) {S-hat = S0} and {S*_{s0} != S0} implies S*_{s0} is not scored. (c) For any PIP estimate p-hat, 0 <= risk_H(a-hat) - risk_H(a_opt) <= 2 sum_{j in a-hat symmetric-difference a_opt} |p-hat_j - PIP_j| <= 2 ||p-hat - PIP||_1; MPM-hat = MPM iff p-hat_j > 1/2 <=> PIP_j > 1/2 for all j.
- The control of scoring and estimation events is not part of this result (it is the subject of T21, T23, T26).

## Assumptions / hypotheses
- Positive marginal likelihood m; a fixed total tie order; no statistical assumption for (i)-(iii)(c).
