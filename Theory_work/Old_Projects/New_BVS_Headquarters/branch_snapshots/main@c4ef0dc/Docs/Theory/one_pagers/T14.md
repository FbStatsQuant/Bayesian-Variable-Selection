# T14 — First-moment evidence consistency (old label L-FM)
Status: PARTLY PROVED: (i) PROVED-LOCKED (singleton case, wave 1); (ii), (iii) not locked (CONJECTURED); not adopted (adoption is Felipe's decision)  | Rank: core (lemma; (iii) general set conditional) | Paper role: Supplement lemma

## Statement (as proved)
Source: proofs/T14_LFM_first_moment_evidence/STATEMENT.md; theorems/T14_LFM_first_moment_evidence.md (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- PROVED-LOCKED, (i) singleton case: for a model S* fixed given the calibration C, with eta_t = 1 - q_t(S0), eps_* = max eta_t < 1: Z-hat_r / Z = A_T / b_T exactly (b_t = q_0(S*)/q_t(S*)), and E|Z-hat_r/Z - 1| <= [sum_{t=1}^T (b_{t-1} eta_{t-1} + b_t eta_t) + |1 - b_T|] / b_T <= (2/(1 - eps_*)) sum_{t=0}^T eta_t. The endpoint term |1 - b_T| is essential; convexity gives the same bound for the pooled Z-hat.
- CONJECTURED (not locked): (ii) along launched families sum eta_t -> 0 implies Z-hat/Z -> 1; (iii) general-set bound E|Z-hat_r/Z - 1| <= [2 sum eps_t + sum Phi_t]/(1 - max eps_t), with Phi_t not necessarily vanishing.
