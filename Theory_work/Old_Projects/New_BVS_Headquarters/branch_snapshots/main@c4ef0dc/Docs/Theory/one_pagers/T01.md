## Statement (as proved)
Source: proofs/T01_T02_contrast_dimension/STATEMENT.md section 2 (T01); theorems/T01_A0_contrast_reduction.md (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- (i) Identity (every valid input, deterministic): the v3 joint posterior of (S, theta_S, v) = (S, s_y beta_S, s_y^2 sigma^2) equals the contrast-model posterior at inverse-gamma rate b = b0 s_y^2, and m(S) = c_n(s_y) m^c_{b0 s_y^2}(S) with c_n(s) = s^(n-1) Gamma(0.51)/(sqrt(2 pi b0) Gamma(0.01)). Hence BF(S), pi(S) and Z are the contrast-model quantities at that rate; z^c_S = s_y z_S and Q^c_S = s_y^2 Q_S; and v | S, y ~ IG(nu, b0 s_y^2 + Q^c_S/2), theta_S | v, S, y ~ N_k(n H_S^-1 z^c_S, n v H_S^-1).
- (ii) Envelope (deterministic): for 0 < b1 <= b <= b2 and kappa12 = (b2/b1)^0.51, kappa12^-1 m^c_{b2}(S) <= m^c_b(S) <= kappa12 m^c_{b1}(S) for every S and every y_c; for every event E, kappa12^-1 I_{b2}(E) <= I_b(E) <= kappa12 I_{b1}(E), so Pi_b(E) <= kappa12^2 I_{b1}(E)/Z^c_{b2}.
- (iii) Scale event, under G and R: s_y^2 - (sigma*^2 + ||mu||^2/(n-1)) = O_P(n^-1/2), P0(B_n) -> 1 for B_n = {sigma*^2/2 <= s_y^2 <= 2(sigma*^2+M)+1}; and eps_c = U^T eps ~ N_{n-1}(0, sigma*^2 I) exactly, y_c = X_c theta* + eps_c.
- (iv) Rate derivative: d/db log[m^c_b(S)/m^c_b(S')] = 2 nu (Q^c_S - Q^c_S') / ((2b + Q^c_S)(2b + Q^c_S')).
- (T) Transfer rule. (a) Mixed-endpoint transfer: on B_n, Pi(E | y) <= kappa^2 I_{b-}(E)/Z^c_{b+}, with b- = b0 sigma*^2/2, b+ = b0(2(sigma*^2+M)+1), kappa = (b+/b-)^0.51; so a bound I_{b-}(E_n)/Z^c_{b+} <= eps_n transfers at cost kappa^2. (b) Same-rate bounds do not transfer: a worst case over inputs (b1: no data-free implication between bounds at two distinct fixed rates; b2: witnesses inside B_n where a same-rate bound at b- or b+ does not bound the v3 posterior by any constant).

## Assumptions / hypotheses
- (i), (ii), (iv): none beyond a valid input (n >= 3, no constant column, non-constant y).
- (iii) and (T): G (fixed design, Gaussian errors) and R (s0 fixed, p <= n^A, ||mu||^2/n <= M, lambda_min(R_S0) >= phi0^2, s0 <= K eventually). No SE, no beta-min, no H-xx. EX-A for exact arithmetic.
