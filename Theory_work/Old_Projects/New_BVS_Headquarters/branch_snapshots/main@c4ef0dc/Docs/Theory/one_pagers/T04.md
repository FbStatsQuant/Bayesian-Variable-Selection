## Statement (as proved)
Source: proofs/T04_A3_contraction/STATEMENT.md section 3 (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- There is a constant C depending only on (sigma*^2, M, phi0, A) such that, in R1 under G, R and H-T02 ('-> 0' means in P0-probability), with l_n = log(p v n), eps_2^2 = (s0+1) l_n^2 / n, eps_1^2 = (s0+1) l_n / n, d* = s0 + ceil(s0 (2A+1)):
- (i) fallback (secondary): Pi-dagger(||X theta - mu||^2/n > C eps_2^2 | y) -> 0.
- (ii) under SE in addition: Pi(|S| > d* | y) -> 0; Pi-dagger(||X theta - mu||^2/n > C eps_1^2 | y) -> 0; Pi-dagger(||theta - theta*||^2 > C eps_1^2/phi0^2 | y) -> 0.
- (iii) for every deterministic u_n -> infinity: Pi-dagger(|v/sigma*^2 - 1| > C[eps_n^2 + u_n/sqrt(n)] | y) -> 0, with eps_n = eps_2,n under G, R and eps_1,n under SE in addition.
- (iv) under SE and DX: Pi-dagger(||D_x^-1 (theta - theta*)||^2 > C eps_1^2/(phi0^2 d-^2) | y) -> 0.
- Not claimed: beta-min; out-of-sample, intercept-posterior or random-design Hellinger results.
