# W1-T37R: Restate T37 (truth dominance and greedy repair) so it is true

**Paper role:** Thm 3 (repair), primary route. Feeds T38(b1).

## Problem
T37 (`Docs/Theory/PAPER_SELECTION_20261028/new_conjectures/T37_truth_dominance_greedy_repair.md`) assumes TD(d, m): at every near-truth state missing a true variable, *adding* a missing true variable beats every other move. The preliminary p ≫ n audit (`Docs/THEORY_PRIORITIES.md` §5) and decision D18 found that the **literal TD fails generically**: TD held strictly in 0 of 95 sampled d = 0 cases, because a *swap* that brings in a missing truth (and removes something) is often a better move than the plain addition. The "toward S₀" variant did not separate from the literal one in that partial audit. In the same data, the final local search never repaired a fit (0 repairs; 541 fits had a centre in 𝓡₂ \ {S₀}), and the HPM was delivered by Gibbs flips.

## Goals, in order
1. **Diagnose.** Give an exact characterisation of why literal TD fails: which move beats the missing-truth addition, at which states, and with what score gap (express it with T01 contrast coordinates and residual projections). Confirm this by exact computation on small designs (p ≤ 20) that mimic the study scenarios S1–S6. The generators are in `Scripts/Data_generators/` and the R scenario code they source; you cannot run R, so reimplement the design in Python.
2. **Restate.** Propose the *weakest* condition, call it TD′, under which greedy best-improvement local search started from any S ∈ 𝓡_d reaches S₀ and certifies it. Candidates:
   - a progress or potential condition: every best move strictly decreases a potential, for example |S Δ S₀| or a lexicographic (missing truths, extras) potential, with truth-bringing swaps counted as progress;
   - a path-wise condition along the greedy path only, which avoids the 2^{s₀} union;
   - a version with an extra scan.

   State the refined T37(i) and prove it (deterministic; PROVED is expected here).
3. **Finite-n probability.** For TD′, give the analogue of T37(ii): an explicit bound on P₀(TD′ fails) in terms of non-central Gaussian or chi-square events. Aim for a dependence-aware or path-wise bound rather than a 2^{s₀} union. Then state T37(iii) (→ 0 under G, R, SE and BM-∞, with s₀ and d fixed), with proof or sketch.
4. **Check against the data.** On simulated small cases, report how often TD′ holds at n = 200-like signal (c = 1 and c = 0.5, correlated scenarios). If TD′ also fails at n = 200, say so plainly: the theorem would then be asymptotic only. Also report whether the move cap ℓ = 10 < s₀ + d matters.
5. **Assess the Gibbs route.** Say whether the right repair statement for this method is about *Gibbs flips* rather than the local search (task W1-T24G covers that route; just state your view, and keep it brief).
