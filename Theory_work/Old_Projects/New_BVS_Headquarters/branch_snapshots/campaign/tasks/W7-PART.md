# W7-PART: The partition-recovery lemma for iid designs

**Why.** The p ≫ n masked family LH-iid (`theory/W3-PXN`) and the iid version of EXP′ (`theory/W1-EXP` §1.5, `theory/W3-VEXP` repair R3) both rest on the event **"blocks = groups"**: the method's X-dependent partition (`Docs/Methodology/METHODOLOGY_v3.md`, partition algorithm; `Scripts/SMC_BVS/core/`) recovers the equicorrelated groups with probability → 1. W3-VEXP calls the in-sample version a GAP ("with ≥ 2 groups per block the packing depends on the noise column"); A-REV2 flags "random-design / actual-packing extensions" as GAP; `Docs/Theory/DROPPED.md` lists "the design-to-partition lemma (CHANGE_PLAN 16)" as an open research idea. The cross-family reviewer A-REV3 (`theory/A-REV3`, if pushed) may comment on it.

**Goal.** State and prove the **partition-recovery lemma**: for iid Gaussian rows with the LH / equicorrelated-group correlation (group size g, 9 ≤ g ≤ 16 ≤ B < 2g, within-group correlation ρ, cross-group correlation 0 or weak ψ with |ψ| < ρ), and p_n ≤ n^A, the actual partition algorithm applied to the sample Gram matrix returns blocks = groups with probability ≥ 1 − p^{−C}, with explicit constants in (n, p, g, ρ, ψ). Handle exactly what the algorithm does (read the code: thresholds, tie-breaking, the cap B, any dependence on y). If the algorithm uses y (the noise column), say precisely where and bound it. Give the finite-n probability at the study's (n, p) = (200, 500) and (200, 1000). If the lemma is false for the actual algorithm in some regime, give the counterexample and the smallest algorithm change that fixes it.

**Deliverable:** `theory_campaign/W7-PART/REPORT.md` with the lemma, proof, numerics (exact simulation of the partition step at small and study-size p) and the confidence card.
