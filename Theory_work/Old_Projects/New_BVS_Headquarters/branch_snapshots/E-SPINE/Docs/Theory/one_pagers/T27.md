## Statement (as proved)
Source: proofs/T27i_T20C_cancellation_budget/STATEMENT.md; theorems/T27_T20C_cancellation_budget.md (repo paths under `Docs/Theory/`). Faithful condensation; the source file is authoritative.
- PROVED-LOCKED, (i) start-mass law under cancellation (a conditional implication): if along a chain S^(0) subset ... subset S^(c) = S0 of c feasible single additions each table ratio is n^-1/2 e^{O_P(1)} jointly (H2), and the starting model keeps normalised start mass pi0(S^(0)) >= c0 with probability -> 1 (H3), then log pi0(S0) + c log p + (c/2) log n = O_P(1), i.e. pi0(S0) = p^-c n^-c/2 exp(O_P(1)). For c = 0 the conclusion is log pi0(S0) = O_P(1).
- CONJECTURED (not locked): (ii) budget exponent beta = max(1, a) - c(a + 1/2) for p ~ n^a (iid discovery tends to certainty if beta > 0, to zero if beta < 0); (iii) scales [max(n,p) log n]^-1 and [max(n,p) log^2 n]^-1; (iv) without the two-sided law T10 gives only a lower bound.
- Must not be combined with T22(iii) on one sequence (different regimes).
