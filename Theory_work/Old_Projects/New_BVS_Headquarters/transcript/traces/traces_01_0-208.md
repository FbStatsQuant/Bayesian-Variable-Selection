**Notation**
- **Near-truth region:** 𝓡_d = {U ∪ P : U ⊆ S₀, P ⊆ S₀ᶜ, |P| ≤ d}, with s₀ + d ≤ K.
- **Gains:** g(S,l) = F(S+l) − F(S) and h(S,j) = F(S−j) − F(S).
- **TD(d,m), truth dominance with margin m:**
  - for every S ∈ 𝓡_d that is missing a true variable, some missing true j has a gain ≥ m + the gain of every other feasible move;
  - for every strict superset of S₀, some extra l has a deletion gain ≥ m + every other move;
  - at S₀, every move has gain ≤ −m.
- **Local search:** it scores every flip and swap, takes the best strict improvement for at most ℓ moves, and ends with a certifying scan.
- **Other symbols:** π₀ is the start distribution, S̃₀ the start mode, Q_f the number of iid π₀ draws scored, U the no-output event, and 𝒮 the set of scored models.

**T37 (truth dominance and greedy repair), verbatim:**
- "(i) Deterministic. Assume TD(d, 0) with strict inequalities. Then from any centre S ∈ 𝓡_d, the local search with ℓ ≥ |S Δ S₀| moves monotonically to S₀ in exactly |S Δ S₀| moves, scores S₀, and reports `local_certified` at S₀. The path never leaves 𝓡_d."
- "(ii) Finite n. Under G, … P₀(TD(d, m) fails) is at most the sum, over the ≤ 2^{s₀} C(p, d)(p + s₀p) distinct move comparisons, of P₀(a single score difference falls below m)." Each term is a non-central Gaussian event with non-centrality (n−1)δ²/σ*² and penalty ½log(n+1) + log[(2p−k−1)/(k+1)].
- "(iii) … ℓ_n = ⌈log₂(n+p+1)⌉ ≥ s₀ + d eventually, and G, R, SE and BM-∞ hold. Then the bound in (ii) → 0." Clause (i) then replaces GAIN_d, LK_d and EXIT_d.

**T38 (two-regime HPM consistency, the main theorem):**
- It starts from T21: P(no output or Ŝ ≠ S₀) ≤ P(U) + 2E₀[1−π(S₀)] + P(Uᶜ, S₀ ∉ 𝒮).
- **(a) Favourable regime:** under EXP′, VIS and NL, Q_f·π₀(S₀) → ∞, so the iid draws score S₀ (T11(iii)).
- **(b) Masked regime:** "π₀(S₀) may vanish as in T27, but the start puts mass π₀(𝓡_d) ≥ b_n on the near-truth region" (T22(i), with a reference S° ∈ 𝓡_d that need not be S₀). Then one of two routes:
  - **(b1)** TD(d,0) holds with probability → 1, and some local-search centre lies in 𝓡_d: either the best-scored model before the final search, or S̃₀ with the LS0 tweak.
  - **(b2)** T24's conditions hold, with a particle in 𝓡_d at the terminal rounds.
- **(c) Cost:** O(N_n T_n (p+B+2) + ℓ_n p) score evaluations.
- **Conclusion:** "Hence P(Ŝ = S₀) → 1 − limsup P(U)."
- **Not claimed:** masked-regime evidence or PIP accuracy, results for fits selected for having completed, and superiority over other methods.

**T39 (contingency, a method change):**
- M scoring-only tracks, each starting from an exact π₀ draw and running h rounds at φ = 1. Their scores feed only the HPM.
- On a data event G_n with π₀(𝓡_d) ≥ b_n, inf K₁(x,S₀) ≥ a_n and exit ≤ η_n, define s_n = 1−(1−a_n)^h − hη_n. Then "P(S₀ never scored) ≤ (1 − b_n s_n)^M ≤ e^{−M b_n s_n}".
- Choosing h = ⌈log 4/a_n⌉ and M = ⌈2b_n⁻¹ log(1/ε_n)⌉ gives a miss probability ≤ ε_n.
- The cost is O(p n^{r+s}) if b_n ≥ n^{−r} and a_n ≥ n^{−s}.

**Masked regime.** This is T27's regime: true variables cancel along an addition chain, so π₀(S₀) = p^{−c} n^{−c/2} e^{O_P(1)}. The start alone cannot find the truth, which is why the sampler is needed.
