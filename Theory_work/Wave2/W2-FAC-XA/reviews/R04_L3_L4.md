## 1. L3 — line-by-line check

### 1.1 Setup and identity
c = s + κ > 1, q_t = m + c, m = p − t (p = initial nulls), x_t = (B + Σ_{K_t} ξ)/q_t. Matches the FAC-B
centre x_T = (Σ_{j∈T} ξ_j − ϱ_n)/(k + κ_n) with B = Σ_{truths} ξ − ϱ_n, k = m + s0, provided ϱ_n is
k-free (it is, FAC-B §3) and the truths stay retained. Since s0 ≥ 1 and κ_n > 0, c > 1. Identity
x_{t+1} = x_t − (ξ_j − x_t)/(q_t − 1): checked (q_t x_t − ξ_j = (q_t − 1) x_{t+1}).

### 1.2 Shadow and (2)
δ_t = v_t − ξ_j with v_t moved straight toward h_t to distance d_other (or δ = 0 if j is already nearest
to h_t). If δ ≠ 0: |δ| = |ξ_j − h_t| − d_other; |ξ_j − h_t| ≤ d_act + ε + |e_t|; d_other ≥ d_act − |e_t|.
So |δ_t| ≤ ε + 2|e_t|. **Correct.** Moving toward h_t never crosses h_t (d_other ≥ 0). Correct.

Stronger claim. The sentence "If δ_t increases |e_t| … such a delta is negative" is imprecise: with e ≥ 0,
δ ∈ [0, e) also increases e. What the proof actually uses, and what is true, is the case split:
e ≥ 0 and δ < 0 ⇒ ξ_j > h_t ≥ x_t ⇒ |ξ_j − h_t| = |ξ_j − x_t| − e and d_other ≥ d_act − e ⇒ |δ| ≤ ε.
**Correct as a case split**; wording must be fixed (F3-3).

### 1.3 Update and (3)
e_{t+1} = (q_t e_t − δ_t)/(q_t − 1): checked. Case e ≥ 0, δ ≥ 0: q e − δ ∈ [(q−2)e − ε, q e] ⊂ [−ε, q e]
(uses q ≥ 2). Case e ≥ 0, δ < 0: q e − δ ∈ [q e, q e + ε]. So q_{t+1}|e_{t+1}| ≤ q_t|e_t| + ε and
q_t|e_t| ≤ tε. **Correct.** q_t > 2 always (m ≥ 1, c > 1).

Observation (recommended addition, not a fix): q_{t+1}e_{t+1} = q_t e_t − δ_t telescopes to the exact
identity **q_t e_t = −Σ_{r<t} δ_r**, i.e. h_t is the actual centre with offset B replaced by B − Σ_{r<t}δ_r.
Verified to relative 1e−7 on every step of 612 adversarial paths (≈ 250,000 steps; R04_l3_adversary.py). This makes (3)
transparent, permits step-dependent tolerances (q_t|e_t| ≤ Σ_{r<t} ε_r), and isolates the loss: the bound
is lost exactly when the clipping displacements δ_r keep one sign.

### 1.4 Shadow-interval certificate
Induction: v_t ∈ [a_t, b_t] (it is at distance ≤ d_other from h_t on j's side, and the nearest retained
point on that side is at distance ≥ d_other — whether it is j or another point). Drift |v_t − h_t|/(q_t − 1)
is strictly smaller than |v_t − h_t| ≤ distance to every other retained point (q_t > 2), and the drift is away
from v_t, so h_{t+1} crosses no point of K_{t+1}; the K_{t+1}-gap containing h_{t+1} therefore contains
[a_t, b_t] ∋ all previous v_r and v_t. **Correct**, including one-sided (infinite) gaps. Degenerate ties
(h_t equal to a retained coordinate) can occur only at t = 0 on a null set or with d_other = 0 (then drift 0);
closed containment handles both, as the file says.

Consequence: retained ⊂ complement of (a, b); each deleted ξ_{j_r} is within |δ_r| ≤ E_t of [a, b]. So
K_t = {ξ ≤ a or ξ ≥ b} up to deleted points lying in the **one-sided outer** bands [a − E_t, a) ∪ (b, b + E_t].
**Correct.**

### 1.5 Bound (1)
E_t ≤ ε + 2 max_{r<t} rε/q_r = ε[1 + 2(t−1)/q_{t−1}], and with m = p − t, (t−1)/q_{t−1} = (p−m−1)/(m+1+c).
**(1) is correct**, for t ≥ 1. Monotone in p, so ambient p is an upper bound. Independently checked on
all steps of adversarial paths (R04_l3_adversary.py: p ∈ {50, 200, 800}, ε ∈ {0.01, 0.1},
c ∈ {1.05, 1.5, 4}, policies random/right/left/far/shadow-push/greedy-width (greedy only p ≤ 200), 6 seeds;
assertions for (2), (3), the strong case and (1) passed on every step; the certificate and band containment
were asserted on every step for p ≤ 200).

### 1.6 What the sampled numerics say about (1) (new evidence; falsification only)
- The **actual** minimal one-sided two-tail width (min over representations "retained outside (a,b),
  deleted within w of [a,b]"), evaluated at about 30 checkpoints per path (every p/20 steps and all m ≤ 10),
  never exceeded 0.99998ε on any sampled path up to p = 800, including the
  greedy width-maximising policy at p ≤ 200 (R04_l3_adversary_out.json).
- The **shadow** band E_t does grow: final E/ε up to 49.5 at p = 800 (one-sided policies "left"/"right"),
  16.5 at p = 200, 4.6 at p = 50. The trace (R04_l3_shadow_growth_out.json, p = 800, ε = .1, c = 1.05) shows
  shadow drift |h − x|/ε ≈ 0.33, 0.69, 1.1, 1.6, 2.6, 3.8 at m = 400, 200, 100, 50, 20, 10 — roughly
  linear in log(p/m) on these paths, far below (1) (bound 3.0, 6.9, 14.7, 29.8, 71.7, 132) — while the actual
  width stays ≤ ε.
- Reading: on these sampled paths the polynomial factor in (1) is not realised by the shadow, and the shadow
  band itself is a construction artifact relative to the actual retained-set geometry. This supports the
  file's caveat that the loss "might be entirely a proof artifact", and adds that **the shadow construction
  itself (not only its worst-case estimate) produces bands larger than the actual geometry**: any O(ε log p)
  proof must either control sign persistence of δ_r or bypass the shadow. Not a proof of anything; no
  adversary is exhaustive at large p.

### 1.7 §3 crossing
u ≤ (u + ε)/(q − 1) ⇒ u ≤ ε/(q − 2); displacement ≤ (u + ε)/(q − 1) ≤ ε/(q − 2). **Correct.** The worked
example (x = 0, x′ = −3/5, z = −1/2) is valid (exact: excess 1 = ε, crossing occurs) but is **not extremal**
(u = 1/2 < 2/3, displacement 3/5 < 2/3). The extremal case is a tie: c = 3/2, m = 2, ε = 1, z = −2/3,
y = 5/3, B = −1 gives x = 0, x′ = −2/3 = z exactly (R04_l3_checks_out.json). So "sharp" holds only as a
supremum attained at a tie. The paragraph's own caveats (no bound on between-crossing drift, boundary identity
can jump) are accurate.

### 1.8 §4 counterexample — exactness and scope
Rerun with Fractions: excesses [12/25, 1/25, 417/950, 202/425, 33/100, 12/25, 477/1100], all < 1/2;
survivors {−89/50, −1/20, 38/25}; deleted hull [−.78, .67]; survivor −.05 depth 18/25 = .72 > ε = .5.
**Verified.** Homogeneity (scale ξ and ε, B = 0) and openness of strict inequalities: correct, so the pattern
survives small perturbations and arbitrarily small ε; correctly *not* claimed as a high-probability event.

Scope issue. The file says a D-K-D pattern gives only a width lower bound of half the depth "for arbitrary
two-tail thresholds", hence the example does not refute width ε. That is true for **symmetric** bands, but
(1) bounds the **one-sided outer** band of the certificate (retained outside the open gap; deleted within w
outside [a, b]). For that form every representation of the witness needs w ≥ 18/25 = 1.44ε (exact:
R04_l3_checks_out.json, "witness_min_onesided_width"). So the witness **does** refute "certificate width
≤ ε" (constant 1), while still saying nothing about Cε or O(ε log p). The file must state which width (1)
controls and record this correctly. Not a counterexample to the method, to L2's conditional theorem, or to
O(ε log p) — the file's disclaimers on those points are right.

### 1.9 §5 rate accounting
Symbols H and m_e are undefined in L3; from L2 (lines 168, 183–185) H = bar H with H² ≤ 2a log n + o(log n)
and m_e = ⌈K log log n⌉. With these: ε ~ sqrt(ζ) ~ p polylog n / n^{1/4}; (1) gives
w_{m_e} ≲ ε p/m_e; m_e w_{m_e} ~ p² polylog n / n^{1/4} = o(H) = o(sqrt(log n)) iff 2a < 1/4, i.e. a < 1/8.
**Arithmetic correct** and properly labeled as a loss of the sufficient estimate, not an impossibility.
Missing: the map from a score/gain tolerance ζ to a squared-distance excess τ. FAC-B L1.3–L1.4 give the gain
as a strictly monotone function of |ξ_j − x_T| with a k-dependent scale; τ = O(ζ) needs that derivative
bounded below uniformly over the relevant k and distance range (it is order one while distances are o(sqrt n),
but this must be stated, not assumed). The reduction |ξ_j − x| ≤ d + sqrt(τ) is correct.

### 1.10 Generality
(1) is Gaussian-free and deterministic, but it lives on the **one-dimensional centre recursion**, which is
specific to exact compound symmetry (FAC-B L1). It applies to C1 only through an exact-CS reference world
(e.g. L4's A-world with Σ = CS) and does not apply to C2 (unequal loadings) or to general designs, where the
gain is not a function of one scalar distance. The file does not say this; it must (F3-2).

## 3. L4 — line-by-line check

### 3.1 Fidelity to the production score
Production (FAC-B §1, D0): F(T) = log w(|T|) + log c_n − ½[log det H_T − log det(G_T + I)] − ν log(0.02 + Q_T),
G_T = X_T'X_T, H_T = (n+1)G_T + I, Q_T = y'y − n z_T'H_T^{-1}z_T, ν = n/2 + .01, y'y = n − 1 = d,
w(k) = 1/(2C(2p−1, k)). L4 uses exactly these (g = n ⇔ (n+1)G + I; ν; .02; normalization of the response to
squared norm d). The constant log c_n is omitted from L4's display of F_M; harmless (n-only) but must be stated.

Representation. For a centered, sd-standardized X of rank p (‖x_j‖² = d) and Y = Xθ + Cε, any B with
B'B = R = X'X/d defines U = X B^{-1}/sqrt(d) with U'U = I_p and range(U) ⊂ range(C); then
X'Y = sqrt(d)B'(sqrt(d)Bθ + σz), Y'Y = ‖sqrt(d)Bθ + σz‖² + σ²r, with z = U'Cε/σ ~ N(0, I_p) and
r = ‖(I − UU')Cε‖²/σ² ~ χ²_{d−p} independent given X (for any X-measurable choice of B). Since F depends only
on (X'X, X'y, y'y), F_B(T) equals the production score exactly. **Confirmed numerically**: on real iid CS rows
(n = 400, p = 12; n = 2000, p = 30), 60 random T each (including ∅ and full), max |production − coordinate|
= 2.7e−12 (R04_l4_checks_out.json "fidelity"). L4 asserts the coordinates but never states or proves this
bridge (F4-1). The A-world (A'A = Σ, same z, r) is, conditional on X, exactly the exact-Gram world with
population Σ (law of z, r does not depend on X); that is how L4 should be used, and it should say so.

Coupling choice. Taking A = Σ^{1/2} and the polar choice L = (Σ^{-1/2}RΣ^{-1/2})^{1/2} (B = LA, B'B = R) gives
‖L − I‖ ≤ ‖Σ^{-1/2}RΣ^{-1/2} − I‖ (whitened deviation). Worth recording; it is the only way e enters.

### 3.2 Projection input is redundant
For V = span(A_T), span(B_T) = LV with dim equal, ‖P_{LV} − P_V‖ = max sine ≤ ‖(L−I)v‖/‖Lv‖ ≤ e/(1 − e) ≤ 4e/3
for e ≤ 1/4. So "projection difference ≤ 3e" follows from ‖L − I‖ ≤ e and need not be an input. Numerics:
projection difference / e ∈ [0.69, 0.80] (R04 scaling table). Not an error; simplify (F4-2).

### 3.3 Residual identities
T ⊇ S0 ⇒ Mθ = M_Tθ_T ∈ span(M_T): signal residual exactly 0. RSS_M = σ²[r + ‖(I − P_{M_T})z‖²]. Correct.
|RSS_B − RSS_A| = σ²|z'(P_A − P_B)z| ≤ σ²‖P_A − P_B‖‖z‖². Correct.
V_M ≥ σ²r ≥ σ²c1 n; V_M ≤ C n using ‖Mθ‖ ≤ ‖θ‖_1 (unit columns, both A and B) and ‖z‖² = o(n). Correct.
|V_B − V_A| ≤ d‖(B−A)θ‖(‖Aθ‖ + ‖Bθ‖) + 2sqrt(d)σ‖(B−A)θ‖‖z‖ ≤ C e[n + sqrt(n)‖z‖] ≤ C e n. Correct.

### 3.4 Ridge decomposition
On the SVD of X_T with eigenvalue g of G_T: n v'H^{-1}v = Σ c_i² n g_i/((n+1)g_i + 1); deficit from n/(n+1)
is n/[(n+1)((n+1)g + 1)] ≤ C/n² since g ≥ d c(1 − e)² (A: λ_min(Σ_TT) ≥ c; B: ≥ c(1−e)²). Hence
Q^raw = RSS + (V − RSS)/(n+1) + J, 0 ≤ J ≤ C V/n² ≤ C/n. **Correct.** N6 measured max J ≈ 0.0056 at n = 512.
Normalization: .02 + Q = (d/V)W with W = Q^raw + .02V/d. Correct. W ∈ [σ²c1 n, C n]. Correct.
|W_B − W_A| ≤ 3σ²e‖z‖² + Ce + C/n + Ce ≤ C[e(‖z‖² + 1) + 1/n]; ν|log W_B − log W_A| ≤ (ν/(c n))|W_B − W_A|. Correct.

### 3.5 Log-determinant
log det H − log det(G + I) = |T| log(n+1) + D, D = logdet(I + G^{-1}/(n+1)) − logdet(I + G^{-1}), each term in
[0, tr G^{-1}], so |D| ≤ tr G^{-1} ≤ |T|/(d c(1−e)²) ≤ C p/n. Correct (requires the global eigenvalue floor
for every T, as the file stresses).

### 3.6 Assembly
F_M(T) = log w + log c_n − |T| log(n+1)/2 − D_M/2 − ν log W_M − ν log(d/V_M). With C_M = −ν log(d/V_M) (T-free,
M-dependent), size/prior/c_n terms cancel for the same T and (ST) follows with C2 depending on
c, c1, C1, C, σ, ‖θ‖_1 only. Gain corollary (both endpoints ⊇ S0; factor 2): correct. Null deletions, null
additions, null-out swaps covered; truth-out moves and any set not containing S0 not covered: correct as stated.

### 3.7 Dependence and inputs
No unchecked XA lemma (L1–L3) is used; inputs (‖L − I‖ ≤ e, eigen floor, ‖z‖², r) are explicit and the
rate paragraph is explicitly conditional. **Compliant with the brief.** "For all large n" depends on the rate at
which pL_n/n → 0 and e → 0 (n0 depends on the sequence), which should be said (F4-4).

### 3.8 Scaling evidence (R04, evidence only)
CS iid rows, ρ = .5, p ∈ {10, 40, 80}, n ∈ {1e3, 1e4, 1e5}, polar coupling, 120 random T ⊇ S0 (incl. full):
e·sqrt(n/p) ∈ [0.75, 1.05] (stable), i.e. **e ≈ sqrt(p/n), not p/sqrt(n)**; ST/[e(‖z‖²+1) + p/n + 1/n] ∈
[0.055, 0.18], decreasing in p. So L4's prospective input e = O_P(p/sqrt n) is conservative. If a whitened
bound e = O_P(sqrt(p/n)) for the sd-standardized correlation matrix were proved (the STATEMENT's norm
discipline forbids assuming it; under CS κ(Σ) ~ p, so the standardization step is exactly the delicate
part), ST would be O(p^{3/2}L_n/sqrt n), i.e. a < 1/3 for the transfer step alone. Evidence, not a claim.

Truth-out diagnostic: for T ∖ {truth}, the centered discrepancy is 7–123 in absolute terms but ≤ 0.11·n e
(R04 "truthout_over_ne"). Since truth-out losses in the exact world are of order n (partial variance ≥
λ_min(Σ) ≥ c), a one-paragraph extension of L4 to truth-out sets at scale C n e (signal residual now nonzero,
relative W error O(e)) looks routine and would make L4 cover all moves out of truth-containing sets. Sketch
only; not checked.

## 5. Do these deliver general-assumption ingredients? (No upgrade to consistency.)

- **L4: yes, a genuine design-agnostic ingredient.** Inputs: global eigenvalue floor λ_min(Σ) ≥ c, a coupling
  ‖L − I‖ = e with e(pL_n) → 0, residual degrees of freedom ≍ n, bounded ‖θ‖_1. Output: uniform o(1) transfer
  of the exact production score (prior included) over the whole truth-containing lattice. No CS or factor
  identity is used, so it fits the project's "general assumptions on X" direction. Its limits: it gives no
  margin, and FAC-B gives none among null moves, so it cannot transfer the path order; it yields only an
  ε-fuzzy path (input to L2/L3), plus the S0 endpoint certification against null additions (exact-world margin
  −c log n ≫ ST).
- **L3: a deterministic, Gaussian-free geometry lemma, but CS-specific** (scalar centre recursion). Its
  polynomial loss limits even the width step to a < 1/8; occupancy, balanced fronts, straddling, entry
  majority, start mode and delivery remain unproved.
- **Not delivered:** X1 (start mode / block tables, sets not containing S0), X2 (needs L2's hypotheses, which
  L3 does not supply at a < 1/4), the ζ → τ conversion, the e-rate for the standardized correlation matrix,
  random-design transfer (uniform events A_n), X3, X4. No consistency statement is supported by L3 + L4.
  No counterexample to the method or to the target was found or claimed.
