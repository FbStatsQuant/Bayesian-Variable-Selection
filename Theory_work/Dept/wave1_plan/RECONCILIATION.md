## 7. Method and limits

- Registry: `INFRA/registry/claims.tsv` (553 claims). DEPS: each ticket’s DEPS.tsv; W3-DIST uses `sha256 | first 16`, W3-MISR-R’s `deps_hand.py` hashes the raw bytes of the line range including newlines (re-computed with `splitlines(keepends=True)` and all six S:* rows matched). I did not run any ticket’s `deps_hand.py` because it rewrites DEPS.tsv.
- Evidence rule: a review counts as checking the current file only if the sha it names (or the manifest it is bound to) equals the current LF-normalised sha, or the DEPS row’s sha = checked_sha = current. Where a record gives no sha, I say so.
- Family rule: Claude Opus 5.5 is the author’s family, so Opus line checks, PURE checks and council seats are same-family evidence; the cross-family evidence is Sol and Astra (OpenAI/codex).
- Not examined: the mathematics of any proof (this is a bookkeeping reconciliation); the contents of the Old_Projects snapshot except the byte-identity of `sources/W1-T03R/PROOF.md`; whether the T3-2 item of `PRE_LEAN_PASS/T3/CODEX_gpt-6.2-astra.md` was disposed of.
