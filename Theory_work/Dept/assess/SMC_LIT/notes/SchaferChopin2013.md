## 2. Model and prior
- Likelihood (p.3): Gaussian linear model y | beta, gamma, sigma^2, Z ~ N(Z diag[gamma] beta, sigma^2 I_m); first column of Z is a constant. Model space: ALL 2^d subsets of the d columns, no size cap, no restriction (except the optional heredity restriction below). gamma in B^d = {0,1}^d.
- Prior (p.4): beta | sigma, gamma ~ N(0, sigma^2 v^2 diag[gamma]); sigma^2 ~ Inverse-Gamma(w/2, lambda w/2); gamma ~ Uniform(B^d) (so no beta-binomial / multiplicity correction; prior size is Bin(d,1/2)). Hyper-parameters following George-McCulloch (1997), eq. (2): w = 4.0, lambda = sigma_hat^2_1 (least-squares variance in the saturated model), v^2 = 10.0/lambda. Not a g-prior, no ridge-g structure.
- Marginal posterior (p.4): log pi(gamma|y,Z) = mu - sum_i log c_ii^(gamma,v) - |gamma| log v - ((w+m)/2) log(w lambda/m + sigma_hat^2_{gamma,v}), with Cholesky Z_g'Z_g + v^-2 I = C C', up to an unknown constant mu. Closed form up to a constant; the constant (evidence) is NOT computed.
- Heredity-restricted variant (p.23, eq. (17)): d main effects and d(d+1)/2 variables, pi(gamma|Z) proportional to the indicator that interaction gamma_ij <= gamma_i gamma_j for all i,j; SMC then starts from iid draws from this prior (17) instead of uniform.
- Also noted: BIC (p.4) and LASSO (p.4-5) as related approaches; no comparison to them.

## 3. Sampler design
- Particle: a binary vector gamma in B^d. n = 1.5 x 10^4 particles in the experiments (p.24); NB p.15 says "n = 2 x 10^4 particles" (internal inconsistency between p.15 and p.24; v2 had 2 x 10^6 on p.15, a typo). Single population (no islands); parallelism only by distributing evaluations of pi inside the move step (p.24).
- Initial distribution (p.8): pi_0 = Uniform(B^d), explicitly recommended; "premature adjustment of pi_0, for example using Markov chain pilot runs, leads to faster but less robust algorithms". Any pi_0 with pi << pi_0 allowed in theory. (Heredity case: iid sample from the restricted prior, p.23.)
- Path (p.8, eq. (6)): geometric bridge pi_t proportional to pi_0^(1-rho_t) pi^(rho_t) proportional to pi(gamma)^(rho_t), rho_t from 0 to 1. Note: since pi_0 is uniform, this tempers the WHOLE (unnormalised) posterior, prior times marginal likelihood, not only the likelihood. Alternatives mentioned but not used: mixture path (1-rho)pi_0 + rho pi, and data-sequential path pi(gamma | z_1..z_floor(rho m)) (Chopin 2002) (p.8-9).
- Weights (p.9, (7)-(8)): u_t(x) = pi(x)^(alpha_t), alpha_t = rho_t - rho_{t-1}; w = u/sum u.
- Adaptive temperature rule (p.9-10): conditional ESS with equal weights before reweighting, eta(alpha,X) = (sum_k pi^alpha(x_k))^2 / (n sum_k pi^{2alpha}(x_k)) in [1/n,1]; choose alpha so that eta(alpha,X) = eta* by bisection (Proc. 2: l=0, u=1.05-rho, start alpha=0.05, tolerance eps; return alpha ^ (1-rho)); rho_t = 1 ^ (rho_{t-1}+alpha*). eta* = 0.9 in all runs ("smaller values significantly speed up ... but lead to a higher variation", p.10). Number of steps tau random and "not known in advance". Cites Jasra et al. (2008) for the rule. Remark (mine): the text says eta is "monotonously increasing in alpha" (p.9-10) but Proc. 2 and p.9 ("weights become more uneven as alpha larger") treat it as decreasing; it is decreasing (log eta = 2 psi(alpha) - psi(2 alpha) - log n with psi convex), so "increasing" is a slip.
- Resampling (p.10): systematic (Proc. 3), at EVERY iteration (since ESS is held at eta*, resampling is not triggered by a threshold).
- Move step (p.11-12, Proc. 4): independence Metropolis-Hastings kernel (ratio (5)) with proposal q_theta (parametric family refitted at every iteration to the weighted particle system (w, X)); invariant measure pi_t. It is repeated for all particles until the particle diversity zeta(X) = #distinct/n changes by < 0.02 between sweeps or exceeds 0.95. The paper states (p.11): "our numerical experiments suggest that making a Sequential Monte Carlo algorithm work with local kernels is practically impossible". No Gibbs, swap or any local move inside SMC; the local kernels of Sec 3 are used only as competitors.
- Aggregated weights discussion (p.12): they do NOT merge identical particles (weights kept per copy).
- Algorithm 2 (p.13): initialise iid Uniform; alpha <- step(0,X); w <- weights; while rho<1: fit q_theta(w,X), resample, move, find alpha, weights, rho += alpha; return sum_k w_k x_k ~ E_pi(gamma). (Ambiguity: the loop updates rho only at the end, and the move kernel is labelled kappa_{pi,q_theta}; the target index of the move in the first iteration is not explicit.)
- Parametric family (Sec 5): requirements (a)-(e) (p.13-14): at most d(d+1)/2 parameters, calibratable from a weighted sample, sequential sampling by chain rule (11), cheap pointwise evaluation, captures dependence like a multivariate normal.
  - Logistic conditionals model (p.14-15, eq. (12)): q_B(gamma) = prod_i Bernoulli(gamma_i; logistic(b_ii + sum_{j<i} b_ij gamma_j)), B lower triangular; fitted by weighted logistic regression of column i on columns 1..i-1 of the particle matrix (weights w). Component order arbitrary ("permuting the components had, in practice, no impact", p.15; no evidence shown).
  - Sparse version (p.15-16): components with weighted marginal mean outside (eps, 1-eps), eps = 0.02, are sampled independently (b_ii = logit(xbar_i), rest 0); for the others the regressor set is L_i = {j<i : |r_ij| > delta}, delta = 0.075, r_ij weighted sample correlation (13)-(14). delta=0 (saturated) gives about the same acceptance rates but much slower calibration.
  - Fitting (p.16-17): Newton-Raphson with ridge penalty eps I (separation fix), warm-started from B_{t-1} (about 4 iterations vs about 13 from zero, p.17). Proc. 6 samples gamma ~ q_B and returns q_B(gamma) in one pass.
  - Product (independent Bernoulli) family rejected (p.17-19): toy example (Fig. 1), and Boston run (Fig. 2): acceptance of the logistic kernel stays above 20%, product kernel decays to about 5%; particle diversity is held up longer by the logistic kernel. Alternatives reviewed and rejected (p.19-21): quadratic multi-linear (negative mass), quadratic exponential (no recursive marginals), Gaussian-threshold latent model (pointwise pmf infeasible), copulas, reduction models.
- Estimator of inclusion probabilities (p.13, p.25): E_pi(gamma) approximated by the final weighted particle average sum_k w_k x_k (raw particle frequencies with the last importance weights; no Rao-Blackwellisation of the Gibbs probabilities, no renormalisation over a visited-model list). Remark p.11: resampling from an augmented system "one would expect a Rao-Blackwellisation effect but its analysis is beyond the scope of this paper".
- Evidence: not estimated or reported. Only a statement (p.24): "Sequential Monte Carlo methods are more suitable than Markov chain Monte Carlo to approximate the evidence ... compare regression models with different monotonic link functions". No formula, no unbiasedness statement.
- Reported/best model, local search, certification: none. The output is only the vector of marginal inclusion probabilities.
- Experiments (p.21-31): three data sets, each with and without heredity restriction, so six problems. Largest d: 104 (Boston Housing: 13 covariates + constant + squares + all first-order interactions, n = 506). Concrete: d = 79, n = 1030. Protein activity: d = 88 (after dropping constant-zero columns), n = 96. So p is about 10^2 and p is of the order of n at most; nothing with p >> n except possibly Protein where d = 88 vs n = 96 (p/n about 0.9, still p < n). p.24 mentions in passing "variable selection problems from genetics with about a thousand covariates ... within a few hours ... 64-CPU cluster. A detailed report is going to be published as supplementary material" (no results shown in the paper).
- Competitors: standard metropolised Gibbs (Liu 1996) with k* = 2 flipped components (truncated geometric), and the adaptive MCMC of Nott and Kohn (2005) (delta = 0.01; 2.5x10^5 pre-adaptation iterations, 2.5x10^4 burn-in; adaptation every 2x10^5 iterations). Budget: fixed number of evaluations of pi, nu = 2.5 x 10^6 (SMC uses fewer). Metric: 200 independent runs per method per data set, box-plots of the 200 estimates of each PIP (white box = 80% of runs, black = extent of 20% outliers). No ground truth: "the median of the SMC runs correspond very precisely to the results we obtained by running a Markov chain Monte Carlo algorithm for a few days" (p.25). Not compared to BAS, ESS (Bottolo-Richardson) or parallel tempering (explicitly out of scope, p.5, p.21-22).
- Reported results (tables p.26-31, evaluations of pi / acceptance rate): Boston SMC 1.36e6 / 36.4% (AMCMC 2.5e6 / 29.1%, MCMC 2.5e6 / 0.81%); Boston restricted 1.15e6 / 20.8% (AMCMC 45.4%, MCMC 1.2%); Concrete 1.19e6 / 30.7% (AMCMC 70.4%, MCMC 7.2%); Concrete restricted 2.42e6 / 31.0% (61.1%, 5.31%); Protein 6.17e5 / 30.7% (60.7%, 1.2%); Protein restricted 6.19e5 / 26.65% (22.3%, 1.2%). Wall-clock as printed (units ambiguous): Boston SMC 0:36:59 vs AMCMC 4:50:52 vs MCMC 0:38:06. Text claims (p.25): SMC "did not produce a single major outlier in any of the components" over 200 runs and both (sic) data sets; both Markov chain methods produce outliers; "an adaptive local method is still a local method". Reading the figures: in Fig. 7 (Protein, unrestricted) the three methods look essentially the same, and in Fig. 8 (Protein restricted) AMCMC is visibly worse while standard MCMC looks close to SMC, and p.22 concedes "simple Markov chain methods are faster than our algorithm while producing results of the same accuracy if the components of the target distribution are nearly independent". In Fig. 6 (Concrete restricted) SMC itself shows non-trivial spread for several components (reading of the plot).

## 4. What they prove
- NO THEORY. The paper contains no theorem, proposition, lemma, corollary or proof (grep of the whole v4 text for theorem/proposition/lemma/proof/prove/asymptotic/consisten/central limit/unbiased finds nothing apart from "ergodic theorems" (p.5), "Peskun's theorem" (reference title) and the Rao-Blackwell remark). The reference list (p.32-34) contains Del Moral-Doucet-Jasra (2006) and Chopin (2002) only: no Del Moral (2004) book, no Chopin (2004) CLT, no Douc-Moulines, no Whiteley, no Schweizer, no Jasra-Doucet 2008 theory; no consistency literature for Bayesian variable selection (no Yang-Wainwright-Jordan, no Castillo-van der Vaart, no Narisetty-He).
- Informal / qualitative claims, with pages:
  1. p.2 (1.2): "growing evidence that global methods, which track a population of particles, initially well spread ..., are often more robust than local methods ... prone to get trapped in the neighbourhood of local modes"; no citation to theory, only to their simulations in Sec 6.
  2. p.5 (3.1): the Markov chain "admits pi as unique stationary distribution" and its distribution "converges to pi"; ergodic averages valid "if ... the ergodic theorems apply" (standard textbook, Robert-Casella). Warning that local kernels "often fail to sample ergodic trajectories within a reasonable amount of time if pi is very multi-modal" (no quantification).
  3. p.7 (3.4): independent MH with q such that pi << q has unique invariant measure pi (support condition only; no rate, no Doeblin constant).
  4. p.8 (4.1): "Theoretically, we can use any pi_0 with pi << pi_0" (support condition).
  5. p.9-10: larger alpha makes weights more uneven; ESS is a continuous function of alpha so bisection solves eta(alpha)=eta*; "the number of steps tau depends on the complexity of the integration problem at hand and is not known in advance" (no bound on tau).
  6. p.11: particles after repeated independent-MH moves "are almost independent after sufficiently many move steps" (heuristic); Rao-Blackwellisation effect "analysis is beyond the scope".
  7. p.17-19: product family fits badly and gives falling acceptance rates, logistic family keeps acceptance above 20% (empirical, one data set).
  8. p.24: speed-ups / parallelism and evidence estimation are advantages of SMC (qualitative).
- None of the above is a Monte Carlo convergence statement (type i), a complexity or mixing bound (ii), a posterior or selection consistency result (iii), or a guarantee about a reported model (iv). The consistency of the SMC estimate in n (number of particles) is implicitly delegated to Del Moral et al. (2006) with no statement. Notably, the adaptive ESS rule and the adaptive refitting of q_theta make the algorithm outside the standard fixed-schedule CLTs, and the paper does not discuss this.

Theory against our Theorems 1-6 and planned P1-P5:
- Thm 1-2 (posterior concentration / Hellinger contraction), Thm 3 (reported model = S0), Thm 4 (certified screening), Thm 6 (sharpness): no overlap; the paper has no statistical-consistency statement of any kind and no reported-model object.
- Prop 5 (unbiased evidence given frozen calibration): no overlap and no contradiction; the paper neither estimates the evidence nor states unbiasedness. Their fully adaptive design (schedule and proposal recomputed from the same particles) is exactly the situation where our frozen-grid conditioning matters, so it supports the design choice but implies nothing.
- P1 (trap theorem for single-flip chains and weighted tempered Gibbs): no theorem in the paper, but Sec 6 (p.25-29) and Figs 3-6 are an empirical precedent that single-component metropolised Gibbs and Nott-Kohn adaptive Gibbs are trapped on multimodal variable-selection posteriors where SMC is not (Boston, Concrete; and not Protein, p.30-31). Citable as motivation, not as a result. The Zanella-Roberts weighted sampler did not exist yet (2011).
- P2-P5: no overlap (their d <= 104; no raw-scale list mass; no misspecified fixed-p projection result).
- Contradiction? One design-level tension, not a theorem: they report that SMC with local kernels "is practically impossible" (p.11) and that a pilot-adapted pi_0 gives "faster but less robust algorithms" (p.8); our method uses local moves inside SMC and a data-adapted block-product start. This is a different regime (their model sizes tiny, uniform start), so no logical conflict, but a referee may quote these lines.

## 6. Verdict
- Novelty risk to us: THEORY: NONE. ALGORITHM: PARTIAL OVERLAP (low-to-moderate) at the level of the generic idea "tempered/adaptive SMC (geometric bridge, ESS-adaptive step, resample-move) on binary model space for Bayesian linear-regression variable selection"; this paper is the earliest SMC-for-variable-selection precedent in our set and a referee will expect it to be cited. It does not overlap on the start law, the move set, islands, RB/list PIPs, evidence/unbiasedness, reported model + certification, scale (p up to 10^6), or any theory.
- Must cite: Schäfer and Chopin (2013) as the SMC-on-model-space precedent (geometric bridge from the uniform law, ESS-adaptive temperatures, independence MH with a logistic-conditional proposal), and as empirical support that local single-flip MCMC fails on multimodal variable-selection posteriors (motivation for P1).
- One-sentence differentiation: "Schäfer and Chopin (2013) introduced tempered SMC over binary model vectors with a uniform start and learned logistic-conditional independence proposals and report only empirical comparisons at d <= 104 with no theory; we instead start from a block-exact law, use local Gibbs/swap moves on independent islands, and prove posterior concentration, correctness of the reported model, certified screening and unbiased evidence estimation in the p >> n regime."
