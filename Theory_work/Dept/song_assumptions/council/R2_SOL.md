1. **BLOCKER. State the mixed-rival rate bound using the coded likelihood.** Paths §3.3 steps 1–3 and Linearisation, Definitions §4.2. The displayed bound for the log of the class odds uses B_Dm, which includes +γ log n, without subtracting γ log n. It also substitutes a quadratic for the full log likelihood over an unrestricted residual range. The latter is not an upper bound on the odds for residuals of order n. Define W = (min_S √λ̂_S − w_Dm − t_n)_+² on the Gaussian-concentration event and H_Dm = Pr_n(d) − (m/2) log(n/(C log p)) = B_Dm − γ log n. Then a bound for the log of the summed odds is
   `H_Dm + O_P(1) − (n/2+a₀) log(1+W/V_n)`,
   with V_n = RSS_T/σ² + 2b₀s_y²/σ² = n(1+o_P(1)), using Q_S ≥ RSS_S, the uniform ridge bound on U, and RSS_U ≤ RSS_T. Derive it termwise against U and then sum the containing-model odds. The uniform lower RSS_U bound needed for the tight remainder follows on the superset truncation event. For B_Dm ≤ 0, use W = 0. For B_Dm > 0, use monotonicity at W = 2(1+δ)B_Dm = O(log n) to obtain a penalty at least B_Dm with probability tending to one. This also handles m = 0 and avoids linearizing at the actual residual. State that U ranges through size s0+J (inside the sparse window for large n, with the number of available predictors imposing a further cap). Identify C as a fixed choice for the bound with a tight multiplier. The truncation scale alone does not select a unique C.
